R8 覆盖率位打包定义 + EncodeThinGeometry / IsThinGeometry

0. R8 覆盖率的位布局与打包（核心）

// Coverage 纹理 (PF_R8 UNORM) 位布局：
//  ON : [0]高对比线 [1]半透明 [2:7]覆盖率(6bit)
//  OFF: [0]高对比线 [1:7]覆盖率(7bit)
#if CONFIG_TRANSLUCENCY_COVERAGE_BIT && CONFIG_INTENSITY_LINE_DETECTION
    kCoverageMaxValue = 63.0; kCoverageShift = 0x2; kTranslucencyBit = 0x2;
static const tsr_ushort kHighContrastLineBit = tsr_ushort(0x1);
tsr_tensor_bool IsThinGeometry(tsr_tensor_half CurrentCoverage) { return CurrentCoverage == 1.0; }

说明

薄几何的所有信号要塞进一张 R8（8bit）纹理省带宽，本库定义其位布局：最低位恒为高对比线标记，中间视 permutation（CONFIG_INTENSITY_LINE_DETECTION/CONFIG_TRANSLUCENCY_COVERAGE_BIT）插入半透明位，剩余位存覆盖率（6/7 bit）。kCoverageShift/kCoverageMaxValue 随之调整。EncodeThinGeometry/DecodeThinGeometry 按此打包解包，IsThinGeometry（覆盖率==1）判纯薄几何。#7/WeightRelaxation/MeasureCoverage 共享这套编码——是薄几何链数据格式的单一事实源。
