0. 一个 CS，多种诊断视图（发散点）

BRANCH by VisualizeId → 各 Display* 函数
复用生产追踪的中间缓冲，只做染色

说明

Visualize 不参与画面生产，纯读 TSR 各 pass 留下的中间缓冲（累积样本数、拒绝掩码、重投影、复活区域），按 r.TSR.Visualize 选一种映射成伪彩叠屏。与各生产 pass 共享同一套 ApplyScreenTransform / 镜头畸变处理，保证可视化像素与生产像素一一对应。

1. 排障用法（汇聚点）

SampleCount 偏低 → 该区历史不稳（噪/闪）
Rejection 偏高 → 拒绝过度（糊/丢细节）

说明

实战：画面有鬼影看 DisplayHistoryRejection（该拒没拒）与 DisplayParallaxDisocclusionMask（遮挡判定对不对）；画面糊/丢细节看拒绝是否过度、HistorySampleCount 是否被反复清零；细线闪烁结合 #7 薄几何。TSR 通过 ITemporalUpscaler 接口与 DLSS/FSR/XeSS 互斥切换（见 #8 正文）。
