TSRDetectThinGeometry.usf 整源解析

TSR 的薄几何检测（UE5.4+ 新增）：识别电线/栏杆/头发这类亚像素细结构——它们太细，普通拒绝会当噪声拒掉导致闪烁/消失。本 pass 用覆盖率 + 强度线检测算出松弛因子，让 #4 对这些区域放宽拒绝。核心 DetectThinGeometryCS（tensor 抽象）。下方内嵌完整 569 行真实源码，再逐段真实代码批注。

0. 取覆盖率 + 常规通道判定（发散点）

tsr_tensor_short2 PixelPos = ComputePixelPos();
FetchCommonInput(PixelPos, CurrentCoverage, bHasPixelAnimation, MaterialMask);
bool bRegularPass = AnyThread(AnyComponent(and(CurrentCoverage > tsr_tensor_half::Const(0.0), not(bHasPixelAnimation))));
tsr_tensor_half ThinGeometryEdge = tsr_tensor_half::Const(0.0);
tsr_tensor_half HistoryRelaxationWeight = tsr_tensor_half::Const(0);
tsr_tensor_half NewSampleWeight = tsr_tensor_half::Const(0.1);

说明

FetchCommonInput 取当前覆盖率（coverage——一个像素被多细的几何覆盖）、像素动画标记、材质掩码。bRegularPass 用 AnyThread（波前内任一 lane 满足即真）判断该 tile 是否需要走完整薄几何检测——有覆盖且非动画的区域才做，动画像素跳过（动画物体不适用静态细线假设）。tsr_tensor_* 让整组像素在波前内并行分析（同 RejectShading）。NewSampleWeight=0.1 是薄几何区新样本的基准权重。

本 pass 的汇聚点：FetchRegularPassInput 取邻域覆盖率/深度，检测"细到覆盖率随位置剧变"的薄几何边缘与簇洞（cluster hole——细网格间的空隙）。CONFIG_INTENSITY_LINE_DETECTION 额外检测高强度细线（发光电线、高光边）——这类在亚像素抖动下最易闪烁，用 FlickeringLuma 跟踪。CONFIG_VARYING_RANGE_DETECTION 按材质掩码用不同检测范围。产出 ThinGeometryRelaxationFactor 交 #4：在这些区域放宽拒绝，保住细节不被误判失效。见 ThinGeometryCommon.ush。
