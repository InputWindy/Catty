TSRSpatialAntiAliasing.ush 整源解析库 / 空间 AA 采样

TSR 空间抗锯齿的采样函数库（600 行）：提供带视口 clamp 的点/双线性亮度采样（双像素向量化），供 SpatialAntiAliasing.usf 做边缘导向重采样。下方内嵌完整 600 行真实源码，再逐段真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/TemporalSuperResolution/TSRSpatialAntiAliasing.ush

SampleAAInput / BilinearSampleAAInput（DPV 采样）

0. 带 clamp 的双像素亮度采样（核心）

tsr_half2 SampleAAInput(Texture2D<tsr_half> Texture, tsr_short2x2 KernelCenter, tsr_short2x2 Offset) {
    tsr_short2x2 SampleInputPixelPos = ClampPixelOffset(KernelCenter + Offset, InputPixelPosMin, InputPixelPosMax);
    return dpv_interleave_registers(Texture[dpv_lo(SampleInputPixelPos)], Texture[dpv_hi(SampleInputPixelPos)]); }
// BilinearSampleAAInput：按方向 clamp UV 到 ViewportBilinearMin/Max 再双线性采

说明

空间 AA 要沿边缘方向反复采样亮度，本库把采样封装好：SampleAAInput 用整数偏移 + ClampPixelOffset 防越界，一次取 2 个像素（dpv_lo/dpv_hi + dpv_interleave_registers 交织成双像素寄存器）；BilinearSampleAAInput 做亚像素双线性采样，按搜索方向把 UV clamp 到 ViewportBilinearMin/Max（负向 max、正向 min）避免采到视口外。SPATIAL_ANTI_ALIASER_MIN_LUMIMANCE=0.05 是边缘检测的亮度阈值。这些是 SpatialAntiAliasing.usf 边缘导向重采样的采样原语。
