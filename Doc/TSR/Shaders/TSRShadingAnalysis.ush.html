ComposeTranslucency + SMCS 着色差异度量 + total variation

0. 合成分离半透明（核心）

tsr_tensor_halfC ComposeTranslucency(tsr_tensor_halfC Color, tsr_tensor_half4 Translucency, ...) {
    ComposedColor = Color * tsr_tensor_halfC::Vectorize(Translucency[3]) + ResizeChannels<CONFIG_CHANNEL_COUNT>(Translucency);
    #if CONFIG_SCENE_COLOR_ALPHA  ComposedColor.SetComponent(3, select(bPassthroughAlpha, Color[3], Color[3]*Translucency[3]));
    ComposedColor = min(ComposedColor, tsr_tensor_halfC::Const(LargestSceneColorRGB));   // 防溢出
    return ComposedColor; }

说明

TSR 对分离渲染的半透明（separate translucency）要在拒绝分析前先合成回不透明色上——ComposeTranslucency 按 Color * Translucency.a + Translucency.rgb（预乘 over 合成）在线性色空间叠加，并 clamp 到 LargestSceneColorRGB 防 fp16 溢出。本库随后把合成色转 SMCS（见 ColorSpace）用 张量卷积做邻域着色差异度量、算 total variation（TotalVariationCountInvThreshold 控何时介入）——这些就是 #4 RejectShading 判"历史该不该拒"的实际数学。FlickeringFramePeriod 关联抗闪。
