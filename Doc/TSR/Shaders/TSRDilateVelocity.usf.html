0. 速度膨胀：3×3 取最近遮挡物速度（发散点）

FetchDepth3x3(SceneDepthTexture, InputPixelPos, /* out */ DevizeZNeighborhood);
FindClosestDepthOffset(DevizeZNeighborhood, /* out */ ClosestDeviceZ, /* out */ ReprojectionOffset);
bHasReprojectionOffset = any(ReprojectionOffset != tsr_short(0));
float ParallaxDepthError = ComputeDepthError(DevizeZNeighborhood);
FetchAndComputeScreenVelocity(SceneVelocityTexture, InputPixelPos, DeviceZ, ReprojectionOffset, ...);

说明

直接用本像素速度重投影历史，会在运动物体边缘拖影——边缘像素的速度可能属于背景。FindClosestDepthOffset 在 3×3 邻域找离相机最近的遮挡物及其偏移（ReprojectionOffset），用它的速度作本像素的"膨胀速度"，让边缘跟随前景运动、消除拖尾——这是所有高质量 TAA/TSR 的标准手法。ComputeDepthError 估视差深度误差（供 #3 判 disocclusion）。

1. 重投影场：高画质的更优对齐（汇聚点）

BRANCH if (bReprojectionField) {
    FetchDepthVelocity3x3(SceneDepthTexture, SceneVelocityTexture, InputPixelPos, DevizeZNeighborhood, VelocityNeighborhood);
    ComputePixelVelocityNeighborhood(InputPixelPos, DevizeZNeighborhood, VelocityNeighborhood, PixelVelocityNeighborhood, ...);
    ReprojectionEdge = ComputeReprojectionEdge(ScreenVelocity, DilatedScreenVelocity.xy);
    tsr_half2 ReprojectionBoundary = ComputeReprojectionBoundary(InputPixelPos, ReprojectionOffset, ScreenVelocity, DilatedScreenVelocity.xy, DevizeZNeighborhood);
    EncodedReprojectionBoundary = EncodeReprojectionBoundary(ReprojectionOffset, ReprojectionBoundary);
}

说明

高画质档（r.TSR.ReprojectionField，high/epic/cinematic 默认开）不只算单个速度向量，而是拟合一个带 Jacobian（局部形变）的重投影向量场——把速度先转成像素速度降寄存器压力，用深度空间抗锯齿器（ComputeReprojectionBoundary）算出亚像素级重投影边界并编码进纹理。这样在旋转/缩放运动下能把历史更精确地对齐到抖动网格。膨胀速度 + 编码信息交给 #3 DecimateHistory，细节见 ReprojectionField.ush。
