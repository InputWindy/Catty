ComputeStaticVelocity / ComputePixelDeviceZError / EncodeDeviceZError

0. 静态速度 + 逐像素深度误差（核心）

float3 ComputeStaticVelocity(float2 ScreenPos, float DeviceZ) {
    float4 ThisClip = float4(ScreenPos, DeviceZ, 1);
    float4 PrevClip = mul(ThisClip, View.ClipToPrevClip);   // 用相机矩阵反投影到上帧
    return float3(ScreenPos, DeviceZ) - PrevClip.xyz / PrevClip.w; }
float ComputePixelDeviceZError(float DeviceZ) {   // 一个像素在该深度下的世界尺寸→ DeviceZ 误差容差
    float ErrCorrDeviceZ = ConvertToDeviceZ(GetDepthPixelRadiusForProjectionType(Depth)*2 + Depth); ... }

说明

两个基础量：ComputeStaticVelocity 只用相机矩阵（ClipToPrevClip）算出"仅因相机运动"的重投影位移——静态物体没有物体速度时用它。ComputePixelDeviceZError 算一个像素在该深度下覆盖的世界尺寸对应的 DeviceZ 误差——这个容差是 #3 判 disocclusion 的关键：历史深度与当前深度差异只有超过这个"一像素厚度"才算真被遮挡/露出，否则是正常的亚像素抖动。EncodeDeviceZError 相对最近深度归一化压进 8bit。CONFIG_DEPTH_EDGE_DETECTION 让膨胀只在深度边缘做，提平坦面的重投影精度。
