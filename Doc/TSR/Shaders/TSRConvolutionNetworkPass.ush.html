按 DIM_WAVE_SIZE 派生 WAVE_COUNT/LANE_COUNT/LANE_STRIDE

0. 按 wave 大小选布局（核心）

#if DIM_WAVE_SIZE == 0 || DEBUG_DIGESTABLE   // 纯 LDS 回退：一 lane 一像素
    #define GROUP_TILE_SIZE 32; LANE_COUNT_X 1; LANE_COUNT_Y 1;
#elif DIM_WAVE_SIZE == 64 || 32 || 16   // 行主序：整行像素落入单个 wave
    #if DIM_WAVE_SIZE == 16  LANE_STRIDE_X 2; LANE_STRIDE_Y 1;   // Intel Arc 降寄存器
    #else LANE_STRIDE_X 1; #if CONFIG_COMPILE_FP16 LANE_STRIDE_Y 4 #else 2
#define WAVE_COUNT_Y (GROUP_TILE_SIZE / LANE_STRIDE_Y)

说明

同一套 卷积框架要在不同 GPU 上跑到最优——本头按编译期 DIM_WAVE_SIZE 挑布局：无波前平台退化为纯 LDS（一 lane 一像素）；有波前时用行主序 32×32让整行像素落进一个 wave（横向 waveop、纵向 LDS）。每 lane 承载的 SIMD 像素数 LANE_STRIDE_Y 随 fp16（4）/fp32（2）调，Intel Arc（wave16）特化为 LANE_STRIDE_X=2 降寄存器压力——这是 TSR "一份卷积代码、多平台高性能"的 permutation 配置层。
