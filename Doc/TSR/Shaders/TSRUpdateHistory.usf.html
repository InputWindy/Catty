TSRUpdateHistory.usf 汇聚/发散批注版

TSR 计算量最大的 pass：拿 #4 的拒绝权重，把当前帧输入按加权指数移动平均（EMA）累积进历史——先把历史 clamp 进输入颜色盒，再按 HDR 权重与运动钳制软混合，输出更新后的高分辨率历史（含累积样本数 validity）。核心 UpdateHistoryCS（8×8 tile，支持 dual-pixel 向量化）。说明：完整文件 1262 行，下方内嵌核心入口与累积公式的真实源码。

一眼看懂：一条解题弧线

拒绝权重 + 当帧输入#4 输出 + 重采样输入
▶
历史 clamp进输入颜色盒，抑鬼影
▶
EMA 加权混合运动钳制 + full-float 权重
▶
更新后历史颜色 + validity(8bit)

核心源码对照 （1262 行文件的核心节选，逐行真实）

Engine/Shaders/Private/TemporalSuperResolution/TSRUpdateHistory.usf · UpdateHistoryCS L636 / 累积核 L1254

0. 历史 clamp：抗鬼影的第一道闸（发散点）

ClampedPrev = fastClamp(Prev, InputMinColor, InputMaxColor)
DisableHistoryClamp 时退化为不 clamp（软混合）

说明

把重投影来的历史颜色钳进当前帧邻域颜色盒——这是时序算法最经典的抗鬼影手段。但 TSR 不做硬 clamp，而是用 WeightedLerpFactors 在"clamp 后"与"原历史"间按 HDR 权重软混合，避免硬 clamp 在高光/边缘处闪烁。真正判断历史"能不能信"的连续权重来自 #4 RejectShading。

1. EMA 加权混合：稳定性与清晰度的平衡（汇聚点）

CommonWeight = SafeRcp(BlendPrevHistory + BlendFilteredInput)
FinalColor = BlendedPrev*w_prev + FilteredInput*w_cur

说明

本 shader 的汇聚点：历史与当前输入按各自 HDR 权重做指数移动平均。不同点混合权重的分子分母（BlendPrevHistory / BlendFilteredInput / CommonWeight）源码显式声明为 float，而整个 pass 为省带宽跑 fp16——因为历史与输入亮度差极大时 fp16 权重会量化失真。运动钳制（MaxValidity）让快速运动像素压低历史占比减少拖影。

最终总结

骨架

Catmull-Rom 重采样输入 → 历史 clamp 进颜色盒 → 按 HDR 权重 + 运动钳制做 EMA 混合（权重用 full float）→ 输出更新历史 + 8bit validity。把"每帧一点新样本"稳稳累积成高分辨率成片。
