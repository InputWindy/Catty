TSRConvolutionNetwork.ush 整源解析库 / 张量卷积框架

TSR 的张量卷积框架（997 行，最复杂的库）：把一组像素打包成"张量"（tsr_tensor_*），用 lane 向量化在波前内做卷积/规约——非 AI，是手写 SIMD 卷积基础设施。RejectShading/DetectThinGeometry/WeightRelaxation 全建于其上。下方内嵌完整 997 行真实源码，再逐段真实代码批注。

lane/wave 内存序 + tsr_tensor 卷积/规约（基于 LaneVectorization.ush）

0. lane 内像素坐标映射（核心）

TVECTOR_FUNCTION_1PARAMS(ScalarType, SafeRcp)   // 为 LaneVectorization 扩展 TSR 专用函数
#define WAVE_COUNT (WAVE_COUNT_X * WAVE_COUNT_Y)
#define LANE_COUNT (LANE_COUNT_X * LANE_COUNT_Y)
template<uint LaneStrideX, uint LaneStrideY>
tsr_short2 GetSimdIndexPixelCoordinateInLane(const uint SimdIndex) {
    return tsr_short2(SimdIndex % LaneStrideX, SimdIndex / LaneStrideX); }

说明

这套框架把 波前的 lane 排布映射成 2D 像素网格（LANE_COUNT_X×Y lane + 每 lane 承载 LaneStride 个 SIMD 像素），让"一个像素的邻域卷积"变成跨 lane 的 wave 操作 + lane 内 SIMD——既省 LDS 又省寄存器。建在引擎 LaneVectorization.ush 之上，tsr_tensor_half/bool/short2 等就是这套框架的"张量"类型。拒绝/薄几何的邻域分析全靠它并行——这是 TSR 能在移动/主机上跑复杂启发式的性能关键。注意"卷积网络"是手写 SIMD 卷积，非神经网络。
