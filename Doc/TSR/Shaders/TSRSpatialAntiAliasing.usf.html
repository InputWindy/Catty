完整源码（逐行真实） · Engine/Shaders/Private/TemporalSuperResolution/TSRSpatialAntiAliasing.usf

SpatialAntiAliasingCS @ L84（TILE_SIZE²/2 线程，DPV）

0. 掩码判定 + 无需 AA 快退（发散点）

tsr_short2x2 InputPixelPos = dpv_add(InputPixelPosMin + GroupId*TILE_SIZE, Map8x8Tile2x2LaneDPV(GroupThreadIndex));
bAntiAlias[0] = AntiAliasMaskTexture[dpv_lo(InputPixelPos)] > tsr_ushort(0);
bAntiAlias[1] = AntiAliasMaskTexture[dpv_hi(InputPixelPos)] > tsr_ushort(0);
bool bSkipAntiAliaser = all(!bAntiAlias);
BRANCH if (bSkipAntiAliaser) { TexelOffset = 0; NoiseFiltering = 0; }

说明

只有 Resolve/#4 标记为"历史不可信"的像素（AntiAliasMaskTexture > 0）才需要单帧空间 AA。bSkipAntiAliaser 让绝大多数有历史可用的像素直接快退（TexelOffset=0），只在少量新露出区花算力——这是 TSR 相对纯空间 AA 的效率优势。双像素向量化（dpv_lo/dpv_hi）一 lane 处理 2 像素。

1. 3×3 亮度邻域找边缘方向（汇聚点）

InputCache[ci] = SampleInputLDRLuma(dpv_lo(InputPixelPos), tsr_short2(cx-1, cy-1));   // 缓存 3×4 亮度
tsr_half2 InputC = ReadCache(0, 0);
tsr_half2 InputN = ReadCache(0,-1); InputS = ReadCache(0,+1); InputE = ReadCache(+1,0); InputW = ReadCache(-1,0);
tsr_half2 InputNE = ReadCache(+1,-1); InputNW = ReadCache(-1,-1); InputSE = ReadCache(+1,+1); InputSW = ReadCache(-1,+1);
tsr_short2x2 BrowseDirection;   // 沿边缘方向搜索并算亚像素 TexelOffset

说明

本 pass 的汇聚点：把 3×3（缓存成 3×4）亮度邻域载入寄存器（SampleInputLDRLuma 取 LDR 亮度），由中心与 8 邻居的亮度梯度判断边缘方向（BrowseDirection），沿边缘搜索算出亚像素级 TexelOffset 做边缘导向重采样——原理同 FXAA/SMAA 的边缘检测+混合，但集成进 TSR 只对失效区施加。质量档由 r.TSR.RejectionAntiAliasingQuality 控。
