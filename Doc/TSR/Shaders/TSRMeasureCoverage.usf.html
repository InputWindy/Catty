0. 从 GBuffer 读薄几何标记（核心）

uint2 OutputPixelOrigin = (InputInfo_ViewportMin + GroupId * uint(TILE_SIZE * TILE_ROWS)) + GroupThreadId;
uint ThinGeometryArray[TILE_ROWS * TILE_ROWS];
UNROLL_N(TILE_ROWS) for (uint y ...) UNROLL_N(TILE_ROWS) for (uint x ...) {
    uint2 InputPixelPos = OutputPixelOrigin + uint2(x, y) * TILE_SIZE;
    ThinGeometryArray[x + y * TILE_ROWS] = GetThinGeometry(GetGBufferDataUint(InputPixelPos));
}

说明

薄几何检测需要知道每像素是否被"薄"几何覆盖。本 pass 从 GBuffer（GetGBufferDataUint）取出材质写入的薄几何位（GetThinGeometry——材质可标记自身为细线/头发等），分块（TILE_ROWS×TILE_ROWS）读入并输出覆盖率纹理。这是 #7 DetectThinGeometry 的输入前置——把"哪些像素属于薄几何"的原始信号从 GBuffer 提取出来供后续张量分析。
