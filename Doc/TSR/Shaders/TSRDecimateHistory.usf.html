TSRDecimateHistory.usf 整源解析

TSR 的历史重投影 pass：拿 #2 膨胀出的重投影矢量，把上一帧的全部历史纹理（引导色/不确定度/摩尔纹/覆盖率/复活历史）用运动矢量重投影对齐到当前帧，并算出重投影边界（reprojection edge）与离屏标记，供 #4 拒绝使用。核心 DecimateHistoryCS（8×8 tile）。下方内嵌完整 478 行真实源码，再逐段真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/TemporalSuperResolution/TSRDecimateHistory.usf

DecimateHistoryCS @ L256（TILE_SIZE*TILE_SIZE 线程）

0. 采样当前帧信息 + 重投影边界（发散点）

tsr_ushort2 InputPixelPos = Map8x8Tile2x2Lane(GroupThreadIndex) + (InputInfo_ViewportMin + GroupId * TILE_SIZE);
uint EncodedDilateMask = DilateMaskTexture[InputPixelPos];
uint EncodedDeviceZError = DepthErrorTexture[InputPixelPos];
bHasReprojectionOffset = (EncodedDilateMask & 0x80u) != 0u;
PremilinaryReprojectionEdge = tsr_half(tsr_ushort(EncodedDilateMask & 0x7Fu)) * rcp(tsr_half(127.0));
PrevDeviceZ = abs(DeviceZAndPrevDeviceZ.r); bHasPixelAnimation = DeviceZAndPrevDeviceZ.r < 0.0;
FetchReprojectionNeighborhood(DilatedReprojectionVectorTexture, InputPixelPos, EncodedReprojectionVectorNeighborhood);

说明

用 Map8x8Tile2x2Lane 把线程映射到 2×2 lane 分块（改善波前内相邻像素的一致性）。从 #2 DilateVelocity 输出的纹理里解码：DilateMask 的最高位是"有重投影偏移"标记、低 7 位是预估重投影边界（归一化到 0..1）；ClosestDepth 的符号位复用为"像素动画"标记（<0）——TSR 大量用位打包省带宽。DeviceZError 解码出深度误差用于后续遮挡判定。

1. 用运动矢量重投影上帧全部历史（汇聚点）

FCatmullRomFetches<tsr_half4> ReprojectedHistoryGuideSamples;
ReprojectAllPrevTextures(
    GroupId, GroupThreadIndex,
    DilatedEncodedReprojectionVector, DeviceZ,
    /* out */ HistoryClosestDeviceZSamples0, HistoryClosestDeviceZSamples1,
    /* out */ ReprojectedHistoryGuideSamples,        // Catmull-Rom 重采样
    /* out */ ReprojectedHistoryMoireColor, ResurrectedHistoryGuideColor, bIsOffScreen, ...);

说明

本 pass 的汇聚点：ReprojectAllPrevTextures 用膨胀后的重投影矢量一次性把上帧所有历史纹理重采样到当前像素——引导色用 Catmull-Rom（FCatmullRomFetches，比双线性锐利、抗糊）、还包括摩尔纹历史、薄几何覆盖率、以及"复活历史"（resurrection——比上帧更早的一份历史，用于修复被错误拒绝的区域）。bIsOffScreen 标记重投影落到屏幕外。产物交给 #4 RejectShading 判断历史是否可信。
