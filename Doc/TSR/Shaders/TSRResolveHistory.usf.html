0. 加载历史 + HDR 加权 + 邻域 clamp（发散点）

for (uint SimdIndex = 0; SimdIndex < INPUT_SIMD_SIZE; SimdIndex++) {
    tsr_short2 PixelPos = GroupPixelOffset + GetLaneSimdPixelOffset<...>(LaneIndex, SimdIndex);
    Colors.SetElement(SimdIndex, UpdateHistoryOutputTexture[PixelPos]);
}
#if CONFIG_HDR_WEIGHT
    LDRColors.SetElement(SimdIndex, Colors.GetElement(SimdIndex) * HdrWeight4(Colors.GetElement(SimdIndex)));
#if CONFIG_CLAMP  Min = DownsampleMin2x2(Colors); Max = DownsampleMax2x2(Colors); ...

说明

每个 lane 用 GetLaneSimdPixelOffset 取一小组（SIMD）历史像素批量处理。HDR 加权（HdrWeight4）是关键：直接对 HDR 颜色做重采样，一个超亮高光像素会在下采样时渗漏（firefly/糊边）；先按亮度加权到近似 LDR 域再滤波、最后 HdrWeightInvY 还原，能保住高光边缘锐利。CONFIG_CLAMP 时用 DownsampleMin/Max2x2 + 波前邻居扩展算局部颜色包围盒，最后把输出 clamp 进去防溢出。

1. Mitchell-Netravali 2×2 下采样（汇聚点）

const float WeightA = MitchellNetravali(0.5, MitchellNetravaliB, MitchellNetravaliC);
const float WeightB = MitchellNetravali(1.5, MitchellNetravaliB, MitchellNetravaliC);
const tsr_half Weights0[4] = { FinalWeightC, FinalWeightB, FinalWeightB, FinalWeightA };
tsr_output_halfC Out0 = DownsampleDot2x2(LDRColors, Weights0);   // 4 组权重各点积
Output = Out0 + WaveAccessNeighborTexel(Out1,(1,0)) + WaveAccessNeighborTexel(Out2,(0,1)) + WaveAccessNeighborTexel(Out3,(1,1));
#if CONFIG_HDR_WEIGHT Output *= HdrWeightInvY(Luma4(Output)); #if CONFIG_CLAMP Output = clamp(Output, Min, Max);

说明

本 pass 的汇聚点：用 Mitchell-Netravali 重建核（B/C 可调，UE 默认接近 Catmull-Rom，锐利且少振铃）对 2×2 邻域做加权下采样，把内部高分辨率历史（可能是输出的 1×/2× 采样）解析成最终屏幕图。四组权重矩阵 Weights0..3 对应 2×2 输出格子的四种相位，DownsampleDot2x2 各算点积后用 WaveAccessNeighborTexel 跨 lane 收集邻居贡献相加——这是 TSR 上采样锐度的最后一环。输出交给后处理（Bloom/Tonemap）。
