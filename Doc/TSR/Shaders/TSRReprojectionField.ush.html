0. 偏移 + 边界的位打包编解码（核心）

uint EncodeReprojectionOffset(tsr_short2 Off) { return dot(tsr_ushort2(Off + 1), tsr_ushort2(1, 4)); }
tsr_short2 BoundaryBits = tsr_short2(round(ReprojectionBoundary * 1023)) + 1024;
BoundaryBits = fastClamp(BoundaryBits, 1, 2047);
uint Encoded = EncodedOffset | (uint(BoundaryBits.x) << 4) | (uint(BoundaryBits.y) << 15);   // 4+11+11=26bit
bool HasEncodedReprojectionOffset(uint E) { return (E & 0xF) != 5; }   // 5 = 偏移(0,0) 的编码

说明

高画质重投影场（#2 的 bReprojectionField）产出两类信息要塞进纹理：膨胀偏移（3×3 里选了哪个最近遮挡物，[-1,1]² 用 dot(Off+1, (1,4)) 编成 4bit）和亚像素重投影边界（xy 各量化到 11bit，偏移 +1024 使范围居中，clamp 到 [1,2047]）。合计 26bit 一个 uint。HasEncodedReprojectionOffset 判定用了个小技巧：偏移 (0,0) 编码为 5，故 !=5 即"有偏移"。#3 解码后用于精确对齐历史——这套紧凑编码是省带宽的典型。
