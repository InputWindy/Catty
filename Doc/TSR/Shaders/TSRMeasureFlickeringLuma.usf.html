MeasureFlickeringLumaCS @ L21（TILE_SIZE² 线程，TILE_ROWS 展开）

0. 分块读场景色 → 亮度（核心）

uint2 OutputPixelOrigin = (InputInfo_ViewportMin + GroupId * uint(TILE_SIZE * TILE_ROWS)) + GroupThreadId;
tsr_half3 ColorArray[TILE_ROWS * TILE_ROWS];
UNROLL_N(TILE_ROWS) for (uint y ...) UNROLL_N(TILE_ROWS) for (uint x ...) {
    uint2 InputPixelPos = OutputPixelOrigin + uint2(x, y) * TILE_SIZE;
    ColorArray[x + y * TILE_ROWS] = SceneColorTexture[InputPixelPos];   // 后续算亮度写闪烁纹理
}

说明

闪烁（flickering/摩尔纹）本质是亮度在时间上周期性抖动。本 pass 分块（TILE_ROWS×TILE_ROWS 展开摊薄开销）读取场景色 SceneColorTexture，计算并输出闪烁亮度信号——这是 #4 RejectShading 里 FetchMoireInput/ComputeMoireError 的输入前置。有了逐帧亮度，#4 才能沿时间轴分析出哪些像素在闪并放宽其拒绝、避免细密纹理忽明忽暗。
