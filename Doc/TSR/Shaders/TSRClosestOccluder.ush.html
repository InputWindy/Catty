空洞填充速度的极坐标编码/解码

0. 极坐标量化编码空洞速度（核心）

#define VELOCITY_HOLE_FILLING_BITS 18   // 角度5bit + 长度13bit
void PolarCoordinateHoleFillingVelocity(float2 PixelVelocity, out float Angle, out float Length) {
    Angle = atan2Fast(PixelVelocity.y, PixelVelocity.x); Length = length(PixelVelocity); }
EncodedAngle = Angle * (0.5 * AngleBitDepth / PI) + (0.5 * AngleBitDepth);
EncodedLength = Length * VELOCITY_HOLE_FILLING_LENGTH_PRECISION;

说明

并非每个像素都有速度写入——天空、某些半透明或未输出速度的物体留下"速度空洞"。#2 DilateVelocity 需要把邻近有效速度散射填充进这些空洞。本库用极坐标（角度 + 长度）而非笛卡尔编码速度：角度 5bit（atan2Fast + 按 2π 量化）、长度 13bit（定点精度 2⁵），共 18bit——极坐标对"方向一致、幅度渐变"的散射填充更友好，插值角度不会像笛卡尔那样在反向时突变。CONFIG_SUPPORT_ORTHO_VIEW 兼容正交相机。
