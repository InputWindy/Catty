0. 摩尔纹（闪烁）检测（发散点）

if (bEnableFlickeringHeuristic) PLATFORM_SPECIFIC_ISOLATE {
    tsr_tensor_short2 PixelPos = ComputePixelPos();
    FetchDecimateMask(PixelPos, VelocityEdge, bIsDisoccluded, bHasPixelAnimation, bIsResurrectionOffScreen);
    FetchSceneColorAndTranslucency(PixelPos, OriginalOpaqueInput, OriginalTranslucencyInput);
    FetchMoireInput(PixelPos, MoireInput, PrevMoireHistory, bIsStatic);
    ComputeMoireError(bIsDisoccluded, ..., /* out */ MoireHistory, MoireError);
    // 薄几何影响摩尔时先取 ThinGeometryRelaxationFactor
}

说明

时域上采最怕亚像素摩尔纹闪烁——细密纹理在抖动网格上逐帧忽明忽暗。bEnableFlickeringHeuristic 开启时，本段用 FetchMoireInput 取当前摩尔输入 + 上帧摩尔历史，ComputeMoireError 沿时间分析闪烁幅度，得到 MoireError。这个误差后面会放宽拒绝（不因闪烁而误判历史失效）从而稳定画面。tsr_tensor_* 是 TSR 把一组像素打包成"张量"在波前内并行处理的抽象（见 ConvolutionNetwork.ush）。

1. 拒绝度量 + 历史复活比较（汇聚点）

tsr_tensor_half RejectionBlendFinal = tsr_tensor_half::Const(1.0);
tsr_tensor_halfC ExposedInput = LinearToSMCS(Input * tsr_half(ExposureOffsetFactor));
tsr_tensor_halfC ExposedHistory = GCSToSMCS(History);
if (bEnableResurrection) {
    tsr_tensor_halfC ExposedResurrectedHistory = GCSToSMCS(OriginalResurrectedHistory);
    bResurrectionIsCloser = IsResurrectedFrameCloserThanPreviousFrame(bIsResurrectionOffScreen, ExposedInput, ExposedHistory, ExposedResurrectedHistory);
}

说明

本 pass 的汇聚点：把输入与历史都转到 SMCS（Shading Metric Color Space，感知均匀的比较空间，见 ColorSpace.ush）再度量差异，算出 RejectionBlendFinal（1=完全信任历史，趋 0=拒绝历史用当前输入）。IsResurrectedFrameCloserThanPreviousFrame 判断"复活历史"是否比上帧历史更接近当前输入——若是则用复活历史，专治 disocclusion 后被错误拒绝导致的糊/闪。薄几何区（细线/栏杆）用 ThinGeometryRelaxationFactor 放宽拒绝防止细节被判失效。产物驱动 #5 UpdateHistory 的累积权重。
