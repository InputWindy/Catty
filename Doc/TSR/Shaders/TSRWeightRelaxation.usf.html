WeightRelaxationCS @ L149（LANE_COUNT*WAVE_COUNT 线程，tensor 抽象）

0. 半透明比例调节松弛权重（发散点）

FetchInput(PixelPos, InputLuma, Translucency, HistoryRelaxationWeight, IsPartialCoverageRegion);
tsr_tensor_half TranslucencyRatio = Translucency[0] * rcp(Translucency[0] + InputLuma * Translucency[1] + tsr_tensor_half::Const(0.0005));
tsr_tensor_half RatioToLerpWeight = max(tsr_tensor_half::Const(0.6) - TranslucencyRatio, tsr_tensor_half::Const(0));
RatioToLerpWeight = min(RatioToLerpWeight * RatioToLerpWeight * tsr_tensor_half::Const(3.33), tsr_tensor_half::Const(1));
RatioToLerpWeight = select(or(IsPartialCoverageRegion, TranslucencyRatio > 0.6), RatioToLerpWeight, Const(1));

说明

薄几何松弛在半透明物体上要更保守——半透明（如烟雾/玻璃）叠在薄几何上时，若还放宽历史会拖影。TranslucencyRatio 估该像素半透明贡献占比，当比例 > 0.05 起权重开始下降、到 0.6 快速降到 0（RatioToLerpWeight 的二次曲线 ×3.33 实现"缓起急降"）。IsPartialCoverageRegion（部分覆盖=薄几何边）才应用这套调节。

1. lerp 松弛权重 + 回写编码（汇聚点）

bool bRelaxationWeightsModified = AnyComponent(and(HistoryRelaxationWeight > 0, RatioToLerpWeight < 1.0));
BRANCH if (bRelaxationWeightsModified) {
    HistoryRelaxationWeight = lerp(tsr_tensor_half::Const(0), HistoryRelaxationWeight, RatioToLerpWeight);
    tsr_tensor_ushort EncodedThinGeometry = EncodeThinGeometry(HistoryRelaxationWeight, IsPartialCoverageRegion);
    R8Output[int3(OutputPixelPos, ThinGeometryTextureIndex)] = EncodedThinGeometry.GetElement(ElementIndex);
}

说明

本 pass 的汇聚点：只在"确有松弛权重且需要下调"（bRelaxationWeightsModified）时才写——避免无谓的带宽。lerp 把 #7 的原松弛权重按半透明比例拉向 0，再 EncodeThinGeometry 打包（含部分覆盖位）写回 R8 薄几何纹理数组。CONFIG_TRANSLUCENCY_COVERAGE_BIT 时额外写半透明贡献位。产物供 #4 拒绝 与 #5 累积 使用——这是薄几何"检测→松弛调节→拒绝/累积"闭环的中间调节环节。
