ITemporalUpscaler 接口 TemporalUpscaler.h

TSR、DLSS、FSR、XeSS 都实现同一个上采样接口，吃相同输入。引擎侧的 jitter/velocity 准备是共享的，仅"重建"算法不同。

FInputs 成员说明
SceneColor低分辨率带 jitter 的场景颜色（FScreenPassTexture）
SceneDepth深度缓冲
SceneVelocity运动矢量
PostDOFTranslucencyResources景深后半透明（单独重投影）
EyeAdaptationBuffer曝光，用于在感知空间做拒绝
FOutputs 成员说明
FullRes高分辨率输出（FScreenPassTextureSlice）
HalfRes可选半分辨率输出，供后处理复用

FTSRHistory / 历史格式 持久化纹理集

// 历史格式位（决定历史纹理数组里存哪些通道） enum class ETSRHistoryFormatBits { None = 0, Moire = ..., // 开 ShadingRejectionFlickering 时：存闪烁抑制数据 AlphaChannel= ..., // 支持 alpha 后处理时：存 alpha }; // 历史切片序列（支持历史复活 History Resurrection） struct FTSRHistorySliceSequence { uint32 FrameStorageCount; // Clamp(kTransientSliceCount + ..., 4, GMaxTextureArrayLayers) uint32 FrameStoragePeriod; // Clamp(ResurrectionPersistentFrameInterval|1, 1, 1024) };
历史内容作用
累积颜色重建的高分辨率颜色（R11G11B10 或 RGBA16F）
累积样本数 / metadata每像素累积帧数，决定新帧权重（EMA 分母）
Moire / 闪烁 luma周期性闪烁抑制
Guide重投影 / 拒绝所需引导
Resurrection slices周期性保存的更久历史，供"复活"

permutation 的两条主轴

大多数 CS 带 FTSRShader::FWaveSizeOps（wave 大小，r.TSR.WaveOps）与 16bit VALU（Use16BitVALU）两个跨平台性能维度；UpdateHistory 额外有 EQuality（Low/Medium/High/Epic）质量档。

全局 CVar r.TSR.*

CVar默认作用
r.TSR.AlphaChannel-1是否处理 alpha（-1 跟随后处理 alpha 支持）
r.TSR.History.SampleCount16.0每输出像素累积样本上限（clamp 8~32）
r.TSR.History.ScreenPercentage100.0历史分辨率相对输出的倍率
r.TSR.History.R11G11B101历史用 R11G11B10 省带宽
r.TSR.History.UpdateQuality3UpdateHistory permutation 档（受 sg.AntiAliasingQuality 驱动）
r.TSR.ShadingRejection.SampleCount2.0历史完全拒绝后重累积样本上限
r.TSR.ShadingRejection.ExposureOffset0拒绝时的曝光补偿
r.TSR.RejectionAntiAliasingQuality3历史被拒时空间 AA 质量
r.TSR.ReprojectionField0高质量重投影场（high/epic/cinematic 开）
r.TSR.ReprojectionField.AntiAliasPixelSpeed0.125膨胀开始做空间 AA 的输出像素速度阈值
r.TSR.WaveOps1拒绝启发式卷积用 wave ops 加速
r.TSR.AsyncCompute—把 TSR pass 放 async compute 队列
