class FTSRResolveHistoryCS : public FTSRShader { class FNyquistDim : SHADER_PERMUTATION_SPARSE_INT("DIM_NYQUIST_WAVE_SIZE", 0, 16, 32); using FPermutationDomain = TShaderPermutationDomain<FNyquistDim, F16BitVALUDim, FAlphaChannelDim>; // 参数 FScreenTransform DispatchThreadToHistoryPixelPos; FIntPoint OutputViewRectMin / OutputViewRectMax; int32 bGenerateOutputMip1; };
DIM_NYQUIST_WAVE_SIZE路径
0普通路径，TILE_SIZE=8，直接重采样
16 / 32高质量：wave 协作 + TSRConvolutionNetwork.ush Nyquist 重建，DOWNSAMPLE_FACTOR=2、GROUP_TILE 带 overscan

关键宏

KERNEL_SIZE 4、CONFIG_CLAMP 1、CONFIG_HDR_WEIGHT 1。wave 路径用 TLaneVector2D 把每 lane 的输入/输出像素打包成 SIMD（INPUT_SIMD_SIZE / OUTPUT_SIMD_SIZE），配合 lane stride 做寄存器内的重建。

双像素向量化

CONFIG_ENABLE_DUAL_PIXEL_VECTORIZATION（fp16 时开）用 RDNA 的 v_pk_*_{uif}16 指令一次处理两个像素；Map8x8Tile2x2LaneDPV 把 8×8 tile 的线程按 2×2 映射到 lane，配合双像素打包。
