问题：对齐好的历史，凭什么信 The rejection problem

#2/#3 已把历史几何对齐到当前帧，也用 DecimateMask 标了遮挡失效。但还剩一大类历史失效不是几何问题而是着色问题：同一块几何，光照变了（灯亮了）、材质动了（水面波纹）、或者高频细节在亚像素抖动下本就会有差异。这些用深度/速度判断不出来——只能直接比对颜色。

不能简单做邻域 min/max clamp

老式 TAA 的抗鬼影是邻域颜色包围盒 clamp：把重投影历史 clamp 到当前帧 3×3 邻域的颜色 min/max 盒子里。简单但粗暴——盒子太紧会丢历史（变糊、闪），太松挡不住鬼影。TSR 的 RejectShading 换了思路：对"历史引导"和"当前输入"分别做同一套卷积滤波，比较滤波后两者的能量差，差得越多说明着色变化越剧烈、历史越不可信，拒绝权重越高。这是一套连续、空间平滑的启发式，而非硬 clamp。UE5.8 更进一步把这套启发式实现成卷积网络（见 #7），FTSRRejectShadingCS 直接继承 FTSRConvolutionNetworkShader。

MeasureRejection：拒绝启发式的核心 TSRShadingAnalysis.ush

核心函数 MeasureRejection 的完整骨架（取自源码 ~340–377 行，保留真实符号）：

// 1. 用当前输入 3×3 邻域的 min/max 建“颜色包围盒” MinMax3x3(Concatenate(FilteredInput, InputC2), /*out*/ Min, /*out*/ Max); tsr_tensor_half FilteredBoxMin = Min[0], FilteredBoxMax = Max[0]; // 2. ClampError：量化误差 + （响应模式）总变差 + 盒尺寸×滤波权，把盒撑宽 ClampError = max(BackbufferQuantizationErrorVector, InputC2BoxSize * (FilteringWeight * 0.25)) + BackbufferQuantizationErrorVector; FilteredBoxMin -= ClampError; FilteredBoxMax += ClampError; // 3. 把重投影历史 clamp 进盒子 tsr_tensor_half ClampedFilteredHistory = fastClamp(FilteredHistory, FilteredBoxMin, FilteredBoxMax); // 4. Delta：归一化尺度 = max(历史与输入的差, 盒尺寸)，自适应容忍度 tsr_tensor_half Delta = max(abs(FilteredInput - FilteredHistory), BoxSize); // 5. clamp 改动量→能量，改动越大 → 历史越不可信 tsr_tensor_half RawClampedEnergy = abs(ClampedFilteredHistory - FilteredHistory); tsr_tensor_half RawRejection = saturate(1.0 - max(RawClampedEnergy, 0.0) * rcp(Delta)); // 6. 空间滤波：Median3x3 去噪 + MaxRMinG3x3 形态学，防单像素噪点乱拒绝 Deconcatenate(MaxRMinG3x3(Median3x3(Concatenate(RawClampedEnergy, RawRejection))), /*out*/ FilteredClampedEnergy, /*out*/ OutRejectionClampBlend); // 7. 最终拒绝权重（连续 [0,1]） OutRejectionBlendFinal = saturate(1.0 - max(FilteredClampedEnergy, 0.0) * rcp(Delta));
1建包围盒当前输入 3×3 min/max → FilteredBoxMin/Max
▶
2撑宽+Clamp加 ClampError 撑宽盒子，再把历史 clamp 进去，测改动量
▶
3归一化+平滑1 - Energy/Delta，Median→MaxRMinG → RejectionBlendFinal

Delta 与 ClampError：拒绝的“双重容忍度”

这里有两层容忍度：① ClampError 撑宽“包围盒”本身（量化误差 BackbufferQuantizationErrorVector + 盒尺寸×FilteringWeight），让盒子宽到足以容纳“本来就该有的差异”；② Delta = max(|输入−历史|, BoxSize) 是归一化分母，决定“多大的 clamp 改动算作彻底失效”。两者都以 BoxSize = InputC2BoxSize×FilteringWeight + 2×FilteringWeight×量化误差 为尺度——对比度高的区域盒大、容忍度高；平坦区域盒小、一点变化就拒。这就是为什么高频细节（盒大）能稳定累积，而平滑墙面上一点鬼影就会被抹掉。

两种拒绝模式：Responsive 与常规 RejectShadingMode

拒绝有两个档位（RejectShadingMode）。当处于 REJECT_SHADING_RESPONSIVE（响应式，用于需要快速跟随变化的物体）时，ClampError 额外叠加一项总变差（total variation）：

if (RejectShadingMode == REJECT_SHADING_RESPONSIVE) { Deconcatenate(abs(TotalVariation3x3(Concatenate(abs(InputC0 - InputC2), InputC2))), /*out*/ TotalVarInputDiffC0C2, /*out*/ TotalVarInputC2); ClampError = max(ClampError, Blur3x3(min(TotalVarInputDiffC0C2, TotalVarInputC2))); }

为什么要“响应式”这个档

某些内容（快速变化的粒子、UI、高动态物体）宁可少信历史、多信当前帧，以免拖影。响应式模式把“局部总变差”加进容忍度（实际上是把盒子撑得更宽），使这些区域对历史变化更宽容、更快跟随新帧。常规模式则优先稳定（多信历史）。

颜色空间：在感知均匀的地方比较 TSRColorSpace.ush

直接在线性 HDR 空间比颜色差是不行的：一个 1000 尼特的高光波动 10 尼特，和一个 1 尼特暗部波动 10 尼特，数值差相同，但人眼感知天差地别。TSR 用 HdrWeight 系列函数把颜色映射到感知/HDR 加权空间再比较：

// TSRColorSpace.ush：HDR 加权，让高光的大数值波动不至于压倒暗部 tsr_half2 HdrWeightY(tsr_half2 Luma); // 亮度 → HDR 权重 tsr_half2 HdrWeightInvY(tsr_half2 LDRLuma); // 逆变换 // 注：亮像素可能让 HdrWeight 在 fp16 下变 0，源码 clamp 到 ~0.000061（fp16 最小正规数附近）

闪烁（Moire/flickering）抑制

周期性闪烁（薄栅栏的摩尔纹、镜面高光的时序跳动）是拒绝启发式的死敌：每帧都"看起来变了"，会被持续拒绝，导致该区域永远累积不起来、一直糊/闪。当 DIM_FLICKERING_DETECTION 开启时，RejectShading 维护一份 Moire 历史（ClampPlus3x3(PrevFlickeringHistory, InputLuma)），跟踪像素亮度的周期性模式——如果一个像素是在稳定地"来回闪"而非"单向变化"，就识别为闪烁、放宽拒绝、允许它继续累积以平滑掉闪烁。这份 Moire 历史正是 #3 DecimateHistory 帮忙重投影过来的。

拒绝 ≠ 丢弃，而是"降权"

RejectionBlendFinal 是 [0,1] 的连续值：1 表示历史完全可信（几乎不用新帧，画面最稳），0 表示历史完全不可信（几乎全用新帧，等于退化到单帧、需要 #6 空间 AA 兜底）。绝大多数像素落在中间——TSR 的画质就取决于这个权重估得准不准：估太高 → 鬼影拖影；估太低 → 画面闪烁、糊、噪。ShouldSpatialAntiAlias 用 RejectionBlendFinal < 0.25（且可见锯齿/遮挡消失且不复活）来决定是否触发空间 AA。这套连续权重估计，就是 TSR 相比传统 TAA 在大幅上采样下仍稳的根本原因。

小结 Summary

1几何对齐解决不了着色变化类的历史失效，必须直接比对颜色——这就是 RejectShading 的职责。

2核心 MeasureRejection：对历史引导与当前输入各做卷积滤波，测 clamp 能量差，归一化+空间平滑成连续拒绝权重 RejectionBlendFinal，而非硬 min/max clamp。

3比较在 HDR 感知加权颜色空间做（HdrWeightY），并补偿量化误差，避免把正常噪声误判为着色变化。

4闪烁抑制用 Moire 历史识别周期性闪烁并放宽拒绝，救回栅栏/高光。UE5.8 把整套启发式实现为卷积网络（#7）。

5输出连续拒绝权重给 #5 累积、AntiAliasMask 给 #6 兜底。权重估得准不准，直接决定 TSR 的鬼影—清晰度平衡。
