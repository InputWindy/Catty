MeasureRejection · 拒绝启发式

void MeasureRejection( tsr_tensor_halfC InputC0, ..., bool bEnableMoireError, out tsr_tensor_half OutRejectionBlendFinal, // ★ 最终拒绝权重 [0,1] out tsr_tensor_half OutRejectionClampBlend); // clamp 混合系数 // 关键中间量 RawClampedEnergy = abs(ClampedFilteredHistory - FilteredHistory); RawRejection = saturate(1 - max(RawClampedEnergy,0) * rcp(Delta)); OutRejectionBlendFinal = saturate(1 - max(FilteredClampedEnergy,0) * rcp(Delta)); FinalBlendFinal = max(1 - OutRejectionBlendFinal, MinBlendFinal); // 保底最小混合
滤波算子作用
Median3x33×3 中值滤波，去单像素噪点，避免噪声触发误拒绝
MaxRMinG3x3形态学：R 通道取邻域 max、G 通道取 min，膨胀拒绝区域使其空间连续
ClampPlus3x3把闪烁历史 clamp 到当前亮度的 3×3 邻域（十字形）
ShouldSpatialAntiAliasbAliasingIsVisible ∧ (RejectionBlendFinal<0.25 ∨ (disoccluded ∧ ¬resurrect))
ComposeTranslucencyForRejection把模糊半透明合进不透明输入，让拒绝更贴合最终画面

TSRColorSpace.ush · HDR 加权

函数作用
HdrWeightY(Luma)亮度 → HDR 权重（压缩高光的数值主导，接近感知均匀）
HdrWeightInvY(LDRLuma)逆变换
HdrWeight4(Color)对 3/4 通道颜色取 Luma 后加权
PreExposureCorrectGCS引导色彩空间的预曝光校正（与 #3 曝光校正配套）

fp16 下限保护

源码注释：极亮像素会让 HdrWeight 在 fp16 下被压成 0（下溢），导致除零/NaN。因此权重被 clamp 到接近 fp16 最小正规正数（约 0.000061）。这是 16bit ALU（r.TSR.16BitVALU=1）省带宽带来的必须的数值防护。
