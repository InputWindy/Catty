FTSRDetectThinGeometryCS · permutation

class FTSRDetectThinGeometryCS : public FTSRConvolutionNetworkShader { class FVaryingRangeDetectionDim : SHADER_PERMUTATION_BOOL("DIM_VARYING_RANGE_DETECTION"); class FIntensityLineDetectionDim: SHADER_PERMUTATION_BOOL("DIM_INTENSITY_LINE_DETECTION"); class FRejectTranslucencyDim : SHADER_PERMUTATION_BOOL("DIM_REJECT_TRANSLUCENCY_DETECTION"); using FPermutationDomain = TShaderPermutationDomain< FTSRConvolutionNetworkShader::FPermutationDomain, FVaryingRangeDetectionDim, FIntensityLineDetectionDim, FRejectTranslucencyDim>; };
permutation作用
DIM_VARYING_RANGE_DETECTION按深度范围自适应检测尺度（远近线宽不同）
DIM_INTENSITY_LINE_DETECTION基于颜色强度的线检测（TLineEdgeType = tsr_tensor_half2）
DIM_REJECT_TRANSLUCENCY_DETECTION结合半透明覆盖做拒绝

边缘类型

EDGE_TYPE = EDGE_HORIZONTAL_VERTICAL_DIAGNAL（值 2）：同时检测水平/垂直/对角边缘，比只查水平垂直（值 1）更完整地捕捉斜线。

tsr_tensor 张量算子

常见算子：Median3x3、MaxRMinG3x3、ClampPlus3x3、Concatenate/Deconcatenate（多张量打包/拆包，配合形态学）、bicubic 采样、能量/权重估计。这些算子在 lane 张量上批量执行，是 TSR 卷积启发式的构件。
