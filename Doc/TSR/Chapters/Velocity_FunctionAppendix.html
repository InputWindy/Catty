ClosestOccluder · 原子散射编码

// TSRClosestOccluder.ush — ScatterClosestOccluder() // 透视视图：深度量化到 [0, 8388607]（23bit）后左移 9 位占高位，低 9 位塞 hole-filling 速度 uint Depth = clamp(uint(round(PrevClosestDeviceZ * 8388607.0)), 0, 8388607) << 9; uint PrevClosestDepth0 = Depth | ((EncodedHoleFillingVelocity >> 9u) & 0x1FFu); // 用 InterlockedMax 抢位置：深度最大（最靠前）的赢 InterlockedMax(PrevAtomicOutput[tsr_ushort3(PixelPos, 0)], PrevClosestDepth0, PreviousDepth0); // 正交视图分支：f32tof16(DeviceZ) << VELOCITY_HOLE_FILLING_BITS | 速度

为什么深度放高位

InterlockedMax 只能对整个 uint 比大小。把深度放高位、速度放低位，就能让原子最大化先按深度排序（选出最靠前的遮挡物），同时"搭便车"把该遮挡物的速度也存下来——一次原子操作完成"选遮挡物 + 记速度"两件事。globallycoherent 保证跨线程组的原子可见性。

ReprojectionField · 编码/解码

函数作用

HasEncodedReprojectionOffset判断是否有非零偏移（!= 5，即 offset≠(0,0) 的编码）
ComputeReprojectionBoundaryCoverage估计边界覆盖当前像素的比例
