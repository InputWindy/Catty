"抽取"抽的是什么 Decimate = reproject the guide

名字容易误解：DecimateHistory 不是把完整历史颜色搬过来（那是 #5 UpdateHistory 干的）。它重投影的是历史的引导缓冲（guide）——一份存历史"代表色 + 元数据"的低成本代理，专供 #4 的着色拒绝拿来和当前帧对比。同时重投影 Moire 历史（闪烁抑制用）和薄几何 coverage（#7 用）。

1读膨胀重投影向量从 #2 的 DilatedReprojectionVectorTexture + ClosestDepthTexture 取每像素上一帧位置
▶
2重采样历史引导按重投影坐标双线性采样 PrevHistoryGuide / Moire / Coverage，做曝光校正
▶
3算抽取掩码比对散射的 PrevAtomic 深度，判定视差/遮挡失效 → DecimateMaskOutput

为什么要一份"引导"而不是直接用历史颜色

着色拒绝（#4）要逐像素判断"重投影历史 vs 当前帧"差多少。若直接拿全精度历史颜色去卷积对比，带宽和计算都很贵。TSR 的做法是维护一份引导缓冲：一份经过量化（HistoryGuideQuantizationError）的历史色彩摘要，DecimateHistory 把它重投影对齐到当前网格，#4 只在这份轻量引导上做卷积启发式。全精度历史颜色则留到 #5 才按最终权重重采样——把"判断可信度"与"实际累积"解耦，前者用便宜的代理，后者才动真格。

抽取掩码：遮挡消失与视差拒绝 DecimateMask

DecimateHistory 的核心产物是 DecimateMaskOutput（tsr_half2）。它综合几类"历史不可信"的几何信号：

信号来源含义
视差拒绝 parallax rejection重投影深度 vs ClosestDepth重投影位置的深度和当前深度对不上 → 是被遮挡/露出的区域
遮挡消失 disocclusionPrevAtomicTextureArray（#2 散射）历史里没有对应像素（前景刚移开露出的背景）
出屏 off-screen重投影坐标越界上一帧在屏幕外，无历史可用

掩码不是非黑即白

DecimateMask 是连续值而非布尔——它给出"历史有多大程度失效"的软标记。完全遮挡消失的区域掩码接近"完全拒绝"，轻微视差的区域给中间值。这个软掩码进入 #4 后与着色分析的结果相乘/融合，共同决定最终每像素的历史权重。TSR 反鬼影的哲学一以贯之：几乎所有判定都是连续权重，而非硬开关——硬开关会在画面上留下可见的接缝与突变。

历史复活的重投影 Resurrection reprojection

当 permutation DIM_RESURRECTION_REPROJECTION 开启时（对应 #1 讲的历史复活），DecimateHistory 会额外把一份更久远的历史（存在纹理数组的复活 slice）也重投影过来：

// 除了 PrevFrameIndex 的近期历史，还用 ResurrectionFrameIndex 的老历史 float ResurrectionFrameIndex; float PrevFrameIndex; float4x4 ClipToResurrectionClip; // 当前裁剪空间 → 复活帧裁剪空间的变换 // 复活历史用独立的 guide UV 变换重采样 FScreenTransform ScreenPosToResurrectionGuideBufferUV;

两份历史，谁可信用谁

复活重投影的意义：某像素被前景短暂遮挡（近期历史失效），但它在更早的某帧其实清晰可见。DecimateHistory 把"近期历史"和"复活历史"都对齐到当前帧，后续 #4/#5 就能在两者间择优——近期历史被判失效时，用复活历史顶上，避免从零重建导致的模糊闪烁。代价是多一次重投影采样和一份纹理数组 slice，所以只在高画质档开启。ClipToResurrectionClip 是把当前裁剪空间坐标映射到复活帧裁剪空间的矩阵——复活帧的相机位置和现在不同，必须重新投影。

小结 Summary

1DecimateHistory 重投影的是历史引导（guide）而非完整颜色——把"判断可信度用的轻量代理"对齐到当前抖动网格，全精度累积留给 #5。

2核心产物 DecimateMask 是连续的历史失效软掩码，综合视差拒绝、遮挡消失、出屏三类几何信号，交给 #4 融合。

3开启历史复活时，额外用 ClipToResurrectionClip 把更久远的历史也重投影过来，供后续在"近期 vs 复活"间择优。

4至此历史已对齐到当前帧，下一篇 #4 进入全书核心——着色拒绝：逐像素判断这份对齐好的历史到底能信多少。
