#8 附录 · 可视化模式与上采样接口

TSRVisualize pass 的 16 个可视化模式全表、FTSRVisualizeCS 参数、ITemporalUpscaler 接口与 CVar。符号取自 UE5.8 PostProcess/TemporalSuperResolution.cpp（~3540+）+ TSRVisualize.usf + TemporalUpscaler.h。

EVisualizeId · 全部模式

enum class EVisualizeId : int32 { ReprojectionFieldOverview = -3, Overview = -2, ShowFlag = -1, // 概览（宫格） HistorySampleCount = 0, ParallaxDisocclusionMask = 1, HistoryRejection = 2, HistoryClamp = 3, ResurrectionMask = 4, ResurrectedColor = 5, SpatialAntiAliasingMask = 6, AntiFlickering = 7, ReprojectionFieldSummary = 8, ReprojectionFieldOffset = 9, ReprojectionFieldOffsetCoverage = 10, ReprojectionFieldAA = 11, ReprojectionFieldNullJacobian = 12, ReprojectionFieldClampedJacobian = 13, ReprojectionFieldDilatedJacobian = 14, ThinGeometry = 15, MAX, };
Id模式看什么 / 对应篇
0HistorySampleCount累积样本数（红少→绿多）· #5
1ParallaxDisocclusionMask视差遮挡消失区（cluster hole）· #2/#3
2HistoryRejection历史拒绝强度 · #4
3HistoryClamp历史被 clamp 的强度 · #4
4ResurrectionMask历史复活区域（绿）· #3
5ResurrectedColor可复活的最老一帧颜色 · #3
6SpatialAntiAliasingMask空间AA 介入处（绿）· #6
7AntiFlickering防闪烁启发式（橙/红=启用，粉=禁用）
8~14ReprojectionField*重投影场：Summary/Offset/OffsetCoverage/AA/Null·Clamped·Dilated Jacobian · #2
15ThinGeometry薄几何检测（红=单像素细线）· #7

FTSRVisualizeCS · 关键参数

uint VisualizeId; // 当前渲染哪个模式 uint bCanResurrectHistory; // 复活是否可用（灰显禁用项） uint bCanSpatialAntiAlias; uint bReprojectionField; float MaxHistorySampleCount; // 样本数着色归一化上限 float FlickeringFramePeriod; Texture2D DecimateMaskTexture, HistoryRejectionTexture, // 读各 pass 中间纹理 MoireHistoryTexture, AntiAliasMaskTexture, ThinGeometryTexture, ReprojectionBoundaryTexture, ReprojectionJacobianTexture, ...; RWTexture2D<tsr_half4> Output; // [numthreads(64,1,1)] VisualizeCS：8x8 tile，按 VisualizeId 分支调 DisplayXXX

概览宫格的实现

概览模式（负值）走 bIsOverviewVisualize 分支：VisualizeRect 缩到输出中间 1/2，多次调用 Visualize() lambda 生成不同 VisualizeId 的瓦片填入 TArray<FVisualizeBufferTile>（16 格）。Overview 填样本数/遮挡/拒绝/复活/防闪烁/薄几何；ReprojectionFieldOverview 填 7 张重投影场专项图。

ITemporalUpscaler · 接口签名

// TemporalUpscaler.h，namespace UE::Renderer::Private class ITemporalUpscaler : public ISceneViewFamilyExtention { class IHistory : public IRefCountedObject { virtual const TCHAR* GetDebugName() const = 0; // 与 upscaler 同一常量指针 virtual uint64 GetGPUSizeBytes() const = 0; }; struct FInputs { FIntRect OutputViewRect; FVector2f TemporalJitterPixels; float PreExposure; FScreenPassTexture SceneColor, SceneDepth, SceneVelocity; FRDGTextureRef EyeAdaptationTexture; TRefCountPtr<IHistory> PrevHistory; }; struct FOutputs { FScreenPassTexture FullRes; TRefCountPtr<IHistory> NewHistory; }; virtual FOutputs AddPasses(FRDGBuilder&, const FSceneView&, const FInputs&) const = 0; virtual float GetMinUpsampleResolutionFraction() const = 0; virtual float GetMaxUpsampleResolutionFraction() const = 0; virtual ITemporalUpscaler* Fork_GameThread(const FSceneViewFamily&) const = 0; };
成员作用
AddPasses把上采样所需 RDG pass 加入图；返回全分辨率结果 + 新历史
GetMin/MaxUpsampleResolutionFraction声明支持的渲染分辨率比例区间，动态分辨率据此夹取
Fork_GameThread为每个 ViewFamily 派生实例（游戏线程）
IHistory::GetDebugName历史自描述，跨帧校验历史与 upscaler 是否匹配

相关 CVar

CVar默认作用
r.TSR.Visualize-1选择可视化模式；-1/-2 概览宫格，0~15 单模式，-3 重投影场概览
r.TemporalAA.Upscaler10=强制默认 TSR；1=用 GTemporalUpscaler（可被第三方插件覆盖）
r.TemporalAA.HistoryScreenPercentage100历史缓冲相对输出的分辨率
VisualizeTSR show flag—编辑器 show flag，等效触发概览

互斥校验

SceneRendering.cpp 的 checkf 保证 TemporalUpscalerInterface 与 PrimarySpatialUpscalerInterface 不同时存在；GetMainTAAPassConfig(View)==EMainTAAPassConfig::TSR 是各 pass 判断 TSR 路径的开关。
