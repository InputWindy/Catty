1. FScreenProbeParameters / GatherParameters

说明

作用：定义 Screen Probe Gather 的跨 pass 参数契约。所有 RDG pass 都通过这些结构理解 probe atlas、trace buffer、gather buffer 和 indirect args。

共同点：placement、trace、filter、integrate 都依赖同一个参数包。

不同点：FScreenProbeParameters 管全局 probe 布局和 trace 输入；FScreenProbeGatherParameters 管 filter 后的 radiance/irradiance 输出。

2. ScreenProbeGatherScreenData

下钻：ScreenProbeGatherScreenData shader 算法专题

说明

作用：为每个 probe 生成 BRDF PDF、BRDF SH 和 disocclusion 信息，并加载可用历史。

共同点：无论后续是否 importance sampling，这一步都建立每个 probe 的材质/历史基础数据。

不同点：history 有效时会读上一帧 fast update 累积；开启 disocclusion spatial filter 时会额外写 disocclusion texture。

3. GenerateImportanceSamplingRays

下钻：GenerateImportanceSamplingRays 结构化采样专题

说明

作用：根据 BRDF PDF、照明 PDF、Radiance Cache 和历史 probe radiance 生成结构化重要性采样方向。

共同点：最终都写入 StructuredImportanceSampledRayInfosForTracing，供 trace shader 使用。

不同点：是否计算 Lighting PDF、是否使用 probe radiance history、是否使用 Radiance Cache 都是可选分支。

4. TraceScreenProbes

下钻：TraceScreenProbes 多后端级联追踪专题

说明

作用：执行真正的 probe 方向 trace，将方向采样转换成 TraceRadiance 与 TraceHit。

共同点：所有 trace 后端最终都汇聚到统一 trace buffer。

不同点：屏幕 trace、硬件 RT、Mesh SDF、Heightfield、Global SDF、Radiance Cache fallback 由平台和开关选择。

5. FilterScreenProbes

下钻：FilterScreenProbes 深挖专题（主文档 + 函数附录）

说明

作用：将 trace buffer 复合成可插值的 screen probe radiance，并执行 moving 计算、temporal filter、spatial filter、irradiance 转换和 mip/border 处理。

共同点：最终输出 FScreenProbeGatherParameters 给 Integrate。

不同点：temporal filter、spatial filter、irradiance format、extra AO 和 wave ops 都是可选分支。

6. InterpolateAndIntegrate

下钻：InterpolateAndIntegrate 深挖专题（主文档 + 函数附录）

说明

作用：把 filter 后的 probe radiance 插值到像素，再按材质 BRDF 积分，写出 DiffuseIndirect、BackfaceDiffuseIndirect、RoughSpecularIndirect。

共同点：这是 FSSDSignalTextures 前的最终光照生成阶段。

不同点：tile classification、Substrate overflow closure、short-range AO、stochastic interpolation、integrate downsample 都会改变 dispatch 和 shader permutation。

7. UpdateHistoryScreenProbeGather

下钻：UpdateHistoryScreenProbeGather 全屏时域去噪专题（主文档 + 函数附录）

说明

作用：把当前帧结果重投影并写入 history，为下一帧 temporal reuse 做准备。

共同点：Diffuse、RoughSpecular、Backface、ShortRangeAO/GI 都通过同一个 history 更新框架维护。

不同点：history 是否有效、是否有 backface、是否有 short-range AO/GI、是否启用 temporal filter 都会影响实际写入。

8. ScreenGatherMarkUsedProbes

说明

作用：将当前 screen probes 会采样到的世界空间位置标记进 Radiance Cache indirection texture。

共同点：它是 screen-space gather 与 world-space radiance cache 的连接点。

不同点：只在 Radiance Cache 启用且当前视图需要标记时执行；hair、translucency volume 还有额外 mark 回调。标记完成后由 UpdateRadianceCaches 按预算重追这些 probe，其完整流水线见 Radiance Cache 函数附录 / 主文档。
