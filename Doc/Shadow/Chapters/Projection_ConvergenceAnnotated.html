#12 投影采样 SMRT · VSM 怎么变成屏幕上的阴影

物理页里存好深度后，最后一步是投影：对每个屏幕像素查它到光源是否被遮挡，产出阴影因子。VSM 用 SMRT（Shadow Map Ray Tracing，在阴影图深度上"步进式打光线"）取代传统 PCF，得到软阴影且抗自阴影痤疮。本篇讲清投影 CS 的排列（permutation）、SMRT 采样、单遍多光源打包与两种输入。符号取自 UE5.8 shader VirtualShadowMapProjection.usf 与 C++ VirtualShadowMapProjection.cpp/.h。

SMRT：在深度图上打光线 Shadow Map Ray Tracing

传统阴影图用 PCF：在阴影图上采几个点做百分比比较，软硬取决于核大小，且易产生 peter-panning/痤疮。VSM 换成 SMRT——从接收点朝光源方向，在阴影图深度上步进采样若干次，模拟一条射线是否被深度缓冲挡住。多条射线（对应光源面积）平均得到物理正确的软阴影半影。

// SMRT 每像素：发若干射线，每射线步进若干次采样 方向光: RayCountDirectional=7, SamplesPerRayDirectional=8 局部光: RayCountLocal=7, SamplesPerRayLocal=8 // 自适应射线数：已确定全亮/全暗时提前收敛 r.Shadow.Virtual.SMRT.AdaptiveRayCount = 1;

为什么 SMRT 比 PCF 好

SMRT 沿光线步进，天然处理不同深度的遮挡关系，接触硬、远处软（半影随距离增大），无需手调偏移。斜率外推（ExtrapolateMaxSlopeDirectional=5.0）与 texel 抖动（TexelDitherScaleDirectional=2.0）进一步抑制走样与自阴影。方向光射线长度按 RayLengthScaleDirectional=1.5 缩放。

投影 CS 排列 FVirtualShadowMapProjectionCS permutations

一个投影 CS 通过大量编译期排列覆盖所有情况：

维度作用
FDirectionalLightDim方向光 vs 局部光
FOnePassProjectionDim单遍多光源打包
FHairStrandsDim头发输入
FSMRTStaticSampleCount静态采样数（SPARSE_INT: -1,2,4）
FFirstPersonShadow / FPrefilteredDistantClipmap5.8 新特性（仅方向光）

排列约束

源码约束：方向光不与 OnePassProjection 共存（方向光只有一盏主光，无需多光打包）；FFirstPersonShadow 和 FPrefilteredDistantClipmap 仅方向光有效。这些约束在 ShouldCompilePermutation 里裁掉无效组合，减少 shader 数量。

单盏灯输出一张阴影因子

局部光很多时，单遍把多盏灯的可见性打包进 OutShadowMaskBits（每 bit 一盏灯），一次 dispatch 出结果，再由 CompositeVirtualShadowMapFromMaskBits 合成到光照。两种输入：EVirtualShadowMapProjectionInputType::GBuffer=0 / HairStrands=1。下面是单遍多光真实的主循环：

// VirtualShadowMapProjection.usf — void VirtualShadowMapProjection(...)（真实源码节选） #if ONE_PASS_PROJECTION || UBERSHADER const FCulledLightsGridHeader LightGridHeader = VirtualShadowMapGetLightsGridHeader(LocalPixelPos, SceneDepth); const uint LoopCount = min(GetPackedShadowMaskMaxLightCount() + 1, LightGridHeader.NumLights); uint4 ShadowMask = InitializePackedShadowMask(); for (uint Index = 0; Index < LoopCount; ++Index) { const FLocalLightData LightData = VirtualShadowMapGetLocalLightData(LightGridHeader, Index); if (UnpackIsHandledByMegaLights(LightData)) break; // MegaLights 接管的排在尾部，遇到即止 int VirtualShadowMapId = LightData.Internal.VirtualShadowMapId; // ... 对该灯跑 SMRT 采样，将可见性打包进 ShadowMask ... } #endif

逐像素用 Morton 序遍历 tile（MortonDecode(GroupIndex)）使页访问/原子更相干；每灯的 SMRT 采样由上面的 CVar（RayCount/SamplesPerRay）控制。

与整条管线的衔接

投影产出的阴影因子/掩码在光照阶段（LightRendering.cpp）与 BRDF 相乘，得到最终画面。至此 VSM 全链路（#6 总览 → #7 页表 → #8 Clipmap → #9 局部光 → #10 页标记 → #11 缓存 → #12 投影）闭合。相关函数：RenderVirtualShadowMapProjection、RenderVirtualShadowMapProjectionOnePass、CreateVirtualShadowMapMaskBits、CompositeVirtualShadowMapMask。

小结 Summary

1VSM 用 SMRT（阴影图上步进打光线）取代 PCF，得物理软阴影、抗痤疮，接触硬远处软。

2默认 RayCount=7 / SamplesPerRay=8（方向光与局部光），AdaptiveRayCount=1 提前收敛。

3投影 CS 靠排列覆盖：方向光/局部光、OnePass、Hair、5.8 特性；方向光不与 OnePass 共存。

4多局部光走单遍打包 OutShadowMaskBits；逐光走 OutShadowFactor。输入 GBuffer / HairStrands 两类。
