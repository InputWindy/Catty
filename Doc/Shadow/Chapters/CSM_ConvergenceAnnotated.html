#3 级联阴影 CSM · 方向光的分辨率分配

方向光（太阳）平行照亮整个视锥，一张固定分辨率的阴影图远远不够。级联阴影（Cascaded Shadow Map）把视锥按到相机的距离切成多级、近处高分辨率远处低分辨率，用级联间的过渡混合与稳定 snapping 消除接缝与游动。符号取自 UE5.8 ShadowSetup.cpp · SetupWholeSceneProjection。

为什么要分级 Why cascades

方向光没有位置、只有方向，它的阴影视锥要覆盖相机能看到的全部范围——从脚下 1 米到远处几公里。若用一张阴影图，近处每个纹素要覆盖几厘米、远处覆盖几十米，均摊下来近处严重走样。CSM 的做法：把相机视锥沿深度切成若干段（级联），每段用一张独立的阴影图，近段范围小分辨率高、远段范围大分辨率低——这样每一段内的纹素密度都合适。

分割距离：对数 vs 均匀

级联的分割距离通常在对数分布（几何级数，贴合透视投影的深度非线性）与均匀分布之间用一个混合系数插值（光源组件的 CascadeDistributionExponent）。近处用对数分布把更多分辨率给到近景。级联数量由 r.Shadow.CSM.MaxCascades 与光源的 DynamicShadowCascades 决定。每级都是一个独立的 FProjectedShadowInfo，经 SetupWholeSceneProjection 初始化其正交投影矩阵与包围盒。

过渡混合：消除级联接缝 ComputeTransitionSize / FadeAlphas

相邻级联分辨率不同，边界处会有可见跳变。UE 在级联交界处留一段过渡区，在其中把两级阴影按权重混合：

// 每级末端留过渡带，FadeAlphas 控制在过渡带内的混合权重 float TransitionSize = ShadowInfo->ComputeTransitionSize(); // r.Shadow.CSM.TransitionScale 缩放过渡带宽度 // 越靠近级联边界，当前级权重越低、下一级权重越高

此外整个 CSM 在最远处会整体淡出到无阴影（避免远景阴影突然消失），由 FadeAlphas 与 r.Shadow.FadeResolution / r.Shadow.FadeExponent 控制。

稳定 snapping：消除阴影游动 Stable CSM

相机移动/旋转时，若级联视锥跟着连续平移，阴影边缘会像"爬行"一样抖动（shimmering）。稳定 CSM 的关键：把光源正交视锥的中心按阴影纹素网格取整（snap），让阴影图只发生整数纹素的平移，边缘不再抖：

// ShadowSetup.cpp L1090-1104 — 把变换后的中心 snap 到纹素网格 FVector2D TransformedPosition = ...; // 按每纹素世界尺寸取整（Fmod 消掉不足一纹素的偏移） TransformedPosition.X -= FMath::Fmod(TransformedPosition.X, TexelWorldSize); TransformedPosition.Y -= FMath::Fmod(TransformedPosition.Y, TexelWorldSize); // 深度范围钳制，避免远近平面抖动 const float DepthRangeClamp = 5000;

snapping 是 CSM 与 VSM Clipmap 的共同基因

这套"按网格取整让阴影只整数平移"的思想，在中篇 VSM Clipmap（#8）里被再次使用——Clipmap 每一级都按 RoundToDouble(ViewCenter/SnapSize)*SnapSize 对世界中心 snap，从而让缓存的物理页可以整体平移（PageAddressOffset）复用而非重渲。理解了 CSM 的 snapping，就理解了 VSM Clipmap 缓存复用的前提。

小结 Summary

1方向光覆盖整个视锥，CSM 把视锥按距离切成多级，近密远疏，均衡纹素密度。

2分割距离在对数/均匀间插值；每级是独立 FProjectedShadowInfo，由 SetupWholeSceneProjection 设正交投影。

3级联交界用过渡带混合（ComputeTransitionSize / FadeAlphas）消接缝，最远处整体淡出。

4稳定 snapping（纹素网格取整 + DepthRangeClamp=5000）消除相机移动时的阴影游动——与 VSM Clipmap（#8）同源。
