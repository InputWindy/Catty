// L1090-1104：把光源正交视锥中心 snap 到纹素网格 TransformedPosition.X -= Fmod(TransformedPosition.X, TexelWorldSize); TransformedPosition.Y -= Fmod(TransformedPosition.Y, TexelWorldSize); const float DepthRangeClamp = 5000; // 深度范围钳制

级联划分参数 光源组件

参数作用
DynamicShadowCascades动态阴影级联数
CascadeDistributionExponent对数/均匀分布的插值指数
CascadeTransitionFraction级联过渡带占比

CSM CVar r.Shadow.*

CVar默认作用
r.Shadow.TexelsPerPixel1.27324方向光每屏幕像素纹素数（定分辨率）
r.Shadow.FadeResolution64按分辨率淡出起点
r.Shadow.MinResolution32最小阴影分辨率
r.Shadow.FadeExponent0.25淡出指数
r.Shadow.CSMCaching0*CSM 缓存开关（见 #5 滚动缓存）
r.Shadow.CSMScrollingOverlapAreaThrottle0.75滚动缓存重叠面积阈值
r.Shadow.MaxCSMScrollingStaticShadowSubjects5滚动缓存静态投射体上限

* 关于 r.Shadow.CSMCaching 默认值

UE5.8 源码 L446 处该 CVar 注册默认写 0，但其注释描述行为按 default 1 表述——以实际注册值 0 为准，启用需显式设置。CSM 缓存本身在大世界固定光照下能显著省重渲。
