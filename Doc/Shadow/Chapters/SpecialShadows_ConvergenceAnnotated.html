胶囊阴影 CapsuleShadowRendering.cpp

用一组胶囊体（FCapsuleShape3f，从骨骼生成）近似角色，对面光源/天光做柔和的直接与间接遮蔽。开销极低，常用于移动端角色软阴影和静态物对角色的间接阴影。

// CapsuleShadowShaders.usf — float ShadowConeTraceAgainstCulledCapsuleShapes(...)（真实源码节选） // FCapsuleShadowingCS <FShapeShadow, FIndirectPrimitiveType>；GShadowShapeTileSize=8, downsample=2 float ConeVisibility = 1; float AreaOfLight = 6.283185308f - 6.283185308f * cos(LightAngle); // 光锥立体角 LOOP for (uint i = 0; i < NumIntersectingCapsules; i++) { // 遍历本 tile 剔除后的胶囊 uint ObjectIndex = bUseCulling ? IntersectingShapeIndices[MAX_INTERSECTING_SHAPES*GroupIndex + i] : i; // ... 对该胶囊做锥形遮挡测试，取 min → ConeVisibility ... }

软阴影从角度来

胶囊阴影的软硬由光源张角控制：r.CapsuleShadowFadeAngleFromVertical=PI/3、间接锥角 r.CapsuleIndirectConeAngle=PI/8、天光角 r.CapsuleSkyAngleScale=0.6（下限 r.CapsuleMinSkyAngle=15）。shader 在 /Engine/Private/CapsuleShadowShaders.usf。

接触阴影 ScreenSpaceShadows.usf

接触阴影在屏幕空间沿光线方向步进深度缓冲，补全阴影图/VSM 分辨率不足处的"接触细节"（脚与地面、物体缝隙的硬小阴影）。每盏灯可设 ContactShadowLength 开启。下面是默认方法的真实 CS：

// ScreenSpaceShadows.usf — void ScreenSpaceShadowsCS(...)（真实源码节选） float3 OpaqueTranslatedWorldPosition = mul(float4(..., SceneDepth, 1), PrimaryView.ScreenToTranslatedWorld).xyz; float Dither = InterleavedGradientNoise(DispatchThreadId.xy + 0.5f, View.StateFrameIndexMod8); float2 HitUV; float HitDistance = CastScreenSpaceShadowRay(OpaqueTranslatedWorldPosition, LightDirection, ActualContactShadowLength, 8 /*步数*/, Dither, 2.0f, false, HitUV); float Result = HitDistance > 0.0 ? (1.0f - GetContactShadowOcclusion(HitUV)) : 1.0f; // 命中=被遮挡 RWShadowFactors[DispatchThreadId.xy] = float2(Result, SceneDepth);
StochasticJittering = 0默认方法，随机抖动步进
BendSSS = 1Bend Studio 屏幕空间软阴影
CVar默认作用
r.ContactShadows.Standalone.Method00 抖动 / 1 BendSSS
r.ContactShadows.Intensity.Mode0强度模式（PrimitiveFlag/深度近似/强制）
r.ContactShadows.OverrideLength-1覆盖接触长度（-1 用各灯设置）
r.ContactShadows.Bend.OverrideSurfaceThickness0.005BendSSS 表面厚度

tile 与淡出

CS FScreenSpaceShadowsCS / FScreenSpaceShadowsBendCS，tile 8×8、downsample=2，FScreenSpaceShadowsUpsamplePS 上采回全分辨率。远距离按 FadeStart=1600 / FadeLength=800 淡出（屏幕空间射线在远处不可靠）。接触阴影是 VSM/CSM 的常见搭档，补最后一点接触细节。

光线追踪阴影 RayTracingShadows.cpp

有硬件 RT 时，可对每盏灯发实际光线求遮挡，得参考级精确阴影（面光源半影、精确自阴影）。默认关（r.RayTracing.Shadows=0），因为 VSM 已在多数场景达到接近效果且更省。

// 关键 CVar（RayTracingShadows.cpp + LightRendering.cpp） r.RayTracing.Shadows = 0; // 总开关（默认关） r.RayTracing.Shadows.SamplesPerPixel = -1; // -1 = 按光源 r.RayTracing.Shadows.MaxBatchSize = 8; r.Shadow.Denoiser = 2; // 阴影降噪器

降噪是关键

RT 阴影每像素样本少（噪点大），必须配降噪：r.Shadow.Denoiser=2、r.Shadow.Denoiser.MaxBatchSize=4。函数 ShouldRenderRayTracingShadowsForLight / ShouldRenderRayTracingShadows 逐灯判定。可分别对方向/点/聚/矩形光启用。RT 阴影是"预算充足、追求参考画质"时的顶配选项，非默认路径。

小结 Summary

1胶囊阴影：骨骼胶囊近似角色，低开销柔和直接/间接遮蔽（角度控软硬），移动端常用。

2接触阴影：屏幕空间沿光线步进深度，补接触硬细节；方法 0 抖动/1 BendSSS，远处淡出。

3光追阴影：硬件 RT 参考级精确阴影，默认关，必须配降噪器（Denoiser=2）。

4三者都是补充：与 CSM/VSM/DFShadow 叠加提质，而非替代主阴影。
