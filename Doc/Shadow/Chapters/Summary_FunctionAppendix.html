移动端函数与结构

InitDynamicShadows(...) // 移动端阴影初始化入口 BuildCSMVisibilityState(...) // 构建 CSM 可见性 EnableStaticMeshCSMVisibilityState(...) // 静态网格 CSM 可见性 RenderMobileScreenSpaceShadows(...) // 移动端屏幕空间阴影 RenderModulatedShadowProjections(...) // 调制阴影投射 struct FMobileCSMVisibilityInfo { ... }; // 可见性状态 bool bModulatedShadowsInUse; // 是否使用调制阴影

CSMShaderCullingMethod r.Mobile.Shadow.CSMShaderCullingMethod=1

值行为
0禁用剔除
1（默认）光视锥剔除
2合并投射体剔除
3光视锥 + 投射体
4全剔除
5配合距离场
+16位标志：改用球体测试
