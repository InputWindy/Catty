点光：单趟立方体阴影 OnePassPointLightShadow

点光是全向光源，一个像素可能被任何方向的物体挡住，所以阴影图必须是立方体（cubemap）——六个面各覆盖 90° 视锥，拼成全景。UE5 用单趟渲染（one pass）：借助几何着色器或多视图（multi-view）在一次绘制里把三角形分发到 6 个 cube 面，避免 6 次独立 draw。

// SetupWholeSceneProjection L1149 — 点光 6 面方向与上向量 const FVector CubeDirections[6] = { +X, -X, +Y, -Y, +Z, -Z }; const FVector UpVectors[6] = { ... }; // 每面对应的 up for (Face : 0..5) { OnePassShadowViewMatrices[Face] = MakeLookAt(LightPos, CubeDirections[Face], UpVectors[Face]); OnePassShadowViewProjectionMatrices[Face] = ViewMatrix * OnePassShadowFaceProjectionMatrix; } // 6 个面共享同一个 90° FOV 的反向 Z 透视投影 OnePassShadowFaceProjectionMatrix = FReversedZPerspectiveMatrix(PI/4, 1, 1, 1, Radius);

为什么是 FReversedZPerspectiveMatrix(PI/4,...)

PI/4 是半 FOV（即整个视锥 90°），六个 90° 视锥正好无缝拼满整个球面。Reversed-Z（反向 Z：近平面映射到 1、远平面到 0）是 UE 全线采用的深度精度技巧——浮点深度在近处精度更高，反向后正好把精度分配到最需要的近处，大幅减少点光阴影的 acne 与 z-fighting。近平面固定为 1（单位）、远平面为光源半径 Radius。

聚光：单个透视视锥 Spot light

聚光只照一个锥形区域，阴影图就是一张普通的透视 shadow map（EShadowDepthType::Spot）：投影视锥的 FOV 取聚光的外锥角，方向沿聚光朝向。它比点光便宜得多（一张图 vs 六个面），是室内灯光最常用的动态阴影。

点光Cubemap（6 面）6× 90° 透视，单趟渲高

局部光在 VSM 里的对应

点光/聚光在中篇 VSM 里走 局部光 VSM（#9）：不再是固定分辨率的 cubemap/2D 图，而是透视投影的 mip 链，远处光源退化为单页阴影图（single page）。本篇的"点光 6 面、聚光 1 面"结构在 VSM 里依然成立，只是每个面的存储换成了按需分配的物理页。

小结 Summary

1点光全向发光，用 Cubemap 立方体阴影；UE5 单趟渲染一次分发三角形到 6 面。

26 面共享 90° FOV 的 FReversedZPerspectiveMatrix(PI/4,1,1,1,Radius)，反向 Z 优化近处深度精度。

3聚光只需单张透视 shadow map（EShadowDepthType::Spot），成本远低于点光。

4二者在 VSM 里统一走局部光 VSM（#9），存储换成按需物理页。
