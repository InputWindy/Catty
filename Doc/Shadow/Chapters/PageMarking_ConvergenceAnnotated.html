#10 页标记 · 屏幕像素怎么点亮它需要的阴影页

VSM 只渲染"屏幕上真正看得到、需要阴影"的页——怎么知道哪些页需要？答案是页标记：从 GBuffer 深度出发，为每个屏幕像素反投影到光源空间、算出它落在哪张 VSM 的哪一页，把该页标记为"被请求"。本篇讲清 GeneratePageFlagsFromPixels、页标志位与层级页标志（HZB）。符号取自 UE5.8 VirtualShadowMapPageMarking.usf。

核心思路：让像素自己说需要哪页 Demand-driven

传统阴影图是"先渲整张图，再采样"；VSM 反过来——先让屏幕像素申报需求，再只渲被申报的页。这是整套 VSM 省显存/省渲染的动力来源：屏幕看不到的地方、被遮挡的地方、太远只需低 mip 的地方，其对应的高分辨率页根本不会被标记，也就不会被分配和渲染。

① 遍历屏幕像素GBuffer 深度 → 世界坐标
▶
② 反投影到光源算出落在哪张 VSM 的哪一 mip/页
▶
③ 标记该页置 VSM_FLAG_ALLOCATED 等标志

GeneratePageFlagsFromPixels VirtualShadowMapPageMarking.usf L320

// VirtualShadowMapPageMarking.usf — void GeneratePageFlagsFromPixels(...)（真实源码节选） const uint2 PixelPos = uint2(View.ViewRectMin.xy) + DispatchThreadId.xy * PixelStride; // PixelStride 抽样 float DeviceZ = LookupDeviceZ(PixelPos); // 从 GBuffer 深度出发 FGBufferData GBufferData = GetGBufferDataUint(PixelPos, true); half3 WorldNormal = GBufferData.WorldNormal; const FPositionData Primary = InitPositionData(PixelPos, DeviceZ, true); // → TranslatedWorldPosition // 遍历所有方向光 VSM，为该像素标记它需要的页 for (uint Index = 0; Index < VirtualShadowMap.DirectionalLightIdCount; ++Index) { FVirtualShadowMapHandle Handle = FVirtualShadowMapHandle::MakeFromId(VirtualShadowMap.DirectionalLightIds[Index]); if (bBackfaceCull && IsBackfaceToDirectionalLight(WorldNormal, ProjectionData.LightDirection, ...)) continue; // 背光面跳过 MarkPageDirectional(Handle, Primary.TranslatedWorldPosition, bUsePageDilation, PageDilationOffset, ...); }

MarkPageDirectional / MarkPageLocal 内部把像素反投影到该 VSM 的页坐标，并用原子 OR 写入请求标志（VSM_FLAG_ALLOCATED 等）：

页标志含义
VSM_FLAG_ALLOCATED该页需要被分配物理页
VSM_FLAG_PRIMARY_REQUEST主视图直接请求（非仅粗页外推）
VSM_FLAG_DETAIL_GEOMETRY需渲染细节几何（近处高分辨率）

抽样步长省开销

不必每个像素都标记：r.Shadow.Virtual.PageMarkingPixelStrideX/Y=2 表示每 2×2 像素抽 1 个来标记页——因为一页覆盖屏幕若干像素，抽样已足够。另有一条实验路径 GeneratePageFlagsFromFroxelsCS（r.Shadow.Virtual.MarkPagesUsingFroxels=0 默认关），用相机 froxel 体素而非像素来标记，可覆盖半透明/体积。

层级页标志：GenerateHierarchicalPageFlags HZB mip chain

标记完 Level 0 的页后，需要把"某页被请求"的信息向上传播到所有 mip 级——因为分配和缓存决策要在各 mip 级都知道下层是否有需求。GenerateHierarchicalPageFlags 构建一条页标志的 HZB（层级）链（NumHZBLevels=7）：父页 = 4 个子页标志的 OR。

与页表 HZB 的配合

这条层级页标志链同时服务于：分配（#7，快速统计各级需求页数）、投影（#12，采样时跳过未分配页）、以及 Nanite 的 逐页光栅剔除（只把几何光栅到被请求的页里，见 VirtualShadowMapBuildPerPageDrawCommands.usf）。页标记是 VSM "只做必要工作"哲学的入口。

小结 Summary

1VSM 是需求驱动：屏幕像素先申报需要哪页，再只渲被申报的页。

2GeneratePageFlagsFromPixelsCS 从 GBuffer 深度反投影到光源，标记页 VSM_FLAG_ALLOCATED / PRIMARY_REQUEST / DETAIL_GEOMETRY。

3抽样步长 PageMarkingPixelStrideX/Y=2 省开销；froxel 路径默认关。

4GenerateHierarchicalPageFlags 把请求向上传播成 HZB（7 级），服务分配/投影/Nanite 逐页光栅。
