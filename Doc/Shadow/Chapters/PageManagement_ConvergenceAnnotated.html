虚拟地址 → 物理页 The page table

和 CPU 的虚拟内存一样，VSM 有一张页表把虚拟地址翻译成物理地址：

// 虚拟地址由三部分组成 虚拟阴影图 ID (VirtualShadowMapId) // 哪盏灯 / 哪级 Clipmap / 哪级 mip + MipLevel // 局部光的 mip 级 + 页坐标 (PageAddress: uint2) // 该虚拟图内的 128×128 页网格坐标 // 页表项 → 物理页池里的物理页地址（PhysicalPageAddressBits=16，最多 64K 页）

和虚拟纹理是同一套机制

读过本文档集虚拟纹理书的读者会立刻认出：这就是"页表 + 物理页池 + 按需分页"。区别只是虚拟纹理流颜色/法线纹素、VSM 流深度纹素；虚拟纹理靠 GPU feedback 请求页、VSM 靠屏幕像素页标记（#10）请求页。物理页池是一整块大纹理（page pool），所有虚拟阴影图共享——这也是为什么方向光和局部光要统一编 ID、统一分配。

物理页元数据与四个列表 FPhysicalPageMetaData · page lists

每个物理页有一份元数据，记录它当前被谁占用、上次何时被请求：

// FPhysicalPageMetaData（VirtualShadowMapArray.h L147） struct FPhysicalPageMetaData { uint32 Flags; uint32 LastRequestedSceneFrameNumber; // 用于年龄回收（#11） uint32 VirtualShadowMapId; // 当前映射到哪个虚拟图 uint32 MipLevel; uint2 PageAddress; };

物理页在四个列表间流转（VirtualShadowMapPhysicalPageManagement.usf L34）：

REQUESTED = 3本帧被页标记请求，需要内容
▶
AVAILABLE = 1可分配的空闲页
▶
LRU = 0已用页按最近使用排序，最久未用优先回收
▶
EMPTY = 2清空待复用

分配 = 从 AVAILABLE/LRU 取页给 REQUESTED

每帧：先收集本帧被请求（REQUESTED）的页；能命中缓存（#11）的直接复用；未命中的从 AVAILABLE 取空闲页，不够就从 LRU 列表尾部（最久未被请求）回收旧页。LastRequestedSceneFrameNumber 就是 LRU 排序的依据。物理页总数受 r.Shadow.Virtual.MaxPhysicalPages=2048 硬限。

真实分配就是从 AVAILABLE 列表弹一个页、挂到 REQUESTED 列表：

// VirtualShadowMapPhysicalPageManagement.usf — void AllocateNewPageMappings(...)（真实源码） const uint RequestFlags = PageRequestFlags[GlobalPageOffset.GetResourceAddress()]; if (RequestFlags != 0) { const uint PageFlags = OutPageFlags[GlobalPageOffset.GetResourceAddress()] & VSM_PAGE_FLAGS_BITS_MASK; if (PageFlags == 0u) { // 尚未映射物理页 int PhysicalPageIndex = PopPhysicalPageList(PHYSICAL_PAGE_LIST_AVAILABLE); // 从空闲列表取 if (PhysicalPageIndex >= 0) { PushPhysicalPageList(PHYSICAL_PAGE_LIST_REQUESTED, PhysicalPageIndex); // 挂到本帧请求列表 uint2 PhysicalPageAddress = VSMPhysicalIndexToPageAddress(PhysicalPageIndex); // ... 写页表项、更新 FPhysicalPageMetaData ... } } }

动态分辨率：页池满了怎么办 DynamicRes

如果场景太复杂、请求的页数超过物理池容量，VSM 不会崩，而是全局降低分辨率——提高所有虚拟图的 ResolutionLodBias，让每个屏幕像素采样更粗的 mip/更大的世界范围，从而减少所需页数：

// 页池负载超阈值 → CPU(VirtualShadowMapArray.cpp)抬高全局 LOD bias，shader 用 uniform 消费 float GlobalLodBias = VirtualShadowMap.GlobalResolutionLodBias; // 采样更粗 mip → 少请求页 // 上限 r.Shadow.Virtual.DynamicRes.MaxResolutionLodBias = 2.0；触发阈值 MaxPagePoolLoadFactor = 0.85

优雅降级而非硬失败

这是 VSM 相比传统"固定分辨率阴影图"的又一优势：显存压力下自动降质而非丢阴影或崩溃。r.Shadow.Virtual.DynamicRes.MaxResolutionLodBias=2.0 限制最多降 2 级（分辨率降到 1/4）。配合 #11 的缓存，绝大多数场景根本用不满页池。

小结 Summary

1VSM 用页表把虚拟地址（VSM ID + mip + 页坐标）翻译成物理页——与虚拟纹理同一套机制。

2每物理页有 FPhysicalPageMetaData（含 LastRequestedSceneFrameNumber），在 LRU/AVAILABLE/EMPTY/REQUESTED 四列表间流转。

3分配 = 把 AVAILABLE/LRU 的页给本帧 REQUESTED 的页；池上限 MaxPhysicalPages=2048、寻址 PhysicalPageAddressBits=16。

4页池负载超 0.85 触发动态分辨率降级（提 LodBias，上限 2.0），优雅降质不崩溃。
