★ #8 Clipmap 方向光 VSM · 5.8 的大改（全书重点）

本书最重要的一章。UE5.4→5.8，方向光 VSM 全面转向 Clipmap：以相机为中心的一组同心方形阴影环，每级半径按 2^(level+1) 指数增长，近处细远处粗，跨级共享物理页池。本篇讲清 Clipmap 层级配置、per-level 世界中心 snapping、LOD bias、逐级失效判定，以及 5.8 四大新特性：接收者掩码、第一人称阴影、远距离预过滤、动态物紧剔除。符号取自 UE5.8 VirtualShadowMapClipmap.h/.cpp（CPU 建级）与 VirtualShadowMapProjectionCommon.ush（GPU 选级）。

什么是 Clipmap Camera-centered concentric rings

方向光在 CSM 里是"把视锥切成几段"（#3）；VSM 换了个思路——Clipmap：以相机为中心，套一组同心的方形阴影"环"，每一级（level）覆盖的世界范围是上一级的两倍，但都用同样的 128×128 页网格。近处的级半径小、每纹素覆盖的世界范围小（分辨率高）；远处的级半径大、分辨率低。这与虚拟纹理书里的 Clipmap 范式完全同源。

// VirtualShadowMapClipmap.cpp — 每级半径指数增长 float GetLevelRadius(int AbsoluteLevel) { return FMath::Pow(2.0f, AbsoluteLevel + 1.0f); } // Level 6 → 半径 128 单位；Level 8 → 512；Level 18 → 524288；Level 22 → 8388608 int GetClipmapLevel(int ClipmapIndex) { return FirstLevel + ClipmapIndex; }

层级范围：结构默认 vs CVar 默认

务必区分两处默认值：结构体 FVirtualShadowMapClipmapConfig 的字段初值是 FirstLevel=8 / LastLevel=18；但真正运行时用的是 GetGlobal() 从 CVar 读的值——r.Shadow.Virtual.Clipmap.FirstLevel=6、LastLevel=22。也就是说默认相机周围有 Level 6~22 共 17 级 clipmap，覆盖从 128 单位到约 800 万单位（大世界尺度）。RadiiPerLevel=4：每级用 4 个 clipmap 半径覆盖，保证相邻级重叠过渡。

构造：LOD scale、snapping 与投影 Constructor L200

Clipmap 构造函数（L200）建立每级的投影与世界中心：

// 1) 世界→光源视图旋转 WorldToLightViewRotationMatrix = ...; // 2) LOD scale：把虚拟分辨率映射到相机视口宽度 LodScale = 0.5 / ProjectionScale.X * VirtualMaxResolutionXY / CameraViewportWidth; ResolutionLodBias = InterpolateResolutionBias + Log2(LodScale); // 3) per-level 世界中心 snapping（关键：让缓存页可整体平移复用） SnapSize = RawLevelRadius; // = GetLevelRadius(AbsoluteLevel) WorldCenter = RoundToDouble(ViewCenter / SnapSize) * SnapSize; // 4) 每级投影用反向 Z 正交 ViewToClip = FReversedZOrthoMatrix(...);

snapping：Clipmap 缓存的前提（承接 #3）

和 CSM 稳定 snapping 同源：每级世界中心按该级半径取整（RoundToDouble(ViewCenter/SnapSize)*SnapSize）。相机小幅移动时，多数级的 snap 后中心不变，其物理页可原地复用；当移动跨过一个 snap 网格，中心整体平移一个/几个页——此时缓存管理器（#11）用 PageAddressOffset 把旧页整体搬到新位置（VSM_NEXT_FLAG_KEEP_PAGE），只需补渲边缘新露出的页。这就是 Clipmap 能高效缓存的根本。

逐级失效判定 UpdateClipmapLevel L259

每级独立判断本帧是否需要失效重渲：

// UpdateClipmapLevel（VirtualShadowMapCacheManager L259） bool bInvalidate = ViewRadiusZ 变化 // 深度范围变了 || (DeltaZ + LevelRadius) > 0.9 * ViewRadiusZ; // 相机沿光轴移动越界 if (!bInvalidate) { NextData.Flags = VSM_NEXT_FLAG_KEEP_PAGE; // 保留缓存页 NextData.PageAddressOffset = CurrentToPreviousPageOffset; // 整体平移量 }

far plane 与紧剔除

Clipmap 每级用 FReversedZOrthoMatrix；当开启 bForceInvalidate && bCullDynamicTightly 时，远平面被设为 CullingEndDistance = GetLevelRadius(AbsoluteLevel - ResolutionLodBias)，把动态物剔除范围紧贴该级实际覆盖，减少无谓的深度渲染。

其它投影 Flags

ComputeProjectionShaderData 还会设 VSM_PROJ_FLAG_UNCACHED（本帧未缓存）、VSM_PROJ_FLAG_IS_COARSE_CLIP_LEVEL（粗 clipmap 级，Level 15~18 由 FirstCoarseLevel/LastCoarseLevel 界定）。这些 Flags 在 #12 投影 CS 里被读取，决定采样路径。5.8 这四个特性的净效果：第一人称武器阴影更清晰、远景阴影更省、动态物剔除更准，是 VSM 从"能用"走向"电影级默认"的关键一步。

Shader 侧：世界位置 → clipmap 级 VirtualShadowMapProjectionCommon.ush

上面的 GetLevelRadius / snapping / 失效都是 CPU（VirtualShadowMapClipmap.cpp）在建每级投影。到了 GPU，页标记（#10）与投影（#12）需要反过来问：某个世界位置该用哪一级 clipmap？这正是 CPU 侧 GetLevelRadius = pow(2, level+1) 的逆运算——取到 clipmap 原点的距离再 log2：

// VirtualShadowMapProjectionCommon.ush（真实源码） float CalcAbsoluteClipmapLevel(float DistanceToClipmapOriginSquared) { // log(X*X) <=> 2 * log(X) return log2(DistanceToClipmapOriginSquared) * 0.5f; // 距离越远 → 级数越高（越粗） } float CalcDistanceToClipmapOriginSquared(FVirtualShadowMapProjectionShaderData Base, float3 TranslatedWorldPosition) { float3 ViewToShadowTranslation = DFFastLocalSubtractDemote(Base.PreViewTranslation, PrimaryView.PreViewTranslation); float3 TranslatedWorldOrigin = -Base.ClipmapWorldOriginOffset + ViewToShadowTranslation; return length2(TranslatedWorldPosition + TranslatedWorldOrigin); // 到相机中心的距离² }

算出绝对级后，减去该 VSM 的基准级 ClipmapLevel 得到级索引，再用它偏移到对应那一级的虚拟阴影图（每级一个 VSM ID、连续排布）：

// VirtualShadowMapPageMarking.usf 与投影采样共用（真实源码节选） int ClipmapIndex = max(0, BiasedLevel - BaseProjectionData.ClipmapLevel); if (ClipmapIndex < BaseProjectionData.ClipmapLevelCountRemaining) { FVirtualShadowMapHandle VSMHandle = BaseProjectionData.VirtualShadowMapHandle.MakeOffset(ClipmapIndex); // → 用该级 VSM 标记页 / 采样深度 }

CPU 建级、GPU 选级

这条 log2 就是 Clipmap"每级半径 2 倍增长"在 shader 里的体现：世界位置离相机越远，DistanceToClipmapOriginSquared 越大，log2(dist²)·0.5 得到越高的绝对级（分辨率越粗）。CPU 侧的 ClipmapWorldOriginOffset、ClipmapLevel、ClipmapLevelCountRemaining 都打包进 FVirtualShadowMapProjectionShaderData（VirtualShadowMapProjectionStructs.ush，ClipmapLevel 与 CountRemaining 用一个 uint 位打包、带 VSM_PACKED_CLIP_LEVEL_BIAS 偏置）供 shader 消费。#10 页标记与 #12 投影都走这套选级逻辑。

小结 Summary

1方向光 VSM = Clipmap：以相机为中心的同心方环，每级半径 2^(level+1)，近细远粗，共享页池。

2层级默认 CVar FirstLevel=6/LastLevel=22（结构体默认 8/18，运行时以 CVar 为准）。

3每级世界中心按该级半径 snap，是缓存页整体平移复用（PageAddressOffset + KEEP_PAGE）的前提；越界或 ViewRadiusZ 变化才失效。

45.8 四大新特性：接收者掩码（默认开）、第一人称阴影、远距离预过滤、动态物紧剔除（默认开）——提质提速，见 ComputeProjectionShaderData 的 Flags。

5CPU 建级、GPU 选级：shader 用 CalcAbsoluteClipmapLevel = log2(dist²)·0.5（GetLevelRadius 的逆运算）把世界位置映射到 clipmap 级，#10/#12 共用。
