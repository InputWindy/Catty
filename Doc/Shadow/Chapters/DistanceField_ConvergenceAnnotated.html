#13 距离场阴影 · 用 SDF 光线步进的软阴影

进入专项阴影篇。距离场阴影（DFShadow）不用阴影图，而是对场景的有符号距离场（Mesh Distance Field）做光线步进（sphere tracing）求遮挡，天然产生软阴影、适合大范围方向光/远景，也是 Lumen 的近亲。本篇讲清 DFShadow 的开关、质量档、tile 剔除与射线步进。符号取自 UE5.8 DistanceFieldShadowing.cpp。

不用阴影图，用距离场 Sphere tracing occlusion

每个网格预烘一张 Mesh Distance Field（体素化的有符号距离场，记录到最近表面的距离）。求阴影时，从接收点朝光源发一条射线，用 sphere tracing 步进：每步跳过"当前点到最近表面的距离"，若途中距离场值很小说明贴近遮挡物——用最小 圆锥半角估计软阴影强度。

// DistanceFieldShadowing.cpp — 射线步进求遮挡 RayTraceShadows(...): for (step = 0; step < MaxSteps; ++step) { dist = SampleMeshDistanceField(pos); minConeAngle = min(minConeAngle, dist / distAlongRay); // 软阴影 pos += rayDir * dist; }

DFShadow 的定位

距离场阴影擅长大范围、远景、静态几何的柔和阴影，开销与阴影图分辨率无关（分辨率来自 SDF 体素）。它需要 SM5+，且是很多"低配 Lumen / 无 VSM"配置下的方向光远景阴影方案。缺点：只对有 SDF 的网格有效（不支持骨骼动画细节、半透明）。

tile 剔除加速 Scatter / Tiled culling

为避免每像素遍历所有 SDF 物体，先按屏幕 tile 把可能影响该 tile 的 SDF 物体剔除聚集：

DFS_DirectionalLightScatterTileCulling方向光 scatter 剔除（默认）
DFS_DirectionalLightTiledCulling方向光 tiled 剔除
DFS_PointLightTiledCulling点光 tiled 剔除

CullDistanceFieldObjectsForLight 每 tile 收集候选物体，r.DFShadowAverageObjectsPerCullTile=128 预留每 tile 平均物体数，r.DFShadowCullTileWorldSize=200 定 tile 世界尺寸。

质量档 r.DFShadowQuality

档位行为
0关闭
1 low20 步，无软阴影(SSS)
2 medium32 步，无 SSS
3 high（默认）64 步 + 软阴影

与 VSM 的关系

DFShadow 与 VSM 不冲突——常见搭配是 VSM 管中近景高精度阴影、DFShadow 补远景/大尺度柔和阴影。GetDistanceFieldShadowRange 决定二者交接距离。DFShadow 也可异步计算（r.DFShadowAsyncCompute=0 默认关）。高度场阴影 r.HeightFieldShadowing=0 是它对地形的变体。

小结 Summary

1DFShadow 用 Mesh Distance Field + sphere tracing 求遮挡，天然软阴影，开销与阴影图分辨率无关。

2最小圆锥半角估计软阴影强度；RayTraceShadows 逐步跳过最近表面距离。

3tile 剔除（scatter/tiled）聚集候选物体；每 tile 均值 128、tile 世界尺寸 200。

4质量档 r.DFShadowQuality 默认 3（64 步 + SSS）；擅长远景/大尺度，需 SM5+，与 VSM 互补。
