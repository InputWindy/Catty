UE Shadow 阴影系统源码解析 · 总目录

阴影（Shadow）是实时渲染里最"贵"也最容易出瑕疵的一环：它要回答"从光源看，这个像素被谁挡住了"。UE 从最早的 Shadow Map（阴影深度图）一路演进到 级联阴影 CSM、点光/聚光的立方体阴影、Per-Object 阴影，再到 UE5 的划时代方案 Virtual Shadow Map（VSM，虚拟阴影贴图）——把阴影也做成"数据大于显存、按需分页"的虚拟纹理，配合 Nanite 得到近乎逐像素分辨率的阴影。UE5.4→5.8，方向光 VSM 从早期实现全面转向 Clipmap（以相机为中心的多层同心阴影环），并在 5.8 引入接收者掩码、第一人称阴影、远距离预过滤、动态物紧剔除等新特性——这是本书的重点。此外还有距离场阴影、Capsule 阴影、Contact（屏幕空间）阴影、光线追踪阴影、移动端 CSM/Modulated 阴影等专项方案。本书对照 UE5.8 本地源码 ShadowRendering.cpp / ShadowSetup.cpp / VirtualShadowMap*.cpp 等，按"传统 → VSM 核心 → 专项"三篇逐类解析。每主题含一份主文档（设计动机 + 数据流骨架 + 分阶段批注）与一份函数附录（类 / 函数 / permutation / CVar 细节）。所有符号名、CVar 默认值均取自 UE5.8 本地源码。

这本书怎么读

所有阴影贴图方案的本质都是一句话：先从光源视角渲一张深度图（谁离光最近），再从相机视角把每个像素变换到光源空间比较深度——比记录值远就是在阴影里。建议第一次按 #1 → #2 → #3 把这条主线走通：#1 总览建立"深度比较 + 投影阴影 FProjectedShadowInfo + 阴影类型全景"；#2 阴影深度渲染讲"怎么从光源渲深度图（含 Nanite 路径）"；#3 CSM 级联讲"方向光怎么按距离切多级分辨率"。传统篇通了，直接进中篇 VSM——这是 UE5 的核心：#6 总览 → #7 物理页/页表 → #8 Clipmap 方向光（★全书重点，5.8 大改） → #10 页标记 → #11 缓存失效 → #12 投影采样 SMRT。关键常量：VSM 页大小 VSM_PAGE_SIZE = 128、虚拟分辨率上限 16384（16K）、物理页池默认 r.Shadow.Virtual.MaxPhysicalPages = 2048、Clipmap 层级默认 FirstLevel=6 / LastLevel=22。若读过本文档集 Nanite 与虚拟纹理篇，VSM 正是"Nanite 几何 + 虚拟纹理页表"在阴影上的合体。

一眼看懂：一次阴影渲染的四个阶段

① 阴影设置 SetupInitDynamicShadows
按光源类型建 FProjectedShadowInfo
CSM 切级联 / VSM 分页请求
② 深度渲染 DepthRenderShadowDepthMaps
从光源视角渲深度（Atlas / Cubemap / VSM 物理页）
Nanite 走 RenderVirtualShadowMaps
③ 投影 ProjectionRenderShadowProjections
相机像素变换到光源空间比深度
SMRT 光线步进 / PCF 过滤
④ 合成 Composite写 ScreenShadowMaskTexture
→ 光照 pass 采样阴影因子
多光源打包 ShadowMaskBits

传统阴影贴图与 VSM 共享这条主线，区别在深度存哪与怎么采：传统方案把深度渲进一张固定分辨率的 Atlas/Cubemap，用 PCF 采样；VSM 把深度渲进按需分配的物理页（虚拟分辨率 16K），只为"屏幕上真正需要阴影的像素"分配页，再用 SMRT（Shadow Map Ray Tracing）沿阴影图做小步进采样得到软阴影。详见 #1 与 #6。

与本文档集其它篇的关系

阴影是几何、纹理、光照的交汇点

本书（UE Shadow）与 Nanite 解析、虚拟纹理解析、Lumen GI 解析、MegaLights 解析、TSR 解析 同属一套渲染世界观。VSM 是三者的合体：它借用虚拟纹理的"页表 + 物理页池 + 按需分页"范式（本书 #7 与虚拟纹理书的页表式流送、Clipmap 篇是同一套结构）、依赖 Nanite 的多视图批处理渲深度（每个阴影视图=一个 Nanite view，NANITE_MAX_VIEWS_PER_CULL_RASTERIZE_PASS=4096），并与 MegaLights 在"多光源阴影可见性"上互补——MegaLights 用随机采样+光追解耦光源数，VSM 用页表把每盏灯的阴影图虚拟化。读完这几本，"几何 → 纹理 → 光照 → 阴影 → 上采样"的 UE5 渲染主链路就完整了。建议先读 Nanite 主干与虚拟纹理页表篇，再回到本书中篇 VSM。
