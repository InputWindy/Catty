ShadowPercentageCloserFiltering.ush 整源解析库 / PCSS 软阴影

阴影的PCSS（可变半影软阴影）库（372 行）：先做遮挡物搜索估平均遮挡距离，据此算出与"遮挡物-接收面距离"成正比的滤波核——接触处硬、远处软，逼近真实半影。含 Poisson 核、2×2 quad 共享、后置锐化。下方内嵌完整 372 行真实源码，再逐段真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/ShadowPercentageCloserFiltering.ush

FPCSSSamplerSettings + 遮挡物搜索 + 可变核 PCF + 后置锐化

0. 遮挡物搜索 + 可变半影（核心）

#define PCSS_SEARCH_SAMPLES (1 << PCSS_SEARCH_BITS)   // 遮挡物搜索样本数(16)
#define PCSS_SAMPLES (1 << PCSS_SAMPLE_BITS)          // 滤波样本数(32)
#define PCSS_SHARE_PER_PIXEL_QUAD 2   // 2×2 quad 内共享遮挡搜索 + PCF 结果
// 1) blocker search：Poisson 采样估平均遮挡深度 zBlocker
// 2) 半影宽 wPenumbra ∝ (zReceiver - zBlocker) / zBlocker   → 决定滤波核大小
#define PCSS_ENABLE_POST_PCF_SHARPENING 1   // 后置锐化，边缘比阴影图分辨率更锐

说明

PCF 是固定核（半影恒宽，不真实）；PCSS 模拟真实半影：① 遮挡物搜索——在接收点周围用 Poisson 分布采 16 个样本，估出平均遮挡物深度 zBlocker；② 按相似三角形算半影宽 ∝ (zReceiver - zBlocker)/zBlocker——遮挡物离接收面越远半影越宽（接触硬、远处软）；③ 用这个可变核做 32 样本 PCF。PCSS_SHARE_PER_PIXEL_QUAD 在 2×2 像素 quad 内共享遮挡搜索结果省一半开销（用 PixelQuadMessagePassing）。POST_PCF_SHARPENING 后置锐化让边缘比阴影图分辨率更清晰。由 投影 PS 的 USE_PCSS 路径调用（r.Shadow.PCSS）。
