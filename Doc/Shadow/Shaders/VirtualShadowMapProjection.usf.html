0. Morton tile + 反投影世界位置（发散点）

uint2 LocalPixelPos = WORK_TILE_SIZE * TileCoord + MortonDecode(GroupIndex);   // Morton 序提高页访问相干性
float DeviceZ = SceneTexturesStruct.SceneDepthTexture.Load(int3(PixelPos, 0)).r;
if (bIsHairInput) DeviceZ = HairStrands.HairOnlyDepthTexture.Load(...).x;   // 发丝子像素
const float3 TranslatedWorldPosition = SvPositionToTranslatedWorld(SvPosition);
const float Noise = BlueNoiseScalar(SvPosition.xy, View.StateFrameIndex);   // 蓝噪抖动样本

说明

本 CS 按 Morton 序组织组内像素（MortonDecode(GroupIndex)）——让相邻线程访问相近的 VSM 页/原子，提高 cache 相干性、支持 wave 内梯度。逐像素取场景深度反投影出世界位置（发丝走 HairOnlyDepthTexture），再取蓝噪抖动 SMRT 射线起点/方向（时域累积去噪）。GetProjectionShadingInfo 取该像素的着色信息（是否次表面等）。这是 deferred 阴影采样：与经典 ShadowProjection PS 对应，但目标是 VSM 而非单张阴影图。

1. SMRT 阴影图射线步进求软阴影（汇聚点）

// 对每条采样射线：沿光向在 VSM 深度上步进（穿页读物理页深度）
// 比较射线深度 vs 阴影图深度 → 命中即遮挡；多射线平均得软阴影
// SMRT：Shadow Map Ray Tracing，用阴影图当"高度场"做 ray march
// 次表面：SubsurfaceOpacityMFP 走透射；结果写 shadow mask

说明

本 shader 的汇聚点是 SMRT（Shadow Map Ray Tracing）：不做单点深度比较（会硬 + acne），而是把 VSM 当高度场，从接收点沿光源方向发若干条射线在阴影图上步进——射线若在中途被更高的阴影图深度挡住即命中。多条抖动射线（蓝噪 + 时域）平均得到接触硬、远处软的高质量软阴影，且天然自适应半影、极大缓解 peter-panning。透射像素走 SubsurfaceOpacityMFP。SMRT 的实现细节见 SMRTCommon / SMRTTemplate。这是 VSM 相较传统 PCF 的画质飞跃。
