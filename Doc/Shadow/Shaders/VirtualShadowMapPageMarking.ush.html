0. clipmap/mip 级选择（核心）

int GetBiasedClipmapLevel(FVirtualShadowMapProjectionShaderData Base, float3 TranslatedWorldPosition, float ExtraBias)   // 方向光
uint GetMipLevelLocal(FVirtualShadowMapProjectionShaderData ProjectionData, float3 TranslatedWorldPosition, float SceneDepth, float ExtraBias = 0.0f)   // 局部光
// 由屏幕像素与阴影纹素的比例，选够用的最粗级 → 省页
// ExtraBias（含 Throttle 的分辨率偏置）整体拉粗

说明

页标记时对每个可见点要决定"用多精细的阴影"。本库做级选择：GetBiasedClipmapLevel（方向光 clipmap）与 GetMipLevelLocal（局部光 mip）按屏幕像素与阴影纹素的比例——阴影纹素若比屏幕像素还密就是浪费，选够用的最粗级。ExtraBias 把 Throttle 的分辨率偏置叠进来（过载时整体拉粗省页）。选好的级传给 页标记 CS 标记对应页。这是 VSM"按需分辨率"的决策层——近处清晰、远处省算的关键。
