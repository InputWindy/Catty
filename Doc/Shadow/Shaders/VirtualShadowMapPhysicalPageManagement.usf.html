0. 物理页空闲列表操作（发散点）

void SetPhysicalPageListItem(uint PageList, int Index, int Value)
void SetPhysicalPageListCount(int PageList, int NewCount)
[numthreads(VSM_DEFAULT_CS_GROUP_X, 1, 1)] void InitPageRectBounds(uint3 Index : SV_DispatchThreadID)
// 多个物理页列表：Free（空闲）/ Allocated（本帧分配）/ Empty 等

说明

物理页池是固定大小的显存（如 3072² 纹素分成若干页）。本 shader 用几条 GPU 侧的链表/计数列表管理它：SetPhysicalPageListItem/Count 维护 Free（空闲页）、Allocated（本帧新分配）等列表；InitPageRectBounds 初始化每个 VSM 的页矩形边界。整个分配在 GPU 上并行完成（无 CPU 回读），这是 VSM 能每帧动态重分配数千页而不卡的前提。

说明

汇聚点：UpdatePhysicalPageAddresses 把标记后的虚拟页解析到物理页——缓存命中（该虚拟页上帧渲过、内容未被 失效）就复用旧物理页、完全跳过重渲染（VSM 缓存的最大收益：静态场景近乎零阴影渲染）；未命中则从 Free 列表分配，池满时按 LRU 回收最久未访问的页。最终写回页表建立"虚拟页→物理页"映射，供深度渲染（写）与投影采样（读）双向使用。这套 GPU 端动态分配 + 帧间缓存正是 VSM 相较传统 CSM 的核心革新。
