0. 深度加权双边上采样（核心）

void UpsampleShadowFactors(float2 ScreenUV, float SceneDepth, ...)   // 全分辨率像素查半分辨率结果
#define BILATERAL_UPSAMPLE 1
// 取半分辨率 2×2 邻域样本，各自的深度与全分辨率 SceneDepth 比较
// 深度越接近权重越大 → 加权平均（拒绝跨深度边界的样本）
// 避免直接双线性在物体边缘处的漏光/糊边

说明

胶囊阴影、距离场阴影常在半分辨率计算省算力，再上采回全分辨率。若直接双线性会在深度不连续处（物体边缘）把前景与背景的阴影混在一起——漏光或糊边。UpsampleShadowFactors 用双边上采样：取半分辨率 2×2 邻域，每个样本按其深度与当前全分辨率像素 SceneDepth 的接近程度加权（深度差大则权重趋 0，等于拒绝跨边界样本），只混合同一表面的阴影。这样既省了 4× 阴影计算，又保住锐利正确的边缘。BILATERAL_UPSAMPLE 开关可退化为普通双线性（低端设备）。
