0. VSM 投影数据契约（核心）

#define VSM_PSD_OFFSET_LIGHT_TYPE 220
#define VSM_PSD_OFFSET_RESOLUTION_LOD_BIAS 252   // CPU/GPU 共享的字节偏移
struct FVirtualShadowMapProjectionShaderData {
    float4x4 ShadowViewToClipMatrix; ... 光型/世界中心/clipmap 级/分辨率偏置 ...
};   // 从 ByteAddressBuffer 按偏移解包

说明

每张 VSM 需要一组投影参数（视→裁剪矩阵、光型 directional/spot/point、世界中心、clipmap 级、分辨率 LOD 偏置等）。FVirtualShadowMapProjectionShaderData 是它们的结构定义，由 CPU 端打包进 ByteAddressBuffer、GPU 各 pass 按 VSM_PSD_OFFSET_* 字节偏移解包（注释里明说这是权宜之计，理想应用 offsetof/StructuredBuffer）。这是页标记、投影、失效、节流等所有 VSM pass 共享的数据契约——统一了 CPU 与 GPU 对"一张 VSM 是什么"的理解。Throttle 改的 ResolutionLodBias 就写在这里。
