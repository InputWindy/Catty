完整源码（逐行真实） · Engine/Shaders/Private/VirtualShadowMaps/VirtualShadowMapComputeExplicitChunkDrawsViewMask.usf

ComputeExplicitChunkDrawsViewMask @ L12（numthreads 64）

0. 计算块的视图位掩码（核心）

[numthreads(64, 1, 1)] void ComputeExplicitChunkDrawsViewMask(...)
// 对每个显式几何 chunk，测试它与各 VSM 视图的相交
// 相交的视图对应位置 1 → 组成一个 uint 视图位掩码
// 供后续按位掩码把 chunk 分派到需要它的视图绘制

说明

VSM 一帧有多个视图（各 clipmap 级/立方体面）。对于以"显式块"组织的几何（explicit chunk，一批预分组的实例/图元），本 shader 逐 chunk 算出它需要出现在哪些视图——用一个 uint 位掩码紧凑表示（第 i 位=1 表示要渲进第 i 个视图）。后续绘制可直接按位掩码分派，避免逐视图重复相交测试。这是 逐页绘制指令 之外、针对显式块几何的一条更轻量的多视图分派路径。
