MainPS @ L17（按 InstanceId 上色 + N·V shading）

0. 按实例 ID 伪色 + N·V 明暗（核心）

uint InstanceId = DebugAuxTexture.Load(int3(DebugAuxPixelPosition, 0));
float Shading = SceneColorTexture.Load(...).r; // DebugViewMode 输出的 dot(N,V) 明暗
if (InstanceId == 0xFFFFFFFF) discard;   // 非投影者像素丢弃
FInstanceSceneData InstanceData = GetInstanceSceneData(InstanceId);   // 取实例信息上色

说明

调试可视化的一环：DebugAuxTexture 里存了每像素的投影者实例 ID（VSM 渲染时写入），MainPS 读它——0xFFFFFFFF 表示非投影者、直接 discard；否则用 GetInstanceSceneData(InstanceId) 取实例信息映射到伪色，再乘上 SceneColorTexture 里的 N·V 明暗（DebugViewMode 输出的法线-视线点积，给伪色加立体感）。效果是场景里每个投射阴影的物体显示为一种独特颜色 + 光照——直观看清"谁在投影、被归为哪个实例、几何是否重复"。纯调试。
