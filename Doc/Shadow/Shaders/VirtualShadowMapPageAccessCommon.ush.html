VSM_FLAG_* 页标志 + 页表项打包/解包 + 虚拟↔物理映射

0. 页标志位 + 页表项映射（核心）

#define VSM_FLAG_ALLOCATED       (1U << 0)   // 已分配物理页
#define VSM_FLAG_DYNAMIC_UNCACHED (1U << 1)   // 动态几何，未缓存（每帧重渲）
#define VSM_FLAG_STATIC_UNCACHED  (1U << 2)   // 静态几何，未缓存
// 页表项打包：物理页地址 + 标志 + mip 信息 → uint
// 虚拟页坐标 → 页表索引 → 解包出物理页地址

说明

VSM 全靠页表（一张 uint 缓冲）把虚拟页映射到物理页，本库是它的读写协议。定义了页标志位：ALLOCATED（是否已分物理页）、DYNAMIC_UNCACHED/STATIC_UNCACHED（动态/静态几何是否需要重渲——缓存判定的关键位）等；提供页表项的打包/解包（把物理页地址+标志+mip 压进一个 uint）与虚拟↔物理坐标转换。页管理写它、投影读它、失效改它——是 VSM 所有页操作绕不开的中枢。理解 VSM 先理解这里的标志位语义。
