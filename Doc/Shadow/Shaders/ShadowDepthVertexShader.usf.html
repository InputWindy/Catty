0. 世界位置 + WPO + First-Person 变换（发散点）

float4 WorldPos = VertexFactoryGetWorldPosition(Input, VFIntermediates);
FMaterialVertexParameters VertexParameters = GetMaterialVertexParameters(Input, VFIntermediates, WorldPos.xyz, TangentToLocal);
WorldPos.xyz += GetMaterialWorldPositionOffset(VertexParameters);   // 材质顶点偏移（风吹草动等）
ApplyMaterialFirstPersonTransform(VertexParameters, WorldPos.xyz);
#if INTERPOLATE_VF_ATTRIBUTES  OutParameters.FactoryInterpolants = ...;   // masked 材质需 UV 裁剪

说明

阴影深度渲染必须与主渲染顶点变换完全一致，否则会产生自阴影瑕疵（peter-panning/acne）。故这里同样跑 GetMaterialWorldPositionOffset（材质 WPO，如植被摆动）、First-Person 变换——确保阴影跟随几何形变。INTERPOLATE_VF_ATTRIBUTES 只对 masked 材质输出 UV（PS 要按 mask 裁剪），不透明材质省掉插值。PositionOnlyMain 是不带材质属性的快速路径（纯位置，用于不需要 mask 的场景）。

1. 按 ShadowDepthType 分派投影变换（汇聚点）

#if SUPPORT_SHADOW_DEPTH_VSM   // 虚拟阴影图
FPageInfo PageInfo = UnpackPageInfo(InstanceCulling.PageInfoBuffer[InstanceIdIndex]);
OutPosition = TransformShadowVSM(OutParameters.VirtualSmPageClip, PageInfo, WorldPos.xyz);
#if SUPPORT_SHADOW_DEPTH_DIRECTIONAL   OutPosition = TransformShadowDirectional(ProjectionMatrix, ViewMatrix, WorldPos, WorldNormal);
// Spot/Point/OnePassPointLight 各有对应 Transform 分支

说明

本 VS 的汇聚点：同一份 shader 按 PassStruct.ShadowDepthType 走不同投影——VSM（虚拟阴影图，用 PageInfo 把顶点变到对应物理页的裁剪空间 + VirtualSmPageClip 页内裁剪）、方向光（正交投影 + 沿法线的深度偏移抗 acne）、聚光/点光（透视投影，PS 写 SV_DEPTH）、OnePassPointLight（几何/实例化到立方体 6 面）。这套 permutation 让一份深度 shader 覆盖 UE 所有阴影投影类型——是 阴影深度的统一入口。
