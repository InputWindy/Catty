0. 三种投影覆盖几何（核心）

void ShadowProjectionNoTransformVS(...) { OutPosition = float4(InPosition.xyz, 1); }   // 全屏四边形
void ShadowVolumeBoundProjectionVS(...) {   // per-object 阴影体包围盒
    float4 UnprojectedVertex = mul(float4(InPosition.xyz, 1), InvReceiverInnerMatrix);
    float3 WorldPosition = OutVertex * StencilingGeometryPosAndScale.w + StencilingGeometryPosAndScale.xyz;
    OutPosition = mul(float4(WorldPosition, 1), ResolvedView.TranslatedWorldToClip); }

说明

阴影投影 PS 只跑"落在阴影影响范围内"的像素，所以 VS 负责生成合适的覆盖几何限制 PS 调用：全屏光（方向光整级 cascade）用 NoTransformVS 画全屏四边形；per-object 阴影用 ShadowVolumeBoundProjectionVS 画该物体阴影体的世界包围盒（InvReceiverInnerMatrix 反投影出体积角点，只让盒内像素跑 PS，省开销）；方向光 cascade 用 WholeSceneDirectionalShadowStencilVS 配合模板测试把 PS 限制在该 cascade 的深度区间。VS 极简，重活都在 投影 PS。
