0. Rec.601 亮度加权去饱和（核心）

float Grayscale(float3 SourceClr) {
    return 0.299 * SourceClr.r + 0.587 * SourceClr.g + 0.114 * SourceClr.b;   // Rec.601 亮度权重
}

说明

最小的一个 VSM shader：Grayscale 用 Rec.601 亮度权重（0.299R+0.587G+0.114B，符合人眼对绿最敏感）把彩色转灰。DesaturatePS 采 InputTexture 输出灰度。用途是 VSM 调试可视化 时先把场景颜色压成灰底，再叠加高饱和的伪色调试层（页/缓存/mip），让调试信息一眼可辨、不被原画面色彩干扰。纯工具 shader，与阴影算法无关但归属 VSM 模块。
