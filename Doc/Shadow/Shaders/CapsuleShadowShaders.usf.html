说明

胶囊体阴影不仅做直接光，还做间接/天光软阴影。本 CS 为每个待遮蔽点从体积光照图（Volumetric Lightmap）算出主要光照方向：天光模式 2 从球谐（SH）辐照度取最强方向 + 一个锥角（CapsuleIndirectConeAngle——间接光是宽锥形软阴影）；模式 1 用预烘焙的 SkyBentNormal（天光可见性方向）。有了方向 + 锥角，后续入口对每个胶囊做锥形-胶囊求交算软遮挡。这是角色在间接光下也有柔和自阴影的关键——比给角色单开一张阴影图省得多。

1. tile 剔除 + 逐胶囊求交 + 上采样（汇聚点）

// TileIntersectionCS：屏幕分 tile，剔除每 tile 不相交的胶囊 → 紧凑列表
// ComputeShadowCS：逐像素遍历本 tile 的胶囊，锥形求交累积最小可见度
// UpsampleCapsuleShadowPS：半分辨率结果双边上采样回全分辨率

说明

本文件的汇聚点是一条多 pass 管线：① tile 剔除——屏幕分块，每块只保留与之相交的胶囊（角色多时省大量求交）；② 逐胶囊求交——对每像素遍历本 tile 胶囊，做锥形（软阴影半影）或射线（硬）与胶囊求交，取最小可见度；③ 双边上采样——阴影常在半分辨率算再按深度/法线上采回全分辨率省算力。整套用于 r.CapsuleShadows：给带 Physics Asset 胶囊的角色提供廉价柔和的直接/间接/天光阴影与 AO。
