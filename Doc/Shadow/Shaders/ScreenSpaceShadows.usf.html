0. 屏幕空间射线步进求接触阴影（核心）

float3 OpaqueTranslatedWorldPosition = mul(float4(..., SceneDepth, 1), PrimaryView.ScreenToTranslatedWorld).xyz;
const float Dither = InterleavedGradientNoise(DispatchThreadId.xy + 0.5f, View.StateFrameIndexMod8);
float HitDistance = CastScreenSpaceShadowRay(OpaqueTranslatedWorldPosition, LightDirection, ActualContactShadowLength, 8, Dither, 2.0f, false, HitUV);
float Result = HitDistance > 0.0 ? (1.0f - GetContactShadowOcclusion(HitUV)) : 1.0f;
RWShadowFactors[DispatchThreadId.xy] = float2(Result, SceneDepth);

说明

阴影图分辨率有限，物体接触地面的细小阴影（脚底、家具腿）常糊掉。屏幕空间接触阴影（Contact Shadow）补这一环：从像素的世界位置朝光源方向，在屏幕深度缓冲上步进 8 步射线（CastScreenSpaceShadowRay，见 RayCast 库），若中途撞到更近的深度即判遮挡。InterleavedGradientNoise 抖动起点消除条带。长度 ContactShadowLength 可按世界/屏幕尺度。产出 ShadowFactors 与常规阴影相乘。Bend 变体是 Bend Studio 的高质量 SSS 算法。
