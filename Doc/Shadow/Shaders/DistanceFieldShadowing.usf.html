说明

距离场阴影不采样阴影图，而是对场景的 Mesh Distance Field（每网格预烘焙的有符号距离场）做光线步进求遮挡。第一步 CullObjectsForShadowCS 用视锥凸包/包围球剔除——只保留投影且与本次阴影范围相交的 SDF 物体进紧凑列表（bCastShadow + 相交测试 + Nanite 网格开关），大幅减少后续每像素要遍历的 SDF 数。FDFObjectBounds 是大世界坐标（DF=Double-Float）的物体包围。

// 结果写阴影因子，可半分辨率 + 上采样

说明

本 pass 的汇聚点：ComputeCulledTilesStartOffsetCS 把剔除后的物体按屏幕 tile 分桶（前缀和算起点偏移），逐像素只遍历本 tile 的 SDF。追踪用锥形步进（cone tracing）：沿光向前进，每步查 SDF 到最近表面的距离，用"距离 / 锥当前半径"估软遮挡——锥半角取光源角半径，天然产出可变半影软阴影。这就是 UE 距离场软阴影（r.DistanceFieldShadowing）——远景大范围阴影、动态物体无需渲阴影图的高效替代，也是 Lumen/RTGI 之外的 SDF 复用点。
