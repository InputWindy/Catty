VSM 缓存的失效负载均衡（41 行）：用 LoadBalancer 把大量实例的页失效工作均匀分配到 GPU 线程——处理"少数大实例 + 大量小实例"的不平衡，避免个别线程超载。核心 InvalidateInstancePagesLoadBalancerCS。下方内嵌完整 41 行真实源码，再逐段真实代码批注。

0. 负载均衡的页失效派发（核心）

[numthreads(CS_1D_GROUP_SIZE_X, 1, 1)] void InvalidateInstancePagesLoadBalancerCS(...)
// 用 FInstanceProcessingLoadBalancer 把 (实例, 工作项) 均匀映射到线程
// 每线程处理定量工作，无论实例大小分布如何
// 复用 CacheInvalidation.ush 的失效逻辑，只是换了任务分发方式

说明

失效工作量在实例间极不均：一个巨大的建筑覆盖上千页，一个小道具只覆盖几页。若简单"一线程一实例"，处理大实例的线程会拖慢整组。InvalidateInstancePagesLoadBalancerCS 用 UE 的 LoadBalancer（FInstanceProcessingLoadBalancer）把所有 (实例, 页工作项) 摊平后均匀切给线程，每线程处理大致相同的工作量——消除长尾。失效的实际逻辑复用 CacheInvalidation.ush，本 shader 只是它的高效并行外壳。
