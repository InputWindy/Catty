ShadowDepthPixelShader.usf 整源解析

完整源码（逐行真实） · Engine/Shaders/Private/ShadowDepthPixelShader.usf

Main @ L37（SUPPORT_SHADOW_DEPTH_SPOT / VSM permutation）

0. masked 材质裁剪（发散点）

#if INTERPOLATE_VF_ATTRIBUTES
FMaterialPixelParameters MaterialParameters = GetMaterialPixelParameters(Inputs.FactoryInterpolants, SvPosition);
CalcMaterialParametersEx(MaterialParameters, PixelMaterialInputs, SvPosition, ScreenPosition, 1, TranslatedWorld, ...);
GetMaterialClippingShadowDepth(MaterialParameters, PixelMaterialInputs);   // clip() 掉透明部分
#else  ClipLODTransition(SvPosition.xy);   // 仅 LOD 抖动裁剪  #endif

说明

不透明几何的阴影深度不需要 PS（硬件直接写深度最快），本 shader 只在两种情况存在：① masked 材质（如树叶）——必须求值材质 opacity mask 并 clip() 掉透明像素，否则阴影会是实心矩形；② 需要手动写深度的投影类型。GetMaterialClippingShadowDepth 是裁剪入口，非 masked 时退化为仅 ClipLODTransition（LOD 过渡的 dither 裁剪）。

1. 按投影类型写深度（汇聚点）

#if SUPPORT_SHADOW_DEPTH_SPOT   // 聚光/点光：透视投影需手动写深度
Inputs.ShadowDepth = 1 - Inputs.ShadowDepth * InvMaxSubjectDepth; Inputs.ShadowDepth += Inputs.DepthBias;
OutDepth = saturate(Inputs.ShadowDepth);   // SV_DEPTH
#if SUPPORT_SHADOW_DEPTH_VSM
uint2 vAddress = (uint2)SvPosition.xy;   // 虚拟页地址 → 原子写入物理页深度

说明

本 PS 的汇聚点：聚光/点光用透视投影，深度非线性，需在 PS 里手动算 SV_DEPTH（1 - depth*InvMaxSubjectDepth + DepthBias，偏置抗自阴影 acne）；VSM 则把当前像素的虚拟页地址 vAddress 翻译成物理页位置，用原子 min 把深度写进 VSM 物理页池（因为 VSM 用 compute 光栅而非固定深度测试）。方向光走正交投影，深度线性，VS 直接输出即可、无需本 PS。
