// 用间接派发的组数 = 已分配页数 × 每页 tile 数
// 每组处理一页的一个像素块，统一寻址物理页 + 页内坐标
// 供 PropagateMappedMips / 逐页清理等 CS 复用

说明

很多 VSM 的 CS 需要"对每个已分配物理页的每个像素做点什么"（传播 mip、清理、初始化）。但已分配页是动态且稀疏的，不能简单按固定网格派发。FPerPageDispatchSetup 提供统一映射：间接派发的线程组数 = 已分配页数 × 每页 tile 数，本结构从 GroupId/GroupThreadId 反解出"这是哪个物理页的哪个页内像素"。PropagateMappedMips 等逐页 CS 都用它，避免各自重写寻址。是 VSM 逐页并行的通用脚手架。
