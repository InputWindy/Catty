0. 三种阴影图拷贝（核心）

void Copy2DDepthPS(...) { OutDepth = Texture2DSample(...).r; }   // 2D 缓存图 → 本帧图集
void CopyCubeDepthGS(triangle ... inout TriangleStream<FCubeCopyGSToPS>)   // 用 GS 分发到立方体 6 面
void CopyCubeDepthPS(...) { OutDepth = TextureCubeSample(...).r; }   // 点光立方体阴影拷贝
void Scrolling2DDepthPS(...)   // clipmap 滚动：只搬有效区，边缘增量更新

说明

静态几何的阴影每帧都一样，阴影缓存只渲一次存起来、后续帧直接拷贝复用省渲染。本 shader 是搬运工：Copy2DDepthPS 把缓存的 2D 阴影深度写进本帧图集对应位置；CopyCubeDepthGS/PS 用几何着色器把立方体 6 面分发拷贝（点光）；Scrolling2DDepthPS 是方向光 clipmap 的滚动更新——相机移动时 clipmap 平移，只搬仍有效的区域、边缘条带增量重渲，避免整图重画。这与 VSM 的物理页缓存是同一思想的经典版本。
