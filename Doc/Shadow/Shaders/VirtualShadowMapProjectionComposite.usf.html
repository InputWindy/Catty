VSM 投影的合成（48 行）：把 VSM 投影 CS 算出的 per-light 阴影结果合成进屏幕 shadow mask——按 tile 覆盖，或从 mask bits 解码多光合并。核心 VirtualShadowMapCompositePS / VirtualShadowMapCompositeFromMaskBitsPS。下方内嵌完整 48 行真实源码，再逐段真实代码批注。

0. 阴影结果合成进屏幕 mask（核心）

void VirtualShadowMapCompositeTileVS(...)   // 只覆盖有阴影结果的 tile
void VirtualShadowMapCompositePS(...)   // 采 VSM 投影结果 → 写 shadow mask 通道
void VirtualShadowMapCompositeFromMaskBitsPS(...)   // 从打包 mask bits 解码多光合并

说明

VirtualShadowMapProjection 把每光阴影算进中间缓冲，本 shader 负责合成到延迟光照要用的屏幕 shadow mask：CompositeTileVS 只画有阴影结果的 tile（省填充），CompositePS 采样投影结果写进对应通道；CompositeFromMaskBitsPS 走mask bits 路径——多个 local light 的阴影位打包在一张位图里（见 MaskBitsCommon），一次解码合并，省多次 pass。合成结果供 LightRendering 乘进直接光。
