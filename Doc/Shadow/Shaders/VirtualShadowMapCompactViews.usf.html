VirtualShadowMapCompactViews.usf 整源解析

VSM 的视图压缩（93 行）：把每帧潜在的大量 VSM 视图（每个 local light 的每级/每面）压紧成一个紧凑数组——剔除无页可渲的视图，只保留真正要渲染的，供后续剔除/光栅按索引访问。核心 CompactViewsVSM_CS。下方内嵌完整 93 行真实源码，再逐段真实代码批注。

// 遍历所有候选 VSM 视图，检查它是否有被标记的页需要渲染
// 用原子计数 + 前缀和把"有内容"的视图压到连续输出数组前部
// 输出紧凑视图列表 + IndirectDispatchArgs（后续 pass 按实际数派发）

说明

一个场景可能有几十上百个 local light，每个 spot 有一级、point 有 6 面、方向光 clipmap 有多级——潜在 VSM 视图数很大，但大多数视图本帧没有任何被标记的页（不影响可见画面）。CompactViewsVSM_CS 把这些空视图剔掉，用原子计数 + 前缀和把有内容的视图压紧到连续数组，并生成对应的间接派发参数。后续所有 per-view 的 pass（剔除、绘制指令、光栅）都只对这个紧凑集工作、按实际数量间接派发——避免为大量空视图空跑。这是 VSM 处理多光源可扩展性的关键一步。
