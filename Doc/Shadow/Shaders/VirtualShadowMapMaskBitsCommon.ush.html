// 从打包的 mask bits 缓冲取当前像素的位图
// 按 LightIndex 取对应 bit → 该光是否遮挡（0/1）
// 多光共用一张位图，避免每光一张全屏 mask

说明

场景多 local light 时，若每光都存一张全屏 shadow mask，带宽/显存爆炸。VSM 用 mask bits：把每像素对多个 local light 的阴影结果打包进一个位图（第 i 位=第 i 个影响本像素的光是否被遮挡）。GetVirtualShadowMapMaskForLight 在着色时按 LightIndex 取出对应位——一次读位图即可服务多光。这与 ProjectionComposite 的 CompositeFromMaskBits 配合，是 VSM 高效处理大量局部光阴影的编码技巧，属 局部光阴影章。
