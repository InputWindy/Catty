// 用遮挡物距离 OccluderDistance + 平均自由程 MFP 算 Beer-Lambert 透光
// 遮挡浅→透光多；MFP 大→光穿透深（如蜡、皮肤）

说明

次表面材质（皮肤、蜡、玉、叶片）在背光下应透光发亮而非纯黑阴影。VSM 的 SMRT 不仅给"是否遮挡"，还给遮挡物距离 OccluderDistance。本库用它做透射：GetSubsurfaceOpacityFromGbuffer 从 GBuffer 取该像素的次表面不透明度与平均自由程（MFP，光在介质里的平均穿透长度）；GetShadowFactorSubsurface 按 Beer-Lambert 用"遮挡距离 / MFP"算衰减——遮挡物越薄、MFP 越大，透过来的光越多。这让 VSM 阴影里的次表面材质有正确的透光渐变，是画质细节的关键，属 投影章的次表面路径。
