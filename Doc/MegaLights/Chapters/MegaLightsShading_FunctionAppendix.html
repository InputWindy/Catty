① ETileType 全枚举

enum class ETileType : uint8 { SimpleShading = TILE_MODE_SIMPLE_SHADING, ComplexShading = TILE_MODE_COMPLEX_SHADING, SimpleShading_Rect = TILE_MODE_SIMPLE_SHADING_RECT, ComplexShading_Rect = TILE_MODE_COMPLEX_SHADING_RECT, SimpleShading_Rect_Textured = TILE_MODE_SIMPLE_SHADING_RECT_TEXTURED, ComplexShading_Rect_Textured = TILE_MODE_COMPLEX_SHADING_RECT_TEXTURED, Empty = TILE_MODE_EMPTY, // Substrate adaptive 额外类型 SingleShading = TILE_MODE_SINGLE_SHADING, SingleShading_Rect = TILE_MODE_SINGLE_SHADING_RECT, SingleShading_Rect_Textured = TILE_MODE_SINGLE_SHADING_RECT_TEXTURED, ComplexSpecialShading = TILE_MODE_COMPLEX_SPECIAL_SHADING, ComplexSpecialShading_Rect = TILE_MODE_COMPLEX_SPECIAL_SHADING_RECT, ComplexSpecialShading_Rect_Textured = TILE_MODE_COMPLEX_SPECIAL_SHADING_RECT_TEXTURED, SHADING_MAX_LEGACY = TILE_MODE_MAX_LEGACY, SHADING_MAX_SUBSTRATE_BLENDABLE = TILE_MODE_MAX_SUBSTRATE_BLENDABLE, SHADING_MAX_SUBSTRATE_ADAPTIVE = TILE_MODE_MAX_SUBSTRATE_ADAPTIVE };

Legacy 材质只用前 7 个（Simple/Complex × 3 形态 + Empty）；Substrate 材质额外用 Single / ComplexSpecial 系列。permutation 上限用 SHADING_MAX_SUBSTRATE_ADAPTIVE。GetShadingTileTypes(InputType, Platform) 按输入类型裁剪实际编译的子集。IsComplexTileType() 判断是否 Complex 系（头发 complex transmittance 用）。

相比采样 CS，解析 CS 多了 FDownsampleFactorX/Y——因为 Resolve 要把降采样结果上采回全分辨率，下采样因子必须编进 shader。

Resolve 输出

RWResolvedDiffuseLighting（float3）· RWResolvedSpecularLighting（float3）· RWShadingConfidence（float）。是否输出置信度由 r.MegaLights.ShadingConfidence + UseShadingConfidence 控制。这三个 target 直接喂给去噪（#5）。

enum class EMaterialMode : uint8 { Disabled, // 命中即遮挡，最快，忽略 alpha test AHS, // AnyHitShader：命中求材质做 alpha 遮罩（镂空植被等） RetraceAHS, // 先快速遮挡，需要时用 any-hit 重追（半透明阴影） };
模式HWRT permutation 映射用途
Disabled—（minimal payload）纯不透明遮挡，性能最好
AHSFEvaluateMaterials = truealpha test / masked 材质正确投影
RetraceAHSFSupportContinuation = true半透明阴影：命中后继续追踪

由 r.MegaLights.HardwareRayTracing.EvaluateMaterialMode 选择。raygen 路径下 RetraceAHS 会额外做一次 continuation retrace。
