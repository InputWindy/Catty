⑤ 数据流结构体

MegaLightsInternal.h · FMegaLightsParameters / EMegaLightsInput

FMegaLightsParameters 是贯穿所有 CS 的共享 shader parameter struct（用 SHADER_PARAMETER_STRUCT_INCLUDE 内联进各 CS）。它携带下采样因子、光源数据、HZB、蓝噪声、View uniform 等。三种输入用 EMegaLightsInput 区分：

enum class EMegaLightsInput : uint8 { GBuffer, // 不透明主体（默认下采样 2x2） HairStrands, // 头发几何（独立 DownsampleMode） FrontLayerTranslucency, // 前层半透明表面 }; // 命名前缀（GET_MEGALIGHTS_EVENT_NAME 宏） GBuffer → "MegaLights." HairStrands → "MegaLights.HairStrands." FrontLayerTranslucency → "MegaLights.FrontLayerTranslucency."

头发输入额外携带 FHairStrandsViewUniformParameters；前层半透明携带 FFrontLayerTranslucencyGBufferParameters 与 FrontLayerTranslucencySpecularOnly 标志。
