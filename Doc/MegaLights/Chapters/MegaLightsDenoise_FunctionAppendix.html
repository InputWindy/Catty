// 时域方差估计（概念） mean = LightingMoments.rgb // 一阶矩 E[L] m2 = LightingMoments.a // 二阶矩 E[L^2] var = m2 - dot(mean_luma, mean_luma) // Var = E[L^2] - E[L]^2 // var 越大 → 空间滤波越强；低于 HistorySpatialStdDevThreshold(0.15) 则跳过

这些历史纹理由 RDG extraction 保存到 View.PrevViewInfo，下一帧作为 *HistoryTexture 读入，形成时域环路。PrevSceneColorPreExposureCorrection = PreExposure / PrevSceneColorPreExposure 校正曝光变化。
