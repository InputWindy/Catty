去噪 · 时域累积与空间滤波

追踪+着色求出的每像素光照，因为每像素只有 4 个随机样本还带着强烈噪点。去噪是 MegaLights 管线的最后一道工序：先用 时域累积（Temporal）把过去多帧的结果按运动矢量重投影、邻域钳制后混合，把有效样本数放大到十几帧；再用 空间滤波（Spatial）在剩余噪点大的地方做一次几何感知的模糊。两步都由上游的 ShadingConfidence 和历史方差驱动强度——可信的像素少动，不可信的像素多滤。所有符号/CVar 均取自 UE5.8 本地源码。

① 为什么必须去噪：4 样本 ≠ 真值

随机采样的代价是噪声

MegaLights 把"对所有光源求可见性"换成了"每像素随机抽 r.MegaLights.NumSamplesPerPixel=4 个样本追踪"。这让开销与光源数解耦，但 4 个样本的蒙特卡洛估计方差极大——直接显示就是满屏跳动的颗粒噪点。要逼近"无限样本"的真值，唯一现实的办法是跨时间、跨空间复用邻近样本：过去若干帧、周围若干像素其实都在估计同一个（或高度相关的）光照积分，把它们加权平均就等效于把样本数放大了一个数量级。这正是时域 + 空间两步去噪做的事。

② 时域累积：把十几帧的样本攒起来

FDenoiserTemporalCS（DenoiserTemporalCS，MegaLightsDenoiserTemporal.usf）是去噪的主力。它按运动矢量把上一帧的去噪结果重投影到当前像素，与本帧的 Resolve 结果混合：

MegaLightsDenoising.cpp L263-343 · FDenoiserTemporalCS
// 输入 ResolvedDiffuseLighting / ResolvedSpecularLighting // 本帧（含噪） DiffuseLightingHistoryTexture / SpecularLightingHistoryTexture // 上帧历史 LightingMomentsHistoryTexture // 上帧一/二阶矩 NumFramesAccumulatedHistoryTexture // 上帧已累积帧数 ShadingConfidenceTexture // 着色置信度（#4 产出） // 输出（同时作为下一帧历史） RWDiffuseLighting / RWSpecularLighting RWLightingMoments // float4：alpha 存二阶亮度矩→估时域方差 RWNumFramesAccumulated // 本像素有效历史长度

历史命中判定 + 邻域钳制：对抗 ghosting

时域累积最怕拖影（ghosting）：物体移动/遮挡变化后，旧历史已经失效却还在混。MegaLights 用两道防线——① 历史距离阈值 r.MegaLights.Temporal.HistoryDistanceThreshold=0.03：重投影点与当前深度差超阈值就判为 history miss，把累积帧数砍到 MinFramesAccumulatedForHistoryMiss=4；② 邻域钳制 TemporalNeighborhoodClampScale=1.0：把历史值 clamp 到当前像素邻域的均值±方差范围内，越界说明历史不可信。累积上限 Temporal.MaxFramesAccumulated=12——最多把 12 帧的样本当作一帧用，等效样本数 4×12≈48。

FValidHistory permutation 区分"有无有效历史"（首帧/切镜头时无历史走清零路径）；FFastClear 配合 tile 分类只处理有样本的 tile。

③ Moments：用二阶矩估计噪声还剩多少

怎么知道某个像素"还很吵，需要空间滤波"？MegaLights 不猜，而是实测方差。RWLightingMoments 的 alpha 通道存的是亮度的二阶矩（E[L²]），配合一阶矩（均值 E[L]）就能算出时域方差 Var=E[L²]−E[L]²。方差大的像素说明历史里样本波动仍剧烈，需要更强的空间滤波来补；方差小的说明时域已经收敛，空间上可以少动甚至不动。

ShadingConfidence 与历史方差双驱动

空间滤波强度不是全屏一刀切，而是逐像素自适应：ShadingConfidence（#4 着色阶段产出，样本命中越一致越高）+ 历史空间方差（r.MegaLights.Spatial.UseHistorySpatialVariance=true，存于 HistoryConfidence R8G8 纹理）共同决定。方差低于 Spatial.HistorySpatialStdDevThreshold=0.15 的像素直接跳过空间滤波，保住清晰度。

④ 空间滤波：几何感知的自适应模糊

FDenoiserSpatialCS（DenoiserSpatialCS，MegaLightsDenoiserSpatial.usf）是收尾。它在时域输出上做一次联合双边滤波：在核半径内取若干邻居样本，按深度/法线权重加权平均——只复用几何上"属于同一表面"的邻居，避免把不相干表面糊在一起。

为什么空间滤波"寄生"在时域之上

源码里 UseSpatialFilter 显式要求 UseTemporalFilter 为真——没有时域就不跑空间。原因：空间滤波的强度靠时域累积产出的方差/置信度来引导；脱离时域信息单跑空间只能盲目全屏模糊，得不偿失。刚发生 disocclusion（时域历史刚失效、噪声最大）的像素，用 MaxDisocclusionFrames 临时把空间滤波开到最强，等时域重新攒够帧数再退回。FDenoiserSpatialCS 的输出直接写进 RWSceneColor（含次表面 diffuse 分离），完成 Diffuse+Specular 到画面的合成。

与 Lumen / TSR 去噪的关系

同源的时空去噪思想，不同的信号

共同点时域重投影 + 邻域钳制对抗 ghosting、二阶矩估方差驱动空间滤波、几何感知（深度/法线）联合双边滤波——这套方法论与 Lumen 的屏幕空间概率去噪、TSR 的时域抗锯齿一脉相承，都是"用时空样本复用把蒙特卡洛噪声磨平"。

不同点MegaLights 去噪的是直接光照阴影（Diffuse/Specular 两路解调 + ShadingConfidence 驱动），Lumen 去噪的是间接光/反射；MegaLights 的空间滤波强绑定时域（无时域不空间），且用专门的 LightingMoments 二阶矩纹理跨帧追踪方差，这是它区别于通用 TAA 的地方。两者可在同一帧共存，各去各的噪。

最终总结

去噪把"每像素 4 样本的满屏颗粒"磨成"干净的阴影"：① ClearTemporal 用 FastClear 清空 tile；② DenoiserTemporal 按运动矢量重投影上帧结果，用历史距离阈值（0.03）+ 邻域钳制（scale 1.0）挡拖影，累积上限 12 帧（等效样本≈48），并把亮度二阶矩写进 LightingMoments；③ DenoiserSpatial 由 ShadingConfidence + 历史方差驱动，在噪声大/刚 disocclusion 的像素做几何感知的联合双边滤波（核半径 8px、4 样本），镜面少滤防糊高光；最后写回 SceneColor 完成合成。关键设计：空间滤波寄生于时域、自适应强度而非全屏一刀切。至此 GBuffer 输入的 MegaLights 主管线闭环，剩下体积光照（#6）是它在 froxel 网格上的平行分支。
