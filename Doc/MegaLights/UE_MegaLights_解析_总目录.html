UE MegaLights 源码解析 · 总目录

UE5.8 渲染管线中 MegaLights 多光源方案的源码学习文档集。MegaLights 用随机采样 + 光线追踪可见性 + 时空去噪让"阴影投射光源"的开销与场景光源数量解耦——不再逐光源建 tile、逐光源算阴影，而是每个像素固定抽几个光源样本、追光线求可见性、再靠时域累积 + 空间滤波把噪声磨平。本目录按 GPU 单帧执行顺序组织：先门禁与下采样分块，再采样 → 追踪 → 着色 → 解析 → 去噪，最后是体积光照与调试可视化。每个主题含一份主文档（设计动机 + 数据流骨架 + 分阶段批注）与一份函数附录（子 CS / permutation / CVar 细节）。所有符号名、CVar 默认值均取自 UE5.8 本地源码 Engine/Source/Runtime/Renderer/Private/MegaLights/。

这本书怎么读

MegaLights 的管线阶段多、彼此耦合紧（下采样因子贯穿采样/着色/去噪，tile 分类贯穿采样/着色）。第一次读建议：先读 #1 总览与管线 建立"门禁 → 下采样分块 → 采样 → 追踪 → 着色 → 解析 → 去噪"的整体骨架和三种输入（GBuffer / HairStrands / FrontLayerTranslucency）的差异，再按顺序钻 #2 采样、#3 追踪、#4 着色与解析、#5 去噪，最后看 #6 体积光照这条独立分支。若你读过本文档集的 Lumen 篇，可直接从"MegaLights 与 Lumen Stochastic Direct Lighting 的关系"一节切入。

总览与管线入口

光源采样 · 重要性采样与历史引导

MegaLightsSampling.cpp · MegaLightsSampling.usf
每像素怎么从成百上千个光源里"抽"出固定几个样本：FLightTargetPDF 权重构建（光色 × 衰减 × 朝向估计）、MinSampleWeight 早剔除、蓝噪声采样、Guide by History（VisibleLightHash 让被遮挡光源降低抽样概率）。讲清 FGenerateLightSamplesCS 的 permutation 维度与 NumSamplesPerPixel 如何随下采样因子折算成最终每像素样本数。附录含采样 CS 全表 + PDF 公式 + 采样相关 CVar。
主文档采样 CS 附录

追踪与阴影 · 可见性求解

MegaLightsRayTracing.cpp · MegaLightsRayTracing.ush
抽出的光源样本如何求可见性：三条后端（硬件光追 HWRT / Virtual Shadow Map / 屏幕空间 HZB）、样本压缩（compaction）减少无效光线、MarkVSMPages 让 VSM 只渲染被采样命中的页、FarField 远场追踪、光线偏移与自相交处理。讲清 MegaLights 与 Lumen 共享的 MegaLightsRayTracing.ush 求值内核。附录含追踪 CS/RGS 全表 + VSM 页标记 + 追踪相关 CVar。
主文档追踪后端附录

着色与解析 · Tile 类型与结果重建

MegaLightsResolve.cpp · MegaLightsShading.usf
可见性求出后如何着色并把降分辨率的样本重建回全分辨率：ETile­Type 全枚举（Simple/Complex/Single/ComplexSpecial × Rect/Textured）如何按材质复杂度分派 shader、EMaterialMode（AHS / RetraceAHS）、Rect/Textured/IES/LightFunction 的施光路径、Substrate 与 Transmission。Resolve 阶段如何产出 ResolvedDiffuse/SpecularLighting 与 ShadingConfidence。附录含 tile 类型分派表 + 着色/解析 CS 全表。
主文档Tile 与着色附录

去噪 · 时域累积与空间滤波

MegaLightsDenoising.cpp · MegaLightsDenoiser*.usf
单帧几个样本必然有噪，如何用时空复用磨平：FDenoiserTemporalCS 历史累积（NumFramesAccumulated / HistoryDistanceThreshold / NeighborhoodClamp）、FDenoiserSpatialCS 邻域滤波（KernelRadius / 二阶矩 moments 估计方差 / disocclusion 处理）、ShadingConfidence 如何驱动空间滤波强度。讲清与屏幕探针/反射时域降噪一脉相承的设计。附录含去噪 CS 全表 + moments 数学 + 去噪 CVar。
主文档去噪 CS 附录

MegaLights 如何为 Volumetric Fog 与 Lit Translucency Volume 供光：相机对齐的 3D froxel 网格（GridPixelSize=8 / GridSizeZ=128 / log-Z 深度分布 DepthDistributionScale=32）、Unified 统一采样（体积雾与半透明体积共享采样/追踪）、每体素样本数、HZB 遮挡剔除、体积去噪。讲清体积分支与不透明分支在采样/追踪/去噪上的复用与差异。附录含体积 CS 全表 + 网格布局 + 体积 CVar。

与本文档集其它篇的关系

MegaLights 与 Lumen 是两本独立的书

本书（MegaLights）与 Lumen GI 解析 是并列的两套渲染方案文档，各有独立总目录。两者在源码层有一处交汇：Lumen 的 Surface Cache 随机直接光照（实验路径）借用了 MegaLights 的 MegaLightsRayTracing.ush 求值内核，把"随机采样 + 时域累积"的思想搬进 Surface Cache 世界空间。读完本书 #3 追踪后，可回看 Lumen 篇的"随机直接光照"一章理解同一套内核的两处落地。
