采样期材质特性宏开关

0. 采样期材质特性宏开关（核心）

#define ALLOW_SSS_MATERIAL_CHECKERBOARD_OVERRIDE 0   // SSS 棋盘像素保留原漫反/高光
#define HAIR_BSDF_BACKLIT 0   // 采样期禁 Hair TT 背光（易误判正贡献）
#define USE_IES_PROFILE 1
#define USE_LIGHT_FUNCTION_ATLAS 1
#if INPUT_TYPE == 0   // GBuffer 才开透射
    #define USE_TRANSMISSION 1
    #define SUBSTRATE_SSS_TRANSMISSION 1 #endif

说明

这些编译期宏在采样阶段裁剪材质特性，让权重估计既准又省：HAIR_BSDF_BACKLIT 0 关掉发丝 TT 背光——它太强且多数被底层几何遮挡，采样期算进去会造成大量假阳性（选中实则不可见的样本）；USE_IES_PROFILE/USE_LIGHT_FUNCTION_ATLAS 让采样权重考虑 IES 剖面与光函数（与 TargetPDF 一致）；透射路径只对标准 GBuffer（INPUT_TYPE==0）开。是被 Sampling 等 include 的开关面板。
