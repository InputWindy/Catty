0. 相机主光线 BVH 求交 + 命中着色（核心）

float3 CameraVector = normalize(ScreenVectorFromScreenRect(...));
FRayDesc Ray; Ray.Origin = PrimaryView.TranslatedWorldCameraOrigin; Ray.Direction = CameraVector;
LightingContext.bForceClosestHitShader = true;   // 可视化需 CHS 拿命中数据(HitT/材质)
#if MEGA_LIGHTS_EVALUATE_MATERIALS   // 命中点跑材质 CHS → 显示真实材质
TraceLumenShadingRay(TLAS, RayFlags, InstanceMask, RAY_TRACING_SHADER_SLOT_MATERIAL, ..., Payload);

说明

与生产 HWRT（HardwareRayTracing）不同——这里从相机而非着色点发主光线，且强制 ClosestHit（生产阴影线用 any-hit 求快，可视化需最近命中的 HitT/材质数据）。MEGA_LIGHTS_EVALUATE_MATERIALS 开时命中点跑完整材质 CHS 显示真实外观，否则只显示几何命中。用于确认 HWRT 的 TLAS/近场远场分级、instance mask 配置正确——是排查"HWRT 结果异常"的地面真值窗口。
