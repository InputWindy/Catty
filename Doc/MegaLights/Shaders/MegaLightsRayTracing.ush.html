GenerateShadowRay（按光型分派 rect/dir/capsule/sphere）

0. 按光型分派生成阴影光线（核心）

if (bRectLight) return GenerateRectLightOcclusionRay(...);
else if (bDirLight) { GenerateDirectionalLightOcclusionRay(...); return true; }
else { // point or spot
    if (SourceLength > 0.0) return GenerateCapsuleLightOcclusionRayWithSolidAngleSampling(...);
    return GenerateSphereLightOcclusionRayWithSolidAngleSampling(...); }

说明

阴影光线不能只朝光源中心射——面光源有面积，必须在光源可见立体角内随机取一点才能得到软阴影的无偏估计。本函数按光型分派到 RayTracing 库的四个生成器：矩形光/方向光/胶囊光（有 SourceLength）/球光，后两者用立体角采样（SolidAngleSampling，返回 RayPdf 供重要性加权）。产出的 RayOrigin/Direction/TMin/TMax 交给 SWRT/HWRT/VSM 各后端求遮挡——三后端复用同一套光线生成，保证一致性。
