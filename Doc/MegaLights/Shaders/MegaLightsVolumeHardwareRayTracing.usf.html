VolumeHardwareRayTraceLightSamples @ L39（RAY_TRACING_ENTRY_RAYGEN_OR_INLINE）

0. 体素定位 + 构造阴影光线（发散点）

if (TraceTexelIndex < CompactedTraceTexelAllocator[0])
const uint3 SampleCoord = UnpackTraceVoxel(CompactedTraceTexelData[TraceTexelIndex]);
float3 TranslatedWorldPosition = ComputeCellTranslatedWorldPosition(VolumeCoord, VolumeFrameJitterOffset, SceneDepth);
FLightSampleTrace LightSampleTrace = GetLightSampleTrace(TranslatedWorldPosition, LightSample.LocalLightIndex, LightSampleUV);
FRayDesc Ray = (FRayDesc)0; Ray.Origin = TranslatedWorldPosition; Ray.Direction = LightSampleTrace.Direction;
Ray.TMin = RayTracingBias; Ray.TMax = max(Ray.TMin, min(MaxTraceDistance, ClippedNearFieldMaxTraceDistance));

说明

与屏幕 HWRT 对称但更简：体素反投影到世界位置（UnpackTraceVoxel 取 3D 坐标），朝光源构 FRayDesc。不同点体积阴影没有透射/双面分支——雾/半透明体素不需要区分正反面，故 TMin 直接用 RayTracingBias，剔除模式固定剔正面。近场追踪距离同样被 ClipAndDitherNearFieldMaxTraceDistance 裁剪。

1. any-hit 阴影求交（汇聚点）

CullingMode = FORCE_TWO_SIDED ? RAY_FLAG_NONE : RAY_FLAG_CULL_FRONT_FACING_TRIANGLES
LightingContext.bAcceptFirstHitAndEndSearch = true;   // 阴影只需 any-hit
LightingContext.InstanceMask = RAY_TRACING_MASK_OPAQUE_SHADOW;
LightingContext.bIsShadowRay = true;
// TraceLightSampleRay → 命中即遮挡：LightSample.bVisible = false 回写 RWVolumeLightSamples

说明

本 shader 的汇聚点：bIsShadowRay=true + bAcceptFirstHitAndEndSearch=true 让 BVH 遍历命中第一个不透明面即停（比 closest-hit 快得多），InstanceMask=RAY_TRACING_MASK_OPAQUE_SHADOW 只与投影阴影的几何求交。命中即遮挡回写体积样本可见性——与 软件 SDF 体积追踪产出同格式，供 VolumeShading。
