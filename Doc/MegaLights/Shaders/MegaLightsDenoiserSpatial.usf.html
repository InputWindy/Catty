DenoiserSpatialCS @ L158

0. 空 tile 快退 + 定位（发散点）

#if FAST_CLEAR
uint TileBitmask = MegaLightsTileBitmask[GroupId.xy + View.ViewRectMinAndSize.xy / TILE_SIZE];
if (IsFastClearTile(TileBitmask)) return;
#endif
uint2 ScreenCoord = DispatchThreadId.xy + View.ViewRectMinAndSize.xy;

说明

去噪按屏幕像素派发。FAST_CLEAR tile 位图标记的全空 tile（无任何光照）直接 return——MegaLights 全流程反复用这个 MegaLightsTileBitmask 跳过空区，是省 GPU 的一致手法。HairStrands 输入类型走独立分支（不做常规空间滤波，按发丝样本 splat）。

1. 置信度引导双边滤波 + 合成（汇聚点）

float3 CenterDiffuseLighting = DiffuseLightingTexture[ScreenCoord];
// 邻域按 深度/法线/ShadingConfidence 加权，置信低 → 核更宽滤更狠
FDenoisingModulateFactors Factors = GetDenoisingModulateFactors(Material, NoV);
DiffuseLighting *= Factors.Diffuse; SpecularLighting *= Factors.Specular;   // 调制回材质
FLightAccumulator LightAccumulator = (FLightAccumulator)0;
LightAccumulator_AddSplit(LightAccumulator, DiffuseLighting, SpecularLighting, ...);
RWSceneColor[...] += LightAccumulator_GetResult(LightAccumulator);

说明

本 shader 的汇聚点：在解调空间（Shading 已除掉材质项）对两路光照做置信度引导的空间双边滤波——ShadingConfidence 低（样本命中不一致、噪声大）的像素用更宽的核滤得更狠，高置信像素几乎不动，保住细节。滤波后用 GetDenoisingModulateFactors 调制回材质 albedo/specular，经 FLightAccumulator 合成（含次表面分离）写进 RWSceneColor——这是 MegaLights 光照进入主画面的终点。
