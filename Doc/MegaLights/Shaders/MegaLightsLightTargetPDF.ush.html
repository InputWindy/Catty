MegaLightsLightTargetPDF.ush 整源解析库 / 采样目标分布

MegaLights 采样的目标 PDF 构造：GetLocalLightTargetPDF 用真实施光算出该光在此点的施光亮度作为采样目标，再做感知加权（log2）降低强隐藏光的噪声。采样 PDF 正比于实际贡献 = 低方差。下方内嵌完整 61 行真实源码，再对 PDF 构造真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/MegaLights/MegaLightsLightTargetPDF.ush

FLightTargetPDF + GetLocalLightTargetPDF

0. 用真实施光亮度构造采样权重（核心）

FDeferredLightingSplit SplitLighting = GetMegaLightsSplitLighting(TranslatedWorldPosition, CameraVector, Material, ..., LightData, LightAttenuation, ...);
float Lum = SplitLighting.LightingLuminance * View.PreExposure;
if (Lum > MinSampleWeight && LightData.IESAtlasIndex >= 0) Lum *= ComputeLightProfileMultiplier(...);   // IES
Lum *= SmoothFalloffMask(Lum, MinSampleWeight);
LightTargetPDF.Weight = log2(Lum + 1.0f);   // 感知加权抑噪

说明

重要性采样要低方差，PDF 就得正比于被积函数（真实光贡献）。本函数直接调 GetMegaLightsSplitLighting（与最终施光同一函数）算出该光在此点的施光亮度 Lum 作为目标——采样与施光一致，无偏。IES 光乘上剖面倍率，再乘 SmoothFalloffMask 平滑截断低于 MinSampleWeight 的微弱光。关键一招是 Weight = log2(Lum+1) 的感知加权：把权重压到对数域，避免一盏极强的隐藏光（被遮挡但亮度巨大）在 WRS 里霸占全部样本却贡献为零而制造噪声。
