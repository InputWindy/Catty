0. 逐样本反投影标记 VSM 页（核心）

if (TraceTexelIndex < CompactedTraceTexelAllocator[0])
const int VirtualShadowMapId = ForwardLightData.VirtualShadowMapId;
FVirtualShadowMapHandle VirtualShadowMapHandle = FVirtualShadowMapHandle::MakeFromId(VirtualShadowMapId);
if (VirtualShadowMapHandle.IsValid())
{
    float3 TranslatedWorldPosition = GetTranslatedWorldPositionFromScreenUV(ScreenUV, SceneDepth);
    if (bDirectionalLight) MarkPageDirectional(VirtualShadowMapHandle, TranslatedWorldPosition);
    else                   MarkPageLocal(...);
}

说明

这是 MegaLights 与 VSM 需求驱动哲学的对接点（对照 Shadow 书 #10 页标记）：MegaLights 只在少数被采样的样本处需要阴影，如果让 VSM 为整屏所有光渲页会极度浪费。本 pass 遍历压实后的光样本，对每个有 VSM 的样本反投影其世界位置，调 MarkPageDirectional/MarkPageLocal 把对应虚拟页标记为"被请求"——之后 VSM 只渲这些页，VSMTracing 再采样它们。样本已 Compact，故只标记真正要追踪的。
