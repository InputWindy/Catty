0. tile 类型判定 helper（核心）

bool IsSimpleShadingTileType(uint TileType) {
    return TileType == TILE_MODE_SIMPLE_SHADING
        || TileType == TILE_MODE_SIMPLE_SHADING_RECT
        || TileType == TILE_MODE_SIMPLE_SHADING_RECT_TEXTURED; }
#if SUBSTRATE_ENABLED && SUBSTRATE_GBUFFER_FORMAT == 1
    #define MAX_USED_TILE_MODE TILE_MODE_MAX_SUBSTRATE_ADAPTIVE
#else #define MAX_USED_TILE_MODE TILE_MODE_MAX_LEGACY #endif

说明

这些判定把 tile 分类产出的 TileType 归类为 Simple/Rect/Textured 等特性，决定 Shading 走哪条着色路径（简单模型省指令、矩形光需源纹理采样）。MAX_USED_TILE_MODE 随 Substrate 开关与 GBuffer 格式在编译期切换枚举上界——这是 MegaLights 用编译期排列组合（permutation）适配多材质系统的典型手法。此外本头定义了 FLightSample 的 pack/unpack 与 MegaLightsStateFrameIndex 等被全流程共享的基元。
