0. YCoCg + 共享内存邻域加载（发散点）

for (SharedCoordY ...) for (SharedCoordX ...)
half3 DiffuseSample = ResolvedDiffuseLighting[ResolvedCoord];
half4 DiffuseW = select(IsLightingValid(DiffuseSample), half4(LumenRGBToYCoCg(DiffuseSample / LIGHTING_EXTRA_EXPOSURE), 1.0), 0.0);
if (SpecularW.x >= SafeSpecularY) SpecularW.xyz *= SafeSpecularY / SpecularW.x;   // clamp 防 half 溢出

说明

时域滤波要读邻域算方差包围盒，故先把 SHARED_TILE_SIZE（tile + 边框）范围的两路光照批量载入 groupshared，避免重复纹理读。光照转 YCoCg 空间（亮度/色度分离，钳制在亮度上更稳），无效样本权重置 0，跳过角点（GetNeighborhood 也跳）。高光值 clamp 到 sqrt(MaxHalfFloat) 防 fp16 溢出。GroupMemoryBarrierWithGroupSync 后进入累积。

RWDiffuseLighting/RWSpecularLighting = 累积结果（回 RGB）

说明

本 shader 的汇聚点：按运动矢量重投影上帧历史，用 groupshared 邻域的 YCoCg 均值+方差算颜色包围盒，把历史 clamp 进盒内——这是抗鬼影的核心（历史偏离当前邻域太多即判失效）。再做指数移动平均累积（累积帧数越多历史权重越大，disocclusion/快变区重置计数），输出时域稳定的两路光照，交给 DenoiserSpatial 做空间滤波 + 合成。与 TSR 的历史累积思想同源但作用在解调光照上。
