MegaLightsEstimateLight.ush 整源解析库 / 光衰减估计

MegaLights 采样的轻量光估计：EstimateLocalLight 按距离/半径/衰减指数近似局部光贡献（对齐 GetLocalLightAttenuation）、ComputeLightPower 估光总功率（面光乘尺寸）——给采样器算权重时用的廉价估计。下方内嵌完整 58 行真实源码，再对估计公式真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/MegaLights/MegaLightsEstimateLight.ush

EstimateLocalLight + ComputeLightPower

0. 距离衰减估计 + 光功率（核心）

float NormalizeDistanceSquared = DistanceSquared * Pow2(LightInvRadius);
if (LightFalloffExponent > 0.0) LightFalloff = pow(1.0 - saturate(NormalizeDistanceSquared), LightFalloffExponent);
else LightFalloff = Pow2(saturate(1.0 - Pow2(NormalizeDistanceSquared))) / DistanceSquared;   // 反平方 + 窗口
return LightPower * LightFalloff * View.PreExposure / PI;
// ComputeLightPower: Luminance(Color); 矩形光 *= 2*SourceRadius * 2*SourceLength;

说明

采样器要对成百上千盏光快速算权重，不能每盏都做完整施光，故用这个廉价解析估计：EstimateLocalLight 按归一化距离平方 + 衰减指数近似能量（有指数走幂次窗口、否则走反平方 + 平滑窗口，与引擎 GetLocalLightAttenuation 一致以免采样与施光偏差）。ComputeLightPower 取颜色亮度，面光源（矩形）再乘上 SourceRadius×SourceLength 折算面积功率。这些值喂给 LightTargetPDF 与 Sampling 的 WRS 权重，也是 LightPowerDelta 的底层。
