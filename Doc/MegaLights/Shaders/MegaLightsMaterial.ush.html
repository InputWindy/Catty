FMegaLightsMaterial 结构 + LoadMaterial（GBuffer/Hair/FrontLayer 三输入）

0. FMegaLightsMaterial 统一材质结构（核心）

#define INPUT_TYPE_GBUFFER 0
#define INPUT_TYPE_HAIRSTRANDS 1
#define INPUT_TYPE_FRONTLAYERTRANSLUCENCY 2
struct FMegaLightsMaterial {
    float DeviceZ; float Depth;
    float3 WorldNormal; float3 WorldNormalForPositionBias; float Roughness;
    bool bIsValid, bIsSimple, bIsSingle, bIsComplexSpecial, bIsHair, bIsTwoSided; ... };

说明

MegaLights 要对多种材质系统统一施光，故用 INPUT_TYPE permutation 把三种来源——标准 GBuffer、发丝（HairStrands）、前层半透明（FrontLayerTranslucency）——各自的 LoadMaterial 归一到同一个 FMegaLightsMaterial。结构里除常规 PBR 项外，还带 WorldNormalForPositionBias（抗自阴影的偏移法线，区别于着色法线）、bIsSimple/bIsSingle/bIsComplexSpecial（与 tile 分类对应的着色档位）、次表面/双面标记。Shading/TargetPDF 都以它为输入，屏蔽材质差异。
