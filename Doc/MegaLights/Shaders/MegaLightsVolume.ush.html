0. 降采样 jitter + 坐标互转（核心）

uint3 GetSampleVoxelCoordJitter(uint3 DownsampledVolumeCoord) {
    uint3 CellIndex = DownsampledVolumeCoord % 2;
    uint LinearIndex = CellIndex.x + CellIndex.y*2 + CellIndex.z*4;
    LinearIndex = (LinearIndex + MegaLightsStateFrameIndex) % 8;   // 逐帧轮换
    Jitter.x = LinearIndex & 0x04 ? 0 : 1; ... // 4-rooks 采样 }
uint3 DownsampledVolumeCoordToVolumeCoord(uint3 c) { return (c << VolumeDownsampleFactorMultShift) + GetSampleVoxelCoordJitter(c); }

说明

体积光照在 降采样 froxel 上计算再上采，为省算力。本库管这套坐标学：GetSampleVoxelCoordJitter 用 4-rooks 抖动 + 逐帧轮换（MegaLightsStateFrameIndex % 8）让每帧采样降采样体素里的不同子体素——配合时域累积逐渐补全全分辨率。DownsampledVolumeCoordToVolumeCoord/反向做位移互转，ComputeCellTranslatedWorldPosition 用 MegaLightsVolumeZParams（log-Z 分布）把体素坐标转世界位置，VolumeCoordToNoiseCoord 用 R2 序列映射蓝噪声。VolumeSampling 等四件套全靠它定位。
