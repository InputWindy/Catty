MegaLightsDebugCS @ L87

0. 逐 TileType 打印数量（核心）

if (all(DispatchThreadId == 0))
Print(DebugContext, TEXT("TileType             | Num      "), FontSilver);
for (uint TileType = 0; TileType < MAX_USED_TILE_MODE; ++TileType)
{
    PrintTileTypeString(DebugContext, TileType, InitFontColor(GetTileTypeColor(TileType).xyz));
    Print(DebugContext, GetNumTiles(TileType), FontValue);
}

说明

用引擎的 ShaderPrint 设施把 tile 分类的结果打到屏幕：第 0 号线程打印表头 + 逐 TileType（Empty/Simple/Complex…）的 GetNumTiles 数量，用 GetTileTypeColor 着色区分。其余线程逐 tile 打印被选中像素（GetDebugScreenCoord）的采样/追踪明细。纯调试 pass，仅 r.MegaLights.Debug 开启时派发，不影响画面。
