ComputeLightPowerDeltaCS @ L30

0. 逐光源估功率（核心）

uint ForwardLightIndex = DispatchThreadId.x;
if (ForwardLightIndex < NumLocalLights + NumDirectionalLights)
FDeferredLightData LightData = ConvertToDeferredLight(GetForwardLightData(ForwardLightIndex, 0));
if (bUseLightFunctionAtlas && LightData.LightFunctionAtlasLightIndex > 0) LightData.Color *= GetLightFunctionForPowerEstimate(LightData);
float LightPower = ComputeLightPower(LightData) * View.PreExposure;

说明

每线程处理一盏光：转成 FDeferredLightData 后调 ComputeLightPower 估其总功率（强度 × 影响范围的积分近似），LightFunction 光还要乘上函数图谱的平均衰减（GetLightFunctionForPowerEstimate）。这个功率值是 Sampling 构建 FLightTargetPDF 的先验之一——功率越大的光被抽中的概率越高，让固定采样预算优先花在贡献大的光上。
