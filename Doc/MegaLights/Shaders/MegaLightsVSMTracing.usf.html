VirtualShadowMapTraceLightSamplesCS @ L27

0. 取 VSM + 法线偏移 + 屏幕光线首段（发散点）

if (TraceTexelIndex < CompactedTraceTexelAllocator[0])
const int VirtualShadowMapId = ForwardLightData.VirtualShadowMapId;
if (VirtualShadowMapId != INDEX_NONE)
{
    TranslatedWorldPosition += SceneWorldNormal * VirtualShadowMapGetNormalBiasLength(TranslatedWorldPosition);
    float RayStartOffset = ScreenRayLengthWorld;
    if (ScreenRayLengthWorld > 0.0f)
        RayStartOffset = VirtualShadowMapScreenRayCast(TranslatedWorldPosition, ToLightDirection, ScreenRayLengthWorld, StepOffset);
}

说明

只处理有 VirtualShadowMapId 的样本。先沿法线偏移（VirtualShadowMapGetNormalBiasLength）抗自阴影痤疮，再做一段屏幕空间光线投射（VirtualShadowMapScreenRayCast）——用屏幕深度快速跨过近处接触遮挡，得到 RayStartOffset 让后续 SMRT 从更远处起步，省步进。方向光/局部光的 ToLightDirection 分别取常向量/指向光源。

1. SMRT 采样 VSM：方向光 / 局部光两路（汇聚点）

if (bDirectionalLight)

说明

本 shader 的汇聚点：按光源类型走 TraceDirectional/TraceLocalLight——两者都是 SMRT（Shadow Map Ray Tracing，在 VSM 深度上步进式打光线，得软阴影且抗痤疮，与 Shadow 书 #12 同源）。局部光固定 RayCount=1（MegaLights 已在采样阶段选好样本，无需 VSM 内多采样）。ShadowFactor 判遮挡后回写样本可见性——与 SWRT、HWRT 后端产出同一份可见性交给 Shading。
