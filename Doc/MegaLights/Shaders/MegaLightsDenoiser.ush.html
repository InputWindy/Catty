MegaLightsDenoiser.ush 整源解析库 / 去噪打包工具

MegaLights 去噪的小工具头：ShadingConfidenceToMaxFramesAccumulated 把着色置信度换算成时域最大累积帧数（置信高→累积更多帧更干净），加 Pack/UnpackNumFramesAccumulated（R8 打包）与 LinearStep。下方内嵌完整 27 行真实源码，再真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/MegaLights/MegaLightsDenoiser.ush

LinearStep + ShadingConfidenceToMaxFramesAccumulated + Pack/UnpackNumFramesAccumulated

0. 置信度→累积帧数 + R8 打包（核心）

half ShadingConfidenceToMaxFramesAccumulated(half ShadingConfidence, half TemporalMaxFramesAccumulated) {
    half MaxConfidenceFrames = ShadingConfidence > 0.0 ? 1.0 / (ShadingConfidence * 0.5) : TemporalMaxFramesAccumulated;
    return MaxConfidenceFrames; }
uint PackNumFramesAccumulated(half X) { return X * 8.0 + 0.5; }   // R8_UInt
half UnpackNumFramesAccumulated(uint X) { return X / 8.0; }

说明

时域去噪要"该累积多少帧历史"——累积越多越干净但越易鬼影。本头把 Shading 产出的 ShadingConfidence 反比换算成 最大累积帧数：置信度高（样本命中一致、信号稳）→ 允许累积很多帧压噪；置信低 → 少累积以免糊掉快变信号。累积帧数用 ×8 定点打进 R8_UInt 省带宽（DenoiserTemporal 读写它驱动指数累积、Visualize 解包显示）。LinearStep 是用 lerp 实现的省指令 smoothstep。
