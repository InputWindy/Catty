HardwareRayTraceLightSamples @ L60（RAY_TRACING_ENTRY_RAYGEN_OR_INLINE）

0. 构造光线：TMin/TMax + 透射反向（发散点）

float MaxTraceDistance = LightSampleTrace.Distance - UnpackLightRayEndBias(ForwardLightData);
FRayDesc Ray = (FRayDesc)0;
Ray.Origin = TranslatedWorldPosition;
Ray.Direction = LightSampleTrace.Direction;
Ray.TMin = max(LightSampleRay.RayDistance - RayTracingPullbackBias, bTransmissionRay ? 0.0f : RayTracingBias);
Ray.TMax = max(Ray.TMin, min(MaxTraceDistance, ClippedNearFieldMaxTraceDistance));
if (bTransmissionRay) { Ray.Origin += Direction*TMax; Ray.Direction = -Direction; ... }   // 从光源反向追
else ApplyPositionBias(Ray.Origin, Ray.Direction, bFlip ? -Normal : Normal, RayTracingNormalBias);

说明

对每条压实样本构造 FRayDesc：TMin 带 PullbackBias 回拉起点、TMax 减 LightRayEndBias 且被 NearField 最大追踪距离裁剪（近场/远场分级）。透射光线特殊：要估"光到最近表面的距离"，需从光源侧反向追（Origin += Dir*TMax; Direction = -Direction）；普通光线则按法线做 ApplyPositionBias 抗自相交（双面材质翻转偏移方向）。

1. BVH 求交 + 命中着色（汇聚点）

FRayTracedLightingContext LightingContext = CreateRayTracedLightingContext(RayCone, 0, 0,
    bTransmissionRay ? RAY_FLAG_CULL_BACK_FACING_TRIANGLES : RAY_FLAG_CULL_FRONT_FACING_TRIANGLES, ...);
LightingContext.bAcceptFirstHitAndEndSearch = !bTransmissionRay;   // 阴影只需 any-hit
#if LUMEN_HARDWARE_INLINE_RAYTRACING
    LightingContext.HitGroupData = HitGroupData;  // Inline：计算着色器内联遍历
#endif
// TraceLightSampleRay → 命中: LightSample.bVisible=false；透射: 记录命中距离估厚度

说明

本 shader 的汇聚点：CreateRayTracedLightingContext 设剔除模式（普通光剔正面/透射剔背面）。阴影光线只关心"是否被挡"，故 bAcceptFirstHitAndEndSearch=true（any-hit 即停，比 closest-hit 快）；只有透射需要最近命中距离来估次表面厚度。RAY_TRACING_ENTRY_RAYGEN_OR_INLINE 宏让同一份代码既能编成 RayGen shader（走硬件光追管线）也能编成 Inline（计算着色器内联遍历 BVH）——MaxTraversalIterations 限步数。产出与 SWRT/VSM 同格式的可见性。
