MegaLightsSampling.usf 整源解析

MegaLights 的光源采样内核：每个降采样像素在其光网格 cell 内，用重要性采样（结合上帧可见光哈希做 Guide by History）+ 蓝噪声，从众多局部光/方向光里抽出固定数量的候选光样本供后续追踪求可见性。核心 GenerateLightSamplesCS（8×8 线程组，按 tile 类型 permutation）。下方内嵌完整 554 行真实源码，逐段批注。

0. tile 分派与降采样定位（发散点）

if (DownsampledTileIndex < DownsampledTileAllocator[TILE_TYPE])
DownsampledScreenCoord = TileCoord*TILE_SIZE + threadId

说明

MegaLights 在降分辨率上采样以省开销：一个 8×8 线程组处理一个降采样 tile，只有 DownsampledTileIndex 落在该 TILE_TYPE 的已分配数内才干活（tile 分类见 #4）。TILE_TYPE 是 shader permutation 维度——简单/复杂 tile 编译不同分支。

1. Guide by History：读上帧可见光哈希（汇聚点）

if (bGuideByHistory) 读 PackedPixelData + 历史坐标
VisibleLightHashHistory[PrevScreenLinearTileCoord*...]

说明

时域引导的读取端：把当前像素按运动重投影到上帧 tile，读回可见光哈希（上帧这个 tile 里哪些光实际可见）。采样时优先抽历史上可见的光——这就是 MegaLights 降噪的关键闭环之读端（写端在 Shading 的 VisibleLightHash）。蓝噪声抖动（BlueNoiseVec2）避免 tile 边界硬接缝。

2. 重要性采样：FLightSampler 抽样（汇聚点）

InitLightSamplerStratified(RandomScalar)
SampleLocalLight / SampleDirectionalLight → PackLightSample

说明

遍历光网格 cell 内的局部光（标量/向量两条路径，WaveActiveMin 做波前去重）+ 方向光，每盏调 SampleLocalLight/SampleDirectionalLight 累进 FLightSampler（按 FLightTargetPDF 加权蓄水池）。最后 NUM_SAMPLES_PER_PIXEL 个样本 PackLightSample 落盘，交给 RayTracing 求可见性。
