MegaLights 的光源采样内核：每个降采样像素从光源网格里按 FLightTargetPDF（假设完全可见的亮度 + log2 感知加权）+ Guide by History 重要性抽 N 个光源样本，写进 RWLightSamples 供追踪消费。核心 GenerateLightSamplesCS（8×8 线程组）。说明：完整文件 640 行，下方内嵌核心入口的真实源码。

Engine/Shaders/Private/MegaLights/MegaLightsSampling.usf · GenerateLightSamplesCS L286

0. 按 tile 类型 + 降采样调度

if (DownsampledTileIndex < DownsampledTileAllocator[TILE_TYPE])
DownsampledScreenCoord = TileCoord*TILE_SIZE + GroupThreadId + ViewMin

说明

采样只在降采样分辨率上跑（#1 的 DownsampleMode），且按 tile 类型（TILE_TYPE permutation）间接派发——只对被分类为该类型的 tile 启动线程组。这是随机采样管线的通用省法：把工作限制到"确实要采样"的像素，空 tile 不占线程。

1. 光源网格 + Guide by History（历史引导）

GridIndex = ComputeLightGridCellIndex(ScreenCoord, SceneDepth)
if (bGuideByHistory) { 读 PackedPixelData/历史哈希 → 调 PDF }

说明

先用光源剔除网格（与延迟光照共享的 CulledLightsGrid）拿到本像素相关的少量光源，而非遍历全部。Guide by History 重投影上一帧，读 VisibleLightHash：被上帧证明"看得见"的光提高 PDF、"被挡住"的光降低 PDF——这样样本不会浪费在必然返回遮挡的强光上。这与 #2 的采样哲学一致，哈希由 Shading 回写。

2. 构 PDF + 蓝噪声抽样（汇聚点）

FLightTargetPDF = GetLocalLightTargetPDF(...)  // 假设完全可见的亮度 + log2
蓝噪声在离散分布抽 N 个光源 + 光源上一点
RWLightSamples[SampleCoord] = PackLightSample(LightSample)

说明

本 shader 的汇聚点：为网格里每个光源算 FLightTargetPDF（在 MegaLightsLightTargetPDF.ush，假设完全可见跑分离式 BSDF 求亮度，再 log2 感知加权压制"强但被挡"的光），构成离散分布，用蓝噪声抽 NumSamplesPerPixel 个光源、每个再抽光源表面一点，PackLightSample 打包写进 RWLightSamples。可见性此刻未知——交给 追踪。

最终总结

骨架

降采样 + tile 类型调度 → 光网格取候选光 + 历史引导调 PDF → FLightTargetPDF 构分布 + 蓝噪声抽 N 个 → PackLightSample 写 RWLightSamples。把"多光源"化为"固定预算重要性采样"。
