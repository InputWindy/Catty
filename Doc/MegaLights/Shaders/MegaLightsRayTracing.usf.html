Engine/Shaders/Private/MegaLights/MegaLightsRayTracing.usf · CompactLightSampleTracesCS L90 / SoftwareRayTraceLightSamplesCS L382

0. Compact：稀疏光线的高效派发

ThreadOffset = ZOrder2D(LinearThreadIndex, log2(TILE))  // Z 序保局部性
组内前缀和分配槽 → 写 CompactedTraceTexelData

说明

下采样 + 早剔除后，需追踪的样本在屏幕上稀疏且不均。若按像素网格派发，大量线程空转。CompactLightSampleTracesCS 用组内前缀和把有效样本挤成连续列表，配合 InitCompactedTraceTexelIndirectArgsCS 生成 indirect args——追踪 pass 只对"确实要追的样本"启动线程。ZOrder2D 保证压缩后空间相邻样本仍相邻（BVH/SDF 遍历缓存友好）。这是随机采样管线（含 Lumen）通用技巧。

1. 三后端 + 屏幕首段（发散核心）

Screen Trace（屏内首段，可选）→ 命中即省一条世界光线
SoftwareRayTraceLightSamplesCS  → Global SDF（本文件）
HWRT / VSM  → MegaLightsHardwareRayTracing.usf / VSMTracing.usf

说明

共同点三后端都消费同一份压缩样本列表、都把结果回填样本可见性缓冲、都共享 MegaLightsRayTracing.ush 的求值内核（与 #3 所述 Lumen 随机直接光照同源）。

不同点SWRT（本文件）沿 Global Distance Field ray-march；HWRT 走 BVH（inline/raygen，MegaLightsHardwareRayTracing.usf）；VSM 采样阴影深度（MegaLightsVSMTracing.usf）。Screen Trace 是屏内廉价首段，命中屏内几何就省一条世界光线，屏外仍需世界追踪。

最终总结

骨架

Compact（前缀和 + Z 序挤成连续列表）→ indirect 派发 → 三后端之一（SWRT Global SDF / HWRT BVH / VSM 深度）求可见性，可选 Screen Trace 首段。稀疏光线高效派发 + 后端可插拔，是随机阴影的核心。
