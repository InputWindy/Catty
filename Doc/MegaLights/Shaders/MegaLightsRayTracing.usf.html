MegaLightsRayTracing.usf 整源解析

MegaLights 的软件可见性追踪内核：先把 #2 生成的稀疏光样本压实（Compact）成连续列表，再对每条样本沿 Global SDF 做 ray-march 求遮挡，命中则把该样本标记为不可见。含屏幕空间追踪首段 + 软件 SDF 追踪（硬件 RT / VSM 追踪在同名 HardwareRayTracing/VSMTracing 文件）。下方内嵌完整 413 行真实源码，再逐段真实代码批注。

0. Compact：把稀疏光样本挤成连续列表（汇聚点）

const uint2 ThreadOffset = ZOrder2D(LinearThreadIndex, log2(THREADGROUP_SIZE));
const uint2 SampleCoord = SampleViewMin + GroupId.xy * THREADGROUP_SIZE + ThreadOffset;
FLightSampleRay LightSampleRay = UnpackLightSampleRay(LightSampleRays[SampleCoord]);
bool bAcceptTrace = !LightSampleRay.bCompleted;
if (CompactForScreenSpaceTraces != 0)
{
    if (UseHairScreenTraces == 0 && LightSampleRay.IsHair()) bAcceptTrace = false;
    if (LightSampleRay.IsTwoSided() || LightSampleRay.IsTransmission()) bAcceptTrace = false;
}
if (bAcceptTrace)
{
    InterlockedAdd(SharedTraceTexelAllocator, 1, SharedTexelOffset);
    SharedTraceTexels[SharedTexelOffset] = PackTraceTexel(SampleCoord);
}

说明

#2 产出的光样本在屏幕上稀疏分布（很多样本已 bCompleted/无需追踪）。直接对每个像素发追踪会浪费大量空闲 lane。Compact 用组内原子/前缀和（WAVE_OP 有波前指令则走前缀和，否则 InterlockedAdd）把"确实要追踪"的样本挤成连续列表 CompactedTraceTexelData，再用间接派发只对这些样本启动线程——这是随机追踪省 GPU 的关键。屏幕空间追踪还会先过滤掉 FirstPerson/Hair/双面/透射样本。

1. Software SDF 追踪：沿 Global SDF 求遮挡（发散点）

if (TraceTexelIndex < CompactedTraceTexelAllocator[0])
{
    uint2 SampleCoord = UnpackTraceTexel(CompactedTraceTexelData[TraceTexelIndex]);
    FLightSample LightSample = UnpackLightSample(RWLightSamples[SampleCoord]);
    FLightSampleTrace LightSampleTrace = GetLightSampleTrace(TranslatedWorldPosition, LightSample.LocalLightIndex, LightSampleRay.UV);
    const float RayTMin = LightSampleRay.RayDistance;
    const float RayTMax = max(RayTMin, LightSampleTrace.Distance - UnpackLightRayEndBias(ForwardLightData));
    FGlobalSDFTraceInput TraceInput = SetupGlobalSDFTraceInput(TranslatedWorldPosition, LightSampleTrace.Direction, RayTMin, RayTMax, 1.0f, 1.0f);
    TraceInput.VoxelSizeRelativeBias = 0.5f;
    // RayTraceGlobalSDF → 命中(bHit)则该样本被遮挡：LightSample.bVisible = false 回写
}

说明

软件后端对每条压实后的样本从着色点出发、朝光源方向、在区间 [RayTMin, RayTMax] 内沿 Global SDF 做 sphere tracing（RayTraceGlobalSDF）。RayTMax 减 LightRayEndBias 避免打到光源自身；VoxelSizeRelativeBias 抗自相交。命中即遮挡，把 LightSample.bVisible=false 回写 RWLightSamples。硬件 RT 后端在 HardwareRayTracing、VSM 追踪在 VSMTracing——三后端产出同一份可见性交给 Shading。
