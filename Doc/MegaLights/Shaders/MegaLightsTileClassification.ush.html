tile 位掩码定义 + IsFastClearTile

0. tile 特性位掩码 + 快清判定（核心）

#define MEGALIGHTS_TILE_BITMASK_SIMPLE          0x01
#define MEGALIGHTS_TILE_BITMASK_COMPLEX         0x04
#define MEGALIGHTS_TILE_BITMASK_RECT_LIGHT      0x10
#define MEGALIGHTS_TILE_BITMASK_FAST_CLEAR_MASK (SIMPLE | SINGLE | COMPLEX | COMPLEX_SPECIAL)
bool IsFastClearTile(uint TileBitmask) { return (TileBitmask & FAST_CLEAR_MASK) == 0; }

说明

MegaLights 用一个 uint 位掩码描述每个 tile 的着色特性——每盏光按其类型（简单/复杂/矩形/带纹理矩形…）把对应位 OR 进 tile 的 MegaLightsTileBitmask。tile 分类的 GetTileModeFromBitmask 就是读这个位图归档到 TileType。IsFastClearTile 判定：若一个 tile 不含任何实际着色位（SIMPLE/SINGLE/COMPLEX/COMPLEX_SPECIAL 全 0）就是空 tile，可参与快速清零——全流程各 pass 的 FAST_CLEAR 快退都基于它。这些常量必须与 C++ 侧 MegaLightsDefinitions 完全对齐。
