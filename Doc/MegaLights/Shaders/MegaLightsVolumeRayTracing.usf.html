0. 3D Compact：挤压稀疏体积样本（汇聚点）

const uint3 SampleCoord = DispatchThreadId.xyz;
FVolumeLightSampleRay VolumeLightSampleRay = UnpackVolumeLightSampleRay(VolumeLightSampleRays[SampleCoord]);
if (!VolumeLightSampleRay.bCompleted)
{
    bTraceValid = true; TraceTexelForThisThread = PackTraceVoxel(SampleCoord);   // WAVE_OP 路径
    // 否则: InterlockedAdd(SharedTraceTexelAllocator, 1, ...); SharedTraceTexels[...] = PackTraceVoxel(SampleCoord);
}
const uint OffsetInWave = WavePrefixCountBits(bTraceValid);   // 波前前缀和分配连续槽

说明

与屏幕版 RayTracing 的 Compact 完全对称，只是工作在 3D 体积：一个 8×8×8 线程组，把未完成（!bCompleted）的体积光样本用 波前前缀和（WavePrefixCountBits + InterlockedAdd 合并各波前）挤成连续列表 CompactedTraceTexelData，用 PackTraceVoxel 打包 3D 坐标。压实后间接派发给体积追踪（软件 SDF / 硬件 RT）求遮挡，回写体积样本可见性。
