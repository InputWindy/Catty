0. 选中像素材质 + 体积深度锁定（发散点）

uint2 ScreenCoord = WaveReadLaneFirst(GetDebugScreenCoord());
FMegaLightsMaterial Material = LoadMaterial(ScreenUV, ScreenCoord);
#if IS_VISUALIZING_VOLUME
if (!Material.IsValid()) { Material.Depth = min(Material.Depth, GetMaxSceneDepthForInvalidPixels()); Material.bIsValid = true; }
bool bLatchDepth = AddCheckbox(WidgetContext, LATCH_DEPTH_CHKBOX_NAME, false, ...);   // 交互 widget
if (bLatchDepth) { float LatchedDepth = ReadLatchedSceneDepth(); if (LatchedDepth > 0) Material.Depth = LatchedDepth; }
#endif

说明

取鼠标选中像素（GetDebugScreenCoord + WaveReadLaneFirst 全波前统一）的材质。体积可视化模式给了交互 widget：用 ShaderPrint 的 AddCheckbox 画"锁定深度"复选框，勾选后 ReadLatchedSceneDepth/WriteLatchedSceneDepth 冻结当前深度，让开发者能沿视线扫查任意深度体素被哪些光影响——比纯静态热力更实用。

1. 遍历光源计数排序 + 热力/列表（汇聚点）

// 遍历该点覆盖的所有 ForwardLight，累计影响数 + 记录 per-light 贡献
// 按贡献排序（groupshared 排序网络）→ 取 top-N 打印光名/强度/距离
// 复杂度着色：光源数 → 伪彩热力（少绿多红），叠场景灰模
// widget：光源列表 tooltip + 采样预算对比（NumSamples vs 影响光数）

说明

本 shader 的汇聚点：遍历该像素/体素覆盖的所有前向光源，统计"影响此点的光数"，用 groupshared 排序网络按贡献排序取 top-N，通过 ShaderPrint 打出光名/强度/距离列表，并把光数映射成复杂度热力（少=绿、多=红）叠屏。核心价值：直观对比某点的影响光数 vs MegaLights 的固定采样预算（NUM_SAMPLES_PER_PIXEL）——复杂度远超预算的区域正是噪声/偏差高发处，指导 采样调参。
