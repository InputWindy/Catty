MegaLightsVisibility.ush 整源解析库 / 可见光哈希位运算

MegaLights 可见光哈希的位运算核心：用 XXHash32 把光索引哈希成双桶双位，IsLightVisible/MarkVisibleLight 读写可见集、IsLightHidden/MarkHiddenLight 读写隐藏集——布隆过滤器式的紧凑光集合。下方内嵌完整 71 行真实源码，再对哈希逻辑真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/MegaLights/MegaLightsVisibility.ush

VISIBLE/HIDDEN_LIGHT_HASH_SIZE + IsLightVisible/MarkVisibleLight（XXHash32 双桶）

0. XXHash32 双桶双位可见性测试（核心）

const uint LightHash = XXHash32(LightIndex);
uint DWORDIndex0 = BitFieldExtractU32(LightHash, 2, 0);   // 桶0：2bit 选 DWORD
uint BitIndex0   = BitFieldExtractU32(LightHash, 5, 4);   // 5bit 选位(0..31)
bool Test0 = (VisibleLightHash[DWORDIndex0] & (1u<<BitIndex0)) != 0;
bool Test1 = (VisibleLightHash[DWORDIndex1] & (1u<<BitIndex1)) != 0;
return and(Test0, Test1);   // 两桶都命中才算"可能可见"

说明

这是一个 4-uint 布隆过滤器：把 32bit 的 XXHash32(LightIndex) 切成两组 (DWORD 索引 2bit + 位索引 5bit)，在 VISIBLE_LIGHT_HASH_SIZE=4 个 uint 上置/查两位。IsLightVisible 要两位都命中才判"可能可见"（and），降低哈希碰撞误判率。这套哈希是 VisibleLightHash（写端）与 Sampling 的 Guide by History（读端）之间传递"上帧哪些光可见/被挡"的紧凑载体——常量 VISIBLE/HIDDEN_LIGHT_HASH_SIZE 必须与 C++ 侧严格一致。
