0. tile 分派与材质加载（发散点）

uint TileIndex = GroupId.x;
if (TileIndex < TileAllocator[TILE_TYPE])
{
    uint2 TileCoord = UnpackTile(TileData[TileIndex + TILE_TYPE * TileDataStride]);
    uint2 ScreenCoord = TileCoord * TILE_SIZE + GroupThreadId.xy + View.ViewRectMinAndSize.xy;
    FMegaLightsMaterial Material = LoadMaterial(ScreenUV, ScreenCoord, ShadingSampleIndex);
    float3 DiffuseLighting  = INVALID_LIGHTING;
    float3 SpecularLighting = INVALID_LIGHTING;
    if (Material.Depth > 0.0f && Material.IsValid()) { ... }
}

说明

与 Sampling 对称——着色也按 TILE_TYPE 间接派发（TileAllocator 分箱），但这里是全分辨率 tile（施光在全分辨率上做）。TILE_TYPE permutation 决定编译哪套 shading 分支：简单 tile 走精简路径，复杂 tile 才编入各向异性/次表面/矩形光带纹理。深度≤0 或无效材质直接写 INVALID_LIGHTING。

1. 随机双线性：全分辨率像素挑一个降采样样本（汇聚点）

#if DOWNSAMPLE_FACTOR_X == 2
FMegaLightsPackedPixelData PackedPixelData = (FMegaLightsPackedPixelData)PackedPixelDataTexture[ScreenCoord];
int2 StochasticBilinearOffset = PackedPixelData.GetStochasticSampleOffset();
int2 DownsampledScreenCoord00 = floor(ScreenUV * View.BufferSizeAndInvSize.xy / DOWNSAMPLE_FACTOR_X - 0.5f);
bValidPixel = PackedPixelData.HasValidStochasticSample();
DownsampledScreenCoord = clamp(DownsampledScreenCoord00 + StochasticBilinearOffset, DownsampledViewMin, DownsampledViewMin + DownsampledViewSize - 1);
#endif

说明

采样/追踪在降分辨率做，着色在全分辨率——中间要把降采样结果上采样。MegaLights 用随机双线性：每个全分辨率像素按 PackedPixelData 的 GetStochasticSampleOffset 随机挑一个邻近降采样样本（而非固定 bilinear 权重），跨帧+空间抖动后由去噪器（#5）平均——这样上采样噪声是白噪不是结构性 artifact。HasValidStochasticSample 剔除无效。

2. 逐光施光：加载样本 → GetMegaLightsSplitLighting（核心）

uint PackedLightSamples[NUM_SAMPLES_PER_PIXEL_1D];
for (uint SampleIndex = 0; SampleIndex < NUM_SAMPLES_PER_PIXEL_1D; ++SampleIndex)
    PackedLightSamples[SampleIndex] = LightSamples[LightSampleCoord];
bool bAnySampleValid = FindNextLocalLightIndex(PackedLightSamples, NextLocalLightIndex);
while (NextLocalLightIndex < MAX_LOCAL_LIGHT_INDEX)
{
    // AccumulateLightSample 汇总该光在各样本的可见性权重 → SampleWeight
    FDeferredLightingSplit SplitLighting = GetMegaLightsSplitLighting(TranslatedWorldPosition, CameraVector, Material, AmbientOcclusion, LocalLightIndex, LightData, LightAttenuation, Dither, ScreenCoord, SurfaceShadow);
    DiffuseLighting  += SplitLighting.DiffuseLighting.xyz  * SampleWeight;
    SpecularLighting += SplitLighting.SpecularLighting.xyz * SampleWeight;
}

说明

把该像素的 NUM_SAMPLES_PER_PIXEL 个样本载入寄存器，FindNextLocalLightIndex 按位遍历所有被采样到的光源；每盏光用 AccumulateLightSample 汇总它在各样本里的可见性得到 SampleWeight，再调 GetMegaLightsSplitLighting（标准延迟光照，含 Rect/IES/LightFunction/次表面传输）算 Diffuse/Specular，按权重累加。透射材质额外走 USE_TRANSMISSION 分支估 LightAttenuation.w。

3. Resolve：解调 + 写两路光照 + Confidence（汇聚点）

WeightRatioSum /= float(NUM_SAMPLES_PER_PIXEL_1D);
DiffuseLighting *= View.PreExposure;  SpecularLighting *= View.PreExposure;
FDenoisingModulateFactors Factors = GetDenoisingModulateFactors(Material, NoV);
DiffuseLighting /= Factors.Diffuse;  SpecularLighting /= Factors.Specular;   // 解调，供去噪
RWResolvedDiffuseLighting[ScreenCoord]  = DiffuseLighting;
RWResolvedSpecularLighting[ScreenCoord] = SpecularLighting;
RWShadingConfidence[ScreenCoord] = UseShadingConfidence ? WeightRatioSum : 0.0;

说明

本 shader 的汇聚点：样本权重归一化 + 乘 PreExposure 后，用 GetDenoisingModulateFactors 把光照解调（除以材质 albedo/specular 项）——去噪在解调空间做能避免糊掉纹理细节，去噪后再调制回来。分开写 RWResolvedDiffuseLighting/RWResolvedSpecularLighting 两路（镜面需更保守滤波），并输出 ShadingConfidence（WeightRatioSum——样本命中越一致越高）驱动 #5 空间滤波强度。可见光哈希回写在同批 VisibleLightHash pass 完成闭环。
