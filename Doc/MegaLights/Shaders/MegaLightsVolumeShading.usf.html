VolumeShadeLightSamplesCS @ L115（8×8×8）

0. 间接体素派发：只着色有效体素（发散点）

#if INDIRECT_VOXEL_DISPATCH
const uint VoxelIndex = GetUnWrappedDispatchThreadId(GroupId, GroupIndex, THREADGROUP_SIZE^3);
if (VoxelIndex >= VoxelAllocator[0]) return;
const uint PackedVolumeCoord = VoxelData[VoxelIndex];
uint3 VolumeCoord = uint3(PackedVolumeCoord & 0x3FF, (PackedVolumeCoord >> 10) & 0x3FF, (PackedVolumeCoord >> 20) & 0x3FF);
#else
uint3 VolumeCoord = DispatchThreadId.xyz;
#endif

说明

体积施光比屏幕更贵（体素数 = W×H×Z）。INDIRECT_VOXEL_DISPATCH 模式下只对被采样阶段标记为有效的体素（存进 VoxelData 紧凑列表，10bit×3 打包坐标）启动线程，用 GetUnWrappedDispatchThreadId 展开一维索引——空体素（相机后/雾外）完全不着色。非间接模式则直接用 3D DispatchThreadId。

1. 体素→世界 + 体积重采样（汇聚点）

const float3 TranslatedWorldPosition = ComputeCellTranslatedWorldPosition(VolumeCoord, VolumeFrameJitterOffset, SceneDepth);
float CellRadius = length(TranslatedWorldPosition - ComputeCellTranslatedWorldPosition(VolumeCoord + uint3(1,1,1), ...));
float DistanceBiasSqr = max(CellRadius * VolumeInverseSquaredLightDistanceBiasScale, 1); DistanceBiasSqr *= DistanceBiasSqr;
#if RESAMPLE_VOLUME  // 从上帧体积重采样，跨帧稳定
    float3 ResampleUV = ...; VolumeCoord = floor(saturate(ResampleUV) * ResampleVolumeViewSize);
#endif

说明

体积施光的关键差异：光源用 体素尺寸相关的距离偏移（DistanceBiasSqr 基于 CellRadius）软化平方反比衰减，避免体素靠近光源时的走样/爆点。RESAMPLE_VOLUME 把当前体素重投影到上帧体积做时域重采样，跨帧稳定。之后对该体素的样本逐光施光（体积散射相函数），累加进体积光照纹理，供半透明材质与体积雾查询——与 屏幕 Shading 的 Resolve 对称但输出到 3D 体积。
