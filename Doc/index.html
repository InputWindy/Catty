一眼看懂：五本书在渲染管线里的位置

① 几何 GeometryNanite 提供高密度几何，像素级 LOD，输出 visibility buffer 与延迟材质 GBuffer
② 纹理 Texture虚拟纹理 解决"纹理 > 显存"：页表式按需流送 + Clipmap，喂给材质采样
③ 全局光照 GILumen 用 Nanite fallback mesh 做软件光追，算漫反射 GI / 反射 / 体积光照
④ 多光源 LightsMegaLights 让大量阴影投射光源的开销与数量解耦，与上述系统同帧协作

五本书的交汇点 · 同一套渲染世界观

四处关键连接，串起整个 UE5 渲染

① 页流送范式（Nanite ↔ 虚拟纹理）：Nanite 的 #4 流送（几何页）与虚拟纹理书的页表式流送（纹理页）是同一种"数据 > 显存、按需分页进物理池、GPU 反馈驱动请求"的范式——一个流几何、一个流纹理，读完一个再看另一个会非常通透。

② VSM 阴影（Nanite ↔ 虚拟纹理 ↔ MegaLights）：Nanite 的 #9 阴影直接复用虚拟纹理书 VSM Clipmap 篇的 clipmap 结构——Nanite 提供几何、VSM 提供页表，每个阴影视图就是一个 Nanite view（NANITE_MAX_VIEWS_PER_CULL_RASTERIZE_PASS = 4096 多视图批处理）。

③ 几何是光照的输入（Nanite → Lumen）：Nanite 提供的高密度几何是 Lumen（软件光追走 Nanite fallback mesh）与整个延迟管线的输入；MegaLights 的光追可见性也在这套几何上求交。建议顺序：先 Nanite 主干（#1~#7）建立几何与延迟着色的直觉，再看虚拟纹理理解流送，然后 Lumen / MegaLights 理解光照。

④ 运动矢量与上采样（Nanite/整管线 → TSR）：TSR 处于管线最末端，消费前面所有系统产出的 SceneColor + SceneDepth + SceneVelocity（运动矢量由 Nanite 等几何写入），把低分辨率帧跨帧重建成高分辨率。而 TSR 又只是 ITemporalUpscaler 的默认实现——DLSS / FSR / XeSS 可通过同一接口整体替换这一级。
