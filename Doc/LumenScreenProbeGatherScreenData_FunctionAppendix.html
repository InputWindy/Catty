1. ScreenProbeGatherScreenData（C++ dispatcher）

说明

C++ 侧只做三件事：分配输出资源（BRDF PDF 纹理、SH buffer、可选 disocclusion 纹理）、装配参数与选 permutation、按 GroupPerProbe indirect dispatch 发起 compute pass。

SH buffer 大小固定 atlas 宽 × 高 × 9，对应每个 probe 9 个三阶 SH 系数。PDF 纹理则是 atlas × BRDFOctahedronResolution，对应路径 B 的逐 texel 表示。

发散bProbeDisocclusion 决定是否创建 disocclusion 纹理并启用对应 permutation；bIsHistoryValid 且存在历史 RT 时才注册 OldFastUpdateMode_NumFramesAccumulatedHistory，进而开启 VALID_HISTORY permutation。二者共同决定 shader 里那段 disocclusion 代码是否编译。

2. FScreenProbeGatherScreenDataCS（参数结构 + Permutation）

说明

参数结构对应 shader 顶部的资源声明：三个 UAV 输出、View/SceneTextures/Substrate uniform、FScreenProbeParameters（含 atlas 尺寸、下采样、indirect args）、以及 history 相关纹理与阈值。

发散两个 permutation bool SCREEN_PROBE_DISOCCLUSION 与 VALID_HISTORY 决定 shader 里 disocclusion 分支是否存在。

RemapPermutation 是一个约束：没开 disocclusion 时强制关掉 VALID_HISTORY——因为 history 只服务于 disocclusion 判定，没它就没意义。ShouldCompilePermutation 借此剔除无意义组合，减少 shader 变体数量，同时要求平台支持 Lumen GI。

3. CalcDiffuseTransferSH3（法线 → 余弦瓣 SH）

说明

这是路径 A 里每个像素生成 BRDF SH 的核心。它先用 SHBasisFunction3(Normal) 求法线方向的三阶 SH 基，再对每个 SH band 乘上把 SH 与 max(0,cosθ)^Exponent 卷积的缩放系数。

Exponent=1 时就是标准 Lambert 余弦瓣，得到的 SH 恰好表达"以法线为轴的余弦加权半球分布"——正是 diffuse 表面对入射方向的敏感度。把整个 probe 足迹内的这些 SH 相加归一，就得到该 probe 的平均 BRDF PDF。

4. Shader Helper 速查

Helper作用
ReadMaterialData(coord, uv)对 GBuffer / Substrate 的统一抽象读取，返回 FLumenMaterialData（法线、深度、有效性、shading model 特性）。屏蔽 GBuffer 与 Substrate 两套材质表示的差异。
HasSphericalVisibility(Material)判断材质是否会向全方向采样（如次表面散射、双面植被）。为真时 BRDF 退化成各向同性常量，避免裁掉这些材质实际会用到的背面方向。
SHBasisFunction3(dir)求某方向的三阶球谐基（9 系数），是 CalcDiffuseTransferSH3 与方向求值的基础。
AddSH3(a, b)两个三阶 SH 向量逐系数相加，用于并行归约求组内 SH 之和。
RoundUpToPowerOfTwo(n)把有效样本数向上取到 2 的幂，保证并行归约每轮整齐减半。
EquiAreaSphericalMapping(uv)把 octahedron 图的 UV 映射回球面方向，路径 B 用它枚举每个 texel 对应的世界方向。
UnpackFastUpdateModeAmountAndNumFramesAccumulated(...)解包历史纹理中打包的"快速更新量 + 累计帧数"，供 disocclusion 判定读取历史帧数。
GetBilinearCustomWeights(filter, validity)按样本有效性对双线性四邻域重新加权，避免把无效历史样本算进平均。

宏C++ 来源影响
BRDF_PDF_SPHERICAL_HARMONIC编译环境常量选择路径 A（SH 9 系数，默认）或路径 B（octahedron 纹理）。
SCREEN_PROBE_DISOCCLUSIONLumenScreenProbeGather::UseDisocclusionSpatialFilter()是否创建 disocclusion 纹理并编译 disocclusion 计数/输出代码。
VALID_HISTORYOldFastUpdateMode_NumFramesAccumulatedHistory != nullptr是否编译"读历史累计帧数判定新暴露"逻辑；被 RemapPermutation 约束为 disocclusion 的子集。

说明

三个宏共同决定 shader 变体：BRDF_PDF_SPHERICAL_HARMONIC 选表示法（大分叉），另两个决定 disocclusion 侦测是否参与。RemapPermutation + ShouldCompilePermutation 保证只有有意义的组合会被编译，控制变体爆炸。
