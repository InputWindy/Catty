1. ReSTIR：用"蓄水池重采样"把少量样本榨出高质量

说明

ReSTIR（Reservoir-based SpatioTemporal Importance Resampling）不追更多光线，而是把已有样本的价值最大化：每像素只留一个"加权代表样本"，再通过时间（上一帧）与空间（邻居）重采样，让等效样本数暴涨。它是屏幕空间、逐像素的，因此比降采样的 ScreenProbe 保留更多高频细节（接触阴影、锐利间接光），代价是更吃带宽、且要小心历史失效导致的拖影（故有校验机制）。

共同点时间重采样 + 空间重采样的双重复用，与 ④ FilterScreenProbes 的时域+空间滤波异曲同工——都靠"复用邻近（时/空）信息"压噪声。

不同点ScreenProbe 在降采样 probe 上采样再插值回像素（省追踪但糊细节）；ReSTIR 直接在每像素上做，用统计重采样代替 probe 降采样，细节更好但更贵。

2. Irradiance Field：世界空间 DDGI 探针网格

说明

Irradiance Field 就是引擎内建的 DDGI：把间接光缓存在世界空间规则探针网格上，屏幕像素只做插值。它最便宜、最稳定（世界空间、跨帧稳定、无屏幕噪声），但分辨率受探针间距限制，细节最糊、易漏光——所以每探针专门存了一张遮挡/深度 map做可见性加权来压漏光。适合中低端硬件或大场景 GI 打底。

共同点探针存辐照度 + 八面体映射 + 遮挡可见性测试，与 Radiance Cache 完全同源（它本就复用 RC 基础设施）；"周围 8 探针加权插值"与 ⑤ InterpolateAndIntegrate 的 probe 插值同理。

不同点Radiance Cache 的 probe 是自适应、按需放置（clipmap + 使用标记）的稀疏缓存；Irradiance Field 的 probe 是规则网格全覆盖、直接作为最终 GI 输出，而非中间缓存。

最终总结

骨架

Final Gather 三选一：主线 ScreenProbe（降采样 probe，平衡）、ReSTIR（逐像素蓄水池 + 时空重采样，高细节高成本）、Irradiance Field（世界 DDGI 探针 + 遮挡插值，最省最稳最糊）。三者共享 ③ 追踪、Surface Cache、Radiance Cache，仅屏幕侧采样组织不同，统一输出 FSSDSignalTextures。

分派在 RenderDiffuseIndirectAndAmbientOcclusion，由 GetFinalGatherMethod / UseIrradianceFieldGather 决定。

阅读建议

先记 ReSTIR = "样本复用最大化"、Irradiance Field = "世界探针打底"。ReSTIR 抓四阶段（初始→时间→空间→解算）与 reservoir 内容；Irradiance Field 抓"探针存辐照度+遮挡、插值时遮挡加权防漏光"。与主线的对照始终回到 ScreenProbeGather。
