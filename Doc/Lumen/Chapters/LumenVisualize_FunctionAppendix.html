2. 整屏可视化入口

说明

VisualizeLumenScene 是整屏模式的总入口。它先建输出 UAV，再用 SetupVisualizeParameters 把追踪距离、卡片插值半径等打包进 FLumenVisualizeSceneSoftwareRayTracingParameters，取 FLumenCardTracingParameters（可带 Surface Cache feedback），最后按硬件能力二分派。参数与生产追踪同构，保证可视化忠实。

3. 软件 SDF 可视化路径

说明

软件路径几乎是生产 SDF 追踪的翻版：先 CullMeshObjectsToViewGrid 把 mesh SDF 剔进 froxel 网格（GridPixelSize 默认 32），再逐屏幕像素做 sphere trace 命中 mesh SDF、采 Surface Cache 写颜色。HiResSurface 可选让它采高分辨率 Surface Cache 页看更清晰的内容。

共同点与 Mesh SDF 剔除的 froxel grid 剔除、sphere tracing 完全同源。

4. HWRT 可视化路径

说明

硬件路径调 LumenVisualize::VisualizeHardwareRayTracing（在 LumenVisualizeHardwareRayTracing.cpp），复用 F 章讲的 HWRT 基座。关键是只有 Lumen Scene 和 Reflection View 两个模式会开 bVisualizeModeWithHitLighting——因为这两个模式最需要看"命中点真实材质"的效果，其余模式读 Surface Cache 即可。

共同点HitLighting 命中重着色与 HWRT 消费者的两遍法完全一致。

5. Overview 拼图布局

说明

Overview 通过 GetTileOutputView 计算每个子模式在屏幕上的格子偏移与尺寸，然后为每格用对应子模式渲染，实现"一屏并排看多层数据"。VisualizeTileIndex 标识当前是第几格、NumOverviewTilesPerRow 控制排布，逻辑与 StochasticLighting 的可视化复用同一 tile 布局工具。

6. 叠加式：射线 / 探针 / 统计

说明

RenderLumenMiscVisualizations 是叠加式调试总入口，不替换画面。它画追踪射线（RenderVisualizeTraces）、Radiance Cache 探针、Radiosity 探针，并在 GLumenSceneDumpStats 被设时往控制台 dump 统计（值 2/3/4 分别 dump mesh SDF / 剔除信息 / primitive group），dump 后自动复位为 0（单次触发）。LumenVisualizeRadianceCache.cpp 承载探针可视化实现。
