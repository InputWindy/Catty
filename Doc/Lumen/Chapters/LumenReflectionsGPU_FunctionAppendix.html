1. ReflectionGenerateRaysCS

说明

用 ImportanceSampleVisibleGGX（可见法线分布 VNDF）依粗糙度采样半程向量、反射得到射线方向。ConeAngle = 1/max(PDF, 0.0001) 把 PDF 转成锥角——PDF 低（方向稀疏/粗糙）则锥宽，追踪采更高预滤波 mip。粗糙度超过 RadianceCacheMaxRoughness=0.8 的部分交给 Radiance Cache 兜底而非逐像素追踪。

2. FRayData / 编码

说明

反射射线的公共数据契约。FRayData 打包方向、PDF、锥角与 Radiance Cache 最大追踪距离，是生成→追踪→降噪各 pass 之间传递的载体。命中距离用 EncodeRayDistance/DecodeRayDistance 打包（把"是否命中"位与距离压进一个 uint），节省带宽。线程组 2D 尺寸 8×8。

3. Trace 级联入口

说明

与 Final Gather 同构的级联：屏幕→压实→（排序）→MeshSDF→Voxel。反射独有 ReflectionSortTracesByMaterialCS：按命中材质排序，让 warp 内采样相似材质提升相干。MinReflectionConeAngle=0.00001 是纯镜面（roughness≈0）时的锥角下限，防止除零并保持锐利。

4. LumenReflectionResolveCS

说明

空间重建：把邻域像素的射线按"相对本像素 BRDF lobe"的 GGX 权重加权聚合。数学上是用邻居样本帮本像素完成镜面积分的蒙特卡洛估计——同 lobe 的不同方向样本，几何正确。采样偏移用 Hammersley16 低差异序列 + UniformSampleDiskConcentric 映射到圆盘，在 SpatialReconstructionKernelRadius 内均匀铺开。这是三段降噪里唯一"重建/补积分"的一段，后两段只是平滑。

5. DenoiserTemporal

说明

时域累积。用 groupshared 缓存 12×12 tile（8 + 2 border）供邻域统计，在 YCoCg 空间算 3×3 均值/方差组成 AABB，把历史 clamp 进去防鬼影（ClampScale=0.5）。混合系数 Alpha=1/(NumFrames + reconstructed?4:0)——刚被 Resolve 重建过的像素额外 +4 加速收敛，最多累 60 帧。双历史分别按命中点（hit-based，适合光滑反射跟随命中物）与按表面（surface-based，适合粗糙反射跟随本表面）重投影，按可靠性择优。

6. DenoiserSpatial

说明

空域收尾滤波，仅当时域累积帧数不足时权重更大（方差自适应）。三重权重相乘：DepthWeight=exp2(-10·ΔDepth²) 保深度边、NormalWeight=1-saturate(angle/lobeHalfAngle) 保法线边（锥角随粗糙度）、LuminanceWeight=exp2(-ΔLum/stddev) 保高光边。任一维不一致该邻居权重就趋零，从而只在同几何同材质区域平滑，不糊边。3 半径 16 样本。

7. FConeTraceInput / cone march

说明

cone march 是 Lumen 所有追踪链路（反射/屏幕探针/Radiance Cache/可视化）的公共底座。FConeTraceInput 描述一个圆锥：起点、方向、锥角、追踪距离区间、步进系数。追踪沿锥轴步进，锥随距离变宽 → 采样越来越高的 mip（预滤波），既抗锯齿又用少量步数覆盖大范围。FConeTraceResult 返回累积光照、透过率（软遮蔽/部分透明）与命中距离。FRayCone 的 SpreadAngle/Width 记录锥随程扩张。

8. ConeTraceLumenSceneVoxels

说明

远场 voxel 追踪的核心：SDF 空球步进（sphere tracing）。每步用 Global Distance Field 采到最近表面距离 d，直接跳 d 那么远（空区快速跨越）。当 d < ConeRadius（锥半径，随距离线性增大）判定命中，按 mip=log2(ConeRadius) 采预滤波的 voxel 光照。锥越宽 mip 越高——这就是 cone trace 相比纯 ray trace 的省钱之处：一条锥等效一束光线，用 mip 预积分代替超采样。这套是反射与 Final Gather 远场兜底共用的同一函数。
