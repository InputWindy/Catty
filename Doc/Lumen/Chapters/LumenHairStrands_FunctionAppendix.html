1. TraceHairScreen（屏幕空间 HZB 追踪）

参数含义
RayTranslatedWorldOrigin / RayWorldDirection光线起点与方向（TranslatedWorld 空间）
MaxWorldTraceDistance最大追踪距离
InHZBUvFactorAndInvFactor / MaxIterationsHZB UV 缩放因子 / 最大迭代步数
UncertainTraceRelativeDepthThreshold / NumThicknessStepsToDetermineCertainty不确定命中的深度阈值 / 厚度判定步数
out bHit / bUncertain / OutScreenUV / OutHitTileZ命中标记 / 不确定标记 / 命中 UV / 命中 tile 深度

说明

受 USE_HAIRSTRANDS_SCREEN 宏门控。内部直接转调通用 TraceHZB，但喂的是毛发专属的两张纹理：HairStrands.HairOnlyDepthTexture（只含毛发的深度）与 HairStrands.HairOnlyDepthClosestHZBTexture（对应 closest-HZB）。因为是屏幕空间，只能命中屏内、朝相机的毛发——所以默认只在反射里开。

2. TraceHairVoxels（Virtual Voxel 体素追踪）

参数含义
PixelCoord / SceneDepth像素坐标（用于抖动）/ 场景深度（算像素半径）
SampleTranslatedWorldPosition / SampleDirection光线起点 / 方向
TraceDistance追踪距离（外部取 min(RadianceCacheMaxTraceDistance, OpaqueHitDistance)）
bIsReflectionTracing关键开关：true→Shadow 档，false→Environment 档（切换 DensityScale/SteppingScale）
out bHit / OutTransparency / OutHitT命中标记 / 透明度 / 命中距离

遍历逻辑

受 USE_HAIRSTRANDS_VOXEL 宏门控，内部 include HairStrands/HairStrandsVoxelPageTraversal.ush（VOXEL_TRAVERSAL_LINEAR_MIPMAP）。流程：① GetHairVoxelJitter2 抖动起点补偿粗体素；② 遍历 VirtualVoxel.NodeDescCount 个 node，逐个 UnpackVoxelNode + ComputeHairCountVirtualVoxel 得 HairCount；③ 透明度 Transparency = min(Transparency, saturate(1 − HairCount))，命中距离取 min；④ Transparency > 0.01 时提前终止。TraversalSettings.bUseOpaqueVisibility=false——只算毛发自身遮挡。

3. 遮蔽应用（以 Reflections 为例）

命中后三步衰减

在 LumenReflectionTracing.usf 主追踪 ConeTraceLumenScene* 之后：先 HairTraceDistance = min(RadianceCacheMaxTraceDistance, TraceResult.OpaqueHitDistance)，再调 TraceHairVoxels(..., bIsReflectionTracing=true, ...)。若 bHairHit && HairHitT < HairTraceDistance：

TraceResult.Lighting *= HairTransparency;
TraceResult.Transparency *= HairTransparency;
TraceResult.OpaqueHitDistance = min(HairHitT, TraceResult.OpaqueHitDistance);

不同点与所有其它追踪相反——它只把 Lighting 往下乘，从不往里加颜色。毛发是遮蔽体，不是光源。

5. 全部 CVar

CVar默认作用

r.Lumen.ScreenProbeGather.HairStrands.ScreenTrace0GI 探针对毛发深度屏幕追踪

说明

全部标记 ECVF_Scalability | ECVF_RenderThreadSafe，可随质量档缩放。注释统一为 "hair casting shadow onto opaques"。规律：VoxelTrace 默认全开（主力、不受屏幕限制），ScreenTrace 只在反射默认开（便宜但只覆盖屏内朝相机的毛发）。
