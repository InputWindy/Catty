0. 平台适用性：PC Deferred 会走，Mobile Forward 通常不会走

return (bSkipProjectCheck || bLumenSupported)
    && FDataDrivenShaderPlatformInfo::GetSupportsLumenGI(Platform)
    && (IsFeatureLevelSupported(Platform, ERHIFeatureLevel::SM6) || bVulkanSM5 || bMetalSM5)
    && !IsForwardShadingEnabled(Platform);

说明

共同点：PC 和 Mobile 都先经过平台能力判断，只有通过平台门禁后，后续 Lumen GI 路径才可能启用。

不同点：PC Deferred 满足非 Forward Shading 和高特性级别条件时会进入；常规 Mobile Forward 会因为 Forward Shading 或平台能力被上游排除。

因此本章研究的是 PC Deferred Lumen GI 主线，不是 Mobile 常规渲染路径。

1. 上游汇聚点：RenderDiffuseIndirectAndAmbientOcclusion

if (ViewPipelineState.DiffuseIndirectMethod == EDiffuseIndirectMethod::Lumen)
{
    const ELumenIndirectLightingSteps StepsLeft = AsyncLumenIndirectLightingOutputs.StepsLeft;
    if (EnumHasAnyFlags(StepsLeft, ELumenIndirectLightingSteps::ScreenProbeGather))
    {
        DenoiserOutputs = RenderLumenFinalGather(...);
    }
}

说明

作用：这是 Lumen Final Gather 的直接上游入口，只有当前 view 的 DiffuseIndirectMethod 是 Lumen 时才会调用。↳ 下钻：RenderLumenScreenProbeGather 五阶段主流程

共同点：同步和异步路径最终都通过 FSSDSignalTextures 承接 Lumen GI 输出。

不同点：异步路径可能先保存到 FAsyncLumenIndirectLightingOutputs，后续 Composite 只消费已完成结果。

2. RenderLumenFinalGather 的默认输出初始化

ScreenSpaceBentNormalParameters.ShortRangeAOMode = 0;
ScreenSpaceBentNormalParameters.ShortRangeAOTexture = SystemTextures.Black;
ScreenSpaceBentNormalParameters.ShortRangeGITexture = nullptr;
RadianceCacheParameters.RadianceProbeIndirectionTexture = nullptr;
UpsampleParameters.DownsampleFactor = 1;
UpsampleParameters.DownsampledSceneDepth = nullptr;
UpsampleParameters.DownsampledSceneWorldNormal = nullptr;

说明

作用：总入口先给旁路输出设置安全默认值，避免某条 gather 路径不写某些参数时留下脏数据。

共同点：三条 Final Gather 路径共享这些输出参数。

不同点：具体路径可以覆盖这些默认值。例如 ScreenProbeGather 可能生成 ShortRangeAO 或 downsampled GI 参数，IrradianceFieldGather 可能设置 upsample 参数。

3. Final Gather 方法选择

const ELumenFinalGatherMethod FinalGatherMethod = Lumen::GetFinalGatherMethod(*View.Family, ShaderPlatform);

if (UseIrradianceFieldGather())
    return ELumenFinalGatherMethod::IrradianceFieldGather;
else if (Lumen::UseReSTIRGather(ViewFamily, ShaderPlatform))
    return ELumenFinalGatherMethod::ReSTIRGather;
else
    return ELumenFinalGatherMethod::ScreenProbeGather;

说明

作用：这是 Final Gather 的核心发散点，决定后续使用哪种间接光估计策略。

共同点：三条路径都必须生成同一类输出：FSSDSignalTextures，并通过旁路参数把 Composite 需要的辅助信息带出去。

不同点：IrradianceFieldGather 以世界空间 Radiance Cache / probe field 为核心；ReSTIRGather 以 reservoir 重采样为核心；ScreenProbeGather 以屏幕 probe trace / filter / integrate 为核心。

4. 三路实现分发

IrradianceFieldGather

世界空间辐照度场路径，偏缓存化和跨视角稳定。适合更低成本/较低质量目标。

暂无独立解析文档

ReSTIRGather

基于 reservoir 的时空/空间重采样路径，目标是用更少 ray 获得更有效采样。

暂无独立解析文档

ScreenProbeGather

默认高质量路径，屏幕 probe 多方向 trace，再通过滤波和积分输出 GI。

5. 三路后统一处理 Translucency GI Volume

ComputeLumenTranslucencyGIVolume(
    GraphBuilder, View, SceneTextures, FrameTemporaries,
    TranslucencyVolumeRadianceCacheParameters, ComputePassFlags);
return Outputs;

说明

作用：不管三条 Final Gather 路径选择哪一条，函数尾部都会尝试处理 Lumen translucency GI volume，然后返回统一输出。

共同点：三条路径都共用同一个尾部处理和返回点。

不同点：不同路径填充的 TranslucencyVolumeRadianceCacheParameters 可能不同，尾部只消费这个统一参数。

6. 输出契约：FSSDSignalTextures + 旁路参数

FSSDSignalTextures Outputs;
return Outputs;

FLumenScreenSpaceBentNormalParameters& ScreenSpaceBentNormalParameters
FLumenUpsampleParameters& UpsampleParameters
LumenRadianceCache::FRadianceCacheInterpolationParameters& RadianceCacheParameters

说明

主输出是 FSSDSignalTextures，后续 Composite 通过它读取 diffuse GI、backface GI、rough specular 和 reflection 输入。

共同点：三条 Final Gather 实现都要遵守这个输出契约。

不同点：有些信息不是放在 FSSDSignalTextures 里，而是通过引用参数旁路带出，例如 bent normal、upsample 参数和 Radiance Cache 参数。其中 RadianceCacheParameters（世界空间辐照度缓存）由 ScreenProbeGather 内部更新并旁路带出，供 Composite / 半透明体积等下游采样。↳ 下钻：Radiance Cache 解析

最终总结

骨架

RenderLumenFinalGather 是 PC Deferred Lumen GI 的 Final Gather 总入口。它本身不是 Mobile Forward 入口，Mobile 通常在平台或渲染路径门禁处被排除。

这个函数的核心价值是统一输出契约：三条不同 Final Gather 算法都要回到 FSSDSignalTextures 和相关旁路参数。

阅读建议

先记住这一层：RenderDiffuseIndirectAndAmbientOcclusion 是上游调用入口，RenderLumenFinalGather 是 Lumen Final Gather 总调度，RenderLumenScreenProbeGather 只是其中默认的一条分支。
