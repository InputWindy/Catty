1. FScreenProbeTemporalReprojectionCS 参数结构

说明

一趟 CS 同时处理三条输出通道（Diffuse / BackfaceDiffuse / RoughSpecular）加上累积计数图，输入与输出各成一组：读上帧历史 + 本帧结果，写本帧新历史。RWTexture2DArray 的 Z 维是 Substrate closure（多层材质），普通场景 Z=1。

共同点输出 UAV 均带 SkipBarrier，因为每像素独立写、互不依赖，允许 GPU overlap，与 Lumen 其它逐像素 CS 一致。

2. permutation 维度

permutation取值含义
FValidHistorybool历史 + 深度历史都在 → 走重投影混合；否则直接用本帧（首帧/失效）
FFastUpdateModeNeighborhoodClampbool是否用邻域颜色包围盒钳制重投影历史（防鬼影），由 CVar 控制
FOverflowTileboolSubstrate overflow tile 路径（当前 #if 0 停用）
FSupportBackfaceDiffusebool是否处理双面/透射漫反射通道（植被等）
FIntegrateDownsampleFactor1~2与 ⑤ 积分下采样因子对齐
FShortRangeAOMode0~20=关；1=普通；2=在时域里带 bent normal
FShortRangeAODownsampleFactor1~2短程 AO 下采样
FShortRangeGIbool是否同时时域累积短程 GI

说明

核心只有前两维：FValidHistory 决定"混不混历史"，FFastUpdateModeNeighborhoodClamp 决定"混历史时防不防鬼影"。其余维度都是把短程 AO/GI、Backface、Substrate 等可选通道折进同一趟 CS，避免多次 dispatch。RemapPermutation 会把无效组合（如 AOMode=0 时的 DownsampleFactor）收敛掉以减少 shader 变体。

3. 历史 RT 清单与有效性校验

说明

历史分两类：光照历史（存在 ScreenProbeGatherState，本步自己产自己用）与几何历史（深度/法线，存在 StochasticLighting，多个 Lumen 环节共享）。重投影需要几何历史来判断"上帧的这个像素今天还是同一个表面吗"——不是就不能复用。

不同点门禁校验非常严格：格式、分辨率、closure 数任一变化都丢历史从头累积。这是防止读到未初始化/错配数据的安全阀，宁可闪一帧噪也不能读脏。

4. Fast Update Mode 系数

说明

这四个系数共同定义"混多少历史"：MaxFramesAccumulated 定上限（静止时最多累积多少帧），LightIsMoving 比例经 InvFraction... 放大后触发快更新、把有效累积帧数往下压（受 MaxFastUpdateModeAmount 限幅），PreExposureCorrection 则保证不同曝光帧的历史亮度可比。

共同点"lerp(历史, 本帧, 1/(N+1))"是指数滑动平均的标准形式，与 ④ 时域滤波、Surface Cache Radiosity 累积同构。

5. 存历史与替换输出

说明

存历史受两道开关保护：ViewState 存在且非只读（截图/离屏等场景可能只读），以及 GLumenScreenProbeTemporalFilter 开启。累积计数图必须一起存，否则下一帧无从知道每个像素已累积多少帧。

不同点替换输出用的是入参引用（FRDGTextureRef&），因此调用方 RenderLumenScreenProbeGather 无需额外接收返回值，拿到的自然是去噪版——历史机制对上层完全透明。
