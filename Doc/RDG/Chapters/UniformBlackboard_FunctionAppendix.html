#7 附录 · UB / Blackboard 接口

本篇给出 FRDGBlackboard 的 Create 真实源码与接口表（RenderGraphBlackboard.h，180 行）。

FRDGBlackboard::Create（真实源码）

// RenderGraphBlackboard.h : L59-L70/** Creates a new instance of a struct. Asserts if one already existed. */ template <typename StructType, typename... ArgsType> StructType& Create(ArgsType&&... Args) { using HelperStructType = TStruct<StructType>; const int32 StructIndex = GetStructIndex<StructType>(); if (StructIndex >= Blackboard.Num()) { Blackboard.SetNumZeroed(StructIndex + 1); } // ...在图分配器上构造 StructType，存入 Blackboard[StructIndex]，返回引用 }

批注

GetStructIndex<StructType>() 靠 RDG_REGISTER_BLACKBOARD_STRUCT 特化出的稳定类型名换算成数组索引，因此 blackboard 底层就是个 TArray，按类型索引存放。Create 若同类型已存在会 assert——保证"一次创建"的语义。

接口表

接口作用
Create<T>(Args...)创建实例（已存在则 assert），返回可变引用
GetChecked<T>()取实例（不存在则 assert），只读/可变两版
Get<T>()取实例指针，不存在返回 nullptr
RDG_REGISTER_BLACKBOARD_STRUCT(T)注册类型（模板特化 GetTypeName）
GraphBuilder.CreateUniformBuffer(Params)创建 RDG uniform buffer，返回 TRDGUniformBufferRef<T>
