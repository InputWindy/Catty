// 一个典型 RDG compute pass 的完整生命（业务代码模式） // [1] 声明参数结构体（#10：宏→UBMT 元数据） BEGIN_SHADER_PARAMETER_STRUCT(FMyCS::FParameters, ) SHADER_PARAMETER_RDG_UNIFORM_BUFFER(FViewUniformShaderParameters, View) // #12 UB 引用 SHADER_PARAMETER_RDG_BUFFER_SRV(StructuredBuffer<float>, Input) // #10 UBMT=读 SHADER_PARAMETER_RDG_BUFFER_UAV(RWStructuredBuffer<float>, Output) // #10 UBMT=写 END_SHADER_PARAMETER_STRUCT() // [2] 建资源（#4 CreateBuffer；此刻只是句柄，无显存 #2） FRDGBufferRef Output = GraphBuilder.CreateBuffer(Desc, TEXT("MyOutput")); // Name→vis #17 // [3] 填参数 + 加 pass（#3 pass；#9 FComputeShaderUtils 转发到 AddPass #4） auto* Params = GraphBuilder.AllocParameters<FMyCS::FParameters>(); Params->Input = GraphBuilder.CreateSRV(InputBuffer); Params->Output = GraphBuilder.CreateUAV(Output); FComputeShaderUtils::AddPass(GraphBuilder, RDG_EVENT_NAME("MyCS"), // EventName #1 Shader, Params, GroupCount); // flags 默认 Compute #3 // [4] 提取跨帧（#16；设 bExtracted 成剔除根 #5，AccessFinal=SRV #14） GraphBuilder.QueueBufferExtraction(Output, &PersistentOutput, ERHIAccess::SRVMask); // [5] 执行——此刻才真正跑 #5 编译 + #6 执行 GraphBuilder.Execute();

批注：每行落在哪章

[1] 参数宏展开成 UBMT 元数据（#10），Input=SRV 标记读、Output=UAV 标记写——这是 RDG 后续一切推导的信息源（#3）。[2] CreateBuffer 返回虚拟句柄（#4），此刻 ResourceRHI==nullptr（#2），Name 供 vis（#17）。[3] FComputeShaderUtils::AddPass 转发到 GraphBuilder.AddPass（#9→#4），造一个 TRDGLambdaPass（#3）。[4] QueueBufferExtraction 设 bExtracted（#16/#2），SRVMask 告诉 RDG 离图时的目标态（#14）。[5] Execute 内：编译（依赖/剔除/生命周期 #5）→ 瞬态分配（#15 给 FRHIBuffer #13）→ 收集/创建屏障（Input 若上个 pass 是 UAV 写，这里插 UAV→SRV transition #6/#14）→ 逐 pass 序言提屏障+执行 lambda（lambda 里 SetShaderParameters 绑定 #11 + Dispatch）→ 帧末把 Output 提取到 PersistentOutput。整条链，前 18 章各司其职。

在其它 6 本书里的落点 Where RDG appears

书RDG 的典型用法
Nanite剔除/光栅一长串 compute pass；间接派发用回调版 CreateBuffer（#4 延迟尺寸）；Visbuffer/GBuffer 走 RDG 纹理 + ERHIAccess 转换
Lumen屏幕探针/Radiance Cache 大量 RDG buffer；历史帧靠 Queue*Extraction+RegisterExternal* 跨帧（#16）
虚拟纹理 / ShadowVSM 页表更新与阴影投影都是 RDG pass；页物理纹理走外部注册
MegaLights / TSR采样/去噪/12-pass 全是 RDG；时域历史帧靠提取+注册；异步计算 pass（#6）藏光追开销

回看那 6 本书的任何一个 pass 声明——GraphBuilder.AddPass(...)、SHADER_PARAMETER_RDG_*、QueueBufferExtraction、ERHIAccess::UAVCompute——你都能一眼说出它在 RDG 生命周期的哪一步、由哪章解释。RDG 作为公共底座的价值，正在于此。
