#16 图内外互通桥 · persistent / 跨帧 / 非 RDG 边界

RDG 图是单帧的，但渲染世界里有大量跨帧、persistent、非 RDG的资源（历史帧、CPU 回读、第三方模块）。它们与图的交界靠一组桥接 API：RegisterExternal*（进）、QueueExtraction（出）、ConvertToExternal（立即出）、UseExternalAccessMode（图外安全读）。这是实战 bug 高发区。源码取自 RenderGraphBuilder.h。

四类互通操作 Four bridges

操作方向用途
RegisterExternalTexture/Buffer外 → 内把图外池化资源纳入图，得图内句柄
QueueTextureExtraction / QueueBufferExtraction内 → 外（延迟）图执行完把资源提取到外部指针（跨帧）
ConvertToExternalTexture / …Buffer内 → 外（立即）当场把 RDG 资源转成外部池化对象
UseExternalAccessMode / UseInternalAccessMode内 ↔ 外（只读窗口）让非 RDG 代码在图执行期安全读某资源

配套附录

各接口全签名与 ERHIAccess AccessFinal 语义见 → 互通 API 附录。

注册与提取：进出图 Register / Extract

// RenderGraphBuilder.h : L79-L95, L345-L360// 外 → 内：把 IPooledRenderTarget / FRDGPooledBuffer 注册进图 FRDGTextureRef RegisterExternalTexture(const TRefCountPtr<IPooledRenderTarget>& ExternalPooledTexture, ...); FRDGBufferRef RegisterExternalBuffer(const TRefCountPtr<FRDGPooledBuffer>& ExternalPooledBuffer, ERDGBufferFlags Flags, ERHIAccess AccessFinal); // 内 → 外（延迟到执行末）：把图内资源提取到外部指针 void QueueTextureExtraction(FRDGTextureRef Texture, TRefCountPtr<IPooledRenderTarget>* OutPtr, ERHIAccess AccessFinal, ...); void QueueBufferExtraction(FRDGBufferRef Buffer, TRefCountPtr<FRDGPooledBuffer>* OutPtr, ERHIAccess AccessFinal); // 内 → 外（立即）：当场物化成外部对象 const TRefCountPtr<IPooledRenderTarget>& ConvertToExternalTexture(FRDGTextureRef Texture);

批注：AccessFinal 是关键

几乎每个接口都带 ERHIAccess AccessFinal（#14）——它告诉 RDG"这个资源离开图时应处于哪种访问态"。为什么重要？因为图外世界要用它：若提取给下一帧当 SRV 读，AccessFinal 就该是 SRVMask，RDG 会在图末把它 transition 到该态；给错了态，图外一读就是脏数据或竞态。注册（RegisterExternalTexture）设 bExternal（#2）——成为剔除根，产它的 pass 不被剔（#5）。提取（QueueTextureExtraction）设 bExtracted——同样是剔除根。TSR/Lumen 的历史帧就是"上帧 QueueTextureExtraction 出来、本帧 RegisterExternalTexture 进去"这样跨帧接力的。

UseExternalAccessMode：给非 RDG 代码开只读窗口 External access mode

// RenderGraphBuilder.h : L384-L390void UseExternalAccessMode(FRDGViewableResource* Resource, ERHIAccess ReadOnlyAccess, ERHIPipeline Pipelines = ERHIPipeline::Graphics); // 之后用 UseInternalAccessMode 恢复 RDG 追踪（源码注释：safe to call）

批注：最容易出 bug 的一个

有时一个 RDG 资源要被图外、非 RDG 的代码读（比如某个老式渲染路径、或某 RHI 直接调用）。UseExternalAccessMode 把资源切到一个稳定只读态（ReadOnlyAccess），并暂停 RDG 对它的屏障追踪——这样图外代码能安全读它，而 RDG 不会在中途给它插 transition 破坏状态。用完必须 UseInternalAccessMode 恢复追踪。实战里忘了恢复、或 ReadOnlyAccess 给错管线（Graphics vs AsyncCompute），是很隐蔽的 bug——校验层（#8）能抓一部分。能不用就不用：绝大多数资源交互应走 Register/Extract，只有真正无法纳入图的图外只读访问才用它。

本篇小结 Summary

记住这几点

1. 四类桥：RegisterExternal*（外→内）、QueueExtraction（内→外延迟）、ConvertToExternal（内→外立即）、UseExternalAccessMode（图外只读窗口）。

2. ERHIAccess AccessFinal 是交接关键：告诉 RDG 资源离开图时的目标态，给错就是图外脏数据/竞态。

3. 注册设 bExternal、提取设 bExtracted——都成剔除根（#2/#5）。TSR/Lumen 历史帧靠"提取→下帧注册"跨帧接力。

4. UseExternalAccessMode 是 bug 高发区：必配 UseInternalAccessMode 恢复，能不用就不用。
