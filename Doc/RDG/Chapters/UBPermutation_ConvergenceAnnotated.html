#12 Uniform Buffer 与 Shader Permutation

Part 2 收尾。两件与参数结构体协作的机制：引用 uniform buffer（SHADER_PARAMETER_STRUCT_REF / SHADER_PARAMETER_RDG_UNIFORM_BUFFER——把整块 UB 作为一个参数成员嵌进来）；Shader Permutation（TShaderPermutationDomain——同一 shader 按维度编出多变体，与参数结构体独立但配套）。源码取自 ShaderParameterMacros.h、ShaderPermutation.h。

两个正交的概念 Two orthogonal things

概念是什么正交性
Uniform Buffer 引用把一整块 UB（一组常量+资源）作为参数成员嵌入决定 shader 读到什么数据
Shader Permutation按编译维度（bool/int/enum）把一个 shader 编成多个变体决定编译出哪份 shader 代码

为什么放一章

它们都不是"图机制"，而是参数结构体的邻居：UB 引用扩展了参数能带的数据形态；permutation 决定了这份参数结构体最终对接哪一份编译好的 shader。理解它们才能读懂真实 shader 类（class FMyCS : public FGlobalShader { ... using FPermutationDomain = ...; }）。

配套附录

SHADER_PARAMETER_STRUCT_REF、TShaderPermutationDomain 维度类型见 → UB/Permutation 附录。

引用 Uniform Buffer：把一块 UB 当成员 UB reference

// ShaderParameterMacros.h : L1854#define SHADER_PARAMETER_STRUCT_REF(StructType,MemberName) \ // 展开为 UBMT_REFERENCED_STRUCT 成员：把 StructType 的 uniform buffer 引用嵌进来

批注

SHADER_PARAMETER_STRUCT_REF 让一个参数结构体引用另一块 uniform buffer（如 View UB、场景 UB），成员类型是 UBMT_REFERENCED_STRUCT。与之配套的 SHADER_PARAMETER_RDG_UNIFORM_BUFFER（#7）则引用RDG uniform buffer——区别在于后者里的 RDG 资源会被图追踪依赖。绑定时（#11），SetShaderParameters 遇到这类成员就把整块 UB 绑到 shader 的 uniform buffer 槽。这就是为什么几乎每个 pass 参数结构体第一行都是 SHADER_PARAMETER_RDG_UNIFORM_BUFFER(FViewUniformShaderParameters, View) ——把视图数据一整块带进来。

Shader Permutation：一个 shader 的多副人格 Permutation domain

// ShaderPermutation.h : L272struct TShaderPermutationDomain { /** Setup the dimension's type in permutation domain as itself so that a permutation * domain can be used as a dimension of another domain. */ // 由若干维度（TShaderPermutationBool / TShaderPermutationInt / enum 维度）组合 // 每种维度取值的笛卡尔积 = 该 shader 要编译的全部变体 };

批注

TShaderPermutationDomain<DimA, DimB, ...> 把一个 shader 的编译期开关组织成维度：每个维度是个 bool/int/enum（如 "是否用半精度""质量档 0-3"），所有维度取值的笛卡尔积就是要编译的全部 permutation。shader 类里写 using FPermutationDomain = TShaderPermutationDomain<...>;，运行时用一个 FPermutationDomain PermutationVector 选具体变体，再 GetShader(PermutationVector) 取对应编译产物。它和参数结构体正交：permutation 选"哪份代码"，参数结构体填"什么数据"。ModifyCompilationEnvironment 则把维度值转成 shader 的 #define。理解它，才明白为什么同一个 .usf 能编出成百上千个变体（Nanite/Lumen 的 permutation 爆炸也源于此）。

本篇小结 Summary

记住这几点

1. SHADER_PARAMETER_STRUCT_REF（普通 UB）/ SHADER_PARAMETER_RDG_UNIFORM_BUFFER（RDG UB，被图追踪）把整块 uniform buffer 作为参数成员引用。

2. TShaderPermutationDomain 用维度笛卡尔积定义 shader 变体；与参数结构体正交——permutation 选代码、参数填数据。

3. Part 2 完结：宏生成元数据（#10）→ 绑定到 RHI（#11）→ UB 引用与 permutation（#12）。这套是 RDG pass 参数的完整支撑。
