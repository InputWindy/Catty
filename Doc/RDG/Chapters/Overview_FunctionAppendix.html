ERDGPassFlags · 完整真实源码

// RenderGraphDefinitions.h : L129-L161enum class ERDGPassFlags : uint16 { /** Pass doesn't have any inputs or outputs tracked by the graph. Only for parameterless AddPass. */ None = 0, /** Pass uses rasterization on the graphics pipe. */ Raster = 1 << 0, /** Pass uses compute on the graphics pipe. */ Compute = 1 << 1, /** Pass uses compute on the async compute pipe. */ AsyncCompute = 1 << 2, /** Pass uses copy commands on the graphics pipe. */ Copy = 1 << 3, /** Pass (and its producers) will never be culled. Necessary if outputs cannot be tracked by the graph. */ NeverCull = 1 << 4, /** Render pass begin/end skipped and left to the user. Only valid with 'Raster'. Disables merging. */ SkipRenderPass = 1 << 5, /** Pass will never have its render pass merged with other passes. */ NeverMerge = 1 << 6, /** Pass will never run off the render thread. */ NeverParallel = 1 << 7, /** Pass uses copy commands but writes to a staging resource. */ Readback = Copy | NeverCull }; ENUM_CLASS_FLAGS(ERDGPassFlags);

逐标志批注

Raster / Compute / AsyncCompute / Copy：声明 pass 用哪种命令、在哪条管线（graphics 还是 async compute pipe）。这直接决定 #6 执行时 pass 被派发到哪个队列，以及需要在图形/异步计算之间插的跨队列同步（fence）。

NeverCull：告诉 #5 编译的剔除算法"别剔我"——当一个 pass 的输出是图无法追踪的（比如写到外部/staging 资源、或有副作用），必须打这个标志，否则会被当成"没人消费"而剔掉。Readback = Copy | NeverCull 就是这个组合的现成别名。

SkipRenderPass / NeverMerge：影响光栅 pass 的 RenderPass 合并优化——RDG 会把连续、兼容的 raster pass 合并成一个 RHI render pass 以省开销，这两个标志用来退出该优化。

NeverParallel：强制该 pass 只在渲染线程执行，不进并行任务（对应 #1 主文档讲的并行约定的"反向开关"）。

ERDGBufferFlags（节选真实源码）

// RenderGraphDefinitions.h : L163-L169/** Flags to annotate a render graph buffer. */ enum class ERDGBufferFlags : uint8 { None = 0, /** Tag the buffer to survive through frame, important for multi-GPU alternate frame rendering. */ MultiFrame = 1 << 0, // ...（更多标志见源码） };

要点

MultiFrame 让 buffer 跨帧存活——对应 #16 讲的"跨帧/persistent 资源"场景。普通 RDG buffer 是单帧瞬态的（帧末即回收进池复用）；只有显式标记或被 QueueBufferExtraction 提取的才跨帧。
