// RenderGraphBuilder.cpp : L1904-L2003（节选）CollectPassBarriersTask = AddSetupTask([this] { CompilePassBarriers(); CollectPassBarriers(); }, TaskPriority, bParallelCompileResources); // ...AllocatePooledBuffersTask / AllocatePooledTexturesTask 分配瞬态资源... CreateViewsTask = AddCommandListSetupTask([this, InViews = MoveTemp(CollectResourceContext.Views)] (FRHICommandListBase& RHICmdListTask) { /* 建 SRV/UAV RHI 视图 */ }, MakeArrayView<FTask>({ CollectPassBarriersTask, AllocatePooledBuffersTask, AllocatePooledTexturesTask }), TaskPriority, bParallelCompileResources);

批注

CreateViewsTask 显式依赖 {CollectPassBarriersTask, AllocatePooledBuffersTask, AllocatePooledTexturesTask}——即"建视图"必须等"收集屏障 + 分配资源"完成。这正是用任务图表达"执行准备"的内部依赖，与 bParallelCompileResources 开关配合决定是否并行跑这些准备工作。
