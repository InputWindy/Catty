外部资源桥接接口（真实签名）

// RenderGraphBuilder.h : L79-L95（详见 #16）FRDGTextureRef RegisterExternalTexture(const TRefCountPtr<IPooledRenderTarget>& ExternalPooledTexture, ...); FRDGBufferRef RegisterExternalBuffer(const TRefCountPtr<FRDGPooledBuffer>& ExternalPooledBuffer, ERDGBufferFlags Flags = ...); FRDGBufferRef RegisterExternalBuffer(..., ERHIAccess AccessFinal);

批注

这组把图外持有的池化资源（IPooledRenderTarget / FRDGPooledBuffer）注册进图，得到图内句柄。带 ERHIAccess AccessFinal 的重载指定"图执行完该资源应处于哪种访问态"——这是 RDG 与图外世界交接屏障状态的关键，详见 #16 图内外互通桥。

提取 / 执行接口

// RenderGraphBuilder.h : L345-L360, L412void QueueTextureExtraction(FRDGTextureRef Texture, TRefCountPtr<IPooledRenderTarget>* OutPtr, ...); void QueueBufferExtraction(FRDGBufferRef Buffer, TRefCountPtr<FRDGPooledBuffer>* OutPtr); const TRefCountPtr<IPooledRenderTarget>& ConvertToExternalTexture(FRDGTextureRef Texture); void AddPassDependency(FRDGPass* Producer, FRDGPass* Consumer); // L249 void Execute(); // L412

批注

QueueTextureExtraction/QueueBufferExtraction 把图内资源标记为"执行完提取到图外指针"（设 bExtracted，成为剔除根——#2）。AddPassDependency 是手动加依赖的后门：极少数图无法自动推导的顺序约束时用（#5 会讲它内部如何处理跨管线）。
