0. 固定输入输出契约

Texture2D AmbientOcclusionTexture;
Texture2DArray DiffuseIndirect_Lumen_0;
Texture2DArray DiffuseIndirect_Lumen_1;
Texture2DArray DiffuseIndirect_Lumen_2;
Texture2DArray DiffuseIndirect_Lumen_3;
Texture2D DiffuseIndirect_Textures_0;
Texture2D DiffuseIndirect_Textures_1;
Texture2D DiffuseIndirect_Textures_2;
Texture2D DiffuseIndirect_Textures_3;
OutAddColor / OutMultiplyColor / OutColor

说明

Composite 的外部契约稳定：读若干间接光 signal、GBuffer、AO，输出到 SceneColor。上游 Gather 只要遵守 signal 语义即可。

1. 发散点：方案选择

#define DIM_APPLY_DIFFUSE_INDIRECT_SSGI                  1
#define DIM_APPLY_DIFFUSE_INDIRECT_SCREEN_PROBE_GATHER   2
#if DIM_APPLY_DIFFUSE_INDIRECT == DIM_APPLY_DIFFUSE_INDIRECT_SSGI
    #define CONFIG_SIGNAL_PROCESSING SIGNAL_PROCESSING_SSGI
    #define CONFIG_INPUT_TEXTURE_COUNT 2
#elif DIM_APPLY_DIFFUSE_INDIRECT == DIM_APPLY_DIFFUSE_INDIRECT_SCREEN_PROBE_GATHER
    #define COMPILE_SIGNAL_COLOR_ARRAY 3
    #define CONFIG_INPUT_TEXTURE_COUNT 4
#endif

说明

共同点：SSGI 和 Lumen 都会进入同一个 composite 出口，最终都要变成当前像素的间接光贡献。

不同点：SSGI 使用 ScreenSpaceDenoise 的 signal framework 解释输入；Lumen 使用四路显式 signal：diffuse、backface、rough specular、reflection。

2. 汇聚点：MainPS 共同准备

const uint2 PixelPos = uint2(SvPosition.xy);
const float2 SceneBufferUV = SvPositionToBufferUV(SvPosition);
const FLumenMaterialData Material = ReadMaterialData(PixelPos, SceneBufferUV);
const float DynamicAmbientOcclusion = AmbientOcclusionTexture.SampleLevel(AmbientOcclusionSampler, SceneBufferUV, 0).r;
const float3 TranslatedWorldPosition = mul(float4(GetScreenPositionForProjectionType(ScreenPosition, Material.SceneDepth), Material.SceneDepth, 1), View.ScreenToTranslatedWorld).xyz;
const float3 N = Material.WorldNormal;
const float3 V = -GetCameraVectorFromTranslatedWorldPosition(TranslatedWorldPosition);
const float NoV = saturate(dot(N, V));

说明

所有路径先汇聚到同一套像素上下文：位置、UV、材质、AO、法线、视线方向。Composite 是 material-aware pass。

3. SSGI 路径：不要跳过

#if DIM_APPLY_DIFFUSE_INDIRECT == DIM_APPLY_DIFFUSE_INDIRECT_SSGI
float3 UpsampleLegacySSGI(uint2 PixelPos, float2 SceneBufferUV, FLumenMaterialData Material)
{
    FSSDKernelConfig KernelConfig = CreateKernelConfig();
    KernelConfig.bSampleKernelCenter = true;
    KernelConfig.BufferLayout = CONFIG_SIGNAL_INPUT_LAYOUT;
    #if DIM_UPSCALE_SSGI
        KernelConfig.SampleSet = SAMPLE_SET_2X2_BILINEAR;
        KernelConfig.BilateralDistanceComputation = SIGNAL_WORLD_FREQUENCY_REF_METADATA_ONLY;
    #else
        KernelConfig.SampleSet = SAMPLE_SET_1X1;
        KernelConfig.bNormalizeSample = true;
    #endif
    KernelConfig.CompressedRefSceneMetadata = MaterialToCompressedSceneMetadata(Material.SceneDepth, Material.WorldNormal, Material.Roughness, Material.ShadingID);
    AccumulateKernel(KernelConfig, DiffuseIndirect_Textures_0, DiffuseIndirect_Textures_1, DiffuseIndirect_Textures_2, DiffuseIndirect_Textures_3, ...);
    return Sample.SceneColor.rgb;
}

说明

共同点：SSGI 路径和 Lumen 路径最终都会产出一份 diffuse indirect lighting，回到 MainPS 后续材质合成逻辑。

不同点：SSGI 的核心是 SSD kernel 采样与 bilateral upsample；它没有 Lumen 的 backface、rough specular、reflection 四路显式 texture array 语义。

4. Lumen 路径：四路 signal 读取

下钻：第 4 路 SpecularIndirect（Textures[3]）从哪来——RenderLumenReflections 镜面反射链路下钻：前 3 路 DiffuseIndirect / RoughSpecular（Textures[0..2]）从哪来——ScreenProbeGather 五阶段
#if DIM_APPLY_DIFFUSE_INDIRECT == DIM_APPLY_DIFFUSE_INDIRECT_SCREEN_PROBE_GATHER
#if DIM_UPSCALE_LUMEN_GI
    uint2 StochasticBilinearOffset = GetStochasticBilinearOffsetForUpsample(...);
    int2 UnclampedDownsampledCoord = (int2(PixelPos) - 1) / LumenGIDownsampleFactor + StochasticBilinearOffset;
    LumenBufferCoord = clamp(UnclampedDownsampledCoord, IntegrateViewMin, IntegrateViewMin + IntegrateViewSize - 1);
#endif
DiffuseIndirectLighting = DiffuseIndirect_Lumen_0.Load(uint4(LumenBufferCoord, 0, 0)).rgb;
RoughSpecularIndirectLighting = DiffuseIndirect_Lumen_2.Load(uint4(LumenBufferCoord, 0, 0)).rgb;
if (bLumenReflectionInputIsSSR)
    SpecularIndirectLighting = DiffuseIndirect_Textures_3.SampleLevel(GlobalPointClampedSampler, SceneBufferUV, 0).rgba;
else
    SpecularIndirectLighting = DiffuseIndirect_Lumen_3.SampleLevel(GlobalPointClampedSampler, float3(SceneBufferUV, 0), 0).rgba;

说明

共同点：Lumen 路径也只是在 MainPS 中生成 diffuse/specular 需要的中间 lighting 变量，之后继续进入统一材质合成。

不同点：Lumen 有四路显式输入，其中 diffuse 和 rough specular 可按低分辨率 LumenBufferCoord 取样，reflection 通常按屏幕 UV 取样。

5. Substrate vs Legacy GBuffer

共同点

SSGI 或 Lumen 得到间接光 signal 后，都要按当前像素材质解释。

Substrate

按 closure 遍历，每个 BSDF 单独计算 indirect lighting。

Legacy GBuffer

按 ShadingModelID 分支处理 Hair、Foliage、SSS、Cloth、ClearCoat、Toon。

6. Substrate 分支

#if SUBSTRATE_GBUFFER_FORMAT==1
Substrate_for(uint ClosureIndex = 0, ClosureIndex < SubstratePixelHeader.ClosureCount, ++ClosureIndex)
    const uint4 LumenFetchCoord = uint4(LumenBufferCoord, ClosureIndex, 0);
    const float3 InDiffuseLighting = DiffuseIndirect_Lumen_0.Load(LumenFetchCoord).rgb;
    const float3 InRoughSpecularLighting = DiffuseIndirect_Lumen_2.Load(LumenFetchCoord).rgb;
    const float4 InSpecularLighting = bLumenReflectionInputIsSSR ? InputSpecularLighting : DiffuseIndirect_Lumen_3.Load(LumenFetchCoord).rgba;
    FSubstrateBSDF BSDF = UnpackSubstrateBSDF(...);
    FSubstrateEnvLightResult SubstrateEnvLight = SubstrateEvaluateForEnvLight(...);
    OutBSDF.Diffuse += BSDFThroughput * SubstrateEnvLight.DiffuseWeight * (InDiffuseLighting * Occlusion.DiffuseOcclusion + ShortRangeGI);
    OutBSDF.Specular += BSDFThroughput * InGlossyLighting * SubstrateEnvLight.SpecularWeight;
#endif

说明

Substrate 是材质复杂路径。它对上游 Gather 透明，因为 Gather 只负责提供 array signal，Composite 内部按 closure 解释。

7. Legacy GBuffer 材质分支

FGBufferData GBuffer = Material.GBufferData;
float3 DiffuseColor = GBuffer.DiffuseColor;
float3 SpecularColor = GBuffer.SpecularColor;
if (GBuffer.ShadingModelID == SHADINGMODELID_HAIR) ...
if (GBuffer.ShadingModelID == SHADINGMODELID_TWOSIDED_FOLIAGE)
    BackfaceDiffuseIndirectLighting += SubsurfaceColor * DiffuseIndirect_Lumen_1.SampleLevel(...).rgb;
if (GBuffer.ShadingModelID == SHADINGMODELID_SUBSURFACE || GBuffer.ShadingModelID == SHADINGMODELID_PREINTEGRATED_SKIN)
    DiffuseColor += SubsurfaceColor;
if (GBuffer.ShadingModelID == SHADINGMODELID_CLOTH)
    DiffuseColor += ClothFuzz * GBuffer.CustomData.a;

说明

这里是材质模型发散区。Gather 不需要知道这些细节，Composite 自己决定不同材质如何使用同一份 indirect signal。

8. Diffuse 和 Specular 重新汇聚

IndirectLighting.Diffuse =
    (DiffuseIndirectLighting * DiffuseColor + BackfaceDiffuseIndirectLighting)
    * Occlusion.DiffuseOcclusion
    * EnergyPreservationFactor
    + ShortRangeGI * DiffuseColor;

RoughSpecularIndirectLighting *= Occlusion.SpecularOcclusion;
IndirectLighting.Specular = CombineRoughSpecular(GBuffer, HasBackfaceDiffuse(Material), NoV, SpecularIndirectLighting, RoughSpecularIndirectLighting, SpecularColor, EnvBRDFValue);

说明

无论中间如何发散，最后都会汇聚成两个结果：IndirectLighting.Diffuse 和 IndirectLighting.Specular。

9. 最终输出汇聚

LightAccumulator_Add(LightAccumulator, IndirectLighting.Diffuse + IndirectLighting.Specular, IndirectLighting.Diffuse, 1.0f, Material.bNeedsSeparateLightAccumulation);
OutAddColor = LightAccumulator_GetResult(LightAccumulator);
OutMultiplyColor = FinalAmbientOcclusion;
#if !ENABLE_DUAL_SRC_BLENDING && DIM_APPLY_DIFFUSE_INDIRECT
OutColor = SceneColor * OutMultiplyColor + OutAddColor;
#endif

说明

最后大汇聚：所有方案和材质路径都回到 SceneColor 写回。没有 dual source blending 时，公式就是 SceneColor * AO + Indirect；启用时由 C++ blend state 完成等价合成。

汇聚/发散总表

层级类型代表符号对外透明性
MainPS 输入准备汇聚ReadMaterialData / AO / N / V对上游透明
SSGI/Lumen发散DIM_APPLY_DIFFUSE_INDIRECT输入契约不同
SSGI 采样发散UpsampleLegacySSGI / AccumulateKernel对最终输出透明
Lumen 采样发散DiffuseIndirect_Lumen_0..3对 Gather 契约固定
Substrate/Legacy发散SUBSTRATE_GBUFFER_FORMAT对 Gather 透明
ShadingModel发散Hair/Foliage/SSS/Cloth/ClearCoat对 Gather 透明
Diffuse/Specular汇聚IndirectLighting.Diffuse/Specular内部统一
SceneColor 写回汇聚OutAddColor/OutMultiplyColor/OutColor输出固定

最终总结

骨架

外壳稳定：读当前像素材质 + 读间接光 signal + 输出到 SceneColor。

复杂度在发散区：SSGI/Lumen、Substrate/Legacy、ShadingModel、SSR/LumenReflection、上采样、dual source blending。

先记住四个汇聚点：MainPS 输入准备、IndirectLighting.Diffuse、IndirectLighting.Specular、OutAddColor/OutMultiplyColor。具体分支之后逐个展开。
