1. CompactTraces（命中压实 —— 级联能省的关键）

说明

CompactTraces 是级联管线的粘合剂，做三件事：

① 建一个原子计数器和一个紧凑列表 buffer；② CompactTracesCS 遍历所有光线，对"仍需继续追踪"的 texel（未命中、且在距离/深度范围内）用原子操作追加进紧凑列表；③ SetupCompactedTracesIndirectArgs 把计数器转成 indirect dispatch 参数。

这样下一个追踪后端就能用 CompactedTraceParameters.IndirectArgs 只对紧凑列表里的光线 dispatch——GPU 不会为已命中的光线启动线程。bWaveOps 用 wave 级原子聚合减少全局原子争用；bCullByDistanceFromCamera / CompactionMaxTraceDistance 控制哪些距离段的光线交给当前后端，bCompactForSkyApply=true（兜底层）则把所有 miss 都收进来以便统一应用 Radiance Cache + 天光。

2. 三个追踪后端 CS 的职责

后端 CS覆盖范围关键 permutation
FScreenProbeTraceScreenTexturesCS屏幕空间 ray march（HZB 加速），命中屏幕内可见几何，复用上一帧 SceneColor。最廉价。FHierarchicalScreenTracing / FTraceFullResDepth / FTerminateOnLowOccupancy / FRadianceCache

FScreenProbeTraceVoxelsCSGlobal SDF 追踪 + 应用 Radiance Cache + 天光。兜底层，保证每根光线都有结果。FTraceVoxels / FRadianceCache / FSimpleCoverageBasedExpand / FScreenProbeExtraAO

说明

三个后端共享几个 permutation：FStructuredImportanceSampling（按上一阶段的 RayInfosForTracing 方向表发线）、FRadianceCache（命中或 miss 时用世界空间缓存补光）、FHairStrands（可选头发）。

差异在覆盖范围与代价：Screen 只看屏内、几乎免费；MeshSDF/HWRT 看屏外几何、较贵；Voxels 精度最低但永远给结果。ClearTracesCS 与 SetupVisualizeTraces 是辅助 pass（清零与调试可视化）。

其中 FRadianceCache permutation 所读的世界空间缓存，其更新流水线见 Radiance Cache 函数附录。

3. RenderHardwareRayTracingScreenProbe（硬件 RT 分支概览）

说明

硬件 RT 分支实现在单独文件 LumenScreenProbeHardwareRayTracing.cpp，与 Mesh SDF 分支互斥。它的编排模式和软件后端一致：先 CompactTraces 压实，再对硬件加速结构发线，命中后走同一套 Surface Cache 采样。

硬件 RT 的公共骨架（门禁与回退 / Inline vs RayGen 派发 / SurfaceCache vs Hit Lighting 着色 / 两层 TLAS / 共享参数）已有专题解析：↳ 下钻：Hardware Ray Tracing 后端。本附录只标明它在 TraceScreenProbes 级联中的位置：作为"后端②"的高精度选项，输出契约与其它后端完全一致，因此对下游 Filter 透明。
