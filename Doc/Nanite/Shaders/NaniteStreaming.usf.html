[numthreads(1, 1, 1)] void ClearStreamingRequestCount()   // 每帧清零流送请求计数器
[numthreads(64, 1, 1)] void Memcpy(uint3 GroupID, uint GroupIndex)   // GPU 端批量拷贝
// Memcpy：把流入的页数据从暂存缓冲搬到目标位置（GPU 侧并行拷贝）

说明

Nanite 流送由 GPU 生成页请求（剔除遍历遇缺页时写请求）、CPU 读回后从磁盘加载、再搬进显存转码。本 shader 是流送管线的两个小工具：ClearStreamingRequestCount 每帧把请求计数器归零（准备收集本帧新请求）；Memcpy 是 GPU 端并行批量拷贝——把加载进暂存区的页数据搬到目标缓冲（比逐次 CopyBuffer 更省 barrier）。搬完由 Transcode 解码。请求收集/优先级排序等主逻辑在 C++ 侧（StreamingManager），shader 只做这些 GPU 原语。
