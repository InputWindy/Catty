// 每曲线基元取控制点 → 投影到屏幕 → 沿曲线 DDA 步进

说明

头发/毛发是曲线基元（curve/strand），不是三角，需专门光栅。NaniteCurve 把 Nanite 曲线簇投影到屏幕后用 DDA（数字微分分析器，沿线段逐像素步进）光栅成细线段，写进 Visbuffer（带曲线 ID 供延迟着色）。CurveTileClear 准备 tile 缓冲。这让 Nanite 统一处理"实体网格 + 发丝"——发丝也享受 Nanite 的剔除/LOD/延迟材质。与 Rasterizer 的曲线分支、CurveCommon 配套。是 Nanite 从实体扩展到线状几何的能力，属可编程光栅范畴。
