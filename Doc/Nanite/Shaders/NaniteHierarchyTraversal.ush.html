GroupNodeData + 工作队列遍历模板（回调驱动）

0. 回调模板化的持久线程遍历（核心）

uint4 GetGroupNodeData(uint NodeIndex) / SetGroupNodeData(...)   // groupshared 节点缓存
// 持久线程从全局队列取节点 → 调回调 ProcessNodeBatch/ProcessCluster
// 回调返回子节点/簇 → 入队继续；LDS 缓存本组节点减全局访问
// 调用方提供 FTraversalCallback 特化遍历行为（剔除/RT/流出）

说明

Nanite 多处需要遍历同一棵 BVH，但"遍历到节点做什么"各异（剔除测试/光追选簇/流出选簇）。NaniteHierarchyTraversal 把遍历框架抽出来：持久线程从全局工作队列取节点、用 groupshared（GroupNodeData）缓存本组节点减少全局访问、把回调返回的子节点/簇再入队——而"节点如何处理"交给调用方的回调 functor（HLSL 用宏/模板模拟）。簇剔除 传剔除回调、光追/流出 传各自回调。这是"遍历逻辑与业务逻辑解耦"的框架层，配 TraversalCommon 的队列结构。
