NaniteClusterCulling.usf 汇聚/发散批注版

Nanite 剔除漏斗的第二三级：拿 InstanceCull 产出的候选节点，用 persistent threads + 工作队列（FQueueState）遍历 BVH，边走边做 LOD cut 与视锥/HZB 剔除，最终吐出 VisibleCluster。一个入口 NodeAndClusterCull 按 CULLING_TYPE 分派节点/簇/持久三态。说明：完整文件 1153 行，下方内嵌核心入口的真实源码。

一眼看懂：一条解题弧线

候选节点来自 InstanceCull（QueueState）
▶
NodeCull遍历 BVH 节点：LOD 判据 + 视锥/HZB，推子节点或候选簇
▶
ClusterCull候选簇最终剔除测试 → VisibleCluster
▶
VisibleClustersSWHW标好软/硬光栅 → #6

0. 输入输出契约

// 输入：候选节点/簇（QueueState，来自 InstanceCull）+ 层级/簇数据（#4）
FQueueState  // 节点/簇的读写游标 + 计数（PassState[0]主 / [1]后）
VisibleClustersSWHW  // 输出：可见簇，SW/HW 两段分别写

说明

输入是 InstanceCull 写进 FQueueState 的候选节点，以及 #4 流入的 Hierarchy/ClusterPageData。输出是 VisibleClustersSWHW（一个 buffer 两端分别是软光栅段与硬光栅段），直接喂 #6 光栅。遍历遇缺页时在此写 StreamingRequests（回 #4）。

1. 一个入口三态分派

#if CULLING_TYPE == NANITE_CULLING_TYPE_NODES     NodeCull(...)
#elif ... == NANITE_CULLING_TYPE_CLUSTERS         ClusterCull(...)
#elif ... == PERSISTENT_NODES_AND_CLUSTERS        PersistentNodeAndClusterCull(...)

说明

共同点三态都用同一 CS NodeAndClusterCull + 同一回调 FNaniteTraversalClusterCullCallback，围绕 FQueueState 工作队列协作。

不同点NODES 遍历 BVH 节点（测 LOD/视锥/HZB，推子节点或候选簇）；CLUSTERS 对候选簇做最终剔除→VisibleCluster；PERSISTENT_NODES_AND_CLUSTERS 用持久线程在一个内核里边遍节点边剔簇（r.Nanite.PersistentThreadsCulling，默认 0，主机等固定硬件可开），省多轮 dispatch 的 barrier。

2. persistent 遍历：工作队列 + 常驻线程

FQueueState.PassState[0/1].NodeWriteOffset / NodeCount
FQueueState.PassState[0/1].ClusterWriteOffset
// 常驻线程组自旋从队列取活：产出子节点就 push 回队列，空了取下一个

说明

BVH 遍历的工作量遍历前无法预知（实例深度差异大）。persistent culling 让固定数量线程组常驻并自旋从队列取活——谁产出子节点就 push 回队列、谁空了取下一个，天然负载均衡，一次 dispatch 完成整棵 BVH 的自适应遍历。LOD cut 就在节点遍历时按 ParentError > Threshold ≥ ClusterError 定（见 #2/#5）。MaxNodes/MaxCandidateClusters 是队列容量上限。

3. CalculateSafeRasterizerArgs：给光栅兜底

InRasterizerArgsSWHW → OutSafeRasterizerArgsSWHW
// 钳制 indirect args：不越界、SW 段与 HW 段不重叠

说明

剔除产出的可见簇数写进 SW/HW 两段。CalculateSafeRasterizerArgs 把光栅 indirect dispatch/draw 的参数钳制到安全范围，防止越界、防止 SW/HW 段在同一 buffer 里重叠——因为两段是从 buffer 两端相向分配的（见 #6）。InitArgs 则在剔除前清零 QueueState、准备主/后趟的 args。

最终总结

骨架

一个 CS（NodeAndClusterCull）三态分派，围绕 FQueueState 工作队列 + persistent threads 遍历 BVH，边走边定 LOD cut 与剔除，产出 VisibleClustersSWHW。
