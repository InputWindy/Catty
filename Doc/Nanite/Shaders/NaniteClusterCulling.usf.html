// 持久线程：循环从全局队列取节点，剔除→合格则把子节点/簇再入队
void TransformNodeCullingBounds(...)   // 节点包围球变换到视图空间

说明

Nanite 每个网格是一棵 BVH（层级簇组），叶子是 128 三角的簇。NodeAndClusterCull 用持久线程模型（persistent threads）：线程组不退出，循环从全局工作队列取节点处理——因为 BVH 遍历工作量不可预知，持久线程比固定派发更能均衡负载。每取一节点，TransformNodeCullingBounds 把其包围球变到视图空间，做视锥 + HZB 剔除。这是 GPU 上的动态队列驱动遍历，避免 CPU 回读或多次派发。

说明

本 shader 的汇聚点是 LOD 切割（cut selection）：Nanite BVH 每层是同一几何的不同精度。遍历到某节点时比较它的投影屏幕误差与阈值——误差已足够小（该 LOD 在屏幕上够精细）就把这一层选为 cut、其簇入可见队列；否则下钻更精细的子节点。这样每个像素区域都自动选到"刚好 ≈1 像素/三角"的 LOD，实现无缝连续 LOD（no popping）。选中的簇原子写入队列交给 Rasterizer，并按边长分到软/硬光栅（见 RasterBinning）。这是 Nanite "屏幕无关几何复杂度"的核心机制。
