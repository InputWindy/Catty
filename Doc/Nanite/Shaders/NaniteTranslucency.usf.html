TranscodeRasterizerArgs @ L20（numthreads 64）

0. 半透明光栅参数转码（核心）

[numthreads(64, 1, 1)] void TranscodeRasterizerArgs(uint RasterBin : SV_DispatchThreadID)
// 把每个光栅 bin 的可见簇数转成半透明路径所需的间接派发参数
// 半透明不写 Visbuffer 深度覆盖，需单独的光栅/合成 args

说明

Nanite 主要面向不透明几何（Visbuffer 深度胜者写入）。半透明材质不能这样——它需要按深度顺序混合、不做深度覆盖。UE5 后期给 Nanite 加了半透明支持，本 shader 是其调度小工具：TranscodeRasterizerArgs 把 RasterBinning 得到的每 bin 可见簇数转码成半透明专用光栅/合成的间接参数，让半透明 Nanite 几何走独立路径光栅后与场景做正确的透明混合（配合 TranslucencyFactory）。小而关键的扩展支持。
