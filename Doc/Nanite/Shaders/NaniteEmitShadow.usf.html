NaniteEmitShadow.usf 汇聚/发散批注版

Nanite 阴影的深度搬运 shader：把 Nanite 光栅出的深度缓冲（VisBuffer 的深度部分）转成阴影图深度写进 VSM 物理页 / cubemap。全部逻辑就是"取深度 → 按投影类型换算 → 写 SV_Depth"，按方向光/点光分正交/透视/cubemap 三路。说明：完整文件 112 行，下方内嵌整份真实源码。

Engine/Shaders/Private/Nanite/NaniteEmitShadow.usf（全文）

0. 取深度：非零才写，否则 discard

uint DepthInt = DepthBuffer[ PixelPos + SourceOffset ];
if( DepthInt != 0 ) { float DeviceZ = asfloat(DepthInt); ... }
else discard;

说明

输入是 Nanite 阴影视图光栅出的深度（DepthBuffer，uint 存 float 的位模式）。SourceOffset 把 VSM 物理页在 atlas 里的偏移对齐到源。深度值为 0 表示这个像素 Nanite 没光栅到（无几何）→ discard 不写阴影深度，让该处保持"无遮挡"。asfloat(DepthInt) 把 uint 位模式还原成 DeviceZ——因为 Nanite 的 64 位原子写是按整数比较的，这里读回来再转 float。

1. 三种投影换算（发散核心）

#if DEPTH_OUTPUT_TYPE == 0   OutDepth = DeviceZ;                     // 标准
#elif == 1   OutDepth = 1 - saturate(DeviceZ) + DepthBias;          // 正交(方向光)
#else        OutDepth = ViewToClip22*(DeviceZ-1)/(DeviceZ-ViewToClip22) + DepthBias;  // 透视

说明

全 shader 的发散点，一个 permutation 宏 DEPTH_OUTPUT_TYPE 分三路：

共同点三路都是把 Nanite 主视图光栅得到的 DeviceZ 重投影到阴影视图的深度空间，都加 DepthBias 消阴影痤疮（shadow acne）。

不同点标准直接用 DeviceZ；正交（方向光 clipmap）关近裁剪导致 DeviceZ 可能 >1，用 1 - saturate(DeviceZ) clamp 回近平面、与非 Nanite 阴影路径对齐；透视（点光/聚光）用 ViewToClip22 做非线性重投影公式换算。

2. 点光 cubemap：写到指定面

float2 Corner = float2(VertexID&1, (VertexID>>1)&1);
Output.Position = float4(Corner*4-1, 0.5, 1);   // 全屏三角
Output.RTIndex = CubemapFaceIndex;   // SV_RenderTargetArrayIndex

说明

方向光的阴影是 clipmap（平面页表），点光要 cubemap 6 面。EmitCubemapShadowVS/GS 用一个 全屏三角（顶点从 VertexID 位运算出 [-1..3] 覆盖整个视口）把深度搬到 SV_RenderTargetArrayIndex = CubemapFaceIndex 指定的那一面。两条路：硬件支持 VS 直接写 array index 就跳过 GS（USE_GEOMETRY_SHADER==0）；否则走 GS 指定面——省一个 GS 阶段是性能优化。EmitCubemapShadowPS 逻辑同标准趟：非零取深度、否则 discard。

最终总结

骨架

取 Nanite 光栅深度 → 0 则 discard → 按 DEPTH_OUTPUT_TYPE 三路（标准/正交方向光/透视点光）重投影 + DepthBias → 写 SV_Depth。点光另用全屏三角 + SV_RenderTargetArrayIndex 写 cubemap 6 面。极薄的一层"深度格式转换"。
