void EmitShadowMapPS(...)   // 从 Nanite Visbuffer 解深度 → 写 2D 阴影图深度
void EmitCubemapShadowVS(...)   // 点光立方体阴影顶点

// 让 Nanite 阴影深度落进传统阴影图 / VSM 物理页

说明

Nanite 阴影深度也走可见性 pass 存进 Visbuffer（阴影视图=一个 Nanite view），但传统阴影投影/部分路径需要标准阴影图深度。EmitShadowMapPS 从 Nanite 阴影 Visbuffer 解出深度写进 2D 阴影图；点光立方体阴影用 EmitCubemapShadowVS+GS，几何着色器把三角分发到立方体 6 个面（SV_RenderTargetArrayIndex）。这样 Nanite 几何的阴影能无缝进入引擎的阴影采样路径（含 VSM——VSM 物理页的 Nanite 光栅也在此体系）。是 Nanite 与阴影系统的衔接。
