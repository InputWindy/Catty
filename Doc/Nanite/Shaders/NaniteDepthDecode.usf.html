说明

DepthExport 把深度写成 HTILE 压缩布局（高效但只有硬件/特定 API 能直接读）。有些路径（调试、某些平台后处理）需要普通线性排布的深度纹理。DepthDecode 就是逆操作：8×8 tile 的 compute 把 HTILE 布局深度解码/拷贝成常规深度纹理，供这些消费者按普通 UV 采样。是 HTILE 编码 ↔ 线性纹理的桥，属深度导出的配套工具。
