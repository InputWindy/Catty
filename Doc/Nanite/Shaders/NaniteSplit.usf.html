NaniteSplit.usf 汇聚/发散批注版

Nanite 曲面细分的递归拆分内核：当一个三角要的细分密度超过一张细分表能覆盖时，先把它逐层拆成子三角（每个子任务再判断要不要继续拆），直到每片够一张表搞定，再交给光栅展开。用工作队列 + 逐 level dispatch 实现 GPU 上的递归。核心入口 PatchSplit。说明：完整文件 438 行，下方内嵌核心入口与任务模型的真实源码。

一眼看懂：一条解题弧线

初始 patchSplitWorkQueue level 0
▶
FSplitTask.Run算 SplitFactors，决定拆几个子 patch
▶
DistributeWork子 patch 入队（下一 level）
▶
叶子 patch够一张表 → 交光栅 patch 路径

核心源码对照 （438 行文件的核心节选，逐行真实）

Engine/Shaders/Private/Nanite/NaniteSplit.usf · PatchSplit L343 / FSplitTask L52 / RunChild L298

0. 工作队列 = GPU 上的递归栈

SplitWorkQueue    // level 0 = 初始 patch，逐 level 往后追加
CurrentIndirectArgs[Level*..+4]  // 每 level 的起点/数量

说明

GPU 不能像 CPU 那样函数递归，Nanite 把递归展平成分层工作队列：SplitWorkQueue 里 level 0 是初始 patch，每处理一层就把产生的子 patch 追加到队列末尾成为 level+1。CurrentIndirectArgs 用 indirect dispatch 记录每 level 的起点与数量——一层一次 dispatch，层数即递归深度。这与 簇剔除 的 persistent 队列同源：都是"队列 + 原子游标"实现 GPU 动态工作量。

1. PatchSplit：逐 level 判定拆分

Task.Load(SplitWorkQueue, ClampedStartIndex + GroupIndex);
NumChildren = Task.Run();   // SplitFactors>1 → 拆
DistributeWork(Task, GroupIndex, NumChildren);

说明

每次 PatchSplit dispatch 处理当前 Level：每线程取一个 patch，FSplitTask::Run() 用 GetSplitFactors 判定——>1 就拆，返回子 patch 数（NumChildren）。≤1 的 patch 是叶子，不再拆，直接进光栅的 patch 路径。GroupID==0&&GroupIndex==0 的线程把下一 level 的起点写进 NextIndirectArgs，链式驱动下一次 dispatch。

2. DistributeWork：子 patch 入队（发散点）

uint WriteOffset = SplitWorkQueue.Add();      // 原子分配
if( WriteOffset < SplitWorkQueue.Size )       // 越界丢弃（预算保护）
    Store( SplitWorkQueue, WriteOffset );

说明

这是拆分树的发散点：一个 patch 可拆出多个子 patch，各自 SplitWorkQueue.Add() 原子分配写偏移追加到队列。子 patch 的重心坐标由父 patch 的 TransformBarycentrics 算出、EncodeBarycentrics 压缩后 Store。队列满则丢弃（WriteOffset < Size 检查）——用固定预算兜底，防止病态高细分撑爆显存（宁可降细分，不崩）。

3. 何时停：叶子 → 光栅

SplitFactors ≤ 1  →  叶子 patch（一张表够用）
→ 光栅 PATCHES 路径：FTessellatedPatch 展成微三角

说明

当某 patch 的 split factor 降到 1 以下，说明它足够小、一张 细分表就能覆盖，于是停止拆分、标为叶子，交给 NaniteRasterizer 的 PATCHES 分支（PatchRasterize）——那里用 FTessellatedPatch 查表展成微三角、应用位移、逐个软件光栅。拆分（本文件）与展开（光栅）分工：拆分把大三角降到"可查表"粒度，光栅完成最后一层细分 + 位移 + 写像素。

最终总结

骨架

分层工作队列模拟递归：PatchSplit 逐 level dispatch，每 patch Run() 判 split factor >1 则拆、子 patch DistributeWork 入队下一 level；≤1 成叶子交光栅。队列满即丢弃保预算。
