0. HZB 屏幕矩形遮挡测试（核心）

#define USE_HZB_HALF_TYPE 1   // 半精度 HZB 采样省带宽
// 包围盒/球 → 投影成屏幕矩形 [minUV, maxUV] + 最近深度
// 选覆盖该矩形的 HZB mip（≈2×2 纹素覆盖）→ 采样 4 个纹素取最远
if (物体最近深度 > HZB 最远深度) → 被遮挡（整块可剔）

说明

HZB（Hierarchical Z-Buffer，层级 Z）每 mip 存该区域的最远深度。遮挡测试：把物体包围盒/球投影成屏幕矩形，选一个合适 mip（让矩形约覆盖 2×2 纹素），采样这几个纹素的最远深度——若物体的最近深度都比 HZB 记录的最远还远，说明整块被前面几何完全挡住，可剔。USE_HZB_HALF_TYPE 用半精度采样省带宽。这被 实例/簇剔除的 FrustumHZB 调用，配合两趟遮挡（上帧 HZB 主趟 + 当前帧 HZB 后趟）。是 Nanite 遮挡剔除的核心算法，也与 VSM/主渲染共享 HZB 思想。
