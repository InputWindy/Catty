NaniteHZBCull.ush 汇聚/发散批注版

Nanite 遮挡剔除的底层工具库：把一个包围盒投影成屏幕矩形（FScreenRect），选一个合适的 HZB mip，采样该矩形覆盖的 HZB 纹素取最小深度，与矩形自身深度比较判可见。实例剔除、簇剔除、阴影页剔除全部调它。核心 GetScreenRect + IsVisibleHZB。说明：完整文件 704 行，下方内嵌核心结构与判定的真实源码。

一眼看懂：一条解题弧线

包围盒视锥求交得 NDC RectMin/RectMax
▶
GetScreenRectNDC→屏幕矩形 + 选 HZB mip（覆盖 footprint）
▶
GetMinDepthFromHZBGather 该 mip 上矩形覆盖的纹素，取最小深度
▶
IsVisibleHZBRect.Depth ≥ MinDepth ? 可见 : 遮挡

核心源码对照 （704 行文件的核心节选，逐行真实）

Engine/Shaders/Private/Nanite/NaniteHZBCull.ush · FScreenRect L27 / GetScreenRect L71 / IsVisibleHZB L195 / MipLevelForRect L40

0. FScreenRect：包围盒的屏幕足迹

int4  Pixels;       // 全分辨率像素范围
int4  HZBTexels;    // 该 mip 下的纹素范围
int   HZBLevel;     // 选中的 mip
float Depth;        // 矩形最近深度（Inverted-Z 越大越近）

说明

剔除的基本单位不是三角、不是簇，而是包围盒投影出的屏幕矩形 FScreenRect。它记住矩形的像素范围、对应 HZB 纹素范围、选中的 mip，以及矩形最近深度 Depth（UE 用 Inverted-Z，越大越近）。GetScreenRect 从 FFrustumCullData 的 RectMin/RectMax（视锥求交结果）构造它。

1. 选 mip：一次 Gather 覆盖整个足迹

int2 MipLevelXY = firstbithigh(RectPixels.zw - RectPixels.xy);
int MipLevel = max(max(MipLevelXY.x, MipLevelXY.y) - MipOffset, 0);
MipLevel += (量化对齐不够) ? 1 : 0;   // 兜底再降一级

说明

关键优化：选一个足够粗的 mip，使矩形足迹只需 2×2（或 4×4）个纹素就能覆盖——这样一次 GatherLODRed 就取完，避免遍历大量像素。MipLevelForRect 用 firstbithigh(n-1) 算最低可行 mip（比 log2 在 GCN 上快 4 倍），再按对齐量化补一级兜底。HZB mip0 本身是半分辨率起步（一个纹素盖 2×2 全分辨率像素）。

2. 判定：Inverted-Z 的一次比较（汇聚点）

float MinDepth = GetMinDepthFromHZB(Rect, bSample4x4);  // Gather 取最小
return Rect.Depth >= MinDepth;   // 矩形最近 ≥ HZB 最小 → 可见

说明

全库的汇聚点：GetMinDepthFromHZB 在选中 mip 上 Gather 矩形覆盖的 4（或 16）个纹素取最小深度（HZB 存的是各块最近深度）。因为 Inverted-Z 越大越近，Rect.Depth >= MinDepth 表示"矩形最近点比 HZB 记录的遮挡物还近或齐平"→ 没被完全挡住 → 保守判可见。HZB 是保守的：宁可放过（多画），绝不错杀。bSample4x4 用更大足迹换更保守（用于对精度敏感的场景）。

3. 谁在调它

InstanceCull:  Cull.FrustumHZB()  → GetScreenRect + IsVisibleHZB
ClusterCull:   簇包围盒 → 同一套判定
IsVisibleHZBArray: 阴影页 array（VSM，带 ArrayIndex）

说明

共同点实例剔除、簇剔除、#9 阴影页剔除，都用这同一套 GetScreenRect+IsVisibleHZB，只是喂进不同的包围盒与 HZB。

不同点主视图用 2D HZB（IsVisibleHZB）；VSM 阴影页用 Texture2DArray HZB（IsVisibleHZBArray 带 ArrayIndex）。两趟遮挡（#5）里主趟用上帧 HZB、后趟用本帧新建 HZB，调的都是这里。

最终总结

骨架

包围盒 → GetScreenRect（NDC→屏幕矩形 + 选覆盖足迹的最低 mip）→ Gather 取最小深度 → Inverted-Z 一次比较判可见。保守、廉价、一次 Gather，全 Nanite 剔除共用。

阅读建议

调用方见 InstanceCulling/ClusterCulling；两趟遮挡与 HZB 何时重建见 #5；VSM 页 HZB 见 #9。
