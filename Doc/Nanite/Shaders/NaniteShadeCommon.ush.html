0. 着色线程组常量与 quad 掩码（核心）

#define COMPUTE_MATERIAL_GROUP_SIZE_BITS 5/6   // 组大小位数（平台相关）
#define COMPUTE_MATERIAL_GROUP_SIZE (1u << BITS)   // 32 或 64 线程/组
uint PackQuadMask(bool4 Quad)   // 2x2 quad 覆盖位打包

说明

NaniteShadeCommon 是延迟材质着色的共享常量小库（31 行）：COMPUTE_MATERIAL_GROUP_SIZE 定义着色分箱 compute 的线程组大小（1u << BITS，按平台取 32 或 64），ShadeBinning 与延迟材质求值都按它组织线程。PackQuadMask 把 2x2 像素 quad 的四个覆盖布尔打成一个掩码——Nanite 延迟着色以 quad 为单位跑（为算屏幕空间导数/mip），掩码标记 quad 内哪些像素实际属当前材质。它是着色阶段的底层工具头，被 GBuffer 导出与材质分箱共用。
