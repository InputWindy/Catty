0. 输入输出契约

// 输入：实例数据、NaniteView[]（多视图，最多 4096）、PrevHZB
OutQueueState[0].PassState[0/1]  // 候选节点写偏移/计数（主/后趟）
OutOccludedInstances[] + OutOccludedInstancesArgs  // 被遮挡实例暂存 + 间接args

说明

输入是场景实例 + #5 传入的 FPackedView 数组（一次可处理主相机 + 所有阴影页视图）+ 上帧 PrevHZB。输出两条：可见实例的候选节点写进 QueueState（喂 NaniteClusterCulling.usf ↗ 的层级遍历），被遮挡实例写进 OccludedInstances（供后趟复核）。

1. 两趟遮挡在这里分叉

#if CULLING_PASS == CULLING_PASS_OCCLUSION_MAIN
    if( Cull.bWasOccluded ) WriteOccludedInstance(ViewId, InstanceId);
#endif
uint QueueStateIndex = ( CULLING_PASS == CULLING_PASS_OCCLUSION_POST );  // 0=主 1=后

说明

共同点主趟（OCCLUSION_MAIN，QueueStateIndex=0）与后趟（OCCLUSION_POST，QueueStateIndex=1）跑同一份 InstanceCull，用 permutation 宏切。

不同点主趟用上帧 HZB 剔除，把被遮挡的实例 WriteOccludedInstance 暂存；后趟只处理这批暂存实例、用主趟建的新 HZB 复核，救回"其实没被遮挡"的。两趟的候选节点写进 QueueState 的 PassState[0]/[1] 两套游标（见 ClusterCulling）。

2. 剔除核心：FrustumHZB + 标志位

bCacheAsStatic = ShouldCacheInstanceAsStatic(...);  // 静态几何归类（VSM 缓存）
Cull.FrustumHZB( false );                           // 视锥 + HZB 屏幕矩形遮挡
// 可见者带标志入候选：TEST_LOD / FALLBACK_RASTER / ENABLE_WPO / CACHE_AS_STATIC
WaveInterlockedAddScalar_( OutQueueState[0].PassState[i].NodeWriteOffset, 1, NodeOffset );

说明

FrustumHZB 以包围盒投影的屏幕矩形为单位做视锥 + HZB 遮挡（实现在 NaniteHZBCull.ush ↗）。可见实例用 WaveInterlockedAdd 原子分配 QueueState 里的写偏移（wave 内先归约再一次原子，减少争用），并带上 TEST_LOD/FALLBACK_RASTER/ENABLE_WPO/CACHE_AS_STATIC 等标志——这些标志随候选节点一路传到簇剔除与光栅，决定走软/硬光栅、是否缓存。

最终总结

骨架

每实例每视图：FrustumHZB → 被遮挡则暂存（主趟）→ 可见则原子写候选节点入 QueueState。全 GPU 驱动、多视图批处理、两趟遮挡靠 permutation 分叉。
