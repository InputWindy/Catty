RasterizeBricks.usf 汇聚/发散批注版

Nanite 体素的绘制 shader：把 AutoVoxel 建出的稀疏体素 brick 画进深度/可见性。用实例化把每个 brick 当一个盒子，VS 建包围盒 + 算光线方向，PS 在盒内 ray-march 体素占用掩码找首个命中体素写深度。核心 DrawBricksVS + DrawBricksPS。说明：完整文件 259 行，下方内嵌核心入口的真实源码。

一眼看懂：一条解题弧线

brick 列表BrickBuffer（每 brick 一个实例）
▶
DrawBricksVS解 BrickKey → 世界包围盒 → 光线方向
▶
DrawBricksPS盒内 ray-march 64 位占用掩码
▶
命中→写深度首个占用体素 → SV_Depth

核心源码对照 （259 行文件的核心节选，逐行真实）

Engine/Shaders/Private/Nanite/Voxel/RasterizeBricks.usf · DrawBricksVS L26 / DrawBricksPS L150

0. brick 即盒子：实例化绘制

FBrick Brick = BrickBuffer[InstanceID];      // 每 brick 一个实例
DecodeBrickKey(Brick.Key, BrickPos, CubeSize);
WorldMin = BrickPos*CubeSize; WorldMax = WorldMin + CubeSize;

说明

不是逐三角画，而是把每个 brick 当一个盒子实例：SV_InstanceID 索引 BrickBuffer，DecodeBrickKey 解出该 brick 的世界位置与尺寸，建出 [WorldMin, WorldMax] 包围盒。VS 输出盒子顶点的裁剪位置，硬件光栅把盒子投影到屏幕生成候选像素——盒子只是"哪些屏幕像素可能被这 brick 覆盖"的粗界，真正的体素在 PS 里 ray-march。VertsPerBrick/BricksPerInstance 让一个 draw 实例打包多个 brick，减少 draw 开销。

1. 读根掩码收紧范围

uint2 RootBlock = BlockBuffer.Load2( 8 * Brick.BlockOffset );
BlockBounds( RootBlock, BrickMin, BrickMax );  // 从 64 位占用算实际范围

说明

brick 的 block 根掩码就是 AutoVoxel 用 AddVoxelToBlock 填的 64 位占用位。BlockBounds 从这 64 位算出实际占用体素的 [BrickMin, BrickMax] 子范围——如果 brick 大部分是空的，就把包围盒收紧到真正有体素的部分，减少 PS 的 ray-march 步数与光栅像素。这是稀疏体素相对稠密网格的又一处省法。

2. DrawBricksPS：盒内 ray-march 占用掩码

float3 RayOrigin, RayDirection;   // VS 传入：相机→该像素的光线
// 沿光线在 brick 内步进体素，查 64 位掩码是否占用
命中首个占用体素 → OutDepth = SV_Depth；否则 discard

说明

PS 拿到 VS 算好的光线（RayOrigin/RayDirection），在 brick 盒内沿光线步进体素格子，每步查 64 位占用掩码——命中第一个被占用的体素就写 SV_Depth（该体素表面深度），没命中则 discard。这本质是体素版的"光栅 = 求交"：盒子用硬件光栅粗定像素，掩码 ray-march 定精确表面。产出的深度/可见性供超远距离显示或次级光线遮挡估计。

3. 与主管线的呼应

brick 盒实例 → 硬件光栅 → PS ray-march（粗定 + 精求交）

说明

共同点#11 提到的 Tile → Scatter → Rasterize 与主管线的剔除→分箱→光栅（#6）、着色的 count→reserve→scatter（#7）是同一种"GPU 分桶 + 间接派发"范式，这里的 brick 绘制是其体素化身。

不同点主管线光栅三角形写 VisBuffer 供材质着色；这里光栅的是体素占用，PS 做 ray-march 求交而非三角覆盖测试，产出的是"够用就好"的粗几何——服务超远距离与次级光线，不追求像素级轮廓。

最终总结

骨架

brick 当盒子实例：DrawBricksVS 解 key 建包围盒（读根掩码收紧）+ 算光线 → DrawBricksPS 盒内 ray-march 64 位占用掩码命中首体素写深度。硬件光栅粗定像素 + 掩码求交定表面。
