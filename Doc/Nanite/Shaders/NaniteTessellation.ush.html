NaniteTessellation.ush 汇聚/发散批注版

Nanite 曲面细分的数学工具库：算细分密度（GetTessFactors：屏幕边长/深度）、决定要不要继续拆分（GetSplitFactors），以及在递归细分里压缩/还原重心坐标（EncodeBarycentrics）。它给 NaniteSplit.usf 提供判据，给 光栅 的 patch 路径提供细分表查询。说明：完整文件 357 行，下方内嵌核心函数的真实源码。

0. GetTessFactors：细分密度 = 屏幕边长 / 深度

float EdgeScale  = min(PointView[i0].z, PointView[i1].z);
float EdgeLength = length(PointView[i0] - PointView[i1]);
TessFactors[i] = EdgeLength / EdgeScale;   // 透视：远处自动变疏

说明

细分要"近处细、远处粗"，判据就是边在屏幕上占多少像素。这里用视空间边长 / 边的视深近似屏幕像素长度（除以 z 等价透视缩放）：同样的世界边长，离得越远 z 越大、tess factor 越小、细分越少。LODScale/InvDiceRate 是全局密度旋钮；LowTessDistance 外的边额外乘 0.25 进一步降密度。正交视图（bOrtho）不做深度缩放。

1. GetSplitFactors：要不要再拆一层

return TessFactors / NANITE_TESSELLATION_TABLE_SIZE;

说明

Nanite 用预烘的细分表（FTessellatedPatch）一次把一个三角细分到固定上限（NANITE_TESSELLATION_TABLE_SIZE）。当 tess factor 超过一张表能盖的密度，就得先把三角拆成子三角（NaniteSplit 递归），每个子三角再各查一次表。GetSplitFactors = TessFactors / 表尺寸，>1 就意味着"一层不够，继续拆"。这把"任意高细分"拆成"递归拆分 + 每层查表"两级。

2. EncodeBarycentrics：递归里传子三角位置

uint   EncodeBarycentrics(float3 Barycentrics);
float3 DecodeBarycentrics(uint Encoded);

说明

递归拆分时，子三角的三个顶点是父三角内的重心坐标。为省队列带宽，EncodeBarycentrics 把一个 float3 重心（和为 1，只需存两个分量）压进一个 uint，随 FSplitTask 进工作队列；子任务 DecodeBarycentrics 还原，再 TransformBarycentrics 映射到全局。这让细分递归的中间态极其紧凑——和 Nanite 处处"位打包"的风格一致。

3. FTessellatedPatch：查表出微三角

struct FTessellatedPatch { ... GetTessFactors(); ... };
struct FSplitPatch { float3 TransformBarycentrics(float3 Local); };

说明

FTessellatedPatch 封装"给定一组 tess factor，从预烘表里读出这层该产生哪些微三角顶点（重心）"。光栅 的 patch 路径（PATCHES 分支）用它把叶子 patch 展开成微三角逐个光栅。FSplitPatch::TransformBarycentrics 把子 patch 局部重心映回原始三角空间——保证多层递归后顶点仍落在正确世界位置，配合 #8 的位移（PDO/WPO）产出最终几何。

最终总结

骨架

GetTessFactors（屏幕边长/深度=密度）→ GetSplitFactors（÷表尺寸，>1 则递归拆）→ EncodeBarycentrics 紧凑传子三角 → FTessellatedPatch 查表出微三角。把"任意高细分"化为"递归拆分 + 分层查表"。
