AutoVoxel.usf 汇聚/发散批注版

Nanite 体素化的核心内核：把屏幕深度反投影成世界位置 → 量化到体素格子 → 按距离选层级，再以 4×4×4=64 位掩码稀疏存进 block。这是把三角形几何转成"稀疏体素占用场"的第一步（超远/次级光线用）。核心 DepthToVoxel + AddVoxelToBlock。说明：完整文件 201 行，下方内嵌核心函数与入口的真实源码。

Engine/Shaders/Private/Nanite/Voxel/AutoVoxel.usf · DepthToVoxel L16 / AddVoxelToBlock L36 / VisibleBricksHash L44

0. DepthToVoxel：深度 → 体素 + log2 层级

float3 TWP = SvPositionToTranslatedWorld(float4(PixelPos+0.5, Depth, 1));
float Level = log2( Distance * DistanceFactor );  // 距离分级
VoxelPos = floor( VoxelPos * exp2(-Level) );      // 按级降采样

说明

先把屏幕像素 + 深度 SvPositionToTranslatedWorld 反投影成世界位置，除以 VoxelSize 得体素坐标。关键是 Level 按距离 log2 分级：DistanceFactor 把"每体素应占多少像素"（PixelsPerVoxel=0.5）折算成距离系数，Level = log2(Distance·factor) —— 远处 Level 大、体素粗，exp2(-Level) 把坐标降采样。这就是体素版 LOD：等价于三角形管线的连续 LOD（#5），只不过粒度是 8 叉树深度。

1. AddVoxelToBlock：64 位掩码稀疏存

uint VoxelIndex = Voxel.x + Voxel.y*4 + Voxel.z*16;  // 3D→线性(0..63)
uint HighInt = VoxelIndex >= 32;
RWBlockBuffer.InterlockedOr(8*BlockOffset + 4*HighInt, 1u<<(VoxelIndex-HighInt*32));

说明

一个 block 是 4×4×4 = 64 个体素，占用状态刚好用 64 位掩码（两个 uint）表示。VoxelIndex 把 3D 体素位置压成 0..63 的线性索引，HighInt 判它落在高 32 位还是低 32 位，InterlockedOr 原子置位。原子或天然去重：多个像素反投影落到同一体素也只置一次位，无需锁。这就是稀疏体素 + 位掩码（SVO 思想）——只有真有几何的格子才占存储。

2. VisibleBricksHash：brick 级去重

int4 Voxel = DepthToVoxel(PixelPos, Depth);
uint3 BrickKey = EncodeBrickKey(Voxel.xyz >> BrickSizeLog2, Voxel.w);
bool bAdded = HashTableAdd(Hash.x, Hash.y);  // 同 brick 只登记一次

说明

体素以 brick（一组 block）为管理单位。VisibleBricksHash 每像素一线程：DepthToVoxel 出体素 → 右移 BrickSizeLog2 得所属 brick → EncodeBrickKey + Rand4DPCG32 哈希 → HashTableAdd 去重。屏幕上成千上万像素可能落进同一 brick，哈希表保证每 brick 只登记/分配一次 block，避免重复分配。后续再由 FillBlocks 用 AddVoxelToBlock 逐像素填占用位。这套"哈希去重 + 原子分配"和 Nanite 全局的 GPU 动态分配一脉相承。

最终总结

骨架

DepthToVoxel（反投影 + log2 距离分级=体素 LOD）→ brick 哈希去重分配 → AddVoxelToBlock 64 位掩码原子置位。把可见几何转成稀疏体素占用场，供超远/次级光线用。
