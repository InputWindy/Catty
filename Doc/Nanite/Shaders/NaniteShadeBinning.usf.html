0. 按材质分箱统计（发散点）

void BinScalarization(FTask Task, int4 ShadingBins, uint ThreadIndex)   // wave 内按 bin 标量化
// 读该像素/quad 的材质 ShadingBin（从 Visbuffer 的 cluster→材质映射）
void AllocateElements(uint Bin, ..., inout uint FullTileDataOffset, inout uint LooseDataOffset)   // 每 bin 分配
void UpdateVRSActiveAndWriteMasks(...)   // 可变速率着色(VRS)掩码

说明

Nanite 用延迟材质：可见性 pass 只在 Visbuffer 记"哪个簇/三角可见"，材质着色推迟。但屏幕相邻像素材质各异，若逐像素分支着色会极度发散。ShadeBinning 先把屏幕按材质 ShadingBin 分箱：BinScalarization 在 wave 内把同 bin 像素聚合，区分整 tile（full tile，一整块同材质，最高效）与散像素（loose，边界混合），AllocateElements 为每 bin 原子分配输出空间。UpdateVRSActiveAndWriteMasks 处理可变速率着色。这一步把"屏幕像素"重组为"按材质聚合的着色元素"。

1. 散射写着色元素列表（汇聚点）

[numthreads(SHADING_BIN_TILE_THREADS, 1, 1)]   // 分箱计数
[numthreads(64, 1, 1)]   // 前缀和/参数生成
// 散射：把每 tile/quad 写进其材质 bin 的连续区段 + 每 bin IndirectArgs
// 输出供 Shading pass 逐 bin 一次派发对应材质 shader

说明

本 shader 的汇聚点：经典的计数-前缀和-散射——先统计每材质 bin 的元素数、前缀和算偏移、再把 full tile 与 loose 像素散射写进各 bin 的连续段，并生成每 bin 的间接派发参数。之后 C++ 侧对每个材质 bin一次派发它的材质 shader（读 Visbuffer 解出属性着色写 GBuffer），全 tile 内材质一致、零分支发散。这套屏幕空间材质分箱是 Nanite 延迟材质高效的关键——把"每像素材质分支"变成"每 bin 批量着色"。VRS/quad 打包进一步压缩着色量。
