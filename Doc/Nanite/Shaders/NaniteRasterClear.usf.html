0. tile 化清除 Visbuffer（核心）

void ClearPixelPos(uint2 PixelPos)   // 把单像素 VisBuffer64 写成初始值(0/远)
[numthreads(8, 8, 1)] void RasterClear(uint3 TilePos : SV_DispatchThreadID)
// 8×8 线程组按 tile 清除——只对将被光栅覆盖的区域间接派发

说明

软件光栅用 InterlockedMax 写 VisBuffer64，前提是缓冲已被清成"最远/空"初始值。RasterClear 用 8×8 tile 的 compute 清除——但不是全屏清，而是只清将被光栅覆盖的 tile（按视口/裁剪区间接派发），省下大量无效写带宽。ClearPixelPos 把单像素写成初始值。这是可见性 pass 的准备步，与 Rasterizer 配对；相邻的 FastClear 是另一条更激进的 tile 清除路径。
