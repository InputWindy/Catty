// Counterpart to Nanite::FPackedView in NaniteShared.h
float4x4 TranslatedWorldToClip / ViewToClip / ClipToRelativeWorld ...

int4 ViewRect; float4 ViewSizeAndInvSize; 剔除视点 / ViewForward / NearPlane

说明

FPackedNaniteView 是 GPU 侧的视图打包结构，与 C++ Nanite::FPackedView（NaniteShared.h）一一对应——CPU 每帧把每个渲染视图（主视图、每级 VSM、每个阴影视图）打包成它上传 GPU。内容含：当前帧各种变换矩阵（TranslatedWorldToClip 投影、ClipToRelativeWorld 反投影等）、上一帧 Prev* 矩阵（时域重投影/HZB 遮挡剔除用）、视口 ViewRect/ViewSizeAndInvSize、剔除视点（CullingViewOriginTranslatedWorld/半径/距离）、ViewForward、NearPlane、可选全局裁剪面。它被解包为运行时的 FNaniteView（见 本文件下方 UnpackNaniteView），供实例/簇剔除、光栅投影、HZB 采样统一读取。多视图并行剔除的每 view 数据就是它的数组。
