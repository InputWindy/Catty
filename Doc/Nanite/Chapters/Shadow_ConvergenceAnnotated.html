难题：给上千万三角形做阴影 The problem

传统阴影贴图撑不住 Nanite

传统 shadow map 每盏灯一张固定分辨率深度图，重新画一遍所有几何。Nanite 场景动辄上千万三角、几十盏灯——每盏灯都重画一遍完整几何，开销爆炸；而且固定分辨率要么近处糊、要么远处浪费。VSM 的思路：把阴影贴图做成一张超高分辨率（16384×16384）的虚拟纹理，但只为真正被采样到的区域分配物理页（128×128），其余留空。这样"分辨率随距离自适应"且"只画看得见阴影的地方"。

VSM 的稀疏页表思想与虚拟纹理（见 虚拟纹理书）一脉相承：虚拟地址空间巨大，物理页按需分配、LRU 缓存。

核心：把 Nanite 管线复用到阴影视图 Shadow as views

阴影就是"从光源看的另一组视图"

Nanite 剔除/光栅管线（#5/#6）本就设计成多视图并行（MAX_VIEWS_PER_CULL_RASTERIZE_PASS = 4096）。VSM 把每盏灯的每个 mip/clipmap 层级注册成一个Nanite render view，和主相机视图一起进入同一趟剔除+光栅。光栅结果不是写主 visibility buffer，而是写进 VSM 的物理页（#6 的 VIRTUAL_TEXTURE_TARGET 分支正是为此）。一次遍历，几何只处理一遍，同时喂主视图和所有阴影视图。

1标记需要的页从主相机深度反推：哪些 VSM 页会被采样 → 标记 dirty
▶
2为脏页建阴影视图每个需渲染的页区域 → 一个 Nanite view（含光源投影矩阵）
▶
3Nanite 剔除+光栅与主视图同趟；HZB 用 VSM 物理页 HZB 做遮挡剔除
▶

页缓存：不动的东西不重画 Page caching

VSM 的性能关键是缓存复用

大多数帧里，静态几何 + 静态光源产生的阴影页完全不变。FVirtualShadowMapCacheManager 缓存上一帧的物理页，只有当几何移动、光源移动、或页首次被采样时才把相关页标记失效（InvalidatePages）重画。Nanite 的 CACHE_AS_STATIC 标志（#5）把静态实例单独归类，让缓存判断更精准。结果：每帧真正重新光栅的阴影页往往只是一小部分。

失效来源处理
几何移动 / 动画该实例覆盖的页失效（用移动前后包围盒）
光源移动该光源的 VSM 全部页失效
页首次被采样分配物理页 + 标记需渲染
WPO/位移几何（#8）用保守包围盒判定失效范围

深度输出：三种投影 EmitShadow depth

附录里 EmitShadowMapPS 按 DEPTH_OUTPUT_TYPE 分三路把 Nanite 的深度转成阴影图深度：

// DEPTH_OUTPUT_TYPE == 0：标准深度，直接用 DeviceZ OutDepth = DeviceZ; // == 1：正交阴影（方向光 clipmap），关近裁剪，clamp 回近平面 OutDepth = 1 - saturate(DeviceZ) + DepthBias; // == 2：透视阴影（点光/聚光），重投影公式 OutDepth = ViewToClip22 * (DeviceZ - 1) / (DeviceZ - ViewToClip22) + DepthBias;

方向光用 clipmap，点光用 cubemap

方向光覆盖整个世界，用 clipmap（一圈同心的正交层级，随距离降精度）；点光用 cubemap（6 面）——EmitCubemapShadowVS/GS/PS 用 SV_RenderTargetArrayIndex 把每面写进对应数组切片。DepthBias 消除阴影痤疮（shadow acne）。

与本书其它篇的关系 Cross-topic

阴影是"多视图 Nanite"最大的受益者

共同点：VSM 完全复用 #5/#6 的多视图剔除+光栅；#6 的 VIRTUAL_TEXTURE_TARGET WritePixel 分支就是为写 VSM 物理页而设。稀疏页表思想与虚拟纹理书同源。

不同点：主视图光栅写 64 位 visibility buffer 供 #7 着色；阴影视图只关心深度（DEPTH_ONLY），不需要材质着色，故 EmitShadow 只搬深度。

不同点：主视图每帧全画，VSM 靠页缓存只重画失效页——这是 VSM 相对传统阴影的根本性能优势。

本篇小结 Summary

记住这几点

1. VSM = 阴影版虚拟纹理：16384² 虚拟分辨率，按需分配 128×128 物理页，分辨率随距离自适应，只画被采样到的区域。

2. 复用 Nanite 多视图：每盏灯每层级注册成 Nanite render view，与主视图同趟剔除+光栅，几何只处理一遍；光栅写进 VSM 物理页。

3. 页缓存：静态几何/光源的阴影页跨帧复用，只有移动/失效才重画；CACHE_AS_STATIC 提升缓存精度。

4. EmitShadow：按标准/正交/透视三种 DEPTH_OUTPUT_TYPE 转深度；方向光用 clipmap、点光用 cubemap（数组切片）。
