FCandidateNode 位打包 NaniteCulling.ush · PackCandidateNode

候选节点（实例剔除产出、等待 BVH 遍历）以位打包存进 OutCandidateNodes（ByteAddressBuffer）：

uint4 PackCandidateNode(FCandidateNode Node){ uint4 RawData = 0; RawData.x = (Node.InstanceId << 5) | Node.Flags; // Flags[5位] | InstanceId[24位] RawData.y = (Node.ViewId << 16) | Node.NodeIndex; // NodeIndex[16位] | ViewId[12位] #if NANITE_ASSEMBLY_DATA RawData.z = Node.AssemblyTransformIndex; RawData.w = Node.EnabledBitmask; #else RawData.z = Node.EnabledBitmask; #endif // 每个字段都留≥1位未用，保证 0xFFFFFFFF 永不是合法值（用作哨兵） return RawData; }
字段位宽常量
Flags5NANITE_NUM_CULLING_FLAG_BITS
InstanceId24NANITE_MAX_INSTANCES_BITS
NodeIndex16NANITE_MAX_NODES_PER_PRIMITIVE_BITS
ViewId12NANITE_MAX_VIEWS_PER_CULL_RASTERIZE_PASS_BITS

为何能塞进 32 位：static_assert 守卫

NaniteCullRaster.cpp（L46-48）用编译期断言保证位域不溢出：1 + 5 + 24 ≤ 32（x 字段）、1 + 16 + 12 ≤ 32（y 字段）。预留的 1 位使 0xFFFFFFFF 不会撞上合法值，可用作“空”哨兵。节点占用 dwords：含装配数据时 post 趟 4 / 主趟 3，否则 3 / 2（主/后趟候选从 buffer 两端分配）。

函数说明

FQueueState / FQueuePassState NaniteHierarchyTraversalCommon.ush

struct FQueuePassState { uint ClusterBatchReadOffset; // 以 batch 为单位的簇读偏移 uint ClusterWriteOffset; // 以单个簇为单位的写偏移 uint NodeReadOffset; uint NodeWriteOffset; int NodeCount; // 可能临时保守偏大 }; struct FQueueState { uint TotalClusters; // 产出候选簇总数（对 MaxCandidateClusters 封顶） uint AssemblyTransformsWriteOffset; FQueuePassState PassState[2]; // [0]=主趟, [1]=后趟 };

GetMaxClusterBatches() = MaxCandidateClusters / NANITE_PERSISTENT_CLUSTER_CULLING_GROUP_SIZE。读写偏移用 WaveInterlockedAdd 原子推进，实现无锁工作队列。
