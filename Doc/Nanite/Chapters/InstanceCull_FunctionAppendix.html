#5 附录 · 剔除遍历结构

本附录汇总实例剔除与层级遍历的核心结构、剔除标志与常量。取自 UE5.8 本地源码 NaniteCullRaster.h、NaniteHierarchyTraversalCommon.ush、NaniteDataDecode.ush、NaniteDefinitions.h。

剔除常量 NaniteDefinitions.h

常量值含义
NANITE_PERSISTENT_CLUSTER_CULLING_GROUP_SIZE64持久化剔除线程组大小
NANITE_MAX_BVH_NODES_PER_GROUP64 / 4 = 16每组处理的 BVH 节点数（组大小 / fanout）
NANITE_MAX_BVH_NODE_FANOUT4每个 BVH 节点最多 4 个子节点
NANITE_MAX_VIEWS_PER_CULL_RASTERIZE_PASS4096 (1<<12)一次剔除+光栅最多处理的视图数
InstanceCull numthreads64实例剔除线程组大小

剔除标志位 NANITE_CULLING_FLAG_*

标志值含义
NANITE_CULLING_FLAG_TEST_LOD1<<0后续需做 LOD 判据（实例阶段默认打上）
NANITE_CULLING_FLAG_USE_HW1<<1用硬件光栅器（大三角）
NANITE_CULLING_FLAG_CACHE_AS_STATIC1<<2可作为静态几何缓存（VSM/HZB 复用）
NANITE_CULLING_FLAG_ENABLE_WPO1<<3启用世界位置偏移（材质动几何）
NANITE_CULLING_FLAG_FALLBACK_RASTER1<<4用回退光栅路径

FQueueState / FQueuePassState NaniteHierarchyTraversalCommon.ush

struct FQueuePassState { uint ClusterBatchReadOffset; // 以 batch 为单位的簇读偏移 uint ClusterWriteOffset; // 以单个簇为单位的写偏移 uint NodeReadOffset; uint NodeWriteOffset; int NodeCount; // 可能临时保守偏大 }; struct FQueueState { uint TotalClusters; // 产出候选簇总数（对 MaxCandidateClusters 封顶） uint AssemblyTransformsWriteOffset; FQueuePassState PassState[2]; // [0]=主趟, [1]=后趟 };

GetMaxClusterBatches() = MaxCandidateClusters / NANITE_PERSISTENT_CLUSTER_CULLING_GROUP_SIZE。读写偏移用 WaveInterlockedAdd 原子推进，实现无锁工作队列。

FVisibleCluster NaniteDataDecode.ush · 剔除输出单元

字段说明
Flags剔除标志（USE_HW / ENABLE_WPO / ...）
ViewId所属视图（多视图批处理，≤4096）
InstanceId实例索引（NANITE_MAX_INSTANCES_BITS 位）
PageIndex / ClusterIndex簇在页数据里的定位
AssemblyTransformIndex装配（骨骼/组合）变换索引
DepthBucket深度分桶（排序/光栅调度用）
vPage / vPageEnd (uint2)虚拟页范围（VSM 软光栅时，最后一页 inclusive）

打包时 WriteBits(RawData, BitPos, VisibleCluster.InstanceId, NANITE_MAX_INSTANCES_BITS) 等逐字段位打包进 VisibleClustersSWHW buffer。

FConfiguration NaniteCullRaster.h · 本次剔除行为开关

位含义
bTwoPassOcclusion开启两趟遮挡剔除
bUpdateStreaming本次遍历是否写流送请求
bForceHWRaster强制硬件光栅
bPrimaryContext / bIsShadowPass主视图 / 阴影 pass（#9 复用）
bDrawOnlyRootGeometry / bDrawOnlyRayTracingFarField只画根几何 / 只画光追远场
bIsSceneCapture / bIsReflectionCapture / bIsLumenCapture各类捕获 pass
bDisableProgrammable禁用可编程光栅（#8）
HiddenFilterFlags (EFilterFlags)隐藏过滤标志

SetViewFlags(const FViewInfo&) 从视图信息填充这些位。
