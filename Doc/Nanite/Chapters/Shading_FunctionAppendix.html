#7 附录 · 材质着色结构

本附录汇总 visibility 解码、shade binning 与 G-Buffer 导出的核心符号。取自 UE5.8 本地源码 NaniteShading.cpp/.h、NaniteShadeBinning.usf、NaniteExportGBuffer.usf、NaniteDefinitions.h。

着色常量 NaniteDefinitions.h

常量值含义
NANITE_MAX_CLUSTER_TRIANGLES128 (1<<7)簇内三角上限（TriIndex 位宽 7）
NANITE_MAX_CLUSTER_VERTICES256 (1<<8)簇内顶点上限
NANITE_MAX_CLUSTER_INDICES128×3 = 384簇内索引上限
NANITE_SHADING_BIN_META_BYTES—每个 shading bin 的 meta 字节数
NANITE_VISUALIZE_SHADING_BINS11u可视化模式：shading bins

Visibility 解码 NaniteExportGBuffer.usf

// 从 64 位 vis 像素解出深度 + 可见簇 + 三角索引 UnpackVisPixel(VisPixel, out DepthInt, out VisibleClusterIndex, out TriIndex); // ShadingMask 打包/解包 OutShadingMask = PackShadingMask(ShadingBin, /*bCastShadow 等*/ ...); FShadingMask Mask = UnpackShadingMask(ShadingMask[PixelPos]);

导出路径宏：SHADING_MASK_LOAD（读 mask）、SHADING_MASK_EXPORT（写 mask，SV_Target0）。深度 OutDepth = asfloat(DepthInt)。FShadingMask 含 ShadingBin、是否投影阴影等标志。

shade binning pass NANITE_SHADING_BIN_*

Pass值作用
NANITE_SHADING_BIN_COUNT0统计每个 bin 覆盖像素数
NANITE_SHADING_BIN_RESERVE1为每个 bin 预留输出连续范围
NANITE_SHADING_BIN_SCATTER2把像素散布进各自 bin 列表
NANITE_SHADING_BIN_VALIDATE3校验（调试）
NANITE_SHADING_BIN_CMASK_CLEAR4清 CMask
NANITE_SHADING_BIN_GROUP_COUNT / GROUP_RESERVE5 / 6线程组级粗粒度归拢（减原子竞争）

着色成本上界

延迟材质让着色开销 ≈ 屏幕像素数 × 平均每像素材质求值一次，与三角形总数无关。同一 shading bin 内所有像素共用材质 shader，无发散、无状态切换。
