全局常量 NaniteDefinitions.h

常量值含义
NANITE_MAX_CLUSTER_TRIANGLES128 (1<<7)单簇最大三角形数
NANITE_MAX_CLUSTER_VERTICES256 (1<<8)单簇最大顶点数
NANITE_MAX_CLUSTERS_PER_GROUP512 (1<<9)单个 group 最大簇数
NANITE_MAX_BVH_NODE_FANOUT4 (1<<2)BVH 节点最大子节点数
NANITE_ROOT_PAGE_GPU_SIZE32 KB (1<<15)根页 GPU 尺寸（常驻）
NANITE_STREAMING_PAGE_GPU_SIZE128 KB (1<<17)流送页 GPU 尺寸（按需）
NANITE_NUM_PACKED_CLUSTER_FLOAT4S8FPackedCluster 占 8 个 float4
NANITE_GPU_PAGE_HEADER_SIZE16GPU 页头字节数
NANITE_HIERARCHY_NODE_SLICE_SIZE_DWORDS60FPackedHierarchyNode 的 dword 数
NANITE_MIN_POSITION_PRECISION-20位置量化精度下限
NANITE_MAX_POSITION_PRECISION43位置量化精度上限
NANITE_MAX_VIEWS_PER_CULL_RASTERIZE_PASS4096 (1<<12)单趟剔除光栅化最大视图数（多视图/阴影）

根页与流送页尺寸的比例（32KB : 128KB）体现"少量常驻、大量按需"；NANITE_MAX_CLUSTERS_PER_PAGE 由页尺寸减去簇最小期望尺寸推导。

FPackedCluster NaniteResources.h · GPU 使用的紧凑簇

占 NANITE_NUM_PACKED_CLUSTER_FLOAT4S = 8 个 float4，所有字段位打包。分四组用途：

分组字段说明
光栅化NumVerts_PositionOffsetNumVerts:14, PositionOffset:18
NumTris_IndexOffset / PosStartNumTris:8, IndexOffset:24 / 位置起点
剔除LODBounds (FSphere3f)LOD 选择用的包围球
BoxBoundsCenter / Extent / LODErrorAndEdgeLength包围盒 + LOD 误差与边长
材质AttributeOffset_BitsPerAttributeAttributeOffset:22, BitsPerAttribute:10
DecodeInfoOffset_HasTangents_Skinning_NumUVs_ColorMode属性布局标志位
量化BitsPerIndex_PosPrecision_PosBits_...索引位数、位置精度、法线/切线精度
扩展ExtendedDataOffset_Num / BrickDataOffset_Num / NumCurves_...体素 brick、曲线（Nanite curves）等扩展数据
其它ParentLODError_ParentSphereBoundRadius / VertReuseBatchInfo[4]父级 LOD 误差（DAG 单调性）/ 顶点复用批

配套的 GetNumVerts()/GetPositionOffset()/GetPosPrecision() 等访问器用 GetBits(Value, NumBits, Offset) 解位域。ParentLODError 用于运行时 LOD cut 判定（见 #2/#6）。

FPackedHierarchyNode BVH 层级节点

每个节点最多 NANITE_MAX_BVH_NODE_FANOUT = 4 个子项，三段并行数组：

字段说明
LODBounds[4] (FVector4f)每个子项的 LOD 包围球
Misc0[4]: BoxBoundsCenter + MinLODError_MaxParentLODError子项包围盒中心 + LOD 误差区间
Misc1[4]: BoxBoundsExtent + ChildStartReference子项包围盒范围 + 子节点/簇引用起点
Misc2[4]: ResourcePageRangeKey + GroupPartSize_AssemblyPartIndex + NumBones_BoneIndicesOffset页范围键、group 分块、骨骼信息

静态断言 NANITE_HIERARCHY_NODE_SLICE_SIZE_DWORDS == sizeof(FPackedHierarchyNode)/4（60 dwords）保证 CPU/GPU 布局一致。运行时层级遍历（#5）沿这些节点用 LOD 误差区间决定是否深入子节点。
