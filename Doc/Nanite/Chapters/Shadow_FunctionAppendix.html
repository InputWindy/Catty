#9 附录 · 阴影 VSM 集成结构

本附录汇总 VSM 页表常量、页缓存管理、Nanite 阴影视图注册与深度发射的核心符号。取自 UE5.8 本地源码 VirtualShadowMapDefinitions.h、VirtualShadowMapArray.cpp、VirtualShadowMapCacheManager.cpp、NaniteEmitShadow.usf。

VSM 页表常量 VirtualShadowMapDefinitions.h

常量值含义
VSM_LOG2_PAGE_SIZE7物理页边长 log2
VSM_PAGE_SIZE128 (1<<7)物理页边长（像素）
VSM_LOG2_LEVEL0_DIM_PAGES_XY7第 0 级每边页数 log2
VSM_LEVEL0_DIM_PAGES_XY128 (1<<7)第 0 级每边 128 页

FVirtualShadowMapArray VirtualShadowMapArray.cpp

符号说明
FVirtualShadowMapArray一帧内所有 VSM 的集合，持有页表、物理池、HZB
PageTable (RWTexture2D<uint>)虚拟页 → 物理页的间接寻址表
OutPageTable页表更新 pass 的输出 UAV
HZBPhysical / GetHZBPhysicalPoolSize()物理页 HZB，供阴影视图遮挡剔除
DummyPageTableElement = 0xFFFFFFFF未分配页哨兵值
PageTableRowMask / RowShift页表行寻址位运算参数
CalcBin(VirtualShadowMapId, MinMipLevel)按 mip 层级把 VSM 归入渲染 bin（<6 直接，否则 /2）

页缓存管理 VirtualShadowMapCacheManager.cpp

符号说明
FVirtualShadowMapCacheManager跨帧缓存物理页与页表，决定哪些页可复用
PrevUniformParameters上一帧页表参数（复用判定基准）
InvalidatePages(...)把几何/光源移动波及的页标记失效重画
FreeHZBPhysicalPool释放物理 HZB 池
NANITE_CULLING_FLAG_CACHE_AS_STATIC (1<<2)Nanite 侧把静态实例归类，提升缓存判定精度

缓存与失效的平衡

缓存越激进，重画越少但失效判定越易漏（残影）；失效越保守，正确但重画越多。VSM 用"移动前后包围盒并集"标记失效页，静态几何走 CACHE_AS_STATIC 缓存路径，动态几何每帧判定。

EmitShadow 深度发射 NaniteEmitShadow.usf

符号说明
EmitShadowMapPS从 Nanite 深度 buffer 搬深度进阴影图；按 DEPTH_OUTPUT_TYPE 分路
DEPTH_OUTPUT_TYPE 0 / 1 / 2标准 / 正交(clipmap) / 透视(cubemap) 深度转换
EmitCubemapShadowVS / GS / PS点光 cubemap 6 面发射，用 SV_RenderTargetArrayIndex 选面
ViewToClip22 / DepthBias透视重投影系数 / 抗阴影痤疮偏置
SourceOffset / ShadowMapID源深度采样偏移 / 目标 VSM 标识
DepthInt != 0 else discard空像素丢弃（不覆盖已有页深度）
// 透视阴影深度重投影（DEPTH_OUTPUT_TYPE == 2） float DeviceZ = asfloat( DepthInt ); OutDepth = ViewToClip22 * ( DeviceZ - 1 ) / ( DeviceZ - ViewToClip22 ) + DepthBias;
