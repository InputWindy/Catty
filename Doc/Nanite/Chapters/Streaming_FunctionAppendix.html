#4 附录 · 流送管理器

本附录汇总流送系统的核心类、结构、方法与页池布局。均取自 UE5.8 本地源码 Runtime/Engine/Public/Rendering/NaniteStreamingManager.h 与 Private/Rendering/NaniteStreamingManager.cpp。

FPageKey / FStreamingRequest 页标识与请求

结构 / 成员说明
FPageKey{ RuntimeResourceID, PageIndex }页的全局唯一标识；自定义 GetTypeHash（两质数混合）与 < == !=
FStreamingRequest{ Key, Priority }一条流送请求；排序按 Key，Key 相同时 Priority 高者优先
FGPUStreamingRequestGPU 端写入的请求结构（RuntimeResourceID_Magic / PageIndex_NumPages_Magic 位打包）

位宽约束（static_assert）：NANITE_MAX_GPU_PAGES_BITS + MAX_RUNTIME_RESOURCE_VERSIONS_BITS + NANITE_STREAMING_REQUEST_MAGIC_BITS ≤ 32；NANITE_MAX_RESOURCE_PAGES_BITS + NANITE_MAX_GROUP_PARTS_BITS + MAGIC_BITS ≤ 32。

FStreamingManager 公共接口 : FRenderResource

方法说明

BeginAsyncUpdate(GraphBuilder)每帧至少一次，Nanite 渲染前调用；启动异步更新任务
EndAsyncUpdate(GraphBuilder)在 Begin 之后、任何 Nanite 渲染之前调用；落地 GPU buffer
IsAsyncUpdateInProgress() / IsSafeForRendering()更新状态查询 / 是否可安全渲染
GetStreamingRequestsBuffer(GraphBuilder)取 GPU 请求 buffer（GPU 往这里写缺失页请求）
GetHierarchySRV / GetClusterPageDataSRV取层级 / 页数据的 SRV（供 #5/#6 读取）
PrefetchResource(Resource, NumFramesUntilRender)提前预取资源页，抵消一帧延迟
RequestNanitePages(InRequestStream)显式请求页（非 GPU 反馈驱动）
GetQualityScaleFactor / GetMaxStreamingPages / GetMaxRootPages / GetMaxHierarchyLevels运行时参数查询
GetAndClearModifiedResources / GetAndClearModifiedPages取本帧变更的资源 / 装卸的页集合

页身份结构 虚拟 / 注册 / 常驻

结构字段层级
FRegisteredVirtualPagePriority + RegisteredPageIndex虚拟页（Priority≠0=本帧引用）
FResidentVirtualPageResidentPageIndex (uint16, 0xFFFF=无效)虚拟→常驻映射
FRegisteredPageKey + VirtualPageIndex + RefCount(uint8)注册页（进调度视野）
FResidentPageKey + MaxHierarchyDepth常驻页（在显存槽）
FNewPageRequestKey + VirtualPageIndex新页请求

相关数组：RegisteredPages / RegisteredPageDependencies（每页最多 16 内联依赖）、ResidentPages / ResidentPageFixupChunks / ResidentVirtualPages、LRU 双向映射 RegisteredPageIndexToLRU / LRUToRegisteredPageIndex、VirtualPageAllocator (FSpanAllocator)。

FRootPageInfo 每资源的根页元数据

字段说明

bInvalidResource : 1DDC/IO 数据非法时置位，停止从该资源流送而非崩溃

页池大小计算

MaxStreamingPages = (StreamingPoolSizeInMB << 20) >> NANITE_STREAMING_PAGE_GPU_SIZE_BITS; // 128KB MaxRootPages = (MaxRootPoolSizeInMB << 20) >> NANITE_ROOT_PAGE_GPU_SIZE_BITS; // 32KB // ClusterPageData 里流送页在前(128KB步长)、根页在后(32KB步长) Offset = min(PageIndex, MaxStreamingPages) << 17 + max(PageIndex - MaxStreamingPages, 0) << 15;

根页按 16MB 粒度分配（AllocationGranularityInPages = (16<<20) / NANITE_ROOT_PAGE_GPU_SIZE）；扩池用 AddPass_Memmove 搬迁根页数据。
