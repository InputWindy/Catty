FPageSections NaniteEncodeShared.h · 页内分区尺寸/偏移

记录一个页内每个数据分区的大小；GetXxxOffset() 从页头开始逐区累加得到各分区偏移，各区 Align(x,16) 对齐。

// 分区顺序（GetClusterOffset = NANITE_GPU_PAGE_HEADER_SIZE = 16） Header(16B) → Cluster → ClusterBoneInfluence → VoxelBoneInfluence → MaterialTable → VertReuseBatchInfo → BoneInfluence → BrickData → ExtendedData → DecodeInfo → Index → Position → Attribute
分区字段说明
Cluster簇头（FPackedCluster）区，光栅化首先读取
ClusterBoneInfluence / VoxelBoneInfluence / BoneInfluence骨骼蒙皮 / 体素骨骼影响数据
MaterialTable簇内材质范围表
VertReuseBatchInfo顶点复用批次信息
BrickData / ExtendedData体素 brick 数据 / 扩展数据
DecodeInfo解码属性所需元信息（位宽/最小值），transcode 先读它
Index三角索引（光栅化用）
Position量化后位置（光栅化用）
Attribute法线/UV/颜色等属性（材质着色才读）

GetOffsets() 返回一份把各字段替换成偏移的 FPageSections；GetTotal() 返回整页尺寸；operator+= 按分区累加（多簇累加到页级）。

字段说明

NormalPrecision / TangentPrecision法线 / 切线角度量化位数

位置精度可为负

PosPrecision 取值范围 -20 ~ 43。负值意味着量化格子比 1 世界单位还大，用于超大尺度、低细节的几何（如远景地貌），进一步节省位数。

FBitWriter NaniteEncodeShared.h · 非字节对齐位打包

void PutBits(uint32 Bits, uint32 NumBits){ check((uint64)Bits < (1ull << NumBits)); PendingBits |= (uint64)Bits << NumPendingBits; // 攒进 64 位 NumPendingBits += NumBits; while (NumPendingBits >= 8){ // 凑满 8 位就吐字节 Buffer.Add((uint8)PendingBits); PendingBits >>= 8; NumPendingBits -= 8; } } void Flush(uint32 Alignment=1){ // 收尾：补最后不足 8 位 + 对齐补零 if (NumPendingBits > 0) Buffer.Add((uint8)PendingBits); while (Buffer.Num() % Alignment != 0) Buffer.Add(0); PendingBits = 0; NumPendingBits = 0; }

成员：TArray<uint8>& Buffer（输出缓冲）、uint64 PendingBits（待吐位）、int32 NumPendingBits。每字段只占它真正需要的位数，是 Nanite 高压缩比的关键。

FFixupChunk NaniteFixupChunk.h · 跨页引用修补

页可独立换入换出，指向它的引用需在安装/卸载时修补。FFixupChunk 用一段紧凑内存承载多类 fixup，GetSize(...) 计算各段偏移做随机访问。

FHierarchyLocation

// ChildIndex + NodeIndex 打包进一个 uint32 GetChildIndex() = ChildIndex_NodeIndex & NANITE_MAX_BVH_NODE_FANOUT_MASK; // 低 2 位（fanout=4） GetNodeIndex() = ChildIndex_NodeIndex >> NANITE_MAX_BVH_NODE_FANOUT_BITS; // 其余为节点索引

安装/卸载闭环

页安装时置 NANITE_FIXUP_FLAG_INSTALLED(1)，遍历其 fixup，把层级节点里指向本页簇的引用写成真实 GPU 地址；卸载时反向清除，令运行时遍历不会走进已不在显存的页。这是 #4 流送 能独立换页的前提。
