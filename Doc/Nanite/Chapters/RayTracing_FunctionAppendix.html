#10 附录 · Nanite 光线追踪结构

本附录汇总光追模式枚举、FRayTracingManager 生命周期方法、簇流出缓冲与 BLAS 缓存的核心符号。取自 UE5.8 本地源码 NaniteInterface.h、NaniteRayTracing.cpp/.h、NaniteRayTracingASCache.cpp/.h。

目录

ERayTracingMode FRayTracingManager 簇流出缓冲 BLAS 缓存 源码文件索引

ERayTracingMode NaniteInterface.h

enum class ERayTracingMode : uint8 { Fallback = 0u, // 低模代理网格建 BLAS StreamOut = 1u, // 运行时流出簇为三角网格再建 BLAS CLAS = 2u, // 硬件簇级加速结构 }; ENGINE_API ERayTracingMode GetRayTracingMode();

Lumen HWRT 通过 Nanite::GetRayTracingMode() != Fallback 决定是否走 Nanite RT 几何（LumenHardwareRayTracingCommon.h）。

FRayTracingManager NaniteRayTracing.h

方法说明
Add / Remove(FPrimitiveSceneInfo*)注册/注销需要光追几何的 Nanite 图元
AddVisiblePrimitive(...)标记本帧可见、需要 RT 几何的图元
RequestUpdates(UpdateRequests, InstalledPages, UninstalledPages)结合页装/卸载事件请求 BLAS 更新
Update / UpdateStreaming推进流送与资源更新
ProcessUpdateRequestsdispatch compute 流出 mesh 数据
ProcessBuildRequests提交待建 BLAS（内部分配 scratch）
ProcessUpdateRequestsModeStreamOut / ModeCLASStreamOut / CLAS 两种模式的更新实现
GetRayTracingGeometry(SceneInfo)取图元对应的 RHI 光追几何
CheckModeChanged检测 RT 模式切换以重建资源
GetAuxiliaryDataSRV / GetBLASDataSRV辅助数据（材质段映射）/ CLAS 的 BLAS 数据 SRV

簇流出缓冲 FClusterStreamOutBuffers

成员说明
MaxClusters / MaxNumVertices / MaxNumIndices / MaxNumTriangles容量上限（跨帧保持稳定，避免 buffer 池抖动）
ClusterVertexBuffer / ClusterIndexBuffer流出的三角网格顶点 / 索引
ClusterGeometryIndexAndFlagsBuffer每簇几何段索引 + 标志
ClusterCountBuffer / ClusterBuildDescBuffer簇计数 / 构建描述
ScratchBuffer / StagingBuffer构建暂存 / 上传暂存（尺寸缓存复用）
StreamOutClusters(...)把选中 LOD 的簇解码进上述 buffer 的 compute 入口

BLAS 缓存 NaniteRayTracingASCache.cpp/.h

符号说明
NaniteRayTracingASCache缓存已建 BLAS，按页事件增量重建
BuildCLASForPages / ProcessPendingCLASBuildPagesCLAS 模式：按页构建簇级 AS
UpdateBLAS更新/重建 BLAS
ResizeCLASBufferIfNeeded / ResizeBLASCacheIfNeeded按预算管理 CLAS/BLAS 缓存容量
GetTLASBuildDependencies声明 TLAS 构建隐式读取的 AS buffer 依赖（保证 BVHWrite→BVHRead 屏障）

增量更新的触发点

与 #4 页流送耦合：RequestUpdates 收到 InstalledPages/UninstalledPages → 判断哪些资源几何精度变了 → 仅对这些资源重新 StreamOut + 重建 BLAS，其余复用缓存。
