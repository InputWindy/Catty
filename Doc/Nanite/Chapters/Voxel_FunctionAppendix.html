体素化函数 AutoVoxel.usf

// 深度 → 体素坐标 + 层级 int4 DepthToVoxel( uint2 PixelPos, float Depth ){ float3 VoxelPos = TranslatedWorldPosition / VoxelSize; float Level = log2( Distance * DistanceFactor ); // 距离分级 Level = floor( max( Level, 0 ) ); VoxelPos = floor( VoxelPos * exp2( -Level ) ); return int4( VoxelPos, Level ); } // 把体素置入 4x4x4 block 的 64 位掩码 void AddVoxelToBlock( uint BlockOffset, uint3 Voxel ){ uint VoxelIndex = Voxel.x + Voxel.y * 4 + Voxel.z * 16; // 0..63 uint HighInt = VoxelIndex >= 32; uint VoxelMask = 1u << ( VoxelIndex - HighInt * 32 ); RWBlockBuffer.InterlockedOr( 8 * BlockOffset + 4 * HighInt, VoxelMask ); }
符号说明
VoxelSize / DistanceFactor体素基础尺寸 / 距离分级系数（PixelsPerVoxel 推出）
Level = floor(log2(Distance·DistanceFactor))体素 LOD：越远体素越大
4×4×4 = 64 体素 / block用 2×uint32 位掩码表示占用
InterlockedOr并发原子置位（多像素写同 block）
