WritePixel NaniteWritePixel.ush · 原子写入

void WritePixel(RWTexture2D<UlongType> OutBuffer, uint PixelValue, uint2 PixelPos, uint DepthInt){ #if DEPTH_ONLY InterlockedMax(OutDepthBuffer[PixelPos], DepthInt); #elif COMPILER_SUPPORTS_UINT64_IMAGE_ATOMICS const UlongType Pixel = PackUlongType(uint2(PixelValue, DepthInt)); // (payload, depth) ImageInterlockedMaxUInt64(OutBuffer, PixelPos, Pixel); #endif } // 深度测试（earlyZ 风格）：比较高位深度 return UnpackUlongType(OutVisBuffer64[Position]).y < DepthInt; // VSM 目标：写深度 array #if VIRTUAL_TEXTURE_TARGET InterlockedMax(OutDepthBufferArray[PhysicalPosition], DepthInt); #else WritePixel(OutVisBuffer64, Value, Position, DepthInt); #endif

关键点

深度在 64 位的高 32 位（.y），payload（可见簇+三角 id）在低 32 位（.x）。ImageInterlockedMaxUInt64 的 atomic max 天然实现"近者胜出 + 记录 id"。不支持 64 位原子的平台会 #error UNKNOWN_ATOMIC_PLATFORM——这也是 HardwareOnly 回退存在的原因。

光栅着色器 NaniteRasterizer.usf

着色器 / 函数说明
MicropolyRasterize (SF_Compute)软件光栅入口：逐像素扫描微小三角，写 visibility buffer
FMicropolyRasterizeCS软件光栅 compute shader 类（Material shader，材质可参与光栅）
FMicropolyRasterizeWGWork Graph 变体（NaniteWorkGraphMaterialsSupported && RHISupportsWorkGraphs）
RasterizeTri_Adaptive(Tri, NaniteWritePixel)自适应三角扫描（内部按覆盖像素数选路）
TNaniteWritePixel<FMaterialShader[, FCachedPageTable]>写像素模板，绑定材质着色器与页表
SplitWorkQueue (FGlobalWorkQueueParameters)细分/切分工作队列（曲面细分 #8 用）

硬件光栅走 VS/PS 固定功能管线（大三角），软件光栅走 MicropolyRasterize compute（小三角），二者写同一 OutVisBuffer64。
