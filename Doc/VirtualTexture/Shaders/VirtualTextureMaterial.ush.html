0. RVT 材质参数读取接口（核心）

float4 GetRuntimeVirtualTextureMipLevel()   // 当前渲染页的 mip 级别信息
float4 GetRuntimeVirtualTextureCustomData()   // 材质自定义数据（喂给材质图节点）

说明

本头是 VirtualTextureMaterial.usf（RVT 页渲染 PS）与材质图之间的参数桥：材质图里的 RuntimeVirtualTextureReplace/mip 相关节点通过这些 helper 拿到"正在渲染哪一 mip 级别的页""RVT pass 传入的自定义数据"，从而让同一份材质在 RVT 烘焙路径与常规着色路径下表现一致。是把材质编译系统对接到 RVT 渲染的胶水层。
