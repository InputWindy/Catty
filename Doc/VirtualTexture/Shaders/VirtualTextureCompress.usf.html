0. 读 4×4 块 + 按平台选压缩格式（核心）

if (any(ThreadId.xy * 4 >= SourceRect.zw)) return;   // 每线程一个 4×4 块
uint2 SamplePos = SourceRect.xy + ThreadId.xy * 4;
float3 BlockBaseColor[16];
ReadBlockRGB(RenderTexture0, TextureSampler0, GetSourceUV(SampleUV, ThreadId), TexelUVSize, BlockBaseColor);
#if ASTC_PROFIlE || ETC_PROFILE
    OutCompressTexture0_64bit[GetDestPos(0, ThreadId)] = PackRG32(CompressBlock_ETC2_SRGB(BlockBaseColor));
#else OutCompressTexture0_64bit[...] = PackRG32(CompressBC1Block_SRGB(BlockBaseColor)); #endif

说明

每个 8×8 线程负责一个 4×4 纹素块（8×8 线程组覆盖 32×32 纹素）。ReadBlockRGB 采样出块的 16 个纹素，再按平台 permutation 压缩：桌面走 BC1（DXT1，RGB 4bpp）、移动端走 ETC2，输出 64bit/块写进物理纹理 UAV。SRGB 变体保证 gamma 正确。这是 RVT "渲染即缓存"的关键——material pass 产出未压缩页后立即 GPU 压缩，无需 CPU 往返，物理纹理直接存 GPU 原生块格式供采样。

说明

RVT 支持多种页布局（page layout）：只有 BaseColor 的走 CompressBaseColorCS；带法线/高光/粗糙度的走 CompressBaseColorNormalSpecularCS 压成多张 BC3/BC5 物理纹理层（对应 RVT 的 BaseColor,Normal,Roughness,Specular layer）。此外还有 CopyBaseColorPS（PixelShader 路径）做缩略图用的简单拷贝。所有变体通过 permutation 编成不同 shader，由 C++ 侧按 RVT 资产的材质类型选择——产物即 material pass 渲染页的最终落盘格式。
