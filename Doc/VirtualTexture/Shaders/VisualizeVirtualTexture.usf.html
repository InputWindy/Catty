Main @ L21（VT 调试可视化像素着色器）

0. 解包调试缓冲按模式着色（核心）

float SceneColorLuminance = saturate(Luminance(SceneColor)); OutColor.xyz = SceneColorLuminance;   // 场景灰底
uint ReadIndex = PixelPos.y * ViewSize.x + PixelPos.x; uint PackedDebugValue = DebugBuffer[ReadIndex];
if (ViewMode == 1) DebugValue = PackedDebugValue & 0xffff;          // 低 16 位：pending mips
else if (ViewMode == 2) DebugValue = (PackedDebugValue >> 16);      // 高 16 位：stack count
// DebugValue → 伪彩叠加到灰度场景上

说明

VT 采样时会把调试信息累计进 DebugBuffer（每像素一个 uint：低 16 位 pending mips——采样想要的 mip 与实际拿到的差距，>0 表示在等更清晰的页；高 16 位 stack count——该像素采了几张 VT）。本 shader 把场景转灰度作底，按 ViewMode 取对应调试值染成伪彩叠上去：红/热色区就是"正在等页/mip 不足"的地方。这是排查 VT 卡顿即糊（流送跟不上）的直接窗口，对应 #3 反馈与 #4 mip 流送。
