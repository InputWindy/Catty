0. 间接 VT 声明入口（核心）

// 前向声明 FIndirectVirtualTexture / FIndirectVirtualTextureUniform / FIndirectVirtualTextureEntry 等类型
// 供材质编译器生成的间接 VT 采样代码 include

说明

仅 9 行的声明头：把间接 VT 相关的类型（FIndirectVirtualTexture 集合缓冲、FIndirectVirtualTextureUniform 打包 uniform、FIndirectVirtualTextureEntry 条目）前向声明出来，让材质编译器生成的代码能引用而不必拖入完整实现。真正的逻辑在 IndirectVirtualTextureCommon.ush。这种"薄声明 + 厚实现"分离是 UE shader 库控制编译依赖、减少材质 permutation 编译量的常见做法。
