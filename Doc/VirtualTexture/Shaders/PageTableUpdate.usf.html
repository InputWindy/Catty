PageTableUpdate.usf 整源解析

VT 的页表更新：把 CPU 端算好的"虚拟页→物理页"映射批量刷进页表纹理。用一个无顶点缓冲的实例化四边形光栅化——每条更新覆盖页表里对应 vLevel 的一块区域，PS 只做常量写入。核心 PageTableUpdateVS + PageTableUpdatePS_1/2/4。下方内嵌完整 111 行真实源码，再逐段真实代码批注。

完整源码（逐行真实） · Engine/Shaders/Private/PageTableUpdate.usf

PageTableUpdateVS @ L21 · PageTableUpdatePS_1/2/4 @ L86/94/103

0. VS 解码更新项 → 造覆盖四边形（发散点）

uint UpdateIndex = FirstUpdate + InstanceID * QuadsPerInstance + (VertexID >> 2);   // 每实例 8 个四边形
uint4 UpdatePacked = UpdateBuffer[UpdateIndex];   // R16G16B16A16_UINT
uint vLevel = (UpdatePacked.w >> 0) & 0xff; uint vSize = 1u << ((UpdatePacked.w >> 8) & 0xff);
vPage.x = ReverseMortonCode2(vAddress); vPage.y = ReverseMortonCode2(vAddress >> 1);   // Morton→2D
uint2 vCorner = vPage + vSize * CornerOffset; OutPosition.xy = ((float2)vCorner / PageTableSize) * float2(2,-2) + float2(-1,1);

说明

页表更新用光栅化而非 UAV 写——因为一条更新要覆盖页表里 vSize×vSize 的一块（mip 越粗块越大），画个四边形让硬件填充最省事。VS 无顶点缓冲：由 VertexID/InstanceID 索引 UpdateBuffer（RGBA16 打包的更新项），解出虚拟页地址（ReverseMortonCode2 把 Z-order Morton 码还原成 2D 页坐标——VT 页表按 Morton 排布保证空间局部性）、mip 级别 vLevel、物理页 pPage，再由 CornerOffset 生成四边形四角映到 NDC。

1. 打包页项 + PS 常量写入（汇聚点）

uint Page = vLevel;   // 低 4 位存 mip 级别
Page |= pPage.x << 4; Page |= pPage.y << (4 + PageCoordinateBitCount);   // 物理页 xy
OutColor = Page;   // VS 输出 nointerpolation，PS 直接常量写
void PageTableUpdatePS_1(...) { OutColor = InColor; }   // PS_2/PS_4 splat 到 RG/RGBA

说明

本 pass 的汇聚点：把 vLevel（低 4 位）+ 物理页坐标 pPage.xy 打包成一个页表项 Page——采样时读出这个项就能算出物理池里对应的 tile 位置（1/(1<<vLevel) 的缩放技巧见源码注释，避免依赖具体页表尺寸）。USE_16BIT 时物理页压到 6 位。PS 有 _1/_2/_4 三个变体（对应页表纹理是 R/RG/RGBA 几通道），把 nointerpolation 的常量值 splat 到目标通道（配合颜色写掩码只写对应通道）。这是 #2 页表把间接寻址表刷新到 GPU 的机制。
