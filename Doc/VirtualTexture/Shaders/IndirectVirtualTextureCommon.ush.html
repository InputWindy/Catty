IndirectVirtualTextureCommon.ush 整源解析库 / 间接 VT 集合

VT 的间接虚拟纹理集合（TextureCollection）：把一组 VT 打包成集合，材质用一个索引即可访问其中任意一张——支持"纹理集合"式的间接寻址（如可替换的地形层）。核心 FIndirectVirtualTextureInfo + LoadIndirectVirtualTexture。下方内嵌完整 64 行真实源码，再逐段真实代码批注。

0. 间接 VT 集合的索引寻址（核心）

struct FIndirectVirtualTextureInfo { uint BlockX; uint BlockY; uint BlockWidth; uint BlockHeight; uint MaxLevel; };
uint GetIndirectVirtualTextureCount(FIndirectVirtualTextureUniform Uniform) { return Uniform.UniformCountSub1 + 1; }
FIndirectVirtualTextureEntry LoadIndirectVirtualTexture(Collection, Uniform, uint CollectionIndex) {
    CollectionIndex = min(Uniform.UniformCountSub1, CollectionIndex);   // clamp 防越界
    Out.PackedCoordinateAndSize = Collection[CollectionIndex]; ... }

说明

普通 VT 是"材质直接绑一张"，而间接 VT（TextureCollection）让材质持有一个 VT 集合，运行时用 CollectionIndex 动态选一张——典型用途是可切换/数据驱动的纹理层（如地形不同图层、批量实例各用不同贴图但共享一份材质）。FIndirectVirtualTextureInfo 描述集合里每张 VT 在虚拟地址空间的 block 位置与最大 mip，LoadIndirectVirtualTexture 按索引取出对应条目（min clamp 防越界）。放在 Public/ 是因为材质编译器要在生成的材质代码里引用它。
