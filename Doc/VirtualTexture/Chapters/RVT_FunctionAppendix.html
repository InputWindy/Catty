材质 / 属性类型枚举 RuntimeVirtualTextureEnum.h

RuntimeVirtualTexture::MaxTextureLayers = 3；MaterialType_NumBits = 3。

ERuntimeVirtualTextureMaterialType（uint8）

值内容
BaseColor仅基色
Mask44 通道遮罩
BaseColor_Normal_Roughness本地空间法线，省内存，支持 LQ 压缩
BaseColor_Normal_Specular基色+法线+粗糙度+高光（默认）
BaseColor_Normal_Specular_YCoCg基色存 YCoCg，更占内存但质量更好
BaseColor_Normal_Specular_Mask_YCoCg上者 + 遮罩
WorldHeight / Displacement世界高度 / 位移

ERuntimeVirtualTextureAttributeType（uint8，≤8）

BaseColor / Normal / Roughness / Specular / Mask / Mask4 / WorldHeight / Displacement——可组合成上面的完整布局，8bit 掩码。

ERuntimeVirtualTextureMainPassType（uint8）

值行为
Never只画进 RVT，不进主通道
Exclusive无"隐藏图元"Volume 时才进主通道
Always始终进主通道（既读又写 RVT）

ERuntimeVirtualTextureShaderUniform

WorldToUVTransform0/1/2、WorldHeightUnpack、_Count——shader 里 VT 采样所需的 uniform 槽。

FRuntimeVirtualTextureProducer RuntimeVirtualTextureProducer.h

IVirtualTexture 的现画实现（#4 接口）。

方法说明
IsPageStreamed(vLevel, vAddress) const恒 return false——RVT 页非流式
RequestPageData(...)发起请求，RVT 几乎立即就绪
ProducePageData(...)返回内部的 FRuntimeVirtualTextureFinalizer*

构造参数：FVTProducerDescription、RuntimeVirtualTextureId、MaterialType、bClearTextures、Scene、UVToWorld、WorldBounds、CustomMaterialData。

FRuntimeVirtualTextureFinalizer RuntimeVirtualTextureProducer.h

成员 / 方法说明
struct FTileEntry { Targets[MaxTextureLayers]; vAddress; vLevel; }单个待画 tile 描述
bool IsReady()渲染一页所需资源是否齐备
void AddTile(FTileEntry&)把 tile 加入 finalize 队列 Tiles
RenderFinalize(GraphBuilder, SceneRenderer)把队列里的 tile 分批渲染进临时目标（Batches）
Finalize(GraphBuilder)把各 batch 结果拷贝到物理页最终位置

FRuntimeVirtualTextureSceneProxy RuntimeVirtualTextureSceneProxy.h

方法 / 成员说明
Dirty(Bounds, InvalidatePriority)把世界区域转页矩形累加进 DirtyRects
FlushDirtyPages()踢掉脏页，触发下次采样重画
RequestPreload(Bounds, Level)主动预热某区域某 mip
MarkUnused() / Release()共享资产的多组件边缘处理 / 释放（主线程调用后延迟到渲染线程删）
GetUniformParameter(UniformName)取缓存的 shader uniform
ProducerHandle / AllocatedVirtualTexture / SpaceID失效与预加载用的句柄
RuntimeVirtualTextureId / SceneIndex过滤图元 / FScene 索引
bHidePrimitivesInEditor / InGame主通道隐藏控制
struct FDirtyRect { Rect; InvalidatePriority; }脏矩形（Union 时取更高优先级）

按页渲染 API RuntimeVirtualTextureRender.h

命名空间 RuntimeVirtualTexture。MaxRenderPageBatch = 8。

符号说明
bool IsSceneReadyToRender(Scene)调 RenderPages 前必检
void RenderPages(GraphBuilder, FRenderPageBatchDesc const&)渲染一批页（一站式）
FBatchRenderContext const* InitPageBatch(...)建批上下文
void RenderPageBatch(GraphBuilder, Batch)画批内所有页（对应 RenderFinalize）
void FinalizePageBatch(GraphBuilder, Batch)把批内页落到物理位置（对应 Finalize）

FRenderPageBatchDesc

字段说明
ISceneRenderer* SceneRenderer场景渲染器
int32 RuntimeVirtualTextureId过滤要渲染到本 RVT 的图元
FTransform UVToWorld / FBox WorldBoundsUV↔世界变换与范围
ERuntimeVirtualTextureMaterialType MaterialType / uint8 MaxLevel层布局 / 最大 mip
bool bClearTextures / bIsThumbnails清屏 / 缩略图模式
FLinearColor FixedColor / FVector4f CustomMaterialData固定基色 / 自定义数据
FRenderPageTarget Targets[MaxTextureLayers]每层物理目标（IPooledRenderTarget*）
int32 NumPageDescs / FRenderPageDesc PageDescs[MaxRenderPageBatch]批内页数 + 每页描述

FRenderPageDesc

uint8 vLevel；FBox2D UVRange（VT 空间 UV 范围）；FIntRect DestRect[MaxTextureLayers]（物理纹理 texel 空间目标框）。
