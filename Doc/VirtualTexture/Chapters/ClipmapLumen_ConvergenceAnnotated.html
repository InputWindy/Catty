#9 Lumen Clipmap 案例 · Radiance Cache + 全局距离场

本篇是 #7 理论的第二个 UE 实战案例，也是全书的收束：Lumen 全局光照如何用 3D clipmap 组织缓存数据。这里 clipmap 从 2D 纹理（VSM）走向 3D 体纹理——辐照度缓存（Radiance Cache）和全局距离场（Global Distance Field）都是以相机为中心的 3D 嵌套金字塔。更妙的是全局距离场同时用到三种范式：clipmap 分层 + 页表分页 + mip 回退。所有符号取自 UE5.8 本地源码 LumenRadianceCacheInterpolation.h、GlobalDistanceFieldParameters.h。

从 2D 阴影到 3D 光照：clipmap 升维 Clipmap goes 3D

为什么 GI 也需要 clipmap

#8 的 VSM clipmap 是 2D 的（阴影图是屏幕/光源平面）。但全局光照要缓存的是空间中每一点的入射辐照——这是个 3D 场。同样的精度矛盾又出现了：相机附近的间接光需要密集探针（近处反弹清晰），远处只要稀疏采样就够。答案还是 clipmap，只不过升成 3D 体 clipmap：以相机为中心，一叠按幂次递增覆盖体积的立方壳层。Lumen 有两套并行的 3D clipmap——Radiance Cache（辐照度探针）和 Global Distance Field（全局距离场），两者 MaxClipmaps 都 = 6。

近处 clipmap（0 级）覆盖体积小、探针密
脚下间接光清晰
中间 clipmapClipmapDistributionBase
控制每级体积增长比
远处 clipmap（5 级）覆盖大片场景
探针稀疏但够远景

Radiance Cache：3D 探针 clipmap Radiance probe clipmap

辐照度缓存把间接光烘在一叠 3D 探针网格里。FRadianceCacheInputs 定义 clipmap 的组织（源码字段）：

字段含义
RadianceProbeClipmapResolution每级 clipmap 一边的探针数（3D 网格边长）
NumRadianceProbeClipmapsclipmap 级数（≤ MaxClipmaps=6）
ClipmapWorldExtent最细一级 clipmap 的世界半径
ClipmapDistributionBase每级世界范围的增长底数（幂次分布）
RadianceProbeResolution单个探针捕捉的辐照图分辨率
ProbeAtlasResolutionInProbes探针图集一边容纳的探针数
InvClipmapFadeSize相邻级之间的过渡淡入淡出宽度倒数

探针寻址：间接纹理（indirection）——又见页表思想

探针不是密集存储的——RadianceProbeIndirectionTexture 是一张 Texture3D<uint>，作用和 #3 的 VT 页表一模一样：把 clipmap 里的逻辑探针坐标，映射到探针图集里的物理槽位。没被用到的探针不占物理槽——这就是 clipmap 里嵌套的"按需分配"。ClipmapCornerTWSAndCellSize[MaxClipmaps] 存每级的世界角点与格子尺寸，shader 靠它把世界坐标换算到 clipmap 格子。MinRadianceProbeResolution=8 是探针分辨率下限。

Global Distance Field：三范式合一的极致 Three paradigms in one texture

全书最精彩的收束点

全局距离场把整个场景的有向距离烘进一组以相机为中心的 3D clipmap（GlobalDistanceField::MaxClipmaps=6）。看 FGlobalDistanceFieldParameterData 的字段，本书三种范式在同一张纹理上全部出现：

字段对应范式说明
TranslatedCenterAndExtent[MaxClipmaps]Clipmap每级 clipmap 的中心与半径（相机中心嵌套）
PageAtlasTexture + PageTableTexture页表式 VT距离场也分页！页图集存实际距离，页表做间接寻址
MipTexture + MipFactor / MipTransitionMip低分辨率 mip 作粗粒度回退，页缺失时兜底
ClipmapSizeInPages / MaxPageNum—每级 clipmap 有多少页、物理页上限
NumGlobalSDFClipmaps—实际启用的 clipmap 级数

这就是全书的中心论点

全局距离场是本书三范式"可组合"最有力的证据：clipmap 决定"哪一圈"（宏观空间分层，相机中心），页表决定"这圈里哪些格真有数据"（微观按需分页），mip 决定"页还没准备好时用多粗的近似兜底"（精度回退）。三者不是竞争关系，而是三个正交的维度——空间分层 × 按需分页 × 精度层级——叠在一张 Texture3D<uint> 页表 + Texture3D 页图集上协同工作。这正回应了 #7 结尾的判断。

寻址：世界坐标 → clipmap 级 → 页 → 距离 Addressing

1选 clipmap 级按到相机距离选最细能覆盖的级
TranslatedCenterAndExtent 判定
2算 UV → 查页表TranslatedWorldToUVAddAndMul
→ PageTableTexture 取页地址
3页图集采样页命中→PageAtlasTexture 采距离
页缺失→MipTexture 兜底
4跨级过渡MipTransition 在相邻级
间平滑混合避免接缝

与经典 clipmap 寻址对照

第 1 步"距离选级"完全是 #7 的 3D 版；第 2 步的 TranslatedWorldToUVAddAndMul 就是经典 clipmap 的"世界→层内 UV"仿射变换（Add=偏移、Mul=缩放），只是升到 3D；第 3 步多了 VT 页表间接（经典 clipmap 是直接 toroidal 访问，这里为了省显存做了分页）；第 4 步的 MipTransition 对应 clipmap 层间的 blend region，避免壳层边界硬切。

Lumen vs VSM：两个 clipmap 案例的异同 Lumen vs VSM

两个案例横向对比

共同点：都以相机为中心组织嵌套金字塔层，精度随距离衰减；都在 clipmap 层内嵌套了 VT 页表间接（VSM 存深度页、Lumen 存探针/距离页），复用"按需分页"省显存；都靠层中心吸附/世界角点做增量更新。

不同点：维度不同——VSM 是 2D（阴影图在光源平面），Lumen 是 3D 体 clipmap（辐照/距离在空间体积里）。

不同点：层数不同——VSM 约 17 级（FirstLevel 6~LastLevel 22，每级半径 2ⁿ），Lumen 固定 MaxClipmaps=6（每级按 ClipmapDistributionBase 幂增）。

不同点：VSM 只用了 clipmap+页表两范式；Lumen 的全局距离场把 mip 回退也加进来，凑齐了三范式，是组合的极致形态。

与另外两种范式的关系 Cross-paradigm

Lumen 是三范式同框的舞台

共同点：Lumen 的探针间接纹理、距离场页表，本质就是 #2/#3 讲的 VT 页表——逻辑坐标经一层 uint 间接映射到物理图集。

不同点：全局距离场的 MipTexture 用了 #1 的 mip 思想做兜底——但这里 mip 不是磁盘流送，是运行时生成的粗粒度距离。

不同点：clipmap 分层（#7 第三范式）是骨架，与 #8 VSM 同源，但升到 3D 且级数固定。

本篇小结 Summary

记住这几点

1. Lumen 把 clipmap 从 VSM 的 2D 升到 3D 体 clipmap：Radiance Cache（探针）+ Global Distance Field（距离场），两者 MaxClipmaps=6。

2. 探针不密集存储——RadianceProbeIndirectionTexture（Texture3D<uint>）是 VT 页表在 3D 的翻版，按需分配物理槽。

3. 全局距离场 FGlobalDistanceFieldParameterData 是三范式合一：Clipmap（TranslatedCenterAndExtent）× 页表（PageAtlas+PageTable）× Mip（MipTexture 兜底），三个正交维度叠在一张纹理上。

4. 寻址四步：距离选级 → 世界转 UV 查页表 → 页图集采样（缺失走 mip）→ MipTransition 跨级平滑。这是本书三范式可组合论点的最强例证。
