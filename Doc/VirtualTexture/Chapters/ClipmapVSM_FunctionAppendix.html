#8 附录 · VSM Clipmap 类与 CVar

本附录汇总 VSM clipmap 的配置、主类、层数据、CVar。均取自 UE5.8 本地源码 Engine/Source/Runtime/Renderer/Private/VirtualShadowMaps/VirtualShadowMapClipmap.h/.cpp。

FVirtualShadowMapClipmapConfig VirtualShadowMapClipmap.h

GetGlobal() 从 CVar 组装一份全局配置。

字段默认说明
FirstLevel8（CVar 值 6）最近 clipmap 层绝对级号
LastLevel18（CVar 值 22）最远层绝对级号
FirstCoarseLevel / LastCoarseLevel-1（禁用时）/ 15、18标记粗页的级范围
ShadowTypeId0阴影类型标识
ResolutionLodBias / ResolutionLodBiasMoving0.0分辨率 LOD 偏移（静止 / 移动时）
bForceInvalidatefalse强制整体失效
bIsFirstPersonShadowfalse第一人称表示投影用
bCullDynamicTightly / bUseReceiverMask / bHasPrefilteredDistantfalse剔除/接收遮罩/远景预滤优化开关

注：类内默认 FirstLevel=8 / LastLevel=18；运行时由 GetGlobal() 用 CVar（6 / 22）覆盖。

FVirtualShadowMapClipmap : FRefCountedObject

方法说明
FVirtualShadowMapClipmap(VSMArray, LightSceneInfo, CameraViewMatrices, ViewRectSize, DependentView, LightMobilityFactor, Config)构造：按相机/光源建各层
GetViewMatrices(ClipmapIndex)取某层的视图矩阵
GetLevelCount()层数 = LevelData.Num()
GetClipmapLevel(ClipmapIndex)= FirstLevel + ClipmapIndex（绝对级号）
GetPreViewTranslation(ClipmapIndex)= -LevelData[i].WorldCenter
GetViewToClipMatrix(ClipmapIndex)= LevelData[i].ViewToClip
GetWorldToLightViewRotationMatrix()定向光旋转矩阵（无平移）
GetProjectionShaderData(ClipmapIndex)取某层投影 shader 数据
GetWorldOrigin()clipmap 世界原点（≈相机位）
static GetLevelRadius(AbsoluteLevel)= Pow(2, Level+1)
GetMaxRadius()最远层保证覆盖的半径
GetBoundingSphere() / GetViewFrustumBounds()包围球 / 视锥凸体
GetDynamicDepthCullRange(ClipmapIndex)该层动态深度剔除范围
OnPrimitiveRendered(PrimitiveSceneInfo)非 Nanite 图元过剔除时标记（非线程安全）
UpdateCachedFrameData()帧末推缓存数据回 cache entry
GetCacheEntry()取 FVirtualShadowMapPerLightCacheEntry
GetVirtualShadowMapId()= PerLightCacheEntry->GetVirtualShadowMapId()（接到 VT id）
IsFirstPersonShadow()= Config.bIsFirstPersonShadow

私有

ComputeProjectionShaderData(ClipmapIndex)、ComputeBoundingVolumes(CameraOrigin)；成员 WorldOrigin / CameraToViewTarget / LightDirection / WorldToLightViewRotationMatrix / FirstLevel / ResolutionLodBias / BoundingSphere / ViewFrustumBounds / RenderedPrimitives(TBitArray)。

FLevelData 每层数据

存于 TArray<FLevelData, TInlineAllocator<32>> LevelData——内联最多 32 级免堆分配。

字段说明
FMatrix ViewToClip该层投影矩阵
FVector WorldCenter该层中心（吸附到该级页边界）
FInt64Point CornerOffset(0,0) 到 clipmap 角的偏移（以层半径为单位）
FIntPoint RelativeCornerOffset相对 LastLevel 吸附中心的角偏移
double WPODistanceDisableThresholdSquaredWPO 距离禁用阈值²
FVector2f DynamicDepthCullRange动态深度剔除范围

CVar VirtualShadowMapClipmap.cpp

CVar默认说明
r.Shadow.Virtual.Clipmap.FirstLevel6首层；越低近处越清晰但页数增
r.Shadow.Virtual.Clipmap.LastLevel22末层；每级半径翻倍
r.Shadow.Virtual.Clipmap.FirstCoarseLevel15标记粗页起始级
r.Shadow.Virtual.Clipmap.LastCoarseLevel18标记粗页结束级

均 ECVF_Scalability | ECVF_RenderThreadSafe。粗页标记 CVar 值=1 标记末层+coarse 范围；=2 性能模式抑制粗页动态失效。构建常量 RadiiPerLevel = 4。
