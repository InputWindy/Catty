Clipmap 术语表

术语含义
Clipmap被裁剪的 mipmap：大级只保留视点附近固定大小窗口
Clip size每个 clip 层窗口的边长上限；≤ 它的级完整存（mip 层），> 它的级只存窗口（clip 层）
Clip region / clip window某 clip 层实际保留的、以视点为中心的那块
Mip pyramid（金字塔顶部）完整存储的粗级，全局可采，作回退
Clip stack（金字塔底部）只存窗口的细级，叠成栈
Toroidal addressing环形/卷绕寻址：物理纹理坐标取模复用，相机移动只更新新边缘
L-shaped update相机平移一格时需重传的新数据区域（横+竖两条，呈 L 形）
Clipmap center各层的中心，通常随相机（或光源/视点）移动
Nested gridsgeometry clipmap 里嵌套的正方形网格环
Morphing层间几何过渡，消除 LOD 切换 popping

奠基论文

论文贡献
Tanner, Migdal, Jones — "The Clipmap: A Virtual Mipmap", SIGGRAPH 1998提出 clipmap：为超大纹理（如 128K²）只存每级视点附近窗口 + 完整粗级；SGI InfiniteReality 硬件支持
Losasso & Hoppe — "Geometry Clipmaps: Terrain Rendering Using Nested Regular Grids", SIGGRAPH 2004把 clipmap 思想用于地形几何：嵌套网格环 + 增量滚动 + morphing
Asirvatham & Hoppe — "Terrain Rendering Using GPU-Based Geometry Clipmaps", GPU Gems 2把 geometry clipmap 更新与渲染搬到 GPU
