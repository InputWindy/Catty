#9 附录 · Lumen Clipmap 类与常量

本附录汇总 Lumen 两套 3D clipmap 的关键结构：Radiance Cache 的 FRadianceCacheInputs 与 Global Distance Field 的 FGlobalDistanceFieldParameterData。均取自 UE5.8 本地源码 Renderer/Public/GlobalDistanceFieldParameters.h、Renderer/Private/Lumen/LumenRadianceCacheInterpolation.h。

FRadianceCacheInputs clipmap 组织参数

定义辐照度缓存的 clipmap 分布、探针分辨率与追踪预算。

字段类型说明
ReprojectionRadiusScalefloat上帧探针重投影的搜索半径缩放
ClipmapWorldExtentfloat最细一级 clipmap 的世界半径
ClipmapDistributionBasefloat每级世界范围的增长底数（幂次分布）
NumRadianceProbeClipmapsint32clipmap 级数（≤ MaxClipmaps=6）

RadianceProbeResolutionint32单探针捕捉的辐照图分辨率

NumProbesToTraceBudgetint32每帧允许追踪的探针数上限（分帧摊销）
NumFramesToKeepCachedProbesint32探针缓存保留帧数
UseAdaptiveProbesuint32是否按场景复杂度自适应探针密度

FRadianceCacheInterpolationParameters shader 采样参数

供着色阶段把世界坐标插值到探针 clipmap 的参数组。

成员说明
RadianceProbeIndirectionTextureTexture3D<uint>——逻辑探针坐标 → 图集物理槽的间接纹理（3D 版 VT 页表）
RadianceProbeAtlasTexture / FinalRadianceAtlas探针辐照度图集
ClipmapCornerTWSAndCellSize[MaxClipmaps]每级 clipmap 的世界角点（Translated World Space）与格子尺寸
SetClipmapCornerTWS(i, Value) / SetClipmapCellSize(i, Value)填每级角点 / 格子尺寸的辅助方法
RadianceProbeClipmapResolution / NumRadianceProbeClipmaps与 Inputs 对应的采样端拷贝

寻址公式

世界坐标定位到某级 clipmap 的格子：cell = (WorldPos − ClipmapCornerTWS[level]) / CellSize[level]，再经 RadianceProbeIndirectionTexture 查到图集物理槽——与 #7 经典 clipmap 层内定位一致，只是三维。

namespace GlobalDistanceField { /** Must match global distance field shaders. */ inline const int32 MaxClipmaps = 6; }

FGlobalDistanceFieldParameterData GlobalDistanceFieldParameters.h

构造即 Memzero。★ 标注为"三范式合一"的关键字段。

字段类型范式/说明
TranslatedCenterAndExtent[MaxClipmaps]FVector4f[]★Clipmap：每级中心 xyz + 半径 w（相机中心嵌套）
TranslatedWorldToUVAddAndMul[MaxClipmaps]FVector4f[]每级世界坐标→UV 的仿射变换（Add/Mul）
MipTranslatedWorldToUVScale/Bias[MaxClipmaps]FVector4f[]mip 层的世界→UV 缩放 / 偏移
PageAtlasTextureFRHITexture*★页表式：3D 页图集，存实际距离值
PageTableTextureFRHITexture*★页表式：3D 页表，逻辑坐标→物理页间接
CoverageAtlasTextureFRHITexture*覆盖图集（哪些区域有几何）
PageObjectGridBufferFRDGPooledBuffer*页内物体网格缓冲
MipTextureFRHITexture*★Mip：低分辨率兜底层，页缺失时采样
MipFactor / MipTransitionfloatmip 缩放因子 / 跨级过渡宽度
ClipmapSizeInPagesint32每级 clipmap 一边多少页
MaxPageNumint32物理页总数上限
InvPageAtlasSize / InvCoverageAtlasSizeFVector图集尺寸倒数（换算 UV）
GlobalDFResolutionfloat全局距离场分辨率
MaxDFAOConeDistancefloatDFAO 锥追踪最大距离
NumGlobalSDFClipmapsint32实际启用的 clipmap 级数

三范式同框

此结构一处集齐三范式：Clipmap（TranslatedCenterAndExtent 相机中心分层）× 页表式 VT（PageAtlasTexture + PageTableTexture 稀疏分页）× Mip（MipTexture 精度回退）。对应的 shader 参数结构是 FGlobalDistanceFieldParameters2（同文件），其中页表用 SHADER_PARAMETER_TEXTURE(Texture3D<uint>, GlobalDistanceFieldPageTableTexture)。
