#6 附录 · SVT 流送与自适应结构

本附录汇总 SVT 上传实现、自适应 VT、虚拟地址分配器、可伸缩性预算的核心符号。均取自 UE5.8 本地源码 Engine/Private/VT/、Renderer/Private/VT/、Engine/Public/VT/。

FUploadingVirtualTexture UploadingVirtualTexture.h

从 CPU 上传到 GPU、数据取自 FChunkProvider 的 IVirtualTexture 实现。

方法 / 成员说明
FUploadingVirtualTexture(Name, FVirtualTextureBuiltData*, FirstMipToUse)构造：绑定离线数据 + 起始 mip 偏移
IsPageStreamed(vLevel, vAddress) const恒 return true——SVT 页是流式的
GetLocalMipBias(vLevel, vAddress) const该页的本地 mip 偏移
RequestPageData(...)定位 chunk 并发起异步磁盘读
ProducePageData(...)把转码结果上传到目标物理页
GatherProducePageDataTasks(...)收集本页依赖的任务图事件（两个重载：按 ProducerHandle / 按 RequestHandle）
GetCodecForChunk(OutEvents, ChunkIndex, Priority)取 chunk 的 codec，OutEvents 完成前数据无效 → FVTCodecAndStatus
ReadData(OutEvents, ChunkIndex, Offset, Size, Priority)读 chunk 的一段 → FVTDataAndStatus
HandlePerChunk : TArray<TUniquePtr<IFileCacheHandle>>每 chunk 一个文件缓存句柄
CodecPerChunk : TArray<TUniquePtr<FVirtualTextureCodec>>每 chunk 一个转码器
InvalidChunks : TBitArray<>标记加载失败的 chunk
FirstMipOffset / StreamingManager起始 mip / FVirtualTextureChunkStreamingManager*

FAdaptiveVirtualTexture AdaptiveVirtualTexture.h

IAdaptiveVirtualTexture 的具体实现：同 space 内多张子 VT + 间接纹理 + 反馈驱动伸缩。

方法说明
Init(RHICmdList, System)创建常驻低 mip VT
GetPackedAllocationRequest(vAddress, vLevelPlusFixedOffset, Frame) const把反馈请求打包成不透明 key
QueuePackedAllocationRequests(...)入队一批分配请求（静态版把全局请求分发到各对象并排序）
UpdateAllocations(System, RHICmdList, Frame)据请求分配/回收子 VT
ApplyPageTableUpdates(System, GraphBuilder, ExternalAccessQueue)应用页表更新
GetProducers(TextureRegion, MaxLevel, Out)取覆盖某 texel 区域的内部 producer（FProducerInfo）
GetAllocatedVirtualTextures(UVRegion, Level, Out, OutReqs)取覆盖某 UV 区域的子 VT（FAllocatedInfo）
FreeLRU(...)淘汰最久未用分配（LRUHeap）
RemapVirtualTexturePages(System, Old, New, Frame)（静态）换分辨率时直接重映射页表，不重生成页
