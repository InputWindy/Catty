分帧摊销机制

NumRenderAssetProcessingStages = Settings.FramesForFullUpdate；ProcessingStage 从 0 递增，stage 0 启动异步任务，后续 stage 增量更新（IncrementalUpdate），最后 stage 完成一轮。bProcessEverything=true 时同步一次跑完（用于烘焙/命令行）。

Allocator / DataProvider 具体实现

实现文件用途
FTexture2DMipAllocator_AsyncCreateTexture2DMipAllocator_AsyncCreate.h用 RHIAsyncCreateTexture2D 全新创建中间纹理
FTexture2DMipAllocator_AsyncReallocateTexture2DMipAllocator_AsyncReallocate.h用 AsyncReallocateTexture2D 原地扩容
FTexture2DMipAllocator_VirtualTexture2DMipAllocator_Virtual.h基于虚拟纹理内存（硬件 partially resident texture）
FTexture2DMipDataProvider_IOTexture2DMipDataProvider_IO.h运行时从打包 bulk data / .ubulk 磁盘文件读 mip
FTexture2DMipDataProvider_DDCTexture2DMipDataProvider_DDC.h编辑器从 Derived Data Cache 读 mip

组合关系

换入路径 FTexture2DStreamIn_IO / _DDC 会把某个 Allocator 和某个 DataProvider 组装起来。例如运行时最常见的是 AsyncReallocate + IO；编辑器无烘焙数据时用 AsyncCreate + DDC。这就是主文档说的"3 种分配 × 2 种数据源自由组合"。
