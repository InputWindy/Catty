1. 可视化模式清单

说明

Overview 是入口，一屏能大致看出 GI/反射/探针哪块异常。定位到方向后开单项：LumenScene/SurfaceCache 查表面缓存、CardPlacement 查卡片覆盖（红=漏）、GlobalDistanceField 查远场几何。CardGenerationSurfels 能看到离线烘焙的 surfel 分布，用于诊断某网格为什么卡片布局不理想。

2. Profiler pass 清单

说明

ProfileGPU 抓单帧 GPU 耗时树，展开后按上面这些 RDG 事件 scope 名（camelCase）找 Lumen 的 pass。LumenScreenProbeGather 下的 .Trace* 是追踪耗时、.Temporal/.SpatialFilter 是降噪、.ConvertToIrradiance 是 SH 落地。LumenReflections 分 GenerateRays→Trace→Resolve→两段降噪。LumenSceneLighting（DirectLighting/Radiosity）与 LumenSceneUpdate（卡片捕获）属于 Surface Cache 侧，平时稳定但物体变化时 LumenSceneUpdate 会尖峰。stat GPU 适合实时粗看总占比，ProfileGPU 适合抓一帧细分。

3. 画质 CVar

说明

提画质的主力是这几个。ScreenProbeGather.DownsampleFactor 直接决定探针密度——调小更清晰但线性变贵。SurfaceCache.Resolution 决定间接光的"分辨率上限"，物体近看间接光糊多半是它。反射侧 DownsampleFactor 和 MaxRoughnessToTrace 控制"哪些反射真追踪、追多细"。原则：先靠 RadianceCache 兜底稳住远场，再针对性提近场密度，避免全局拉满。

4. 性能 CVar

说明

降开销的思路分三层：总开关（DiffuseIndirect.Allow/Reflections.Allow）用于对比测量各自成本；降质（提 DownsampleFactor、关 TraceMeshSDFs 让远场兜底）换帧率；削尖峰（限 CardCapturesPerFrame 让卡片捕获分摊到多帧，降 Radiosity 更新频率）解决"进新区域卡一下"。移动端/低配优先关近场 SDF + 开 RadianceCache，桌面高配再逐项回调质量。

5. 追踪后端 CVar

说明

追踪后端切换靠 r.Lumen.HardwareRayTracing。软件追踪（SDF cone march）跨平台、无需 RT 硬件，但薄物体/接触阴影会因 SDF 精度出误差（漏光/接触面发虚）；硬件光追精确求交能修掉这些，代价是需要 RT GPU 且更贵。关键：两个后端命中后都采同一份 Surface Cache 取表面光照，所以切后端只影响"几何求交精度"，不影响 GI 管线其余部分。开 Inline 可省 RT 调度开销。
