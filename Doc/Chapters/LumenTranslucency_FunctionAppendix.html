1. froxel 网格与 log-Z 分布

说明

froxel 体积是相机对齐的：XY 直接按屏幕像素分块（GridPixelSize），Z 按对数分布切片——近处切得密、远处切得疏，因为近处 GI 变化快、需要更高体积分辨率。这与 clustered shading / volumetric fog 的 Z-slice 完全同一套数学。GridZParams 就是"世界深度 ↔ 切片索引"的换算系数，着色时反用它定位 froxel。

2. 逐 froxel 八面体追踪（双后端）

说明

每个 froxel 从体素中心出发，追一整张八面体 atlas（把整个球面方向映射进一块 OctRes×OctRes 子图），命中读 Surface Cache、远场切 Radiance Cache（用 RadianceCacheClipmapBias 决定何时切）。追踪后端二选一：UseHardwareRayTracedTranslucencyVolume 为真走硬件 RT，否则走软件 FTranslucencyVolumeTraceVoxelsCS（Global SDF voxel 追踪）。MaxRayIntensity 钳制单根线的强度，防止小亮点炸成萤火虫。

共同点八面体映射 + 双追踪后端 + MaxRayIntensity 钳制，与主线 Screen Probe 追踪的原子完全一致。

3. 可分离高斯滤波（3 趟）

说明

3D 高斯是可分离的：一个 n³ 的三维卷积等价于沿 X、Y、Z 各做一次一维卷积，复杂度从 O(n³) 降到 O(3n)。代码里就是一个 3 次的循环，每趟把 SpatialFilterDirection 设成只有一个轴为 1，输出链式喂给下一趟。抽头数是 SampleCount*2+1（默认 SampleCount=3 → 7 抽头 [-3,3]）。

不同点ScreenProbe 的空间滤波是屏幕 2D 的 gather；这里是体积 3D，必须靠可分离分解才不至于爆炸。

4. SH 投影 + 时域重投影

说明

FTranslucencyVolumeIntegrateCS 把滤波后的方向辐射投影成球谐存两张 3D 纹理（Volume0 主系数 + Volume1 补充）。时域重投影是一个 shader permutation（FTemporalReprojection）：满足门禁（非相机切换、网格尺寸一致、有合法历史）时，用 UnjitteredPrevWorldToClip 把当前 froxel 世界位置投到上帧、三线性采历史、按 HistoryWeight 混合。历史双缓冲乒乓存进 ViewState->Lumen.TranslucencyVolume0/1。

共同点时域重投影 + HistoryWeight + 双缓冲，与 UpdateHistoryScreenProbeGather 同构。

5. Translucency Radiance Cache（专属实例）

说明

半透明体积默认挂一份专属 Radiance Cache（状态独立于不透明的 RadianceCacheState），用来给体积追踪补远场/天光贡献。它复用完全相同的 Radiance Cache 基础设施，只是探针标记回调换成 MarkRadianceProbesUsedByTranslucencyVolume（沿 froxel 视锥标记）。LumenTranslucencyVolumeRadianceCache::ShareWithOpaque() 为真时可直接复用不透明的 RC，省掉一次独立更新。

共同点SetupRadianceCacheInputs / MarkUsedProbes / UpdateRadianceCaches 三段式，与 Irradiance Field、主线 RC 完全一致。
