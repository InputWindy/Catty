1. Tile 分类与降采样

说明

Tile 分类是反射的成本闸门：全屏大部分像素（天空、纯漫反射材质、被遮挡）根本不需要反射，分类后用间接派发让 GPU 只在有效 tile 上跑，省下的正是这些空 tile。

共同点间接派发 + tile 分类与 ⑤ InterpolateAndIntegrate 的 tile classification、反射自己的各 pass 一脉相承。

不同点反射的追踪在下采样分辨率进行（GI 的 probe 是另一套稀疏结构），Resolve 阶段才上采回全屏。

2. GenerateRays：GGX 采样 + Radiance Cache fade

说明

GenerateRays 决定"这根反射线值不值得真追"：光滑近处的反射细节丰富、必须精确追踪；粗糙远处的反射本就模糊，用 Radiance Cache 一查即可，省下大量光线。RoughnessFadeLength 保证两种模式之间平滑过渡不露缝。

共同点与 ② GenerateImportanceSamplingRays 同为"把有限光线预算投到高价值方向"的思想，也共用 Radiance Cache。

不同点② 在半球上按 PDF 分配多根线；这里严格沿 GGX 波瓣采一根方向，且用粗糙度/距离阈值直接切到缓存兜底。

3. FLumenReflectionResolveCS（空间重建 + 上采样）

说明

Resolve 是三段降噪的第一击，也是唯一的纯空间去噪：每像素只有一根线太噪，借周围像素同样为反射发的线（它们方向略有不同，合起来近似覆盖 GGX 波瓣）做加权重建，同时把下采样结果上采回全屏。

不同点这是反射独有的一步——GI 靠 probe 的空间密度天然抗噪，不需要显式空间重建。核半径随粗糙度增大，因为糙反射的波瓣宽、邻域相关性强。

4. FLumenReflectionDenoiserTemporalCS（时域累积）

说明

Temporal 用运动矢量把上一帧结果重投影到当前帧累积，累积越多越干净。它额外维护二阶矩：有了 E[c] 和 E[c²] 就能算每像素方差，这是下一步空域滤波"该滤多狠"的依据。HistoryDistanceThreshold + 邻域钳制两道防线拦鬼影。

共同点velocity 重投影 + 邻域钳制 + NumFramesAccumulated 累积窗口 + PreExposure 校正，与 UpdateHistory / ④ 时域滤波完全同套路。

不同点多算并存了二阶矩（方差），因为镜面噪声需要方差驱动的自适应后处理；GI 的时域步不需要显式方差。

5. FLumenReflectionDenoiserSpatialCS（方差自适应双边滤波）

说明

Spatial 是"补刀"：时域累积够的像素基本不用再滤，主要救刚出现（disocclusion）、历史不足的区域——这些地方方差大，用更大的双边核在保深度边的前提下抹平噪声。滤波强度由二阶矩方差 + 累积帧数共同驱动，做到"该滤的多滤、该留的少动"。

共同点双边滤波（深度权重保边）与 ④ FilterScreenProbes 的空域滤波思想一致。

不同点这里是方差自适应的：滤波强度随每像素方差/累积帧数变化，而非固定核。

6. 反射历史状态（三套）

ReflectionPass状态字段用途
OpaqueViewState->Lumen.ReflectionState不透明物体主反射
SingleLayerWaterViewState->Lumen.WaterReflectionState单层水面反射
FrontLayerTranslucencyViewState->Lumen.TranslucentReflectionState半透明前层反射

说明

每套 FReflectionTemporalState 都含 SpecularAndSecondMomentHistory / NumFramesAccumulatedHistory + 一组 History*ScaleBias/UVMinMax 重投影映射。深度历史 SceneDepthHistory 与 GI 共享 StochasticLighting（半透明前层用 FrontLayerTranslucencyDepthHistory）。bCameraCut / bPrevTransformsReset 时整套丢弃。
