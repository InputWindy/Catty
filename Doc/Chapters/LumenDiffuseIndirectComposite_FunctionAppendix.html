1. GetShortRangeGI

说明

作用：读取 short-range GI 纹理，为最终 diffuse indirect 提供近距离补偿。

共同点：无论主路径来自 SSGI 还是 Lumen，最终 diffuse 公式都可以叠加 short-range GI。

不同点：只有 DIM_SHORT_RANGE_GI 启用时才真正读取 ShortRangeGITexture；否则函数返回零。

  • 输入：当前像素坐标 PixelPos。
  • 输出：近距离 GI lighting。
  • 算法很轻：只是条件读取，没有额外滤波。

2. GetShadingOcclusion

说明

作用：把短程 AO 或 bent normal 转成两个遮蔽量：DiffuseOcclusion 和 SpecularOcclusion。

共同点：所有 Lumen composite 分支最终都需要知道 indirect diffuse/specular 应该被遮蔽多少。

不同点：如果有 bent normal，会用 bent normal 估计 specular occlusion；如果只有 AO，则退化成标量遮蔽；非 Lumen ScreenProbeGather 路径默认不在这里处理 diffuse occlusion。

  • DiffuseOcclusion 使用 AOMultiBounce 保留多次反弹后的颜色能量。
  • SpecularOcclusion 依赖法线、粗糙度、视线方向和 bent normal。
  • Foliage 会进一步按 LumenFoliageOcclusionStrength 调整遮蔽强度。

3. AddContrastAndSpecularScale

说明

作用：对 reflection/specular lighting 做艺术控制，包括对比度和全局 specular scale。

共同点：rough specular 和 reflection 混合之后都会经过这个函数统一调色。

不同点：它不判断材质，也不做物理求解；它是后处理式的强度/对比度调节。

  • 以 0.18 中灰作为锚点做对比度调整。
  • 最后乘 LumenReflectionSpecularScale。

4. MixSpecularAndRoughReflections

说明

作用：混合两种 specular 来源：rough reflection 和 specular reflection。

共同点：最终都要输出一个可用于材质 specular lobe 的 lighting。

不同点：如果输入是 SSR，按 SSR alpha 做 lerp；如果输入是 Lumen Reflection，则按 roughness 计算的 FadeAlpha 进行叠加。

  • RoughReflections 来自 Lumen rough specular signal。
  • SpecularReflections 来自 Lumen reflections 或 SSR。
  • 该函数避免直接相加，核心是根据 roughness 管理两者分工。

5. CombineRoughSpecular

说明

作用：specular indirect 的统一入口，封装 clear coat 与普通材质的差异。

共同点：所有非 Substrate legacy GBuffer specular 最终都汇聚到这个函数。

不同点：ClearCoat 使用 ClearCoatLayerCombine；普通材质使用 MixSpecularAndRoughReflections 后再乘 EnvBRDF。

  • 它是 rough specular、reflection、材质 BRDF 的汇聚点。
  • 不负责读取纹理，只负责组合已经读取出来的 lighting。

6. GetSSSCheckerboadSpecularScale

说明

作用：在 checkerboard subsurface profile 渲染时，避免 specular 被错误写入到 diffuse checker 格。

共同点：它只影响最终 legacy GBuffer 路径中 specular 的累积比例。

不同点：只有材质需要 separate light accumulation 且启用 subsurface postprocess / checkerboard subsurface 时才生效。

  • 返回值通常是 1。
  • checkerboard 条件满足时，某些像素 specular scale 会变成 0。

7. SubstrateIndirectLighting

说明

作用：Substrate 材质路径下的完整 indirect lighting 计算。它按 closure 遍历多个 BSDF，每层单独解释 Lumen 或 SSGI 的输入 signal。

共同点：和 legacy 路径一样，最终也会产生 diffuse/specular indirect lighting，并累积到输出结构。

不同点：Substrate 使用 closure 维度，Lumen 输入通过 Texture2DArray 的 layer 读取；SSGI 只有单一 indirect lighting 值，需要复用到各 BSDF。

  • 先解包 BSDF 与 Substrate 上下文。
  • 调用 SubstrateEvaluateForEnvLight 获得 diffuse/specular 权重。
  • 使用 MixSpecularAndRoughReflections 计算 glossy lighting。
  • 通过 LightAccumulator_AddSplit 和 AccumulateSubstrateDeferredLighting 汇聚输出。

8. UpsampleLegacySSGI

说明

作用：SSGI 路径下从 ScreenSpaceDenoise signal 纹理中采样/上采样 diffuse indirect lighting。

共同点：最终返回值和 Lumen 的 DiffuseIndirectLighting 扮演同一角色，都会进入 MainPS 后续材质合成。

不同点：SSGI 不使用 Lumen 的四路 texture array；它通过 FSSDKernelConfig 和 AccumulateKernel 统一处理 signal 采样、bilateral 权重和压缩 accumulator。

  • 上采样时使用 SAMPLE_SET_2X2_BILINEAR。
  • 非上采样时使用 SAMPLE_SET_1X1。
  • 用材质深度、法线、粗糙度、ShadingID 生成 reference metadata，控制 bilateral 采样。

9. MainPS

说明

作用：整个 composite shader 的主入口。它把前面所有 helper 的结果串起来，最终输出到 SceneColor。

共同点：所有路径都先读取像素上下文，然后根据方案生成 indirect lighting，再按材质解释，最后输出。

不同点：发散点包括 SSGI/Lumen、是否 upsample、Substrate/Legacy GBuffer、不同 ShadingModel、是否 dual source blending。

  • 输入准备：PixelPos、SceneBufferUV、Material、AO、WorldPosition、N、V。
  • 方案分叉：Lumen 读四路 signal；SSGI 调 UpsampleLegacySSGI。
  • 材质分叉：Substrate 或 legacy GBuffer。
  • 汇聚输出：IndirectLighting.Diffuse、IndirectLighting.Specular、OutAddColor、OutMultiplyColor。
