1. 卡片捕获与压缩：材质如何进 atlas

说明

Surface Cache 的物理存储是四张世界空间 atlas（Depth/Albedo/Normal/Emissive）。捕获流程先把材质光栅到临时 target，再由 CopyCapturedCardPageCS（8×8 线程组）拷进 atlas 对应物理页。关键细节是 BORDER_SIZE=1：每个卡片页四周留 1 texel border，避免后续双线性采样时跨页串到邻居的颜色。

压缩走 LumenCardCopyPS 的块压缩路径，按属性选不同 BC 格式：BC7 给 Albedo（RGB 质量优先）、BC5 给 Normal（双通道切线，法线 10bit/通道额外带 1bit valid）、BC6H 给 Emissive（HDR）、BC4 给 Depth（单通道）。这套压缩把 atlas 显存压到可接受范围。

2. 优先级直方图：这帧更新哪些页

说明

Surface Cache 的光照不是每帧全量重算——那样开销爆炸。LumenSceneLighting.usf 用一套优先级直方图在固定预算内挑最该更新的页。GetPriorityBucketIndex 把每页的紧迫度（FramesSinceLastUpdated 越大越急、离相机越近越急）通过 log2 映射到 8 个桶，桶号越小越优先。

三段式：BuildPageUpdatePriorityHistogramCS 先统计每个桶里有多少页 → SelectMaxUpdateBucketCS 从最急的桶往下累加、直到用完预算确定截止桶 → BuildCardsUpdateListCS 产出实际更新列表。最后 CombineLumenSceneLightingCS 把直接光、Radiosity、自发光合成为 FinalLightingAtlas。这套"直方图选桶"和 Radiance Cache 的 probe 预算是同一种思路。

3. 直接光：逐灯烘焙 + 阴影遮罩

说明

直接光烘焙分三步，先剔后算。LumenSceneDirectLightingCulling.usf 把卡片页切成灯光 tile，BuildLightTilesCS 为每个 tile 只挑 MAX_LIGHT_SAMPLES 个最重要的灯（避免每个 texel 遍历全部灯光）。剔选结果打包进 FLightSample：14bit 灯索引 + 2bit 类型 + 1bit 是否有阴影遮罩 + 16bit 权重。

阴影由 ShadowMaskFromLightAttenuationCS 生成——屏幕内的表面直接蹭已有 shadow map，屏幕外的走自适应降采样的阴影追踪，再叠加 light function / IES / cloud shadow。最后 LumenCardBatchDirectLightingCS（8×8 线程组）对 tile 内每盏灯累加 GetIrradianceForLight × ShadowMask，写进 DirectLightingAtlas。

4. Radiosity：无限反弹的 SH 投影

说明

Radiosity 是 Lumen "无限反弹"的来源。核心技巧：它 cone trace 命中表面时采的是上一帧的 FinalLightingAtlas——而上帧的 Final 已经包含了那时的间接光，于是这帧的 Radiosity 就吃到了"上帧的间接光"，帧帧递推等价于无限次反弹。

四步流水线：① LumenRadiosityDistanceFieldTracingCS（32/64 线程组）逐 probe 半球方向 cone trace；② 空域滤波（4-tap 或 13-tap 核）压噪；③ ConvertToSH 把 radiance 用 SHBasisFunction 投影成 2-band 球谐（除以 PDF 做蒙特卡洛无偏估计）；④ IntegrateCS 对每个卡片 texel 双线性插值周围 4 个 probe 的 SH，再和法线的 CalcDiffuseTransferSH 点积得到 irradiance。SH 让"一个 probe 存一个方向分布"变得廉价——9 个（这里 2-band 是 4 个）系数就能重建半球光照。

共同点与 Final Gather GPU 篇的 ScreenProbe 一样，都用 SH 投影 + diffuse transfer 点积把方向光照压成少数系数——只是 Radiosity 作用在世界空间卡片、ScreenProbe 作用在屏幕空间。

最终总结

Surface Cache 的 GPU 侧是"世界表面光照数据库"的实际写入者。捕获压缩把材质属性（Albedo/Normal/Depth/Emissive）光栅进四张世界空间 atlas，用 BC4/5/6H/7 分别压缩、留 1 texel border 防串页。优先级直方图用 log2 映射的 8 桶系统在固定预算内挑最紧迫的页更新，避免每帧全量重算。直接光先剔灯（每 tile 选 N 个最重要）、再算阴影遮罩（屏内蹭 shadow map / 屏外追踪）、最后逐灯累加 irradiance。Radiosity 靠"读上帧 Final"实现无限反弹，用 2-band SH 投影 + diffuse transfer 点积把方向光照廉价重建。理解这一层，就理解了为什么所有追踪命中表面时"查表即可、无需重算光照"——因为光照早已被这些 shader 烘进了 atlas。
