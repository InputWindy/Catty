反射去噪器（Reflection Denoiser）

Lumen Reflections 的追踪结果是稀疏又带噪的：半分辨率、每像素只有少量光线、粗糙表面还带随机方向。要变成能上屏的干净镜面反射，全靠这个专用去噪器。它不是一个滤波器，而是一条三阶段流水线：先做 BRDF 重加权的空间重建，再做时域累积（带二阶矩方差），最后做方差引导的双边空间滤波。本篇讲清三阶段各自解决什么、怎么协作，以及它和半透明/背景可见性的耦合。

核心链条：空间重建先把稀疏 trace 铺开 → Temporal 靠历史压噪并算出方差 → Spatial 用方差决定滤波强度。方差是串起时域与空间两步的关键信号。

为什么反射需要专门的去噪器

追踪结果天生"欠采样"

为了性能，反射追踪是半分辨率 + 每像素极少光线；粗糙表面的 BRDF 又要求对一个锥形方向分布积分，少量光线只能是高噪估计。直接上屏就是满屏闪烁噪点（尤其粗糙金属、动态光照）。去噪器的任务：在不糊掉锐利反射细节的前提下，把噪声压到可接受。

难点在于反射的"噪声特性随粗糙度剧变"——镜面（低粗糙）几乎无噪但要极锐利，粗糙面噪声大但可以糊。所以去噪必须自适应：知道哪里能狠滤、哪里要保护。这就是"二阶矩→方差引导"存在的原因。

阶段一：空间重建（ScreenSpaceReconstruction）

BRDF 重加权，把稀疏 trace 先铺开

在时域之前，先做一次屏幕空间重建：对每个像素，采样邻域里其他像素已经追好的反射光线，按当前像素的 BRDF 重新加权后合并。相当于"借邻居的光线补自己的样本数"——邻居的 trace 方向不完全符合本像素 BRDF，就用 BRDF 权重折算。

由 r.Lumen.Reflections.ScreenSpaceReconstruction 开关，采样数/核半径/粗糙度缩放分别是 NumSamples(默认5) / KernelRadius(默认8) / RoughnessScale。RoughnessScale > 1 允许更激进地把邻居糊在一起（物理上不严格，但换更干净结果）。这一步是反射能用"极少光线"的关键前提。

阶段二：Temporal（时域累积 + 二阶矩）

重投影 + 累积 + 邻域钳制

LumenReflectionDenoiserTemporalCS 做三件事：① 用 Velocity + 深度历史把上一帧反射重投影到本帧；② 按 Temporal.MaxFramesAccumulated 上限做指数累积，等效增加有效样本数；③ 用邻域钳制（Temporal.NeighborhoodClampScale）把历史值限进当前帧邻域的合理范围，防止运动/光照变化时拖影（ghosting）。Temporal.DistanceThreshold 判历史是否有效，Temporal.MaxRayDirections 限制方向多样性。

关键副产物：二阶矩。它同时写 RWSpecularAndSecondMoment——除了颜色，还累积颜色的平方（二阶矩）。有了均值和二阶矩，就能算出每像素反射的时域方差：方差大 = 这里噪/不稳，方差小 = 这里稳定。这个方差直接喂给下一阶段。

阶段三：Spatial（方差引导双边滤波）

用方差决定"糊多狠"

LumenReflectionDenoiserSpatialCS 做双边滤波（bilateral filter）：按深度/法线/粗糙度权重在空间邻域内加权平均，滤掉噪声但保留边缘。它的强度由上一步的方差引导——方差大的像素滤波更狠、采样更多；方差小（已稳定/锐利镜面）则轻滤甚至不滤，保护细节。核半径/采样数由 BilateralFilter.KernelRadius / NumSamples / DepthWeightScale 控制。

抑制 firefly：disocclusion（新露出区域，历史无效）容易出现超亮噪点（firefly）。Spatial pass 用 TonemapLighting 在滤波前把亮度压缩（tonemap）、滤完再逆映射回来——对 disocclusion 因子越大的像素压得越狠，把 firefly 摊平。DenoiserTonemapRange 控制映射范围。

此外它还读 BackgroundVisibilityTexture 与 FinalThroughputTexture、写 RWTranslucencyLighting——也就是说这一步顺带把半透明光照与背景可见性合成进去，与 光追半透明 耦合。

与其它时域降噪的异同

同一套"时空联合去噪"的家族成员

共同点和屏幕探针的时域滤波、随机直接光照 的 Temporal 一样，核心都是"重投影历史 + 累积 + 邻域钳制防拖影"——这是 Lumen 各处"少采样 + 时域补"的通用底座。

不同点反射去噪多了两样独有机制：① 二阶矩方差引导（因为反射噪声随粗糙度剧变，必须自适应滤波强度）；② BRDF 重加权的空间重建（时域之前先空间补样本）。GI 漫反射用 SH3 存方向、噪声较均匀，不需要这么复杂的方差自适应；反射要保护镜面锐度，才有这套"方差决定糊多狠"的设计。

最终总结

反射去噪器把"半分辨率 + 极少光线"的噪声追踪结果，变成能上屏的干净镜面反射，靠的是一条三阶段流水线：①空间重建（ScreenSpaceReconstruction，BRDF 重加权借邻居光线补样本）→ ②Temporal（重投影 + 累积 + 邻域钳制，并算出二阶矩方差）→ ③Spatial（方差引导的双边滤波，方差大狠滤、方差小护细节，配 tonemap 压 firefly）。串起三步的关键信号是方差——它让去噪"知道哪里能糊、哪里要保锐"，这正是反射（噪声随粗糙度剧变）区别于漫反射 GI 去噪的核心。它还在最后一步顺手合成半透明光照与背景可见性，和光追半透明共用同一套收尾。理解它，就理解了 Lumen 反射"为何敢用那么少的光线"——因为后面有一套精心设计的自适应去噪兜底。
