1. 直接光：屏内阴影图 + 屏外距离场阴影的分工

说明

直接光最棘手的不是"算光照"，而是阴影从哪来。Surface Cache 是世界空间的，镜头外的卡片同样要打光，但传统 shadow map 只覆盖屏内。Lumen 因此走双轨：屏内蹭现成的 shadow map，屏外退化成距离场光线步进求遮挡——这也解释了为什么 Lumen 强依赖 Mesh/Global SDF（见 B · Distance Field 地基）。

不同点这里的"屏外阴影追 SDF"与 ③ TraceScreenProbes 追 SDF 是同一套距离场后端，但目的不同：③ 求"光线命中了什么"，这里只求"这条到光源的路上有没有遮挡"（布尔式软阴影）。

共同点"逐 tile 剔光 + 至多 N 盏"与延迟渲染的 tiled/clustered light culling 思路一致，都是先剔除再着色。

2. Radiosity：卡片级的一次反弹，为何等于无限反弹

说明

Radiosity 是 Surface Cache "无限反弹"招牌背后的实际机制，但它自己只算一次反弹——秘诀在于命中时读的是上一帧已经收敛过的 Final。这是一个跨帧的迭代求解器：每帧往稳态解逼近一点，配合时域累积（RadiosityNumFramesAccumulatedAtlas）压掉噪声。probe 分辨率极低（默认 4 texel 一个、半球 4×4 根线），所以整条管线便宜到可以每帧全场景跑。

共同点"半球 probe → 球谐 → 邻近积分"与 ⑤ InterpolateAndIntegrate、Radiance Cache 的 probe→SH 表示完全同源；"时域累积去噪"与 ④ FilterScreenProbes 的历史滤波同理。

不同点ScreenProbe 是屏幕空间、给最终像素用；Radiosity probe 是卡片世界空间、只服务于给 Surface Cache 自身补间接光，分辨率与质量要求都低得多。

3. Combine：材质与三份光照的收敛点

说明

Combine 是三条支路的汇聚点，把材质（Albedo/Emissive）与两份光照（Direct/Indirect）按标准漫反射公式乘加成 FinalLightingAtlas。这份 atlas 有双重身份：对外是所有 Lumen 追踪命中时的采样目标，对内是下一帧 Radiosity 的历史输入——正是这个自反馈让"一次反弹"滚成"无限反弹"。

共同点与 ⑤ 把 diffuse+specular 合成、DiffuseIndirectComposite 把 GI 合进场景一样，都是"多路光照按物理公式收敛成一张图"的汇聚节点。

最终总结

骨架

光照烘焙 = 直接光 + Radiosity + Combine。直接光逐 tile 剔光后，屏内采 shadow map、屏外追距离场，批量施光成 DirectLightingAtlas；Radiosity用低分辨率半球 probe 追踪、读上帧 Final、卷 SH、累帧积分成 IndirectLightingAtlas；Combine按 Albedo×(D+I)+Emissive 收敛成 FinalLightingAtlas。

Final 的自反馈（Radiosity 读上帧 Final）是"无限反弹"的物理根因。

阅读建议

先记住三步产物：DirectLightingAtlas / IndirectLightingAtlas / FinalLightingAtlas。直接光重点是"屏内/屏外双轨阴影"，Radiosity 重点是"六阶段 + 一次反弹为何等于无限反弹"。屏外阴影依赖的距离场后端见 B，逐 CS 细节见函数附录。
