上下文：为什么反射需要单独一套追踪 + 降噪

漫反射（Final Gather）可以用低分辨率屏幕探针 + SH 压缩，因为漫反射是低频的。反射不行：镜面 lobe 随粗糙度收窄，光滑表面几乎是镜像，方向高频、对噪声敏感，无法用 SH 表达。所以反射走独立管线：先按粗糙度分类 tile（ReflectionTileClassificationBuildListsCS）跳过纯镜面/纯漫反射区域省算力，再按 GGX 可见法线重要性采样逐像素发射线（ReflectionGenerateRaysCS），追踪命中后经三段降噪（Resolve 空间重建 → Temporal 时域累积 → Spatial 空域滤波）把每像素 1~N 条噪声射线收敛成干净反射。所有追踪最终都调用公共的 cone march（见附录），反射与 Final Gather 共享这套 SDF/Voxel 追踪基建。

1. Tile 分类 + 生成射线：只在需要处发射线

说明

反射省钱第一步是 tile 分类：ReflectionTileClassificationBuildListsCS 按粗糙度把屏幕分成若干列表（纯镜面、光泽、过粗糙交给漫反射），后续 pass 用 indirect dispatch 只处理相关 tile。

发射线走 GGX 可见法线重要性采样（VNDF）：ImportanceSampleVisibleGGX 依粗糙度采样半程向量得到反射方向，ConeAngle = 1/max(PDF, 0.0001)——越粗糙 lobe 越宽、cone 越大，追踪时采更高 mip 做预滤波，天然抗锯齿。射线打包进 FRayData（方向/PDF/锥角/最大追踪距离）。

2. 追踪：与 Final Gather 共享的级联后端

说明

反射追踪与 Final Gather 结构同构：屏幕空间先追（ReflectionTraceScreenTexturesCS）、ReflectionCompactTracesCS 压实未命中、再级联到 Mesh SDF 与 Voxel。多一步 ReflectionSortTracesByMaterialCS——按材质排序让 warp 内命中相似材质，采样相干。

底层 cone march 是全 Lumen 共享的公共基建：LumenTracingCommon.ush 定义 FConeTraceInput/FConeTraceResult，GlobalDistanceFieldShared.ush 的 ConeTraceLumenSceneVoxels 做 voxel 步进。反射、屏幕探针、Radiance Cache 追踪都调这套，只是 cone 起点/角度不同。详见附录。

3. Resolve：空间重建，用邻居射线补积分

说明

每像素往往只发 1 条反射射线，单条噪声极大。Resolve 做空间重建：把邻域内其它像素的射线"借来"用——但不是简单平均，而是按每条邻居射线相对本像素 BRDF lobe 的 GGX 权重加权。这等价于用邻居的采样帮本像素把镜面积分补全，几何上正确（同一 lobe 的不同样本），既降噪又不糊。采样点用 Hammersley16 + UniformSampleDiskConcentric 在核半径内低差异分布。

4. Temporal + Spatial：两级降噪收敛

说明

Temporal 在 Resolve 之后做时域累积：先在 YCoCg 色彩空间统计 3×3 邻域的均值/方差得到 AABB，把历史裁剪进 AABB（ClampScale=0.5）——YCoCg 让亮度/色度分离，clamp 更贴合人眼。帧累积 Alpha=1/(NumFrames + reconstructed?4:0)，最多累 60 帧。用两条历史（按命中点重投影 hit-based、按表面重投影 surface-based）覆盖不同运动情形。

Spatial 收尾：3 半径 16 样本的双边滤波，权重是深度 × 法线 × 亮度三项相乘——深度用 exp2(-10·ΔDepth²)、法线用锥角归一、亮度用标准差归一，只在几何/材质一致处平滑，保边。三段串起来把稀疏噪声射线收敛成干净镜面反射。

最终总结

反射管线是"为高频信号量身定制的一套追踪 + 降噪"：因为镜面 lobe 高频、对噪声敏感，不能像漫反射那样用 SH 压缩，只能靠密集降噪把稀疏射线收敛。它复用了 Final Gather 的级联追踪后端与公共 cone march（省实现），但在两端加了反射专属的东西：前端按 GGX 可见法线重要性采样发射线并用粗糙度驱动 cone 角/mip，后端用 Resolve→Temporal→Spatial 三段把噪声磨平。理解这条线的关键是粗糙度贯穿始终——它决定 tile 分类、cone 角、预滤波 mip、降噪核宽度。
