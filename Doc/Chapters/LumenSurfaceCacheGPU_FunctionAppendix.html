1. CopyCapturedCardPageCS

说明

捕获阶段的核心搬运 CS。每个 8×8 线程组负责卡片页的一个 tile，从材质光栅出的临时 target 读、写进 atlas 物理页。+ BORDER_SIZE 让写入落在有效区，四周 1 texel border 留空由 dilation 填充，保证跨页双线性采样不串色。四张 atlas（Depth/Albedo/Normal/Emissive）各写一次。

2. BC 块压缩与 dilation

说明

压缩不走 CS 而走 LumenCardCopyPS 像素路径：每个输出像素对应一个 4×4 块，按属性用不同 BC 格式。BC5 只存法线两个切线分量、Z 由重建得到（法线是单位向量）。LumenCardResamplePS 处理页表重分配时的旧数据迁移。GenerateDilationTileDataCS 负责边缘膨胀：把有效区 texel 向 border 外推，填补卡片边缘的采样漏洞。

3. Nanite 卡片捕获

说明

Nanite 网格不走传统光栅捕获，而是用 LumenCardComputeShader.usf 的 Main（64 线程组）直接从 Nanite ShadingBin / visbuffer 计算材质并写 atlas。MortonDecode 把一维线程索引映射到 2D 坐标，保证内存访问的局部性。详见 特殊几何表示主题。

4. GetPriorityBucketIndex

说明

优先级映射公式：紧迫度 = 4 × 帧龄 × 更新速度，再 log2 后反转成桶号（越急桶号越小）。UpdateSpeed 随距离衰减、近视锥翻倍，让近处的卡片更新更勤。三个 pass 构成"统计→选桶→出列表"的经典 GPU 直方图预算分配：先数每桶几页，再从最急桶累加到预算上限确定截止桶，最后展开成实际更新列表。

5. 灯光剔除 FLightSample

说明

直接光的省钱关键：不让每个 texel 遍历全场景灯光，而是先按 tile 剔选。BuildLightTilesCS 为每个灯光 tile 挑最多 MAX_LIGHT_SAMPLES 个贡献最大的灯，打包进紧凑的 FLightSample（14bit 索引足够覆盖数千灯，2bit 区分方向光/点光/聚光/矩形光）。下游直接光 CS 只需遍历这个短列表。

6. ShadowMask 生成

说明

阴影遮罩兼顾两种来源：屏幕内的卡片表面直接复用主视图已渲的 shadow map（零额外追踪），屏幕外的用自适应降采样阴影追踪——每个 tile 只追一部分 texel、其余插值，大幅省射线。之后叠加 light function、IES 光度分布、cloud shadow 等调制项，得到最终遮蔽因子供直接光累加使用。

7. DirectLighting 累加

说明

直接光本体：8×8 线程组，每个卡片 texel 遍历本 tile 的短灯光列表，GetIrradianceForLight 算该灯的 irradiance（含衰减/朝向），乘上对应 shadow mask 后累加，写进 DirectLightingAtlas。因为灯已被剔到每 tile 少量，这个循环很短。

8. Radiosity 追踪 + SH

说明

Radiosity 的数学核心。SHBasisFunction 求方向的球谐基，MulSH 用 radiance/PDF（蒙特卡洛无偏）缩放后 AddSH 累加进 probe 的 SH——这就是把"一堆离散射线的方向 radiance"投影成连续球谐分布。积分时 CalcDiffuseTransferSH 给出朗伯 BRDF 在 SH 空间的表示，与 probe SH 点积 DotSH 一步得到该法线方向的 irradiance。空域滤波用 4-tap 或 13-tap 核，时域累积 Alpha = 1/(1+NumFramesAccumulated)。

共同点SHBasisFunction / DotSH / CalcDiffuseTransferSH 这套 SH 工具与 Final Gather GPU 附录的 ConvertToIrradiance 共用同一份 SH 头文件。
