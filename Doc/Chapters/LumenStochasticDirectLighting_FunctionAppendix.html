2. 逐 CS 职责（按执行顺序）

#Compute Shader职责
1FLumenSceneCompactLightOffsetCS为每个 card tile 计算"候选光源列表"的写入偏移（前缀和）
2FLumenSceneCompactLightListCS按偏移把影响各 tile 的光源填成紧凑连续列表
3FLumenSceneGenerateLightSamplesCS每 card texel 按 FLightTargetPDF + 蓝噪声抽 SamplePerTexel 个光源样本，丢弃权重 < MinWeight
4FLumenSceneEvaluateStandaloneLightCS对样本走 MegaLights 光追求可见性 + 着色（普通光源）
4′FLumenSceneEvaluateStandaloneLightMaterialCS带 Light Function 材质的光源版本（FMaterialShader）
5Temporal（累积 pass）本帧样本结果累加进历史 + 邻域钳制去噪，写回 DirectLightingAtlas

说明

1~2 把"逐 tile 的候选光源"整理成 GPU 友好的紧凑列表（经典的 offset+compact 两步，与直接光传统路径的 FComputeLightTileOffsetsPerLightCS/FCompactLightTilesCS 同构，只是这里按 texel 采样服务）。3 做重要性采样，4 借 MegaLightsRayTracing.ush 求值——可见性来自光追而非 shadow map。矩形光走 USE_RECT_LIGHT → USE_SOURCE_TEXTURE 路径。

3. FLightTargetPDF：抽样按"谁更亮"分配

字段含义
float3 Diffuse该光源对当前 texel 的漫反射贡献估计（未计可见性）
float Weight由 Diffuse 归约出的采样权重，构成重要性采样分布

说明

PDF 正比于"光源对该 texel 的无遮挡漫反射贡献"——亮/近的光源更可能被抽中，把有限样本投到"最可能重要"的光源上。这是重要性采样的标准套路：先用廉价的解析估计（不追光线）算权重，再据此抽样、只对抽中的样本发光线。权重低于 MinWeight 的光源直接跳过，避免为几乎无贡献的光源浪费光线预算。

4. 时域累积：用时间换样本数

为什么必须有 Temporal

每 texel 每帧只抽几个样本 → 单帧必然有噪。Temporal pass 把历史帧结果按 MaxFramesAccumulated 上限做指数滑动累积，等效地把"很多帧的少量样本"汇成"一帧的大量样本"。NeighborhoodClampScale 用空间邻域的均值/方差把历史值钳进合理范围，光照突变（开关灯、光源移动）时快速丢弃过期历史，防拖影。

共同点与反射的 DenoiserTemporal 和屏幕探针的时域滤波是同一套"重投影 + 累积 + 邻域钳制"机制。

不同点它累积的是 Surface Cache 世界空间 card texel 的直接光（跨帧稳定、无屏幕重投影问题），不像屏幕空间那样受 disocclusion 强烈影响，因此可以累积更多帧、更稳。

5. 全部 CVar

CVar作用
r.LumenScene.DirectLighting.Stochastic总开关：启用随机直接光照路径（默认关，实验性）
r.LumenScene.DirectLighting.Stochastic.SamplePerTexel每 card texel 抽取的光源样本数（越大越准越贵）
r.LumenScene.DirectLighting.Stochastic.MinWeight采样权重下限，低于则丢弃该光源样本
r.LumenScene.DirectLighting.Stochastic.Temporal是否启用时域累积去噪
r.LumenScene.DirectLighting.Stochastic.Temporal.MaxFramesAccumulated历史累积帧数上限（越大越稳越可能拖影）
r.LumenScene.DirectLighting.Stochastic.Temporal.NeighborhoodClampScale邻域钳制强度（越小越激进防拖影，越大越稳）
r.LumenScene.DirectLighting.Stochastic.Debug开启调试可视化（ShaderPrint 输出光标下 texel 的采样信息）
