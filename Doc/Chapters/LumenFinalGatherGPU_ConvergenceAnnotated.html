1. 屏幕探针追踪：八面体映射 + 级联

说明

屏幕探针是"稀疏放在屏幕上、每个探针发一把射线"的结构。每个探针是一张 N×N 方向图，texel 坐标经 EquiAreaSphericalMapping（等面积八面体映射）转成世界方向——等面积保证每条射线覆盖相同立体角，采样无偏。

追踪走从廉价到昂贵的级联：ScreenProbeTraceScreenTexturesCS 先在屏幕空间追（HZB 或固定步长），命中就收工；未命中的经 ScreenProbeCompactTracesCS 压实后交给 TraceMeshSDFs（近场）、再到 TraceVoxels（远场 Global SDF + Radiance Cache 兜底）。压实是关键优化：每级只处理"还没命中"的射线，避免已命中的浪费下一级昂贵后端。详见 ③ 追踪。

2. 时空滤波：从噪声到平滑信号

说明

追踪结果很稀疏很噪，滤波把它磨平。① CompositeTracesWithScatterCS 用蓝噪声抖动把射线结果散射进 radiance 图（散射比聚集更 cache 友好）。② 时域累积把当前帧和重投影的历史混合，权重 PositionWeight = exp2(-10000·ΔDepth²)——深度对不上（disocclusion）时权重骤降，丢弃历史防鬼影。③ 空域滤波用 4-tap 十字或 +8-tap 强核，AngleWeight 按邻居命中方向的夹角衰减（夹角超过 SpatialFilterMaxRadianceHitAngle 就归零），避免把不同方向的光糊在一起。④ ConvertToIrradianceCS 把 radiance 图压成 SH3（9 系数）或八面体纹理。详见 ④ 滤波。

3. 重要性采样：固定预算的方向分配

说明

光线预算是固定的，要花在刀刃上。ComputeLightingPDF 先算每个方向的价值（BRDF PDF，可乘上帧的 Lighting PDF），GenerateRaysCS 用 O(N²) 并行排序把方向按 PDF 升序排列，然后做"3 换 1"细分：剔掉 3 条低 PDF 方向、把预算给 1 条高 PDF 方向并细分成 2×2 四条子射线。这样总射线数不变，但都集中到了高价值方向。详见 ② 重要性采样。

4. Radiance Cache：世界空间 probe 缓存

说明

Radiance Cache 是以相机为中心、clipmap 分级的世界空间 probe 缓存，给屏幕探针提供远场兜底。数据流：ScatterScreenProbeBRDFToRadianceProbesCS 让屏幕探针把"我需要哪个世界 probe"的需求散射标记出来 → GenerateAdaptiveProbeTraceTilesCS 按需求把 probe 的追踪任务树细分成 trace tile（高需求 probe 分更多 tile）→ SortProbeTraceTilesCS 按方向 bin（NUM_DIRECTION_BINS_2D=8）排序改善 trace 一致性 → TraceFromProbesCS 逐 tile 追世界（ConeHalfAngle=acosFast(1-1/TraceRes²)）→ FilterProbeRadianceWithGatherCS 用 6 个 clipmap 邻居 + 双向 occlusion 测试滤波。

LumenRadianceCacheUpdate.usf 管 probe 生命周期：ClearProbeFreeListCS 清空闲列表、UpdateCacheForUsedProbesCS 标记本帧用到的、AllocateUsedProbesCS 分配。这套"persistent + budget"让 probe 跨帧存活、每帧只重追一小部分。详见 Radiance Cache。

共同点trace tile 树细分 + 方向 bin 排序的思路，和屏幕探针的重要性采样"把预算集中到高价值方向"是同一哲学——只是一个在世界空间 probe、一个在屏幕探针。

最终总结

Final Gather 的 GPU 侧是"稀疏采样 + 时空复用"的极致。屏幕探针用等面积八面体映射编码方向、从屏幕到 Mesh SDF 到 Voxel 级联追踪、每级压实未命中光线；再经蓝噪声散射、深度权重时域累积、角度权重空域滤波，最后压成 SH3（9 系数）或八面体纹理。重要性采样用并行排序把固定预算"3 换 1"集中到高价值方向。Radiance Cache 则是世界空间的 persistent probe 缓存：BRDF 需求散射 → trace tile 树细分 → 方向 bin 排序 → cone 追踪 → 6 邻居 occlusion 滤波 → 生命周期管理，给屏幕探针提供远场兜底。理解这一层，就理解了 Lumen 漫反射 GI 为何能在有限射线预算下产出稳定平滑的间接光——答案是"稀疏追踪的噪声，全靠时空滤波和 SH 压缩磨平"。
