1. FLumenCardTracingParameters 字段

说明

这个结构体是追踪的"公共契约"清单：一个 pass 只要 include 它，就自动拿到 Surface Cache 全部 atlas、Feedback 回写 UAV、LRU 时间戳缓冲（RWCardPageLastUsedBuffer）、天光泄漏/雾参数、Global SDF 页表。RWCardPageHighResLastUsedBuffer 单独一份是给高分辨率页的 LRU。任何字段变动，所有追踪 pass 一起受益或受累——这既是统一的好处也是耦合的代价。

2. 天光泄漏/高度雾/预曝光

说明

CachedLightingPreExposure 是为了把 Surface Cache 里存的光照值缩放到浮点友好的量级（存时乘、用时除），避免 fp16 atlas 精度问题。反射的天光泄漏还多一个 ReflectionSkylightLeakingAverageAlbedo=0.25——反射命中点上没有真实材质反照率时用它近似。SampleHeightFogOnGI 是"两个 CVar 都开"才为真，说明它是在总雾开关之下的二级子开关。

3. Feedback UAV 与 dummy 回退

说明

Feedback 是可选的：不需要回写时（例如某些不驱动驻留的 trace）绑一个 dummy UAV 并令 Size=0，shader 端据此走空分支。BufferAllocatorUAV 是原子计数器——多线程 append 时用它抢位置。TileJitter 每帧变，让稀疏回写覆盖到不同页。SurfaceCacheUpdateFrameIndex 是 LRU 的"当前帧号"，写进 RWCardPageLastUsedBuffer 作时间戳。

共同点与供给侧附录的 Feedback 打包格式对齐——这里写、那里读。

4. FHemisphereDirectionSampleGenerator

说明

各追踪 pass 需要在半球（或全球）上撒方向发射光线。这个生成器把"撒方向"统一：bCosineDistribution 为真时按 cosθ 加权（匹配漫反射 BRDF，重要性采样），否则均匀。ConeHalfAngle 记录每个样本代表的立体角，供后续 cone trace 用。PowerOfTwoDivisor 把样本数对齐到 2 的幂便于 GPU 分组。CPU 侧生成后上传给 shader。

5. 三个剔除函数

说明

CullForCardTracing 是对外总入口，内部编排另外两个。CullMeshObjectsToViewGrid 建 froxel（视锥体素）：屏幕按 GridPixelsPerCellXY 分格、深度按 GridSizeZ 用 ZParams（非线性）分层，把每个 SDF 物体按包围盒撒进覆盖的 cell，输出 CSR 式的 StartOffsetArray + IndicesArray。MaxMeshSDFInfluenceRadius 决定物体影响膨胀范围，CardTraceEndDistanceFromCamera 是剔除的远裁剪。

不同点Mesh SDF 剔进 3D froxel 网格；Heightfield 只出一个平铺索引 buffer——地形是 2.5D，不需要 Z 分层。

6. SetupLumenDiffuseTracingParameters

说明

这函数把漫反射追踪的"步长/最短最长距离/表面偏移/锥角"一次配齐。StepFactor 控 SDF ray march 步长（越大越快越糊）。SurfaceBias 沿法线推起点，避免自相交。ForProbe 变体把 SurfaceBias 归零（探针从空间点发射、没有表面自交问题），改用抬高 MinTraceDistance 来躲 Mesh SDF 的世界空间误差，并允许每个探针传入自己的锥角。

不同点逐像素 gather 有 SurfaceBias、固定小锥角；逐探针 gather 无 SurfaceBias、锥角外部指定。

7. SetupHZBScreenTraceParameters

说明

核心是决定"在哪张上帧颜色里做屏幕追踪"：优先自定义 SSR 输入（引擎/项目定制），其次 TAA 历史（受 GLumenScreenTracingSource==1 控制，注意处理多切片），再次 SSR 输入。颜色和深度的重投影 scale/bias 分两套算，因为历史颜色缓冲与历史深度缓冲的尺寸/视口可能不同。HZBType（ClosestHZB 保守 / FurthestHZB 激进）由调用方按用途选——屏幕探针追踪用 Closest 更保守防漏光。

8. 关键 CVar

CVar默认作用

r.Lumen.SkylightLeaking.ReflectionAverageAlbedo0.25反射命中点天光泄漏的近似反照率
r.Lumen.HeightFog1对 Lumen trace 的光照施加高度雾
r.Lumen.HeightFogOnGI0是否对 GI trace 也施雾（默认关，反射才施）
r.Lumen.HeightFog.MinDistanceForFoggingSky100000miss(天空) 施雾的最小距离，与 MaxTraceDistance 解耦
GLumenScreenTracingSource-=1 时屏幕追踪用 TAA 历史作输入颜色
GDiffuseTraceStepFactor-漫反射 SDF ray march 步长因子（.1~10）
