1. FLumenSceneData

说明

Lumen 场景的 CPU 权威状态。Cards/CardPages 用稀疏 span 数组（支持空洞复用索引）。PrimitiveGroups 把多个 primitive 合并成 Lumen 场景单元。Feedback 收 GPU 回读，驱动"哪些卡片下帧该捕获"。这个结构每帧被 UpdateLumenScene 维护，再上传成 GPU buffer 供 shader 用。

2. FLumenCardPageData

说明

GPU 追踪命中卡片后，靠这条数据把"逻辑卡片 UV"换算成"物理 atlas texel"。核心是 CardUVToAtlasUVScale/Bias 这对仿射变换 + PhysicalAtlasUVRect 裁剪。ResLevel 记录该页当前分辨率级别（Surface Cache 会按重要性升降分辨率）。GetLumenCardPageData 是 shader 里的统一访问器。

3. FLumenCard / TLumenCardOBB

说明

TLumenCardOBB 用原点 + 三个正交轴 + 半尺寸描述一张卡片的世界空间盒子，提供 WorldToLocal 把世界点投到卡片局部 UV。这是运行时"点→卡片 UV"与离线"卡片布局"的公共几何。FLumenCardBuildData 是离线烘焙的每卡产物（OBB + 6 方向索引），聚合成 FMeshCardsBuildData 存进网格资产。

4. FLightSample 位域

说明

直接光剔灯后的紧凑灯样本。14bit LightIndex 足够覆盖上万灯，2bit LightType 区分四种灯，1bit 标记是否有 shadow mask，16bit Weight 存贡献。整体压进极小空间，让每 tile 的短灯光列表内存友好。下游 LumenCardBatchDirectLightingCS 解包遍历。详见 Surface Cache GPU 附录。

5. 法线 / 距离编码

说明

三处典型的定点压缩。法线：单位向量只需存两个分量，Z 由重建得到，故 BC5（双通道）足够，valid 位标记该 texel 是否有有效表面。距离场：距离先归一化到 [-1,1] 再量化成单字节 PF_G8，靠窄带 + mip 保证 8bit 精度够用。射线距离：把"命中与否 + 距离"打包进一个 uint，节省追踪结果带宽。

6. FDistanceFieldVolumeData

说明

每个网格的距离场资产。3 级 mip，AlwaysLoadedMip（最粗）随资产常驻内存保证随时可粗追踪，细节 mip 打包进 StreamableMips 字节流按镜头距离流式加载。DistanceMinMax 是把 PF_G8 量化值反解回真实距离的范围。bMostlyTwoSided 标记薄壳网格（内外判定不可靠），影响追踪时的符号处理。

7. FSparseDistanceFieldMip

说明

单级 mip 的稀疏布局元数据。IndirectionDimensions 是间接表的三维尺寸（≤1024），间接表每格指向一个 brick 或标记为空。NumDistanceFieldBricks 是实际分配的 brick 数（远小于稠密体积）。两组 scale/bias 负责"世界→volume→brick 内 UV"的坐标链变换。运行时采样先用 VolumeToVirtualUV* 定位间接表格子，查到 brick 再算 brick 内坐标三线性插值。

8. Radiance Cache 间接寻址

说明

Radiance Cache 的寻址链最长。逻辑 probe 由 (clipmap, 格子坐标) 定位，先查 IndirectionTexture 得物理索引（可能是 INVALID 表示未分配），再由物理索引映射到 RadianceProbeAtlas 的 tile，tile 里存八面体方向 radiance 及配套的 depth（做 occlusion 防漏光）。clipmap 让 probe 密度随距离衰减（每级世界范围翻倍）。这套三级间接是"稀疏 probe + 动态分配/回收"的地基——生命周期见 Final Gather GPU 附录。
