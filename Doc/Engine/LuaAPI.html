概述

Catty 在 FScriptSystem::Initialize 时创建全局表 catty， 并登记下列函数。脚本跑在游戏线程；不要从 Worker / Render 线程调用引擎回调。

入口文件：工程 Scripts/main.lua（相对 FEngineConfig::ProjectScriptsDir）。 package.path 指向该目录下的 ?.lua 与 ?/init.lua。

Lua 5.4 sol2 bindings namespace: catty 11 API · 2 hooks 1 usertype (codegen)
约定：本文「Returns」栏的类型按 Lua 侧语义描述 （number / boolean / string）。CVar 名与 C++ FConsoleManager 登记名一致（区分大小写）。

已打开的 Lua 标准库

VM 通过 sol::open_libraries 打开：

base · package · coroutine · string · table · math · utf8

未打开：io · os · debug（刻意收紧磁盘 / 进程面）。

catty — Console Variables (Set)

写入已存在的 CVar。成功返回 true；名不存在或类型不匹配时返回 false （不抛异常）。成功写入会触发该 CVar 的 OnChanged 回调（C++ 侧）。

Engine Hooks（全局回调）

以下不是 catty 表成员，而是可选的全局函数。 由 FApp 在帧循环里通过 FScriptSystem::Call 调用； 未定义时静默跳过（不报错）。

OnUpdate

Hook global
function OnUpdate(dt) end

可变帧更新。对应 C++ FApp 每帧 Update， 传入真实帧间隔秒数。

Parameters

NameTypeDescription
dtnumber本帧 DeltaSeconds（秒）。

Returns

无返回值（引擎忽略返回值）。

Example

local Accumulated = 0.0

function OnUpdate(dt)
  Accumulated = Accumulated + dt
end

OnFixedUpdate

Hook global
function OnFixedUpdate(fixedDt) end

固定步长更新。对应 C++ FApp 的 FixedUpdate， 适合物理 / 确定性逻辑。

Parameters

NameTypeDescription
fixedDt number 固定步长秒数（与引擎 FixedDelta 配置一致）。

Returns

无返回值（引擎忽略返回值）。

Example

function OnFixedUpdate(fixedDt)
  -- physics / fixed-step gameplay
end
加载时机：若存在 Scripts/main.lua，在 InitializeEngine 末尾 DoFile。 请在该文件（或其 require 的模块）里定义上述全局函数。

catty — Reflect Usertypes

由同一套 CATTY_REFLECT_* 标注经 Tools/reflect_codegen.bat 生成 sol2 usertype， 并在 FScriptSystem::Initialize 注册到 catty 表。 跳过：CATTY_LUA_SKIP；改名：CATTY_LUA_NAME("...")。 类型定义须在可 #include 的头文件中。
