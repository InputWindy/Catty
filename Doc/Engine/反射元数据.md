# Catty 编译期反射（refl-cpp）

> 核心能力：`Catty/Core/Reflect.h`。底层 [refl-cpp v0.12.4](https://github.com/veselink1/refl-cpp)（`refl.hpp`）。  
> **不是**运行时 RTTI / RTTR；元数据在编译期编码进类型系统。

## 角色

| 能力 | 做什么 |
|------|--------|
| `CATTY_REFLECT_*` | 给类 / 字段 / 成员函数生成元数据 |
| `ReflectType<T>()` | 取类型描述符（名称、成员列表） |
| `ForEachReflectMember<T>` | 遍历成员描述符 |
| 后续（可选） | 基于描述符做序列化等；**Lua 已由同一套宏 + codegen 生成** |

## 标注宏

**推荐（UE 风格）**：类型定义上一行写 `CATTY_REFLECT_CLASS()`。Codegen 自动导出该类型所有 **public** 字段与成员函数 → 反射元数据（`ReflectMeta.gen.cpp`）+ Lua usertype。

```cpp
#include <Catty/Core/Reflect.h>

namespace Catty
{
CATTY_REFLECT_CLASS()
struct FPoint
{
	float X = 0.f;
	float Y = 0.f;
	float Length() const;
};
}
```

只反射、不上 Lua：`CATTY_REFLECT_CLASS(CATTY_LUA_SKIP)`。

可选手工清单（类后逐成员列出，用于选择性导出）：

```cpp
CATTY_REFLECT_BEGIN(Catty::FPoint)
	CATTY_REFLECT_PROPERTY(X)
	CATTY_REFLECT_FUNCTION(Length)
CATTY_REFLECT_END
```

宏定义见 `Catty/Core/Reflect.h`。`CATTY_LUA_SKIP` / `CATTY_LUA_NAME` 是挂在 CLASS / BEGIN 上的 **属性**，不是另一套独立标注。

## 查询

```cpp
static_assert(Catty::TIsReflectable_v<Catty::FPoint>);
constexpr auto N = Catty::ReflectMemberCount<Catty::FPoint>();
Catty::ForEachReflectMember<Catty::FPoint>([](auto Member)
{
	// Member.name / is_readable / invoke / ...
});
```

## 依赖

- 宏：`CATTY_WITH_REFLECT=1`（Public）

## 与 Lua

**同一套标注驱动反射 + Lua。** 推荐 `CATTY_REFLECT_CLASS()`（类上一行），codegen 导出全部 public 成员。

- 默认：生成 `catty.<ShortName>` usertype + `ReflectMeta.gen.cpp`（refl-cpp）。
- 跳过 Lua：`CATTY_REFLECT_CLASS(CATTY_LUA_SKIP)`。
- 生成物：`ReflectMeta.gen.cpp`、`LuaBindings.gen.*`（gitignore；CMake 自动跑）。
- `CATTY_LUA_*` 定义在 `Reflect.h`，是 CLASS/成员列表的**属性**，不是另一套宏。

## Codegen（仓库级目录 + Lua）

`refl-cpp` 只提供**单类型**编译期元数据；跨 TU 清单与 Lua 绑定由 Python 扫描器生成：

```text
Tools\reflect_codegen.bat
Tools\reflect_codegen.bat --check        # CI：过期则 exit 2
Tools\reflect_codegen.bat --root Catty/Source --root ../MyGame/Source
Tools\reflect_codegen.bat --no-lua       # 只更新目录，不写 LuaBindings
```

产出：

| 文件 | 用途 |
|------|------|
| `Catty/.../ReflectCatalog.gen.h` | C++ 只读目录（含 `bLuaExport` / `LuaName`） |
| `Catty/Source/Generated/ReflectCatalog.gen.json` | 机器可读 |
| `Doc/Engine/ReflectCatalog.md` | 人读总表 |
| `Catty/.../Script/LuaBindings.gen.h/.cpp` | sol2 usertype 注册 |
| `Doc/Engine/LuaAPI.html`（标记区） | 同步 Reflect usertype 文档 |

稳定 include：`#include <Catty/Core/ReflectCatalog.h>`（包装 `.gen.h`）。

**生成物不进 git**（`*.gen.h` / `*.gen.cpp` / `*.gen.json` / `ReflectCatalog.md`）。CMake 配置与编译前会自动跑 codegen；文档里的 `LuaAPI.html` Reflect 区块用手动 `Tools\reflect_codegen.bat`（不要 `--no-lua-api`）同步。CI 可用 `Tools\reflect_codegen.bat --check` 校验本地生成是否与标注一致（需先 codegen）。
