# Catty 编译期反射（refl-cpp）

> 核心能力：`Catty/Core/Reflect.h`。底层 [refl-cpp v0.12.4](https://github.com/veselink1/refl-cpp)（`refl.hpp`）。  
> **不是**运行时 RTTI / RTTR；元数据在编译期编码进类型系统。

## 角色

| 能力 | 做什么 |
|------|--------|
| `CATTY_REFLECT_*` | 给类 / 字段 / 成员函数生成元数据 |
| `ReflectType<T>()` | 取类型描述符（名称、成员列表） |
| `ForEachReflectMember<T>` | 遍历成员描述符 |
| 后续（可选） | 基于描述符做 Lua 导出、序列化等 |

## 标注宏

类定义**之后**书写：

```cpp
#include <Catty/Core/Reflect.h>

namespace Catty
{
struct FPoint
{
	float X = 0.f;
	float Y = 0.f;
	float Length() const;
};
}

CATTY_REFLECT_BEGIN(Catty::FPoint)
	CATTY_REFLECT_PROPERTY(X)
	CATTY_REFLECT_PROPERTY(Y)
	CATTY_REFLECT_FUNCTION(Length)
CATTY_REFLECT_END
```

或等价的 `CATTY_REFLECT_AUTO(CATTY_REFLECT_TYPE(...), CATTY_REFLECT_FIELD(...), ...)`。

继承基类（可选属性，透传 refl）：

```cpp
CATTY_REFLECT_BEGIN(Catty::FDerived, bases<Catty::FBase>)
	...
CATTY_REFLECT_END
```

## 查询

```cpp
static_assert(Catty::TIsReflectable_v<Catty::FPoint>);
constexpr auto N = Catty::ReflectMemberCount<Catty::FPoint>();
Catty::ForEachReflectMember<Catty::FPoint>([](auto Member)
{
	// Member.name / is_readable / invoke / ...
});
```

## 与 Lua

当前 Lua 仍走 `FScriptSystem` 手工 / 将来静态注册表绑定。反射元数据是**独立基础层**，可再写一层「扫 `CATTY_REFLECT_*` → sol2」，不必上 RTTR。

## Codegen（仓库级目录）

`refl-cpp` 只提供**单类型**编译期元数据；跨 TU 清单由 Python 扫描器生成：

```text
python Tools/reflect_codegen.py          # via Tools/catty_python.bat
Tools\reflect_codegen.bat
Tools\reflect_codegen.bat --check        # CI：过期则 exit 2
Tools\reflect_codegen.bat --root Catty/Source --root ../MyGame/Source
```

产出：

| 文件 | 用途 |
|------|------|
| `Catty/.../ReflectCatalog.gen.h` | C++ 只读目录（`Catty::ReflectCatalog::GTypes`） |
| `Catty/Source/Generated/ReflectCatalog.gen.json` | 机器可读 |
| `Doc/Engine/ReflectCatalog.md` | 人读总表 |

稳定 include：`#include <Catty/Core/ReflectCatalog.h>`（包装 `.gen.h`）。

改完 `CATTY_REFLECT_*` 后请重跑 codegen（`Tools/reflect_codegen.bat`），再提交生成物（或 CI `--check`）。内部工具，不必放在仓库根目录。
