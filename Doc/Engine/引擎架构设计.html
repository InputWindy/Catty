  • GC 类型无关：只看见 FObject*；池与 Server Release 由 ResourceManager destroy handler 认领。
  • Package 不拥有内存：Objects 表只登记；内存在 ResourceManager 池里。
  • FApp 成员顺序：GCManager 先于 ResourceManager 构造、后析构。
  • ResourceServer 下沉：由 ResourceManager 拥有并 Init/Shutdown；App 不再直接持有。

Package / CreateResource（建对象）同步；raw 填充异步；Flush(Resource) 只等该资源 raw；GC 与 raw IO 无关。

4. GC 保活与回收

flowchart LR
  Root["AddToRoot RootSet"] --> Keep["保活"]
  Ref["FObjectRef RefCount大于0"] --> Keep
  Persist["Persistent Package Object"] -->|"不进 Transient 回收"| Keep
  Scan["扫 LiveObjects"] -->|"Transient 且未保活"| Pending["PendingKill 约30s Purge"]
  • 保活：RootSet 或 RefCount>0；无引用图 Mark。互持 FObjectRef 会泄漏 — 用 FObjectWeakRef 破环。
  • FPackage 继承 FObject；Unload 只摘 catalog；Free 只走 GC。
  • MarkPendingKill / MarkForImmediateDestroy 立即入队；CollectGarbage 扫完后处理 Immediate。
  • 默认 Tick：Immediate 每帧；Collect 约 1s；Purge Pending 约 30s。

5. Package 跨包依赖（Serialize）

  • 对象持有其它包对象：成员用 FObjectRef；Save 时 override GetReferencedObjects，Load 时 SetReferencedObjects + FObjectRef::Wrap。
  • 软路径：PackageName.ObjectName；JSON 写在 objects[].refs，包级 dependencies[{name,file}]。
  • LoadPackage 先递归加载依赖包再创建本包对象并回填 refs；SavePackage(..., bSaveDependencies=true) 先递归保存依赖包，缺 file / 未加载则失败。
  • GC 不读这套引用图；存活仍只看 Root / RefCount。
