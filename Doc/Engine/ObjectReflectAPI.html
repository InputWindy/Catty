流水线

产物作用
ObjectReflectTypes.gen.h声明 EnsureObjectReflectRegistered

ObjectReflectCatalog.gen.json机器可读目录（工具 / 编辑器）

Phase 1 属性：bool / int32 / uint32 / int64 / uint64 / float / double / string / enum-as-int。 Object 函数：支持属性同款参数类型与返回值（经 FPropertyValue）。 Lua 经同一套反射桥接（maho.call / object userdata）。 Enum 初值：十进制、十六进制、简单 N << M。

标注宏

MAHO_OBJECT

macro object
MAHO_OBJECT() class MAHO_API FMyAsset : public UObject { MAHO_GENERATED_BODY() // ... };

写在 class/struct 上一行。扫描器标记；展开为空。

类内必须有 MAHO_GENERATED_BODY()：声明 StaticType() / GetObjectType()，并 friend codegen 的 FObjectReflectDetail（可访问 protected 成员）。

MAHO_STRUCT

macro struct
MAHO_STRUCT() struct FPoint { MAHO_GENERATED_STRUCT_BODY() MAHO_PROPERTY() float X = 0.0f; };

普通值类型（非 UObject）。类内用 MAHO_GENERATED_STRUCT_BODY() 声明 StaticType() → FStructType。

MAHO_ENUM

macro enum
MAHO_ENUM() enum class EKind : std::uint8_t { None = 0, A, B, };

支持 enum / enum class。无举项写入 FEnumType，经 FEnumTypeRegistry 按限定名查找（如 Maho::EKind）。

MAHO_PROPERTY / MAHO_FUNCTION

macro
MAHO_PROPERTY() std::string DisplayName; MAHO_FUNCTION() void Reset();

MAHO_PROPERTY：标记下一条数据成员（Object 与 Struct 共用）。

MAHO_FUNCTION：仅 Object；返回类型 Phase 1 限 void；参数为已支持的属性类型，调用侧用 CallFunction(Name, args...)。

运行时 API

FPropertyValue

runtime
struct FPropertyValue { EPropertyType Type; bool BoolValue; std::int64_t IntValue; std::uint64_t UIntValue; double FloatValue; std::string StringValue; UObject* ObjectValue; static FPropertyValue FromBool(bool); static FPropertyValue FromInt(std::int64_t); static FPropertyValue FromUInt(std::uint64_t); static FPropertyValue FromFloat(double); static FPropertyValue FromString(std::string); static FPropertyValue FromObject(UObject*); };

类型擦除的属性读写载体。EPropertyType：Bool / Int32 / UInt32 / Int64 / UInt64 / Float / Double / String / EnumInt32 / ObjectRef。

FObjectType / UObject

runtime object
const FObjectType& T::StaticType(); const FObjectType& Obj.GetObjectType() const; bool UObject::GetPropertyValue(name, Out); bool UObject::SetPropertyValue(name, Value); bool UObject::CallFunction(name); // 0 args bool UObject::CallFunction(name, arg0, arg1, ...); // variadic → FPropertyValue bool UObject::CallFunction(name, Args*, ArgCount); // type-erased FObjectTypeRegistry::Get().FindType("Maho::UResource");

FObjectType 含 Name、Super、本类 Properties / Functions。Find*InHierarchy / Gather*InHierarchy 沿 Super 链行走。函数元数据含 ParamTypes / ParamCount，调用前校验个数与类型。

FStructType

runtime struct
const FStructType& T::StaticType(); bool GetStructPropertyValue(Type, &Struct, name, Out); bool SetStructPropertyValue(Type, &Struct, name, Value); FStructTypeRegistry::Get().FindType("Maho::FResourceId");

Struct 以 void* 实例读写；无继承链 / 无 Function（Phase 1）。

FEnumType

runtime enum
const FEnumType* Type = FEnumTypeRegistry::Get().FindType("Maho::EResourceType"); Type->FindByName("Texture"); Type->FindByValue(static_cast<std::int64_t>(EResourceType::Mesh));

枚举无 StaticType() 成员；一律走 Registry。每项为 FEnumValue { Name, Value }。

用法示例

Object 属性

object
FPropertyValue V; if (Pkg.GetPropertyValue("ObjectName", V) && V.Type == EPropertyType::String) { // V.StringValue } Pkg.SetPropertyValue("ObjectName", FPropertyValue::FromString("NewName")); Pkg.CallFunction("MarkPendingKill"); // with args: Obj.CallFunction("Rename", std::string("New"));

Struct 属性

struct
const FStructType& Type = FResourceId::StaticType(); FResourceId Id{}; FPropertyValue V; GetStructPropertyValue(Type, &Id, "Value", V); SetStructPropertyValue(Type, &Id, "Value", FPropertyValue::FromUInt(42));

Enum 查表

enum
const FEnumType* E = FEnumTypeRegistry::Get().FindType("Maho::EResourceType"); if (const FEnumValue* Entry = E->FindByName("Texture")) { // Entry->Value }
